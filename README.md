# LLM Memory Editability

研究问题：**知识被压缩为共享规律后，更新与这些规律的关系，如何影响知识的可修改性？**

本项目基于 [2026-09-24 研究备忘录](docs/research-memo.md)。候选假设是：符合已有共享结构的更新可能较容易，而局部例外可能需要额外的独立表示。编辑条数本身不足以描述这种表示需求。

**当前阶段：研究初始化。** 已实现可复现的低秩数值示例与解析误差诊断；H1–H3、实验 A–D、小型 Transformer 和预训练 LLM 实验均待开展。这里的线性代数例子不构成新的定理，也不能证明真实 LLM 中存在相同机制。

## 快速开始

需要 Python 3.10 或更高版本。当前示例仅依赖 NumPy，在 CPU 上运行。

```bash
git clone https://github.com/zhusq20/llm-memory-editability.git
cd llm-memory-editability
python -m venv .venv
source .venv/bin/activate
python -m pip install -e '.[dev]'

memory-editability --rank 1 --output results/minimal-example.json
# 等价入口：python -m llm_memory_editability --rank 1
```

命令将 JSON 报告输出到终端，并在指定 `--output` 时保存文件。报告包含原始矩阵、目标矩阵、最优低秩重建、秩与表示缺口、修改及保留条目的 RMSE、参数和 Python/NumPy 版本。生成的结果默认不进入版本控制。

## 最小模型

事实表为实体 × 属性矩阵，已有共享表示满足 `Y = UVᵀ`、`rank(Y) ≤ r`。文档中的例子是：

```text
原始事实             规律更新             单条例外
[[1, 1],            [[2, 2],            [[2, 1],
 [1, 1]]             [2, 2]]             [1, 1]]
```

固定 `r = 1` 时，四条事实的规律更新可以精确表示，单条例外不能。提高到 `r = 2` 后，例外也可以精确表示：

```bash
memory-editability --rank 2 --output results/minimal-example-rank2.json
```

| 更新 | 修改条数 | 更新矩阵的秩 | 目标矩阵的秩 | 秩预算 1 下的最优 Frobenius 误差 |
| --- | ---: | ---: | ---: | ---: |
| 规律更新 | 4 | 1 | 1 | 约 0 |
| 单条例外 | 1 | 1 | 2 | 约 0.381966 |

这个示例的编辑数量不同，仅用于说明表示限制，**不是实验 A 中控制编辑数量的比较**。两种更新的 `rank(ΔY)` 都为 1，因此不能把它单独作为新增自由度的指标。当前合成模型报告 `max(0, rank(Y_target) − r)`，作为完整目标表已知时的表示缺口；它不是通用 LLM 指标。

实现通过截断 SVD 计算完整目标表在给定秩预算下的最小平方重建误差。它使用全部目标信息，衡量的是**可表示性**，不包含编辑优化过程、优化步数或训练成本。报告中的保留条目误差描述该最优重建的变化，不是保留所有旧知识的保证。

`--atol`（默认 `1e-10`）用于数值秩判断：只计入大于阈值的奇异值。修改条目由原始值与目标值是否相等确定；阈值不用于隐藏小幅更新。数值秩依赖尺度与阈值，近零重建误差受浮点精度影响。

## 研究路线

| 阶段 | 目的 | 状态 |
| --- | --- | --- |
| 最小低秩模型 | 区分目标秩、更新秩与近似表示误差 | 已实现解析示例 |
| A：匹配编辑数量 | 控制覆盖范围、变化强度、惊讶度与预算，比较更新结构 | 待实现 |
| B：改变组织方式 | 保持知识与答题效果接近，改变共享与独立表示 | 待实现 |
| C：补充自由度 | 相同额外参数预算下比较共享扩容与独立表示 | 待实现 |
| D：从头训练诊断 | 区分容量限制、优化失败与信息可用性 | 待实现 |
| 非线性与语言模型 | 在前述效应稳定后检查行为层面的对应 | 后续阶段 |

具体控制变量、测量项和停止条件见 [实验计划](docs/experiment-plan.md)。实验 D 是扩展研究的必要诊断：有限次从头训练失败不能证明不可表示。表示成本、编辑成本与副作用应分别报告。
