# 旧版终点的5–8跳表现

**原世界的invariant在A五跳有19.24%，B五跳仅0.66%；六至八跳均不超过0.18%。** 常数打分、content与同配方DiscoLoop在B五跳为0%，更长问题也接近零。这说明旧终点的长跳任务表现很弱，尚未建立可靠的五至八跳组合泛化。

本次按用户选择只看旧版完成模型，复用已有GPU评测并逐题核算；新增训练和模型前向均为0。主比较为原世界native四臂150万步、参数EMA；另保留旧固定四轮训练/raw权重DiscoLoop作异配方参考。普通Loop、state-MLP、新初始化、新置换与多对一世界不在这批已有长跳预测中，未据此推断其表现。

## 固定评测

A世界训练过1–4跳组合；B世界只训练原子事实。两个世界均未训练5–8跳。每个世界、每种长度10个关系模板×500起点，共5000题；五模型使用相同题目。主表固定R16（循环16轮）、全词表答案argmax，不计EOS；不选择最佳轮数。答案在每个模板内均匀覆盖500个实体，知道所属世界后的常数猜测为0.2%。

## 位置对照与核验边界

invariant在R16的A四跳原题为100%，仅前补一个pad、把答案移到五跳所在位置便降至15.60%；B四跳同样从82.18%降至0.26%。因此长跳失败包含位置／陌生前缀的影响，不能由低分直接断言循环算法最多只能推四跳。五模型的长跳解释均未通过原协议的位置控制，其中同配方DiscoLoop只能用原子题作控制，控制答案位置还未到长跳答案位置，解释更有限。

A五跳中有979/5000题含已训练的末尾2–4跳子链；去掉它们后invariant仍为18.90%，该筛选仅作诊断，不替代全量19.24%。

240份预测文件的两个读出、R1–32全部与保存分数一致，五个终点权重SHA256也一致。但与原训练记录的R4对照仍有微小偏差：invariant最大0.12个百分点、常数ema最大0.18个百分点，均超过原协议0.1个百分点的门槛；该历史核验失败保留，未因逐题复算通过而改称全部审计通过。其他三组通过该R4门槛。此次没有重载模型，不提升已有独立重载或云端状态。

只在实体中取最大值的读出属于原协议追加诊断，与完整词表主指标分开保存在summary.json和CSV。一个世界、一个初始化上的这些题目和轮次不当作独立实验重复，未作显著性或总体稳定性推断。
