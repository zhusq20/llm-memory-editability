终点均为 1,489,200 次样本曝光。答案 token 是实际 CE/KL 答案掩码计数；PD 前向 token 已含固定上下文教师，SFT 只有学生，两者不能当同计算量。教师 token 未单独记录，PD 额外教师样本前向次数等于曝光数；full/down 使用独立冻结教师，两种 LoRA 禁用 adapter 得到固定教师。r=1024 的原范围 LoRA 仍有约 12.73 亿可训练参数。

前向 token 计数来自 attention mask（不含 padding）；collate 对整个 batch 删除最后一列，因此随 batch 改变存在少量计数差异。它不包含反向、重计算、padding 的实际算力，不能换称 FLOPs。

训练计时相加原训练与接续曲线的进程时钟，包含已记录的废弃重算、共享 GPU 与存储等待，不含探测、模型载入和最终保存，不是独占 GPU 小时或公平速度测量。各组 batch、切换点和开始时刻不同，不能仅凭墙钟给出方法效率排名。重算按停机后曲线和 post-stop audit 复核；原训练尾部每组最多另有 99 次未记录更新，从基座直接启动的两组 down-LoRA 没有旧训练重算。

工程试跑成功更新、失败候选、已计时部分和峰值在 summary.json 单列。失败候选已发生多少计算、纯正式训练显存峰值、精确教师耗时、FLOPs 与独占 GPU 小时均未知；不把包含工程试跑的累计 CUDA 峰值写成正式训练峰值。
