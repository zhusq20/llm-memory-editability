# 固定旧权重的位置编码干预：5–8跳

用户于2026-10-24（America/Chicago）要求排除位置编码影响后，再测旧版invariant及对照。
本批仅推理，不更新权重，不恢复暂缓训练。主问题是：**仅改变显式位置输入，能恢复多少长跳准确率？**
这些处理不能预先保证完全排除位置影响；原模型可能已把位置角色写入其他参数。

## 历史与固定比较

复用原世界native四臂invariant／常数ema／content／recipe-additive的150万步参数EMA，
保持旧首轮F(h0+e)、所有交接、attention、MLP、归一化和因果mask。
历史[完整长跳结果](../loop-long-hop-review-20261025/report.md)的invariant A/B五跳为19.24/0.66%，
旧padding平移控制为A四跳100→15.60%、B四跳82.18→0.26%。旧RoPE三臂同时改变架构与训练，
不能替代这次同权重比较。本次实质变化是干预位置向量，并把纯位置平移与新增padding前缀分开。

沿用同一40,000条长跳测试题（A/B×5–8跳×每池5000题），不重选样本、不挑最佳模式或最佳轮数。
主指标固定R16、全词表答案argmax，保存R1–32、实体限定诊断、答案NLL和EOS比例。
真值、题序与历史数据SHA256核对；不提供中间实体、答案或图身份给模型。

## 干预

P_i为旧模型的位置向量，输入位置从0起算，L=k+1为问题token数。

| 模式 | 位置输入 | 能回答什么与限制 |
| --- | --- | --- |
| absolute | P_i | 重载基准，与原长跳逐题预测核对 |
| zero | 0 | 移除显式位置向量；可能破坏短题，不能自动视为干净的去混淆 |
| clamp4 | P_min(i,4) | 避开位置5的EOS角色和6以上未训练向量；多个关系位置合并 |
| interpolate4 | L≤5保持P_i；L>5按u=4i/(L−1)在P_floor(u)、P_ceil(u)间线性插值 | 仅使用P0–P4但引入新混合；映射依赖完整输入长度，跨长度前缀表示不保持 |

干预只通过wpe输出钩子改变位置输入，同时作用于初态和每轮重新注入的embedding。
不改变tokens、答案读取索引、序列长度、attention mask、参数、残差或反馈机制。
四模式固定报告，不用表现最好的模式代表该方法。

## 控制与解释

- absolute与zero各测8个原子／两至四跳A/B池。clamp4/interpolate4的短题映射完全等于absolute，
  由逐值契约验证后复用基准分数；**这种恒等保持是实现检查，不是长题位置映射已通过校准**。
- A四跳、B四跳各将位置编号整体+1/+2/+3/+4，token序列不加padding。
  这隔离整体位置编号变化，但并不单独定位头实体、某个关系或答案位置的贡献。
- 所有干预相对absolute保存同题新增正确／原正确丢失；零位置若短题也崩溃，长跳低分不排除位置问题。
- 仅改位置若恢复长跳，支持位置输入是瓶颈之一；全部未恢复只能说明这几种无训练处理无效，
  不能证明位置编码不是原因，也不能建立四跳算法上限。
- 只有一个已观察世界和初值；每题、模板、轮次不当作独立实验重复。原R4参考超差状态保持。

## 执行与完成标准

224个实际评测池×5000题，每题记录32轮，共112万题次、3584万样本轮；无优化器更新。
新建独立LM容器，固定原镜像，源码create-copy-start、root所有0444/0555，输入和检查点只读，
输出写入独立/ossfs持久目录。每任务2 CPU、16 GiB主存、0.16显存上限；先测最长9-token输入，
测得峰值后保留6 GiB任务余量和8 GiB整卡余量。共享GPU6现有本项目训练，不中断其进程；
重复核对外部进程与预约，既有明确授权的未变化预约例外保留。55分钟评测上限，保留任何失败。
进程存活、每池状态和完成退出均监测；核对四组权重运行前后哈希、基准一致性和所有逐题分数。
报告中的模型重载、短题保持、长跳恢复和位置归因分别记录。
