# 旧版四臂：固定权重的位置编码干预

用户要求解释四跳到五跳的骤降，并在处理位置影响后补测。所有组使用原世界150万步参数EMA，每池5000题、R16为固定主结果；完整R1–32预测保存在持久目录。新增训练0。

**新证据表明：旧invariant的组合执行强烈依赖原位置输入，而单独的事实读取基本能保留。** 不加padding、仅整体位置编号+1，B四跳82.18%→0.28%，A四跳100%→8.46%；去掉位置向量后B原子仍99.58%，B四跳仅0.10%。位置影响本身足以破坏已会的四跳任务。但三种无训练位置处理均未恢复B五至八跳；不能据此称位置已排除，也不能定位为某个attention头或交接门的唯一故障。

**对照也有正结果：**content的A五跳仅改变位置插值便由0%升至44.60%，invariant同池为19.24%→20.20%。位置输入可以实质限制长跳表现；但该改善没有迁移至B世界：两者插值后的B五跳仅0.10%／0.12%，六至八跳也未恢复。

位置处理只改变wpe输出：zero移除显式位置向量；clamp4把位置≥4映射到P4；interpolate4将长问题的位置线性压缩至P0–P4。tokens、答案读取索引、因果mask、旧首轮、每轮残差、归一化、反馈与聚合不变。

## 解释与核验

观察和解释分别报告：仅改位置恢复长跳，可支持位置输入是瓶颈之一；全部处理失败也只能说明这些无训练处理未恢复能力，不能证明位置编码无关。zero若损伤原子或短题，其长跳低分不具有排除作用；clamp合并位置，插值引入新向量混合，且插值依赖完整输入长度，均有自己的分布变化。invariant只约束门的统计输入，不保证整个Transformer对位置或长度不敏感。

四跳到五跳还改变了位置与token角色的配合：训练时索引4读答案；索引5输入答案实体并预测EOS。五跳却要在索引5输入第五个关系并求出实体答案。位置角色变化是明确的训练边界，但尚未量化它解释了全部五跳跌幅的多少。原invariant B五跳EOS比例只有3.36%，实体限定读出仍为0.66%，所以失败不只是EOS抢占。现有证据更支持组合执行对原布局的依赖，尚不能进一步区分attention读取、桥实体表示、逐轮交接或答案保持中的具体故障。
