# 旧RoPE DiscoLoop第五轮为何不再接受桥：接收残差干扰与关系信息的区分

**RoPE DiscoLoop确实存在“第五轮旧接收状态压住新输入”的问题；缩小或清零这条残差就能解除，不能称不可逆锁死。但其原生attention读取也不足以完成第五跳，单独清理状态不会恢复原题。对于“第五关系是否彻底丢失”，本批没有建立这样的结论。invariant则能明确证明进入块的接收输入仍含可用末关系信息，同时存在形成正确答案后的保持困难。**

本批延续[同方法五跳诊断](../disco-five-hop-diagnosis-20261025/report.md)，只用旧150万步终点的RoPE DiscoLoop／参数EMA与旧invariant／参数EMA。没有换成新初始化或当前在训版本，没有训练。原A/B五跳池各5000题；A参加过短组合训练、B仅训练原子。每次仅在第五位置、第4或第5轮干预一次，然后按原模型继续至R16。新配对关系池另报，不与原池自然准确率混合。

## 1. 先拆开接收残差和读取内容

一个原始Transformer块的第五位置计算为：

`A = c_proj(attention(...)); U = Z + A; H = U + MLP(LN2(U))`。

Z是进入块的接收残差；A是实际attention输出。先按原生输入计算A，再仅改变残差Z，并用原LN2和MLP重算H。这样“原生A＋缩放Z”没有新增真桥或关系，也没有把缩放后的Z用于重新计算Q/K。另从真正第四桥e4与末关系r5的原子调用中提取A_atomic；**它在MLP之前，但可以携带关系乃至答案相关信息，不能称纯桥供体**。

缩放保持Z方向，将其范数调至全体10种原子关系输入范数的共同中位数；该标量不依赖题目当前的r5。fresh关系输入为RoPE的Wte(r5)，旧invariant的2(Wte(r5)+P1)。旧invariant始终采用原训练定义：首轮F(2e)、后续F(h+e)、候选归一化和N/D历史聚合。RoPE仍为H=F(x)、下一轮x=H+q(H)。

第一阶段保留“所有头强制读规范桥V”的原方法，第二阶段改用经过正控校准的真实原子A。第二阶段不拷贝原子H或MLP输出，只复用attention输出、原LN2/MLP和后续交接。

## 2. 相同正确读取，第五轮被旧接收残差压制

以下为**原B五跳5000题、干预当轮raw H准确率**；这里还未经过invariant历史聚合，因而与最终答案分开。

| attention内容与接收残差 | RoPE R4 | RoPE R5 | invariant R4 | invariant R5 |
| --- | ---: | ---: | ---: | ---: |
| 正确原子A＋原Z | 31.98% | 0.10% | 13.52% | 7.24% |
| 同一正确原子A＋缩放Z | 100.00% | 100.00% | 83.70% | 83.98% |
| 同一正确原子A＋Z清零 | 100.00% | 100.00% | 2.90% | 2.90% |
| 原生A＋缩放Z | 0% | 0% | 0% | 0.08% |
| 原生A＋fresh正确关系 | 0.16% | 0.08% | 0.04% | 9.64% |
| 正确原子A＋fresh正确关系（校准正控） | 100.00% | 100.00% | 99.80% | 99.80% |

RoPE在A图也是同一现象：正确原子A＋原Z从R4的62.44%降至R5的0.26%；缩放或清零Z后，R4/R5均99.96%。这排除了“第5轮本身已无法执行这条事实”的解释。使用相同供体和相同MLP，改变接收残差就足以解除该干扰。

RoPE的原Z平均范数，A从R4的82.33增至R5的110.60，B从106.47增至159.54；共同原子输入范数为1.30。R5接入正确原子A后，A/B仍有97.50/93.22%的raw读出与原Z读出相同。范数增长是观察证据；保持方向、只改变幅度后的恢复则直接支持**旧残差与新读取的相对尺度发生冲突**。尚未单独干预soft feedback，不能把根因唯一归给q，也不能据此证明训练动力学中的吸引子。

## 3. 这不等于已证明RoPE的第五关系丢失

RoPE原生A搭配缩放或清零Z，原A/B池与配对关系池的当轮正确率都为0%。把fresh真关系仅放回残差分支、保留原生A，也几乎无效。因此**只清理状态或只在残差端补关系，尚不足以恢复自然第五跳**。这提示原生读取和接收状态至少需要共同考虑；单一干预的负结果不证明内部完全没有关系信息。

为什么不能把“原子A＋缩放Z成功”说成“原Z关系保留”？RoPE中原子A独自配合原MLP就足以答对，而错关系控制进一步表明它自带有效的末关系调用信息。固定R5、原A/B池：

| 对照 | A当轮结果 | B当轮结果 |
| --- | ---: | ---: |
| 真关系原子A＋fresh错关系Z：仍答真正答案 | 97.16% | 98.44% |
| 错关系原子A＋fresh真关系Z：跟随错关系后继 | 98.32% | 98.36% |
| 错关系原子A＋缩放原Z：跟随错关系后继 | 99.98% | 99.96% |
| 错桥原子A＋fresh真关系Z：答真正答案 | 0% | 0% |

RoPE三类供体自身的原子raw正确率均100%；真、错关系目标仅A3题/B8题碰撞，剔除碰撞的跟随率见全量CSV。新结果定位了一个可逆的接收残差干扰，也说明原生A不足；**仍不能在“关系已丢失”和“关系存在但查询/读取未正确使用”之间作最终判定**。

## 4. invariant的关系信息仍可用，且答案形成后仍会丢

第一阶段给规范真桥V，只缩放原来的Z，不添加r5：invariant在R5的A/B当轮raw从9.36/6.46%恢复到89.22/81.20%。仅给同样桥、把Z清零或换成公共常量，不能产生同样效果。

为排除原题末关系频率偏置，对每图固定500个前四跳前缀，每个前缀分别接上全部10个末关系，形成5000题。规范桥V在同一前缀的10题中完全相同；缩放标量也相同。invariant R5：

| 配对关系检查 | A | B |
| --- | ---: | ---: |
| 真桥V＋缩放原Z，当轮raw | 86.68% | 78.66% |
| 能回答至少两个不同正确后继的前缀 | 476/500 | 443/500 |
| 全部10种末关系均答对的前缀 | 354/500 | 310/500 |
| Z清零／公共常量时，能回答至少两个不同正确后继 | 0/500 | 0/500 |

这证明**进入块的Z仍携带可用末关系信息**。但旧invariant的Z=h+e，每轮重注入关系嵌入，所以不能进一步声称历史h单独保存了关系。第二阶段也得到相应内容分离：错关系原子A＋缩放原Z，B仍有83.80%答真正答案；真原子A＋fresh错关系Z，B有99.80%跟随错关系后继。其有效关系选择更多来自Z，与RoPE原子A主导的反应不同。这一分工定位于规范原子供体的交叉组合，不断言自然计算中关系信息的唯一存储位置。

invariant并未被这些局部修复彻底解决。R5接入相同干净原子计算后，继续运行：

| 原B池、R5一次干预 | RoPE当轮raw → R16 | invariant当轮raw → R16 |
| --- | ---: | ---: |
| 正确原子A＋缩放原Z | 100.00% → 99.84% | 83.98% → 36.08% |
| 正确原子A＋fresh正确关系 | 100.00% → 99.98% | 99.80% → 61.64% |

后一正控与完整原子H供体在当轮raw读出逐token一致：RoPE仅1题当轮正确后丢失，invariant为1918题。两者都有接收输入与下一次事实调用的适配问题，但**RoPE更突出晚轮旧残差压制输入及原生读取失效；invariant明确保留可用关系，却仍有路由、接收输入和后续保持困难**。跨模型训练配方不同，不能将全部差别唯一归于某一架构部件。

## 5. 校准修订、全部结果与执行核验

第一阶段“所有头强制单源桥V”的fresh正控，RoPE A/B当轮仅0.36/35.10%，而正常原子调用100%。所以该接口的失败不能支持“关系丢失”；全部152池原样保留，另立[第二阶段协议](protocol.md)补测128池。第二阶段真原子A＋fresh真关系，以及错桥原子A＋fresh真关系，均与对应原子raw读出逐token一致。invariant第一阶段正控为A100/B99.80%，其关系配对证据有效。

首次第一阶段启动在保存上下文字段时发生`wrong_relation`名称冲突，0个正式池完成；修为`wrong_relation_id`后用独立`-r2`目录执行，原失败日志、冻结源码及[失败状态](../loop-receiver-state-20261025/runtime/failure.json)保留。科学矩阵未因此改变。第二阶段是发现正控不成立后的探索性修订，不是事先确认的独立复现。

- 完整矩阵：第一阶段152池、第二阶段128池，共280池，140万主查询题次；两阶段主循环合计2368万样本块调用，第二阶段另12万原子供体块调用与60万次全序列MLP重算。无训练更新。
- 数据单位：同一固定数据世界中的A/B两图、每原池5000题；CF为500个配对前缀各10种关系。各题和多个干预不是独立训练种子或独立世界，不计算伪独立的跨种子显著性，未进行换世界敏感性检验。
