# Loop路线：循环Transformer跨跳复用参数知识的条件

更新：2026-10-20（America/Chicago）。本文是Loop方向的唯一规划，与在写另一篇论文的[主路线图](roadmap.md)分开维护。完成结果写入[结果汇总](results.md)，推导在[理论依据](memory-scaling-theory.md)，执行细节在各批协议。

<a id="thesis"></a>
<a id="goal"></a>
## 1. 论点

**主张（工作假说）：** 循环Transformer要把只学过原子形式的事实用在第k跳上，第k次使用时送进共享事实库的输入，必须和训练时那一次使用相同。这要求三种不变性：
1. **深度不变：** 每一跳用同一组参数。共享参数已经提供。
2. **格式不变：** 上一跳的结果以事实库认得的实体形式交给下一跳。经过词表的解码—再编码在构造上提供，因为绑定的unembedding和embedding正好连接"答案"与"实体"。
3. **位置不变：** 查找方式不依赖第k跳落在第几个token。学到的绝对位置编码会破坏这一条。

另有两个训练条件：
- **只监督答案：** 逐轮监督或能读实体身份的控制会破坏泛化；
- **交接不能让单轮提前定答案：** 否则模型把训练过的长链背在第1轮。

满足这些条件时，模型自己学出"一轮一跳"的算法，只学过原子形式的事实可以被组合；对一处事实的改写，也应当传到所有用它的跳。

**这条主张统一了已有推导：**
- 交叉熵只约束答案的间隔、不约束隐藏状态的方向（[§13.1](memory-scaling-theory.md#pretraining-implicit-alignment-20261004)），所以格式要靠架构保证；
- 跨轮写入只在两次使用的特征重合时起作用（[式36](memory-scaling-theory.md#partial-pooling-20261010)），三种不变性就是让特征重合的条件；
- 加性交接每轮可改变的幅度按[1/r](results.md#additive-carry-freezing-20261020)缩小。

**暂不主张：**
- 测试时深度扩展（多跑多算）：尚无证据，待位置批检验；
- 学到的接收分数或门：已有结果都不稳定；
- InfiLoop训练配方本身有益：它让加性交接退化了。

<a id="principles"></a>
## 2. 原则（用户2026-10-20）

- 架构与训练以[InfiLoop](https://arxiv.org/abs/2610.11570)为主要参照，并提出新的架构构思。
- **监督只有答案与EOS；** 深监督也只在每段末监督答案。
- **不使用的信息：** 桥实体、跳数、轮次、位置角色、图身份等标签；架构中的控制信号也不能读取这些信息。
- **以机制解释为目标：** 每批先写明区分竞争解释的关键比较，不以扩大网格代替判断（[研究原则](../.agents/skills/llm-memory-research/SKILL.md)）。

## 3. 证据

除特别说明外，均为单一开发图、单一初始化。图A的组合参与过训练，图B只训原子。

**各条件的证据：**

| 条件 | 打破时的预测 | 证据 | 状态 |
| --- | --- | --- | --- |
| 深度不变 | 标准Transformer不能组合只学过原子形式的事实 | 本项目多批与Wang等，0–5% | 已确立 |
| 格式不变 | 普通Loop在图B上组合约为0 | [普通Loop ≤0.4%，DiscoLoop图B两/三跳98.4/88.2%](results.md#loop-hop-unified-v1) | 已确立（含DiscoLoop原文） |
| 位置不变 | 跳越靠后越差；只学过原子形式的事实不能平移位置 | ema图B两/三/四跳97/55/11%，比逐跳相乘下降更快；[右移一位](results.md#loop-beyond-four-hops-20261020)后ema原子A/B为74.8/7.9%，两跳74.0/0.9%；答案在第5位及以后全部失败 | 观察支持，干预进行中 |
| 交接不让单轮定答案 | 加性交接把长链背在第1轮 | 新配方加性臂：训练三/四跳第1轮即100%，留出三/四跳0.1%；凸组合ema：k跳恰好在第k轮答对，留出四跳100%（A0为0.14%） | 单图观察；"凸组合＋旧配方"一格进行中 |
| 只监督答案 | 逐轮监督或能读身份的控制破坏泛化 | [第1轮中间CE使OI为7.03%](results.md#supervised-alignment-development-v1)；学习门依赖图的时刻表；content臂30万步后图B崩塌 | 已确立 |

## 5. 下一步

**按位置批结果分支（预定）：**

| 结果 | 结论 | 下一步 |
| --- | --- | --- |
| ema-rope的图B三/四跳明显上升，5–8跳从第k轮起高于随机 | 三种不变性加深度扩展的完整故事 | 换世界复现；在该臂上做第三层编辑 |
| 只有图B上升，5–8跳仍为0 | 位置解释图B差距；深度扩展受限于训练跳数 | 论文主张限于≤训练跳数；另查每轮算子为何不能延伸 |
| 图B与5–8跳都不变 | 位置假说被否定 | 回到"图B实体从未当过桥"的数据解释 |
| ema-absolute-old的留出四跳也约100% | 一轮一跳来自凸组合交接本身 | 论文可去掉新配方，简化方法 |

**候选（均未授权）：**
1. **换一个世界复现：** 关键臂为A0、ema和位置批的胜出臂。目前所有结论只有一个图、一个初始化，这是最大缺口。

3. **通用性：** 构造前缀不是原子问句的模板，把交接读出与下一词头分开。
4. **成本：** 更便宜的交接读出（如top-k）。

## 6. 范围与避免重复

不进入本方向的队列：
- 中间CE、方向对齐、门监督、规则门；
- 学到的接收分数，以及在其上的配方调整；
- 首轮KV、mHC、MoE；
- 跳数课程、轮次嵌入、学习式停止；
- 跳数、宽度、轮数的大网格。
