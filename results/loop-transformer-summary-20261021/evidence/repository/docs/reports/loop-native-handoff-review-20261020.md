# Loop架构评审：对照InfiLoop看训练稳定性、通用性与交接设计

2026-10-20。用户要求对照[InfiLoop](https://arxiv.org/abs/2610.11570)评审当前Loop架构：训练稳定性、方法的通用性、损失设计是否通用稳定；架构与训练方法以InfiLoop为主要参照，提出新的架构构思，不把算法结构写进监督。本文是评审与设计依据，不是结果汇总。§3是一项零训练测量，只读取已保存的R1–16回放；[§5方案](#5-方案循环原生交接与身份无关打分)对应的批次[已准备、未授权](../development-artifacts/loop-native-handoff-development-v1/protocol.md)。

## 1. 核心判断

1. **主线训练的损失本身不含算法结构。** Loop-hop、门控、无门DiscoLoop、TTCD与CE写入批次都只在末轮监督答案与EOS，没有桥实体、跳数或轮次标签。算法结构从三处进入：
   - 10-12两批的辅助损失。原标签中间CE与方向对齐作用在第1轮的原监督位置上。由于原子行与两跳行共享前缀（[理论§13.3](../memory-scaling-theory.md#pretraining-implicit-alignment-20261004)），它在r₁位置相当于逐跳监督桥实体；在两跳行的r₂位置则要求第1轮直接给出最终答案。
   - 数据模板。每个前缀`h r₁…r_j`本身就是原子问句，所以位置j的下一词解码恰好是第j个桥实体。DiscoLoop通道依赖这一点。
   - 训练轮数。固定R=4，且等于最大训练跳数。
2. **训练不稳定主要是训练目标约束不到的行为在漂移，不是优化发散。** 训练损失约1e-3、图A全对时，图B组合仍大幅变化。P门的图B三跳在30万步为37.20%，150万步为1.78%，相邻节点最大下降54.58个百分点；无门DiscoLoop则从0.06%单调升到88.22%，最大下降7.46个百分点（[诊断](loop-depth-extrapolation-gate-stability-survey-20261019.md)）。
3. **学习u门与InfiLoop的内容分数是同一种控制量。** `u=σ(wᵀLN(H)+b)`与`qᵀRMSNorm(z)`读取同样的归一化候选，参数同为d+1。前者已学成依赖图身份的轮次时刻表（同一报告§7.3、§7.7）。InfiLoop的分数没有出这个问题，一个原因是它的训练数据做了数字和颜色置换增强，分数对符号身份天然不变。本项目的划分（图B从不参与组合）恰好去掉了这种对称性。这一点是推断。
4. **加性交接把稳定与可塑性绑在一起。** §3测得：超过训练轮数后，块更新相对状态的比例约按1/r衰减，状态越来越难被改动。无门DiscoLoop因此"多跑不变坏"，也可能因此"多跑不会多算"；后者是假说。
5. **能留下的是DiscoLoop的解码—再编码交接。** 它是目前唯一同时带来图B组合和编辑传播的组件：OI/IO/OO为99.30/97.53/95.66%，单次写入后的组合为100/100%。但它的通用性受模板限制，并在每个位置、每个轮次边界做两次全词表矩阵乘：本项目训练FLOPs约为普通Loop的2.05倍，换成15万词表会更贵。

## 3. 零训练测量：加性交接的1/r冻结

**做法。** 只读取[R1–16回放](../../results/loop-round-extrapolation-diagnostic-20261019/)保存的逐题数组，没有新前向。第r轮在答题位置的相对更新定义为`rel_r = ‖H_r − X_r‖ / ‖X_r‖`，即块输出相对本轮输入状态的变化，取中位数。pre-LN块读取的是`LN(X)`，因此每轮能改变状态方向的幅度约以`rel_r`为上限。

| 模型·池 | rel R8 | rel R16 | r·rel R8 / R12 / R16 | ‖X‖ R4 / R8 / R16 | 块更新‖H−X‖ R8 / R16 |
| --- | ---: | ---: | --- | --- | --- |
| 无门DiscoLoop·图B三跳 | .166 | .057 | 1.33 / 1.01 / .91 | 37 / 198 / 506 | 33 / 29 |
| 无门DiscoLoop·图B两跳 | .125 | .051 | 1.00 / .86 / .82 | 93 / 252 / 555 | 32 / 29 |
| 无门DiscoLoop·图A留出四跳 | .203 | .078 | 1.63 / 1.36 / 1.24 | 123 / 330 / 928 | 66 / 72 |
| 普通Loop·图B三跳 | .141 | .061 | 1.13 / 1.01 / .98 | 23 / 48 / 85 | 7 / 5 |
| 学习u=.90·图B三跳 | .181 | .085 | 1.44 / 1.49 / 1.37 | 22 / 204 / 552 | 37 / 48 |
| P门·图B三跳 | .195 | .072 | 1.56 / 1.26 / 1.15 | 38 / 502 / 1256 | 98 / 90 |

**能说明什么。** 超过训练的4轮后，四类模型的`r·rel`都大致稳定在0.8–1.6，即每轮相对更新约按1/r衰减。无门DiscoLoop的块更新保持在约30，状态范数每轮增长约40，因为反馈与块更新沿着已收敛的方向持续累积（同一报告§7.4，相邻轮余弦≥.99）。到R16时，每轮最多只能把状态方向改变几度。

**不能说明什么。**
- 这只是范数动力学的描述，不能证明衰减阻止了多算一跳。这些模型在R4时已经不会四跳，失败首先来自训练。
- 普通Loop同样呈1/r，说明这一性质来自加性残差累积本身，与解码反馈无关。

**对设计的含义。** InfiLoop式的凸组合在打分相同时稳态步长为1−β，不随轮数衰减；"是否接受新候选"交给内容打分决定。这把稳定与可塑性分开，使"额外轮次能否继续计算"成为可以检验的问题。

## 4. InfiLoop：方法、证据与边界

已读正文、附录A–D和[官方代码](https://github.com/pixeli99/InfiLoop)（Sudoku部分）。arXiv 2610.11570 v2，预印本。

**方法。** 把"只传最后一轮输出"（carry-last）改为对各轮候选的归一化注意力：

```
h_t = Σ_i α_{t,i} z_i,  α_{t,i} ∝ exp(s_i − λ(t−i)),  s_i = qᵀRMSNorm(z_i)
```

它有精确的流式递推`N_t = βN_{t−1} + e_t z_t`、`D_t = βD_{t−1} + e_t`，等价于`h_t = h_{t−1} + γ_t(z_t − h_{t−1})`，其中`γ_t = e_t/(βD_{t−1} + e_t)`。状态位于候选的凸包内。

**代码中的实际配方：**
- 块为post-norm，每个子层后做RMSNorm，候选的RMS恒为1；
- q零初始化，开始时就是固定的指数平均；β₀=.55，可学习；
- 每一步重新注入输入（`block(low, high + embedding)`）；
- TRM式深监督：12段，段间状态切断梯度，每段都只监督最终答案；每段只反传最后一个外循环（21次块调用中的7次）；
- AdamW β₂=.95，wd 1.0，lr 1e-4，余弦衰减到0.1倍，权重EMA .999；
- 数独训练数据为每题1000次数字置换与空间对称增强，ARC也做颜色与二面体增强。

**证据：**
- 数独上TRM在468层达到峰值62.2%，1872层降到58.1%，已解出的题后来被改坏19.7%；InfiLoop为0%。
- 固定深度1872层90.9%，24960层92.74%。
- 训练时去掉内容分数（q=0）为84.1%，推理时置q=0为84.8%，推理时置β=0为1.5%。
- β₀取.10/.90时为66.3/63.3%，取.55时为82.1%。
- 只用一个轴的连接时为72.6/75.1%，两轴都用为82.1%。

**边界：**
- 数独97.9%是在39种深度设置下，用手写的数独合法性检查器挑选答案的结果，任务规则写进了推理程序。可比的是固定深度数字。
- 论文全是双向注意力的谜题任务，所有信息都在输入里，没有参数知识，也不处理交接表示的格式问题。
- 未报告种子间方差；"内容分数反映正确性"是相关观察。
- 内容分数能读出符号身份，在缺少置换增强的划分下可能学成依赖身份的接收规则，见§1第3点。

## 5. 方案：循环原生交接与身份无关打分

原则：
- 监督只有段末的答案与EOS CE；
- 架构不读取标签、跳数、位置角色或图身份；
- 保留证据最强的解码—再编码交接，把稳定性和"何时接收"交给有界的跨轮连接；
- 接收规则只能看到与实体身份无关的信号。

```
e    = wte + wpe                               原生GPT嵌入，每轮重新注入
H_t  = F(h_{t−1} + e)                          共享块执行一次
c_t  = RMSNorm(H_t + q(H_t))                   q 为 DiscoLoop 软解码再编码，候选 RMS=1
N_t  = β N_{t−1} + exp(s_t) c_t
D_t  = β D_{t−1} + exp(s_t)
h_t  = N_t / D_t                               h_0 = N_0 = e，D_0 = 1
读出 = ln_f(h_T) 经绑定词嵌入
```

注入保持原生GPT尺度，与加性DiscoLoop一致。曾试用RMS归一化注入（InfiLoop把嵌入放大到与状态同尺度），但在绑定读出下它使初始化时的状态由输入token主导，初始答案CE为13.6，旧DiscoLoop为7.4；CPU工程冒烟发现后改回原生尺度，见协议。

- **身份无关打分`s_t = ψ(φ_t)`。** φ包括：
  - 解码熵与最大概率；
  - 与上一轮解码的一致度`Σ p_t p_{t−1}`；
  - 状态相对变化与余弦。

  这些量在任意正交旋转和词表重标号下都不变。ψ是一个5→16→1的小MLP，输出层零初始化，开始时与固定指数平均完全相同。它不知道"是哪个实体"，只知道"这个位置稳没稳定"，所以图B会继承图A的接收规则。这是用架构代替InfiLoop的置换增强。
- **训练配方：**
  - 每批第1段R~U{4..6}，第2段R~U{1..4}；
  - 段间切断梯度，段内完整反传。不照搬"只反传最后一个周期"：TRM一步梯度56.5%、完整反传87.4%，而本任务R≤10，完整反传负担得起；
  - AdamW β₂=.95，余弦衰减到0.1倍，评测用EMA .999；
  - wd保持0.1，避免与旧基线混淆。
- **明确不做：**
  - 中间CE、方向对齐、门损失、规则门、首轮KV；
  - 跳数课程、轮次嵌入、学习式停止。
- **候选扩展**（第一阶段结果需要时再加）：
  - 沿模型自身注意力传递的就绪度标量`ρ_i = Σ_j Ā_ij σ(s_j)`，是依赖闭合规则的可学习软版本；
  - 把交接读出`W_h`与下一词头分开，用于"前缀不是原子问句"的模板。

## 6. 预定比较

见[批次协议](../development-artifacts/loop-native-handoff-development-v1/protocol.md)。四个新臂共用同一数据、初始化（主干与已复用的无门DiscoLoop第0步逐位相同）、样本流与轮数序列：
- **A1 recipe-additive：** 无门DiscoLoop＋新配方；
- **A2 ema：** 凸组合交接，分数恒为零；
- **A3 content：** InfiLoop原分数；
- **A4 invariant：** 身份无关分数。

已有无门DiscoLoop（150万步）作为旧配方的A0复用。三组比较分别回答：
- A1对A0：训练配方整体的作用；
- A2对A1：交接方式的作用；
- A3对A2、A4对A3：打分能否读身份的作用。

预测与判读见协议。若A1已消除第+1轮瞬态与节点间掉分、并保住图B组合，架构改动就不必要，这也是有效结论。

## 7. 限制

- 一个已观察开发图、一个初始化；查询、轮次和检查点都不是独立世界。
- 学到的绝对位置编码只覆盖训练长度（序列长6），本批不测五跳及以上，只测1–4跳上的额外轮次（至R32）。
- 新配方作为一个整体改变，A1只隔离整体，不隔离其中每一项。
- 解码—再编码通道依赖本模板"下一词就是中间实体"，在自然语言问句上不成立。通用性需在前缀不是原子问句的模板上另行检验。
