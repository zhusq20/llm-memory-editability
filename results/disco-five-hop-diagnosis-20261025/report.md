**RoPE DiscoLoop主要没有形成可读的第五答案，而不是把已经答对的第五答案覆盖掉；它单独掌握第五条事实，不少题也已有可读的第四桥。接入完整正确原子结果后，它几乎全部保持到R16；这与invariant的明显后续丢失不同。两者不能归成完全相同的故障。**

复用原世界、旧150万步终点和相同A/B五跳池，每池5000题。A参加过短组合训练，B仅训练原子；主终点固定R16，原生保存R1–32。原生观察四版本；事先选定较强的RoPE参数EMA及旧固定R4/raw进行同六类、同四个时刻的干预。没有按本次结果挑选版本或时刻，没有训练。

## 1. 同样的问题，要按真实交接公式记录

DiscoLoop计算为x0=e、Hr=F(x_(r−1))、xr=Hr+q(Hr)。当轮答案读Hr，下一轮读取carry xr。没有invariant的逐轮e注入、候选外层RMS或N/D历史合并。

本次分别记录input、attention后、raw H、carry的原LM头读出、真前缀概率／rank与范数。RoPE attention诊断使用实际旋转后的Q/K，V不旋转。第五位置第r轮的桥前提取前一轮carry第四位置，不能拿同轮raw或另一批四跳题代替。

这里“第四桥”来自五跳题自身前缀；与独立四跳评测池的题型不同。“单独第五事实”是把真实e4与可观察r5写成原子调用，并非让原题获得额外桥监督。EMA/raw为同一次训练的两种权重视图，不是独立重复。

主RoPE/EMA的A/B第五事实在**首轮和R16均100%**可答。其B五跳最终6/5000正确（0.12%），前16轮只有这6题曾正确，0题曾正确后在R16丢失。99.88%的题在前16轮始终未正确；因此oracle第一次答对后直接保留输出也只能达到0.12%。A相应为11/5000正确、99.78%从未正确、0题丢失。

**桥状态存在局部损失，但远不足以解释五跳接近零。** B在R4的第四位置raw可读2618题（52.36%），加软反馈后carry可读2346题（46.92%），272题失去正确读出，没有新增正确。到R16，第四桥raw/carry都是2248题（44.96%）。但在R4 carry已经正确的2346题中，下一轮原生第五答案正确数为0；R15桥可读的2248题中，R16第五答案也为0。因此，不能把第五跳失败仅解释为“桥根本没算出”或这272题的反馈读出损失。原LM头不可读仍不等于内部没有信息。

**R5只改读源，基本不能救回。** A有4999/5000题在前一轮第四桥可读，强制读V4后最终也只有0.28%；B为0.10%。该干预对invariant的A/B则是19.24→94.98%、0.66→8.90%。这是真实的修复反应差异，不能因为原生五跳都低就说读取机制相同。

**提前给规范真桥有部分作用。** 在R4给真正e4的规范原子源V，RoPE的A/B最终为56.44/31.98%；推迟到R5则仅0.28/0.10%。B的R4当轮raw34.50%、carry32.78%、最终31.98%。此时原生carry第四桥尚有且仅有1题可读，规范桥是明确的oracle提前供应；不能把该干预结果当作自然五跳能力。R4改用规范错桥后，A/B最终分别有56.66/31.92%跟随其错误后继，支持这项改变确实依赖桥内容。

这些结果与“到第5轮时，当前接收状态已难被这类桥输入改写”相容。完整原子接口同时改变桥、关系调用格式、接收残差和状态尺度，因此目前还不能在这些因素中确定唯一原因，也不能由一种单源干预失败排除其它路由安排。

## 4. 关键差别：接入完整结果后，RoPE几乎不丢

下表固定R5干预、B五跳；invariant复用上一批逐题结果。

| 比较项 | invariant | DiscoLoop RoPE／EMA |
| --- | ---: | ---: |
| 原生五跳R16 | 0.66% | 0.12% |
| 原生前16轮曾正确、R16丢失 | 0.20% | 0% |
| 强制读原生V4，R16 | 8.90% | 0.10% |
| 完整正确原子供体，当轮正式答案 | 99.80% | 100% |
| 同一供体，继续到R16 | 61.64% | 99.98% |
| 当轮正确后，到R16丢失的题数 | 1918/5000 | 1/5000 |
| 完整错桥供体，R16仍输出其错误后继 | 60.04% | 99.96% |

DiscoLoop的原子供体直接成为当轮正式回答的raw H；invariant还须通过历史聚合。所以两者“当轮”指标的计算环节不同。真正有比较意义的是供体后的轨迹：RoPE能几乎完全保留正确结果，也能几乎完全保留错桥对应的错误结果。**稳定不等于正确；本批RoPE的主要困难在自然地产生正确第五结果，而不是供体结果的后续保持。**

完整供体已经过同一MLP，可能包含第五答案。其当轮改善部分由构造保证，后续保持才是主要观察；它不是纯桥传递修复，更不是可部署的无oracle方法。跨模型训练配方也不同，不能把保持差异全部归因于某一个架构部件。

## 6. 可以确定什么，还不能确定什么

- **共同点：** 原生第五答案主要未形成，单独事实调用比整条链强；不能主要解释为最终答案覆盖。
- **区别：** RoPE第四桥并非完全缺失，但R5强制读桥几乎不恢复；完整原子结果一旦接入，保持远强于本次invariant。旧绝对位置版还存在更早的第四桥失败。
- **尚未定位：** 当前接收状态、关系调用格式和更细的多头读取如何共同造成第五步失败。现有干预不建立唯一模块根因或优化原因。
- **不作的外推：** 本次没有更换训练世界，没有检验data sensitivity；相似分数不是相同内部机制，单个世界也不是跨世界稳健性证明。
