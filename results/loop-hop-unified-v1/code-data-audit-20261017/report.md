## 排除“只因模板留出”的额外诊断

固定64k权重，从图A两跳训练使用过的90组关系序列中，选2048条不在训练中的具体问题。选择采用固定随机种子2026101701，先于模型输出，所有模型同题，未提供额外标签训练。它是事后诊断，不改原ID池、主评分或终点规则。CPU FP32答案正确计数为：

| 层数×训练轮数 | 普通Loop | DiscoLoop |
| --- | ---: | ---: |
| 1×2 | 6/2048（0.293%） | 0/2048（0%） |
| 1×3 | 6/2048（0.293%） | 6/2048（0.293%） |
| 1×4 | 5/2048（0.244%） | 6/2048（0.293%） |
| 2×2 | 2/2048（0.098%） | 4/2048（0.195%） |

因此，即使去掉“整个关系序列没见过”的条件，当前图A仍未表现出组合泛化。旧成功模型正式II中确实有4条训练未见关系序列的题，4条全对；其它三个池也各有3–4条此类题且全对。子集太小，只能说明不能把模板留出本身当作必然失败原因。

## 解释与下一步边界

已建立的观察是：当前模型掌握原子和已给组合，却对同图新组合也缺少迁移；改变模板留出方式不能立即恢复，图B还有整图迁移。未建立的因果解释是：究竟浅层执行、较少的两跳支持、混合长度、词表或图结构哪个因素导致未学出组合操作。没有支持“一跳必须一层／一轮”或DiscoLoop普遍无效的证据。

当前设计缺口是同时改变多个条件，且没有保留成功4×2在新任务上的锚点。要进一步定位，应另定最小的配对比较，先建立成功配方到新任务的可解释桥接，再逐项改变条件；不能直接继续扩大层数／轮数网格。此处记录设计判断，不自动新增训练。
