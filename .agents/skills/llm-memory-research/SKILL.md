# 项目研究原则

## 1. 清晰、简洁地表达

- 先说核心观点，再给必要的理由与证据。使用直接、具体的语言，避免术语堆砌、空泛表述和重复解释。
- 数学符号与专业术语在需要时定义；简洁不意味着省略影响结论的假设、适用条件或不确定性。
- 明确区分已证明的结论、实验观察和待验证的猜想。
- 及时删除过时内容，补充并更新新增内容，同时压缩精简表述，保持文档简洁、准确。

## 2. 以机制解释为研究目标

- 本项目的目标是通过数学推导或实验，解释 MLP 的工作机制及模型架构的原理，回答“为什么发生、通过什么过程发生、在什么条件下成立”。实验设计应从需要解释的机制问题出发。
- 机制研究不要求所有实验先定位具体神经回路或测齐全部理论变量。控制良好的训练与端到端比较也能建立有价值的结论；若进一步归因于某个模块、接口或参数约束，再补充能够支持该归因的证据。
- 测试主要依据模型在目标任务上的端到端指标，以及模型参数的特征图与结构分析。围绕机制假说比较这些指标和特征在不同条件下的变化，按需使用对照、消融或干预，建立内部结构与整体行为之间的联系。
- 不要刻意设计预测实验，不要把研究转向用内部特征预测模型表现、成功或失败，也不要为此另建预测器、拟合预测指标或开展预测探针评测。这类预测任务与本项目的机制解释主线无关；直接测量模型的端到端任务表现不属于另设预测任务。
- 数学推导应明确假设、推导关系和适用边界；实验分析应说明端到端结果与参数特征支持什么机制、还不能解释什么。指标变化或特征图本身不能自动证明机制成立。

## 3. 不因与已有论文话题重叠而放弃有价值的问题

- 不得仅仅为了避免与已有论文的话题、研究对象或方法重叠，就主动放弃值得探讨的研究问题。
- 文献用于理解已知结论、检查证据和识别尚未解释的部分，不把“有人研究过”当作选题禁区。复现、深化解释、检验适用边界和探索反例都可以有研究价值。
- 如有重叠，清楚说明已有工作解决了什么、本项目还要解释什么，并准确引用；不夸大新颖性，也不为制造差异而偏离核心问题。
- 研究优先级依据问题的重要性、机制解释价值、可检验性和资源约束决定。若建议搁置某个问题，应给出实质理由，而不是只说“与某篇论文冲突”。

## 4. 先借鉴原论文的方法，再设计扩展

- 设计新研究实验前，阅读最相关论文的方法、实验及必要附录，提炼其研究问题、关键假设、变量控制、训练前提、基线和结论边界。不能只引用摘要结论或借用技术名称；预印本、已投稿和已发表的状态须按可核实来源区分，发表状态不能代替对证据质量的判断。
- 优先复现与当前问题最相关的关键比较，或复用已经验证的实现与基线，再说明本次扩展改变哪个条件、能回答什么新增问题。不要求完整重跑论文全部实验；增加架构名称、模型规模、案例数或干预数量本身不构成研究推进。
- 每轮明确主要研究问题和希望建立的结论层级：数学条件、受控行为规律、自然模型机制或方法有效性。多个实验应分别服务于明确主张，避免把组合泛化、内部定位和参数编辑混成同一个检验。

## 5. 用关键比较区分解释

- 为核心假设设计能够区分竞争解释的比较，说明改变什么、保留什么，以及不同解释会导致什么可观察差异。指标变化后再附上一个机制故事，不等于检验该机制；不要仅因常用就堆叠对照、消融或patch。
- 核查当前问题依赖的前提，例如相关事实能否提取、任务操作是否学会、目标更新是否真正发生、必要后继事实是否具备。前提未成立时，结果仍应保留，但不能把失败直接归因于组合接口、传播瓶颈或架构能力上限。
- 理论条件与实际操作须对应。激活替换、共享参数更新、模块输出保持和最终行为保持回答不同问题；普通微调不能代替严格受约束更新，数学恒等式或数值一致性也不能代替经验机制证据。
- 对照应针对具体混淆，核查可访问信息、监督、计算预算、干预位置和范围等差异。相同扰动范数不保证相同信息量或相同分布；完整问题的供体可能已经携带答案，不能直接视为纯中间信息。无法完全匹配时说明差异，收窄结论。
- 区分事实知识、格式变化、单跳正确、组合使用和知识保持。保留全量结果，条件子集另报筛选依据与覆盖率；同一事实或世界的不同问法、层、种子和重复测量不当作独立事实或世界。

## 6. 先校准实验，再开展正式比较

- 在开发数据上确认任务定义、提示、评分和目标操作有效，并根据依据调整训练与优化设置；随后确定正式比较及评价规则。预定分析与事后探索分开报告，不能根据确认集结果重选样本后仍按原确认实验解释；已有批次仍遵守其原契约，必要修订保留原因和历史记录。
- 小预算优先缩小问题、数据或模型规模，保留关键比较和有效的目标操作。固定少量训练步数后没有改善，不自动证明理论瓶颈；也不把100%掌握率、显著收益或全面神经定位设为所有研究的统一门槛。
- 冻结配置、完整矩阵、源码哈希、测试和重载审计用于保证执行与复核质量，不能代替合理的研究设计。结果难以解释时，先检查主张、操作和证据之间的对应，再决定是否扩大实验。
