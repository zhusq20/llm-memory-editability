# 实验计划

本计划据 [研究备忘录](research-memo.md) 整理。研究问题是：在编辑数量、变化强度和训练预算受控时，更新相对于原有共享结构需要的独立表示资源，能否预测编辑成本与副作用？这是待检验的假设。

## 当前实现与边界

仓库目前只实现一个 NumPy 低秩矩阵演示：计算矩阵的秩，并通过截断 SVD 求给定秩预算下的最佳近似。它没有训练模型或执行知识编辑，也没有完成下述 A–D 实验、小型 Transformer 实验、预训练 LLM 编辑或系统性文献查新。

演示从全为 1 的 2×2 矩阵出发，比较全体条目改为 2 的规律更新，以及仅左上角改为 2 的例外更新。两个更新矩阵的秩都是 1；更新后目标的秩分别为 1 和 2。因此，在秩预算为 1、要求精确重建整个目标矩阵时，只有前者可表示。这是线性代数事实，不是新定理，也不是 H1–H3 已获支持的证据；两种更新的条数本来就不同。

```bash
memory-editability --rank 1 --output results/minimal-example.json
```

## 预先定义的结构量与评价量

对原事实表 $Y$、已知更新目标 $Y'$ 和秩预算 $r$，首先使用：

$$
g(Y',r)=\max\{0,\operatorname{rank}(Y')-r\}.
$$

这个量描述**目标相对现有秩预算的超额需求**，不是 $\operatorname{rank}(Y'-Y)$，也不等于一般神经网络中的新增参数数量。它在合成任务中利用完整目标表计算，必须在执行编辑及观察编辑结果之前固定。记录秩判定的数值容差，避免把浮点噪声解释为结构差异。

近似重建另报最佳秩 $r$ 近似的 Frobenius 误差及归一化误差；精确不可表示不意味着近似误差一定大。误差阈值、归一化规则与零分母处理均应预先确定。

需要分别报告以下三类量，不能用其中一个替代另一个：

| 类别 | 问题与指标 | 解释边界 |
| --- | --- | --- |
| 表示成本 | 达到指定目标误差所需的最小容量；低秩模型中可用秩及 SVD 误差界 | 可表示不保证某种编辑算法能够找到该表示 |
| 编辑成本 | 从原模型出发达到指定质量所需的步数、训练样本、计算及额外参数 | 当前解析演示不测量这类成本 |
| 副作用 | 保留事实误差或准确率、查询改写泛化、一般能力变化 | 分别报告编辑集合与保留集合；空集合标为不适用，不能记为完美保持 |

转向语言模型后，额外报告离散答案准确率和 margin。抽样检查只能说明被检查的知识，不能保证全部旧知识均被保持。

## 可证伪假设

| 假设 | 预期证据 | 不支持该假设的结果 |
| --- | --- | --- |
| H1：编辑条数不是充分的难度变量 | 同编辑条数下，结构量对未见更新的成本有额外预测力 | 控制置信度、语义冲突、惊讶度与预算后差异消失 |
| H2：原有组织方式影响编辑 | 知识内容及旧知识准确率接近时，改变共享程度改变规律与例外更新的响应 | 组织方式的干预不能稳定改变结果 |
| H3：部分困难来自独立表示不足 | 同等额外参数预算下，独立表示选择性改善例外更新 | 任意扩容同样有效，或独立表示没有帮助 |

## 实验 A–D

### A：固定编辑数量，改变更新结构

在潜在因素生成的合成世界中，对同一个初始模型构造配对更新。规律更新改变少数共享因素；例外更新要求更多独立变化。配对时匹配编辑条数、实体与属性覆盖范围、变化幅度、目标答案分布、编辑前准确率、置信度或目标惊讶度、语义冲突，以及样本、优化步数和参数预算。

比较编辑成功、保留事实、改写泛化，以及达到相同质量所需的计算和容量。结构量在编辑前计算；用未参与指标选择的更新检验预测力，并与仅用编辑条数和其他控制量的基线比较。当前 2×2 演示不具备这些匹配条件，不能代替实验 A。

### B：固定知识内容和答题效果，改变组织方式

直接控制共享因子数量、复用范围、独立表示数量和剩余容量。在同一知识表、旧知识准确率接近时，比较不同组织方式对规律与例外更新的响应。记录总容量，避免把剩余容量差异误写成组织方式效应。

只有合成结果稳定后，再探索小型 Transformer。不能单凭某个激活矩阵的有效秩断言知识采用了特定压缩方式；组织方式的度量需要独立验证。

### C：等预算补充表示资源

在额外参数预算相同的条件下比较扩大共享表示、提供可独立控制的表示，以及冻结原共享部分而只训练新增部分。记录实际可训练参数、初始化、样本和优化预算。

关注“扩容方式 × 更新类型”的差异：独立表示是否对例外更新有选择性帮助，而非所有任务普遍提升。单独观察到新增 memory 模块有效，不能证明假设中的机制。

### D：从头训练的诊断对照

用与编辑模型相同容量的模型，从头拟合完整更新目标。采用充分优化预算和多次初始化，并与从旧模型出发的编辑结果比较。

| 结果 | 可得结论 |
| --- | --- |
| 严格表示下界排除目标，且同容量模型无法拟合 | 支持该受控模型中的表示限制 |
| 同容量从头训练成功，局部编辑失败 | 目标可表示，应进一步研究更新路径或可用信息 |
| 有限次从头训练失败 | 只是经验线索，不能单独证明不可表示 |
| 等预算独立表示选择性改善例外更新 | 提供机制的干预证据，仍需完整对照 |

## 推进、报告与停止条件

推进次序是解析演示 → 配对合成实验 → 从头训练及扩容对照 → 小型 Transformer → 预训练 LLM。每个阶段先固定数据生成方式、结构量、目标质量、预算、随机种子方案和分析方法，再运行并记录失败案例及变异情况。新模型或新算法不得仅沿用已有结论。

出现以下结果时，应停止扩展或改写中心假设：

- 效应完全由原有置信度、语义冲突、惊讶度或训练预算解释。
- 结构量只能事后解释，不能预测未见更新。
- 改变组织方式不能改变结果。
- 容量瓶颈只在刻意收窄的线性模型出现，非线性模型没有对应迹象。
- 不同扩容方式同样有效，缺乏支持独立表示机制的证据。

负结果同样需要记录，不通过不断增加假设来保留原有叙事。
