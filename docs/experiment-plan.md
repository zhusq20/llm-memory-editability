# 实验计划

本计划据 [研究备忘录](research-memo.md) 整理。研究问题是：在编辑数量、目标惊讶度和预算受控时，更新相对于模型已有共享结构的关系，能否预测编辑成本与副作用？这是待检验的假设。

## 研究对象与当前实现

核心实验直接在具有非线性表示的 MLP 和小型因果 Transformer 上进行。当前已实现分组合成事实、旧世界训练、从同一检查点出发的配对编辑，以及相同模型容量的从头训练诊断，覆盖实验 A 的部分控制和实验 D 的有限预算版本。详见 [非线性实验协议](nonlinear-protocol.md)。

Transformer 具有因果自注意力、非线性前馈层和离散答案输出，但尚未使用预训练权重或自然语言知识。共享的数据生成规律不等于模型已学到共享内部表示。实验 B、C 和预训练 LLM 实验尚待实现。

NumPy 低秩示例仅为解析基线：秩和 SVD 给出特定线性模型的最佳近似误差。该结论不提供 Transformer / MLP 的容量下界；离散标签的数值编码也不适合直接作为神经模型的秩指标。

## 假设与测量

| 假设 | 所需证据 | 不支持该假设的结果 |
| --- | --- | --- |
| H1：编辑条数不是充分的难度变量 | 同编辑条数下，预先定义的结构量额外预测未见更新的成本 | 控制置信度、惊讶度与预算后差异消失 |
| H2：原有组织方式影响编辑 | 在知识内容与旧准确率接近时，干预共享程度改变编辑响应 | 可验证的组织方式干预不能稳定改变结果 |
| H3：部分困难来自独立表示不足 | 同等额外参数预算下，独立表示选择性改善例外更新 | 任意扩容同样有效，或独立表示没有帮助 |

分别报告以下三类量：

| 类别 | 测量及解释 |
| --- | --- |
| 表示成本 | 达到指定质量所需的模型容量；当前神经实验没有严格下界，参数量只是已使用的容量 |
| 编辑成本 | 从旧模型出发达到目标质量所需的步数、样本、可训练参数和用时；固定预算的终点分数不等于最小成本 |
| 副作用 | 保留事实准确率与 margin 的变化；自然语言改写和一般能力变化需另行测量 |

当前报告编辑前后目标交叉熵、离散答案准确率与 margin。目标惊讶度由编辑前模型对新答案的概率计算，是已测量、尚未匹配的潜在混杂因素。

## A：固定编辑数量，改变更新结构

当前对同一旧世界和同一已训练检查点构造两种更新：改变一个实体组的共同答案规律，或为该组实体设置不同目标映射。匹配修改集合、编辑条数、实体与属性覆盖、目标答案边际分布、编辑步数、参数范围和回放权重。所有被编辑答案均发生变化；分类答案没有可解释的数值变化幅度。

先检查旧知识准确率，再分析编辑。未通过旧知识质量门槛的运行不能作为“成功存储后的编辑”证据，必须保留并标记。预算在同一模型的规律与例外条件之间匹配，MLP 与 Transformer 的实际容量和计算量并未匹配。

后续需要匹配或分层控制目标惊讶度与置信度，扩大编辑规模及更新分布，预先定义内部结构测量，并在未用于选择指标的更新上验证预测力。自然语言任务还需处理语义冲突和改写泛化。仅出现两种更新的分数差异，不足以证明差异来自表示共享。

## B：固定知识内容和答题效果，改变组织方式

在同一知识表、总容量与旧知识准确率接近时，比较可控的共享表示与实体独立表示。组织方式由可验证的架构或训练干预定义，并记录剩余容量，避免把容量差异归因于共享程度。

不能只凭某个激活矩阵的有效秩认定模型已压缩知识；需结合行为及干预证据。本实验尚未实现。

## C：等预算补充表示资源

在相同额外参数预算下，比较扩大共享前馈表示、提供实体可独立控制的表示，以及冻结原模型而只训练新增部分。记录实际新增与可训练参数、初始化、数据和优化预算。

关注“扩容方式 × 更新类型”的差异：独立表示是否对例外更新有选择性帮助。仅观察到新增 memory 模块有效不能证明机制。本实验尚未实现。

## D：从头训练诊断

当前从头拟合完整更新世界。两种目标使用与旧模型相同容量的网络，从同一初始状态出发训练全部参数；编辑则从旧世界检查点出发，默认仅训练前馈层。因此这是表示可行性的诊断，不是训练成本完全匹配的编辑算法比较。

| 观察 | 可得结论 |
| --- | --- |
| 从头训练达到预定目标质量，编辑未达到 | 该目标在此模型中可达到该质量；应检查参数冻结、优化路径和信息约束 |
| 有限预算、有限种子从头训练失败 | 只是经验结果，不能证明不可表示 |
| 增加预算后编辑和从头训练均成功 | 原预算下的差异不能被称为容量下界 |
| 等预算独立表示选择性改善例外更新 | 可提供干预证据，仍需 B、C 的完整对照 |

报告实际预算与目标质量；默认步数不意味着优化充分。

## 推进与停止条件

推进顺序为 MLP / Transformer 配对实验与从头训练诊断 → 内部组织与等预算扩容干预 → 预训练 LLM。线性基线服务于解释和检查，不作为进入神经模型的研究门槛。

每项实验先固定生成方式、质量阈值、预算、种子与分析方法，再记录效果和负结果。遇到以下情形应缩小或改写中心假设：

- 差异由目标惊讶度、原有置信度或训练预算解释。
- 结构指标只能事后解释，无法预测未见更新。
- 可验证的内部组织干预不能改变结果。
- 表示瓶颈只在线性基线出现，在非线性模型中没有对应证据。
- 不同扩容方式同样有效，缺乏独立表示机制的证据。
