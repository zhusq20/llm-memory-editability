## 对所附分析文档的采纳

| 建议 | 处理 |
| --- | --- |
| 区分会答、能用和能持续保留 | 采纳，作为统一报告的三类结果 |
| 地址、内容、可用深度共同影响迁移 | 采纳；梯度外积是局部SGD恒等式，完整模型和多步Adam效果另论 |
| 强制桥实体、已有权重干预、辅助监督对照 | 保留为解释具体结果的候选，不统一升级为当前P0，也不重做已回答的问题 |
| 下一步以因果识别为中心 | 不作为当前主次顺序；按用户最新目标，先原方法与自然部署效果，再针对行为差异补机制解释 |
| 连续积累尚未解决、只保留负结果 | 更新：遗漏了邻居保护正结果，必须同时报告成功与适用条件 |
| 在Qwen复用24次编辑检查点 | 纠正：3.13%→85.42%属于小型受控模型；不能移接为Qwen证据或假定有对应Qwen权重 |
| 架构主要用于验证机制 | 调整：按最新论文目标，架构仍是核心研究层次，不降为旁证 |
