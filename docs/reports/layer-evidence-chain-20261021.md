# LM Knowledge：逐层表示、逐层干预与写入分解

2026-10-21。按用户要求，先整理内部机制证据，再确定论文中心图。本次只复核已有协议、测量实现与保存的汇总，重画逐层曲线；没有执行模型或新增训练。当前写作安排仍以[Roadmap](../roadmap.md#layer-evidence-chain)为准。

## 1. 当前能建立的解释

**原模型通过实体状态调用知识的过程，与答案监督主要施加写入的位置，不必重合。** 实体位置与末位置的计算随层发生不同变化；替换实体状态和阻断读取能检验哪些变化仍影响答案；梯度分解则显示答案监督选择的地址与内容。训练后状态移植补上了“梯度倾向是否对应实际写入”的证据。

这是几项测量相互支持的解释，尚不是同一条事实从写入到多跳失败的完整逐层因果轨迹。原子与组合准确率适合表格，中心图保留逐层变化，不再把它们压成前段/后段平均，也不先画“知识区→推理区”的固定模块图。

需要纠正两种过强说法：

- **问题依赖不等于已经定位推理，实体依赖不等于已经定位存储。** 方差分解首先测的是表示随什么输入变化。词面信息、关系选择和答案计算都可能贡献份额。联合份额也不是答案实体的直接解码。
- **现有桥读出不支持普遍的“形成太晚”。** 所检查桥位置的主要结果是未测到可用的h，而不是先在晚层测到h，再通过回补救回。不能把后者画成已观察到的主机制。

## 2. 三类测量是否对应同一过程

| T：训练后接口移植 | 注入模型与其原模型；M1/M2/M3/M5/MEMIT分别保存 | 只计原问法已写入的事实，模板/条件子集必须保留 | 主语状态正向/反向移植、显式主语补入桥位置；含逐层或层对网格 | 在各自实验内检验实际写入的可携带性，补充W-content的一步梯度证据 |

R与I既不是同一实体类型，也不是同一关系方向；R/W-map与W-content不是同一目标与同一提示。“第20层附近”在不同实验中的接近是可讨论的一致性，不能当作同一次读取的严格时间对齐。R/W-map的最后提示token与W-content的a*也不能混用：24个U0模板中17个回复不以v开头，a*在回复内部。

## 3. 按机制问题排列证据

### 3.1 表示：实体和问题何时进入同一计算

**操作：** 固定问题换实体、固定实体换问题，对每个层×位置的MLP输入做平衡二因素分解，分成实体、问题、联合份额。三份额和为1；问题份额包含关系与问法。

**观察：** 末位置在前2/3层的问题份额均值为.921 / .812，实体份额.057 / .152。后段联合份额由.022 / .036升至.201 / .227。实体位置以实体为主，但中段明显读入问题；“实体位置几乎不含问题”的原预测K1在两个模型上都失败。只看全部问答正确的国家，末位置前段问题份额仍为.929 / .811。

**支持：** 两个位置以不同方式组织输入依赖，后段末位置更强地结合实体与问题。**不支持：** 实体信息此前完全不存在；联合份额就是答案；所有问题相关计算都属于推理。

[原测量](../results.md#knowledge-reasoning-map-v1)；[协议](../development-artifacts/knowledge-reasoning-map-v1/protocol.md)。

### 3.2 干预：哪些层上的实体状态仍能改变答案

**替换：** 在第l个解码块输出处，把目标主语末token的完整残差换成另一个实体在同类问句中的状态，再继续原计算。评分是教师强制匹配供体答案，不是自由生成准确率。

- 1.7B：第2–19层，两模板的供体答案匹配约61–84%；第20层变为2.27% / 0%，随后接近0。
- 2B：第12层为85.45% / 83.64%，第14层83.64% / 76.36%；第15层降为63.64% / 67.27%，第20层为0。它是较早开始下降，并非第15层立即完全失效。

**阻断：** 只让答案预测位置在移动层窗口中不能读取主语词元。1.7B用五层attention掩码，原正确答案失效比例最高80.23%（窗口17–21，0起算）。2B用四层窗口，attention层掩码、DeltaNet层以主语输入均值替换再计算目标位置输出；全部混合器一起干预最高仅9.17%，attention单独2.75%，DeltaNet单独5.50%。

**支持：** 1.7B自然国家问答中存在一段重要的晚层读取过程，与主语替换的有效层段相接。**未解决：** 2B的同类读取组件尚未定位；较弱的窗口效应不说明它不使用主语。两模型干预操作与窗口宽度不同。整段阻断不能精确归因于某一层、某一头；完整主语状态替换也不是孤立事实向量替换。

[原实验](../results.md#knowledge-read-interface-development-v1)；[干预实现](../../src/llm_memory_editability/read_interface_model.py)；[实际调度与测量逻辑](../../src/llm_memory_editability/read_interface_stages.py)。

### 3.3 写入：答案损失选择哪个位置与哪个方向

**位置：** W-map与3.1使用相同提示，适合直接并排。后1/3层的平均位置范数份额，最后提示token为.567 / .471，实体token为.063 / .043，回复位置为.186 / .189。图保留完整层曲线，包含最后一层主语份额按结构归零的事实。

**内容：** 新事实梯度中，在预测v首token的a*处，`−δ`随层加深越来越接近v的unembedding输出方向；末层余弦约.742 / .788，第二事实集同向。主语位置的下降方向则在2B中更明显地包含v的实体方向；1.7B相应信号较弱，原判据仅部分成立。

**三个“份额”不能混用：**

| 量 | 含义 | 能否相加为1 |
|---|---|---|
| `Σ_G ‖δ_p‖‖k_p‖ / Σ_all ‖δ_p‖‖k_p‖` | 位置外积项的范数质量；忽略项间抵消 | 完整互斥分组可以；图中省略其它位置 |
| `‖Σ_G δ_pk_pᵀ‖_F / ‖Σ_all δ_pk_pᵀ‖_F` | 各组梯度和相对总梯度的精确范数比 | 不可以，且可大于1 |
| `〈ΔW_G,ΔW〉 / ‖ΔW‖²` | 各组沿总梯度方向的投影份额 | 完整互斥分组可以，但可为负 |

中心图c使用第一种；不能据其大小声称某个位置解释了相同比例的实际参数变化或行为效果。`∇W=Σδkᵀ`已通过真实模型数值核对，但这是梯度恒等式；多步Adam更新、其它矩阵变化及长期学到的内容要另测。末层非答案位置梯度为0由结构决定，不作为新的机制发现。

### 3.4 将梯度倾向接到训练后的调用

1. **接口移植：** 四种梯度方法的新事实主语状态放进原模型后，T1接近0；把原主语状态放回注入模型后，很多新答案仍保留。它支持“写入未成为原读取器可直接使用的主语状态”，不能简化成“新事实在主语中完全不存在”。
2. **只改训练层段：** 接口段写入确实改变了主语状态依赖，但T1仍低。这里还需要被一起改变的非主语状态，说明只把写入前移并不足够。两臂达到目标的步数不同，不能称所有成本完全匹配。
3. **桥实体功能读出：** 以M2开发集为例，1.7B桥状态移植的最高命中8.75%，显式实体状态62.50%；2B为12.12%和83.84%。同一批已写入事实内，显式实体可以被使用、桥状态不能同样使用，是比单纯解码失败更直接的证据。
4. **未形成太晚的证据：** 五方法×两模型×两事实集原规则都归为“桥位置无h”，但部分显式身份解码对照未达标；不能仅据解码零值宣称整个网络不存在h。回补没有达到预定救回标准，未支持“已形成、只需搬回前层”的解释。
5. **实际权重增量的位置限制：** 小模型中，仅在答案位置启用写入后的MLP，可恢复刚写事实的100%；仅在主语位置为0–22.7%。这是训练后的功能干预，与Qwen的一步梯度方向相互补充。它不是同模型复核，也不是把非线性输出精确加性分解。旧知识损伤在只启用答案位置时并不逐值完全等于全部位置，不能概括成“全部损伤完整复现”。

[接口与层段](../results.md#knowledge-read-interface-followup-v1)；[实际增量位置干预](../results.md#write-position-20261020)。

## 4. 中心图决定

**中心图采用三列、每列两个逐层面板：表示 → 干预 → 写入。** 横轴使用原始层号，不对不同模型归一化后拼接。图的主问题是：实体状态怎样影响后续答案，答案监督又把更新信号放在哪里？

| 列 | 上面板 | 下面板 | 读者应得到的信息 |
|---|---|---|---|
| 表示 | a：实体token的实体/问题/联合份额 | d：最后提示token的同样三条曲线 | 两个位置何时分别依赖实体、问题及二者组合 |
| 干预 | b：逐层替换主语状态 | e：逐窗口阻断读取主语 | 主语在哪些层仍有作用；哪段读取对答案重要 |
| 写入 | c：与a/d同提示的逐层写入位置 | f：新事实下降方向与实体/输出方向的余弦 | 监督主要作用的位置，以及末端写入更接近哪种内容 |

**主图先用Qwen3-1.7B说明一条清楚的读取过程；Qwen3.5-2B用完全相同坐标给出伴随图，并在正文明确它的阻断未定位结果。** 选择主图的理由是干预可解释性，不是把第二模型包装成相同机制的重复验证。两图都已生成，正文是否并排取决于版面；不放大2B纵轴制造相似峰值。

a/c/d同提示，b/e另一个自然用途，f为新事实；图上已直接标注来源差异，不画跨面板的单样本因果箭头。主图是已有证据的组织，不是新实验或整条机制已证实的标志。开篇无需再加“知识区/推理区”模块示意；方法终点结果仍用表格。完整梯度三种范数、用途共享、bioS和桥实体对照进入相应章节。

## 5. 尚未闭合的连接及完成核对

当前缺口是**同事实、同提示、同权重下，把桥实体的出现、可用性、实际写入和后继答案连起来**。现有材料足以写“互补证据支持什么”，不足以写“逐层追到了每次组合失败的完整机制”。如果后续专门补这一连接，应优先复用已有事实和权重；本次没有启动补测、探针训练或新方法比较。

本次按测量代码核对层输出/MLP输入的区别、0起算层号、窗口宽度、教师强制评分、a*位置与三个梯度份额定义。重算地图全部实体的前后段读数，与保存的主汇总逐值一致到舍入误差；两模型份额和、数组长度及位置归一化检查通过。867个绘图点导出CSV，12份数据/实现来源记录当前SHA256。已有部分标量的bootstrap仍留在源数据；不把不同层、模板或两个事实集当作独立模型重复，也不为缺少逐层置信区间的汇总制造误差带。

这是读取已完成产物后的证据整理，未重新做GPU重放、云端核验或旧训练审计。各批原有完成状态不变。
