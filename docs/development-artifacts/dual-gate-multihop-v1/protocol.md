# 双门多跳开发比较：冻结协议

用户2026-10-17授权实现、检查后利用空闲GPU并行运行五组多跳对照，固定DiscoLoop可复用则不重跑；新增知识实验须看结果后另作决定。本协议仅包含开发图上的多跳比较，不包括独立世界确认或新增知识写入。

## 比较与预算

固定F复用`loop-hop-unified-v1/runs/disco-l1-r4`的300000步终点。新增P（原文sigmoid标量门）、G（共同输入标量注入门）、D（逐维连续门＋标量注入门）、V（同参数逐维注入对照），各300000步，合计1200000科学更新。每臂32步工程短训，共128另计；每臂全尺寸图捕获检查执行1次更新并恢复模型、Adam和RNG，共4次丢弃工程更新。工程过程不改变正式起点。F新增训练0，新增事实/确认世界更新0。

模型为完整GPT-2块组：宽768、12头、1物理层循环4次，原词表/位置embedding、attention、MLP、残差、归一化及dropout保持。通道为原最终LN/绑定输出头→词表softmax（温度1）→绑定输入embedding→无仿射RMSNorm（eps1e-6）。G/D/V的门均为2sigmoid，零初始化后门为1；D/V新增3841参数，G1537，P769。P条件输入为未归一化软embedding，sigmoid偏置log(99)使初始门.99，与F不逐值相同；G/D/V严格退化为F。无仿射门输入LayerNorm eps1e-5，门参数跨轮/位置共享；只读当前位置因果状态，最后轮不交接。无真实桥标签、首轮CE、辅助对齐、额外KV或跨样本状态。

详细公式与竞争解释见[路线图设计](../../roadmap.md#dual-gate-design-20261017)；唯一冻结配置为[配置](../../../configs/dual-gate-multihop-v1.json)。G/D/V同初始化/幅度/门输入，D/V只改变逐维门作用分支，排除原文P门范围及条件输入的混淆。门允许放大，不预设它们删除的是噪声。

## 指标与解释

预定主指标：固定300k、推理4轮、图B三跳全词表答案准确率。两/四跳、原子ID/OOD、图A训练/留出组合、答案+生成EOS、NLL、必要原子覆盖/条件组合、无重复实体子集，以及推理r1–4完整网格均保留。学习节点0/1k/8k/16k/32k/64k/128k/256k/300k；不取最好节点/推理轮数，不提前停止或自动延长。

固定预算报告真实曝光/token、矩阵FLOPs、门O(d)操作说明、参数/耗时/显存；同卡时间不作独占吞吐比较。终点比较需曝光数组与F逐元素相同。单图单初始化，查询、关系模板、推理轮数和节点不算独立世界，不以查询bootstrap宣称跨图优势。仅两跳改善不称三跳成功。原子可答不保证组合操作已形成；所有失败和低分保留。

本批只训练/评价五条件，不自动执行路线图中的反事实门干预、新世界确认、新增事实、边界/lr网格。结果出来后再讨论后续。

## 首次预检失败后的独立工程修订

首次四臂均在图捕获反向遇到legacy stream依赖，未到非零学习率更新/短训/正式训练。原source、freeze、容器、日志和退出码全部保留。修订在preflight对照检查后额外释放仍存活的current/logits/loss计算图引用，保留已有grad置None；新门AdamW补齐原生optimizer已有的capturable=True。它不改变架构、损失、数值精度、样本流或原生核心源码，不把前次失败算科学负结果。

GPU9独立scalar修复探测全尺寸12项检查通过，真实1次工程更新及模型/Adam/RNG恢复均通过、退出0，正式更新0。此额外工程更新单列，连同新修订四次预检合计5次恢复后丢弃的工程更新；128短训和120万科学预算不变。该探测不修改旧运行。

显式使用`--engineering-repair preflight-repair-v2`建立`attempts/preflight-repair-v2`的新source/input/freeze和独立容器名；持有原控制器锁并拒绝任何已有train claim，旧失败阶段不被跳过或重试。`current-attempt.json`只标注当前去向，不覆盖旧失败。新修订仍须全部CPU/CUDA/短训/重放门槛通过后才正式训练。
