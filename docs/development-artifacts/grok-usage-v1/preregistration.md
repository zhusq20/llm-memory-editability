# 事实的组合使用经历：两跳训练开发实验 v1

用户于2026-09-30授权按研究复盘开展实验。本批检验训练经历如何影响知识的组合使用，结论层级为受控训练的行为规律。开发世界146001、初始化14601；先完成四臂开发、核验训练操作后再冻结新世界比较。历史结果与契约保持原样。

## 方法依据与问题

沿用已读的 [Grokked Transformers](https://arxiv.org/html/2405.15071v3) §2–3、附录D.1/E.2：所有原子事实都学习、只让部分事实参与组合、留出完整查询。新增同一事实跨配对模型交换组合使用身份，并以构成原子的重复学习作控制。

[Physics 3.1](https://arxiv.org/html/2309.14316) §2–4和附录B–D、[3.2](https://arxiv.org/html/2309.14402)及其附录B/C提示区分存储、提取和操作迁移。[How do language models learn facts?](https://arxiv.org/html/2503.21676v2) §2–3与附录D提供跟踪学习过程的依据。本批不复制自然语言BIO设置，也不把答案监督的小型符号训练等同于自然语言预训练。

主要问题：在基础事实相同且都有背景组合训练时，事实参加其他组合的经历，是否改变它在从未训练过的完整组合中的可用性？原子重复控制进一步区分实际构成事实出现次数与组合上下文的作用。不会由差值直接推断知识转移至某一层或证明唯一神经机制。

## 数据与四臂

复用随机图：128实体、16关系、每实体8条边，共1024事实。先按独立固定随机流将全图两跳完整查询的10%留出，各臂均不训练这些查询。事实按固定随机角色划为50%共同背景、25%A、25%B，不按模型表现或诊断结果重选图。

- A：组合只使用背景/A事实，包括共同背景池和至少涉及一条A事实的角色池。
- B：同样处理背景/B事实，A事实只接受单跳训练。
- repA：与A共享基础原子及背景组合流；每条角色组合替换为它的两条构成原子。
- repB：对应B的对称原子重复控制。

两个角色池按较小池容量统一抽样，固定样本总数；背景池跨四臂相同。所有原子都参加基础单跳流。每个逻辑batch为32基础原子、112背景组合、112角色槽；A/B实际256行，重复臂368行。角色组合槽的两条替代原子各取1/2损失权重，其他行权重1；每行答案/EOS等权，按256个逻辑槽归一化。

重复臂逐步精确匹配对应角色流的构成事实出现次数，**不匹配监督信息、上下文或计算量**。它显式监督两个原子答案，而组合只监督最终答案。分别记录实际样本、有效token、监督token与展开FLOPs；A/B为主要同预算角色比较。各流独立RNG，基础原子/背景流跨四臂相同，所有batch和每事实曝光可恢复。

## 模型与训练

固定L2：2个独立块各循环2次，宽128、4头、GELU、pre-LN、绑定embedding/head、dropout0.1、scaled_effective初始化。随机初始化；AdamW lr1e-4、wd0.1、warmup2000、裁剪1、128000步。沿用现有Loop模型、CUDA Graph与优化器实现，只增加加权损失及配对三流采样。

节点覆盖早期学习和固定终点，见配置。保留0/16k/64k/128k权重，所有评价节点保留逐题答案、EOS、NLL与实际曝光。先做独立16步工程预飞，不能作为科学结果。每个端点从保存权重重载并复算全部评价分组。

## 终点及解释

评价全量单跳及背景/A/B分组、背景和角色训练组合、固定全图留出组合及两条边角色构成的九格、自主逐跳调用。答案正确率、答案+EOS及逐题正确答案概率均保留。测试全集不按模型答对、供体资格或原子掌握筛选；原子均正确条件另报覆盖。训练曲线描述能力形成，不与测试循环数混为同一时间轴。

主角色效应：同一A-A留出池比较A与B；同一B-B池比较B与A，再对两组等权。给每组原始分数与固定全池成绩。原子重复效应分别比较A与repA、B与repB；背景测试用于报告整体训练差异。不能把题目当作独立世界。

开发保留所有臂与未达标模型，用原子、背景和角色训练拟合核查操作，不要求100%掌握作为统一门槛。若128k尚未形成可解释的参照，先按开发证据调整优化/覆盖并另存修订；不由短预算失败断言架构限制。正式种子不在开发期间评价。
