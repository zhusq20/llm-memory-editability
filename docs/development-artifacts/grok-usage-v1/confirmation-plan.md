# 事实组合使用经历：独立世界比较

本计划承接[四臂开发契约](preregistration.md)，在新世界生成和模型评价前封存。用户已授权按研究复盘开展实验。开发结果与确认结果分开报告，不用开发世界补充确认分母。

## 固定比较

三个新图世界146011、146012、146013，每个世界使用初始化14601及A/B/repA/repB四臂，共12条128k训练。保留开发的图规模、全图10%完整查询留出、BG/A/B事实划分、配对采样和L2架构；无超参数、损失、节点或评价规则变化。

每世界A/B从相同权重开始，背景和基础原子流相同；repA/repB与对应角色组合流逐批精确匹配构成事实计数。重复控制每batch实际368行、主臂256行，前者显式监督两个原子答案，不能称等信息或等计算比较。

## 预定结果与统计单位

固定128k为主终点，所有登记节点保留。主指标为同一AA留出池A−B、同一BB留出池B−A，以及两个事实组等权的角色效应；每个世界分别给原始分子、分母及差值，再对世界等权。

重复控制分别给同一AA池A−repA、同一BB池B−repB，两个组等权；不能仅凭差值排除监督位置、梯度信息和背景干扰解释。各臂九格、全池、单跳、训练拟合、自主两次调用、相关原子均正确子集与覆盖同时报告。正确答案概率由逐题NLL指数化后平均。

三个图是独立世界；同图的查询、两个事实组和训练节点不当作独立世界。只有一个固定初始化，不声称跨初始化稳健性；不进行由大查询数产生的虚假高精度显著性检验。数据角色交换在整个训练语料中实施，主张是该语料处理对固定查询的行为因果效应，不能自动定位知识存储位置或唯一神经机制。

## 执行

所有开发端点完成并核查目标操作后，再写入confirmation-lock.json并构造新世界。锁记录开发校准依据、配置、实际源码哈希、12个运行ID。复用相同训练实现，每运行另存实际数据与源码；零模型成绩筛选世界或删除臂。

完成后逐端点重载全部直接评价，并独立复核自主调用、从原始预测复算统计和从独立随机流复算逐事实曝光。保留失败、恢复与低分，不用中途最佳节点替代固定终点。总新增研究预算为12×128k步；100k bioS、日期编辑、更多架构及训练顺序比较不在本轮预算内。
