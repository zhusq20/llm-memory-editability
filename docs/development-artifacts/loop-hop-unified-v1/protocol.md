# 当前多跳对照：统一方案与执行契约

2026-10-16用户明确：仅统一当前多跳对照；沿用四种结构×普通Loop／DiscoLoop八臂，终点测试1–4轮下1–4跳，重点为仅受原子监督的组合；指定物理cuda9。历史状态、轮次条件、编辑实验及三层研究主线均不在本次新增范围。

## 唯一问题与关键比较

任务跳数记k，每轮完整Transformer层数记L，训练循环次数记R，测试循环次数记r，总测试层执行数为Lr。这四个量分别记录，不将循环次数当作跳数。

| 结构 | 普通Loop | DiscoLoop | 关键用途 |
| --- | --- | --- | --- |
| L1R2 | 300k | 300k | 最基本起点；检查两次层计算对更长链的能力 |
| L1R3 | 300k | 300k | 固定物理层参数，增加循环训练深度 |
| L1R4 | 300k | 300k | 同上；与L2R2比较相同四次层执行 |
| L2R2 | 300k | 300k | 固定两轮而增加轮内层数；两层独立初始化 |

三组主要比较：(1)每结构DiscoLoop减普通Loop；(2)L1的R2／R3／R4；(3)L1R4与L2R2。最后一组总执行深度相同，但唯一参数和通道次数不同，不能自动把差异唯一归因接口。每个300k检查点统一测试r=1,2,3,4；测试加轮与按更多轮训练是不同操作。可靠超过R跳支持轮内推进，可靠超过Lr跳支持压缩，但固定预算下失败不证明表示能力下界；本批不单凭可解码性或响应大小给某层命名为某一跳。

## 一套模型和训练口径

宽768、12头的完整原生GPT-2：因果attention、GELU MLP、pre-LN、残差、学习位置嵌入、最终LN和绑权词表读出。位置上限统一为原40k准备版本的1024，实际输入右补齐至6槽；专用符号词表1013项。三种dropout .1。两层独立随机初始化；同L的架构和不同R配对初值。DiscoLoop只在非末轮全部位置加alpha1、温度1、无仿射RMS软重编码通道；连续状态保留。无历史状态、轮次条件、KV增强、辅助损失、中间实体标签或CoT。

每臂300000步，共2400000正式更新；batch512、lr1e-4、warmup2000后恒定、AdamW wd.1、裁剪1、fp32参数及Adam、bf16前向、TF32开启。只监督最终答案和EOS两位置，训练样本流、初值与dropout种子统一。工程每臂32步另计并全部丢弃；正式八臂重新从共同初值开始，不复用工程权重。已有两套准备均无正式训练，未损失正式预算。

固定曝光为主要成本口径，逐类别真实曝光、有效／执行token、唯一参数、执行层数、包含两次词表投影的通道矩阵FLOPs分别记录。L1R4／L2R2不称等参数，DiscoLoop／普通Loop不称等FLOPs。cuda9同卡并行耗时仅作运行信息，不当作独占GPU效率比较。固定300k失败保留，不自动调参或延长。

## 一套终点评价和独立审计

八个终点×测试r1–4×任务k1–4×A/B，共256个核心结果格。两／三／四跳另保留训练诊断。训练过程中在原R保存0、1k、8k、16k、32k、64k、128k、256k、300k的曲线与检查点；不按最终测试分数选最佳检查点或最佳测试轮数。

主评分为全词表答案argmax；自行预测答案后生成EOS的联合分数另报。答案由第一次因果前向得到，第二次前向仅评分EOS，不反馈中间实体。每池保留全部行、原始预测、EOS和NLL。全量分数为主，另报同测试r下必要原子事实正确的条件分数、覆盖率，以及同模型四个r共同前提子集与非重复实体子集。零覆盖为NA，条件分数不替代全量指标。

扫r时仅改测试重复数，不改权重、输入、训练R、最终读出或停止规则；评价前后恢复训练模式和RNG并校验模型哈希。先做原R独立全池重载，再对全部r网格新容器逐题重放：答案／EOS ID一致，NLL及指标容差1e-6。云端取回全部终点网格与审计JSON逐字段核对。训练完成、重载通过和云端核验分别记录。
