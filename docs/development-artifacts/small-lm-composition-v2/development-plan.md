# 完整Qwen：独立复习、文档关联和事实更新的快速开发

用户在2026-10-01（美国中部时间）授权按复盘计划开展快速实验。本批仅为一个既有开发世界的三个呈现条件及六个后续更新分支，不启动18条新世界确认或其它规模。保留v1全部产物。主张层级为完整预训练LM上的受控行为和功能复用，不定位唯一MLP机制。

## 方法依据与问题

上一轮已阅读[Lessons from Studying Two-Hop Latent Reasoning](https://arxiv.org/html/2411.16353v4)§2–4、§5–6及附录B：同文档比较、独立单跳评价、背景组合训练和无CoT回答。其同文档收益可能来自首尾直接关联；原文采用不同模型、问法数、答案限制及监督，本轮不是数值复现。第二阶段借鉴[MQuAKE](https://aclanthology.org/2023.emnlp-main.971.pdf)§2–4的事实更新与推论更新分开计分；本轮使用人工事实和普通全参数微调，不复现ROME/MeLLo或声称严格受约束编辑。

主问题：补齐独立提取后，相关事实共同呈现是否提高两跳？后续问题：只有第二条事实获得新监督时，组合答案是否随之更新？普通单跳满分不作为所有探索的统一门槛；本轮保留低分，但前提失效时收窄解释。

## 阶段A：独立复习与三种呈现

复用v1世界150001、训练种子15001、原始Qwen3-0.6B-Base权重和全部正常架构。64目标链、16背景链；全部参数全序列交叉熵。三臂同512步、0/128/256/512评价，每批同8组原子事实和2条背景组合，另把这8组的两条原子各独立复习一次：

- separate：两条原子始终独立。
- linked：主呈现按正确链拼接，独立复习仍分开。
- shuffled：同一批的第二条原子作随机置换后拼接；排除相同链和相同最终城市，每批重新抽配对。原子本身保持真值，不制造虚假事实。

原子文本及监督词元的多重集逐批相同，主拼接保留各原子EOS及首词元不计分。背景组合完全相同。匹配事实次数和监督数量，但文档长度、位置、padding及attention工作量可不同，尤其置换人名长度可能影响位置；不声称纯语义或等FLOPs干预。无关联臂也可能有干扰，故保留separate参照。城市共享使不相关拼接仍包含其它头实体的正确城市，不能称全局零共现。

共同AdamW参数：lr 2e-5，20步warmup，cosine到2e-6，weight decay 0，clip 1；FP32权重和优化状态、BF16前向、TF32关闭。GPU2依次运行。端点固定512步，不按两跳挑节点。若需校准，另立配置和运行记录。

主评价使用v1训练问法view0，闭卷、贪心、最多16新token、规范化首行完整答案。背景两条单跳也评价。端点补充一个预先固定、从未用于训练的view1问法，并做两个view的自主两次调用：第一跳使用该权重实际生成的首行去末句点作为第二问的人名，不提供gold桥；保存两次输出和解析身份。所有目标题全量保留，共同单跳正确子集另报覆盖。两次调用提供关系分解和额外计算，不能当同条件直接推理。

## 阶段B：仅第二条事实的新监督

在读取阶段A结果前，按城市分层每城市选2条，共32条目标链为E/D；其余32条作为未回放保持U。新城市使用16城市的无固定点双射，保持城市分布且所有目标答案确实改变。城市替换逐问法验证token长度不变。

每个阶段A端点都派生update/replay两臂，不挑成功模型。两者从相同权重开始，均重置AdamW及随机种子15004；不是继承优化历史的原训练续跑。每步8条E第二跳，update提供新城市，replay提供原城市；共同回放4条E第一跳、4条背景原子和2条背景组合。所有记录独立成文档；U完全不参与更新，目标两跳及其新答案不作为组合监督。回放第一跳是已知事实，无新增首跳监督信息。

固定256步，0/64/128/256评价，lr 2e-5→2e-6、warmup10，其余优化/精度相同。主报告E第二跳新答案、D两跳新答案与旧答案保持、E首跳、U两原子及两跳、背景组合，以及端点真实自主调用；两臂都按相同新世界评分，replay另报原世界成绩。父模型和更新后均答对两原子的条件分数只能作为补充，不替代32条全池。

若E没学会或一般任务明显损坏，不把D低分归为唯一接口失败。若新单跳学会而D停留旧城市，支持功能更新传播的限制，但不能证明纯直接记忆；若D跟随更新，支持功能复用，也不能单凭此唯一确定内部计算链。一个世界一个种子不作确认、显著性或规模结论。
