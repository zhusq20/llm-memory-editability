### 18.7 阶段C：共同旧错误与新答案竞争（结果驱动的新冻结设计）

阶段A/B提示：不同新答案的梯度可能先共同压低旧答案。最小参考情形为同一logit向量、两个不同目标a/b：〈p−e_a,p−e_b〉=‖p‖²−p_a−p_b。若p集中在第三个旧答案c，该量为正；若概率集中于a/b且两者都非零，则为负。对目标b的logit-SGD会令log(p_a/p_b)的一阶变化为−η(1+p_a−p_b)≤0。因此“p_a上升”和“a相对b的竞争优势下降”可以同时发生。该式是softmax损失的参考解释，不是Transformer架构特有定理；真实Transformer还包含输入间Jacobian交叉度量，需实测。

先对阶段A/B成熟主条件的288个已执行更新重建相同权重，校验原权重哈希，补充同人派生问题的新默认a、新替代b、旧答案c概率和a−b logit差；单列为读取A/B结果后提出的次要分析，不追改原主终点。使用原标签清单、原梯度因子和原步长，不重新挑案例，不产生新的优化轨迹。

两层最小模型配置`configs/bios-path-minimal-v1.json`。固定32人物、3关系、3值：关系0和1的旧答案均为person mod 3，关系2为(person+1) mod 3；96条孤立事实，全词表答案CE，无EOS损失。模型为标准2层pre-LN/GELU/因果attention、宽度64、2头，沿用共享输入输出嵌入。初始化0/1各用全96事实训练1024步AdamW，lr=0.001、weight decay=0.1，不按准确率延长；报告旧知识达标情况。只作为最小机制开发，不把简单表格记忆称为原关系链任务复现。

对固定人物0/1/2，每个模型分别以关系0为源：coherent更新到a=(旧值+1) mod 3，conflict到b=(旧值+2) mod 3；关系1以a为评价目标，关系2保持旧答案。源每次仅一条事实；关系1/2不进入编辑。只更新第0层MLP down.weight。使用full/no_cross/no_mlp/fixed_qk四臂，干预仅作用于第1层对应分支，均从相同预训练权重重置。每条轨迹512步SGD，lr=0.01、无动量、衰减、裁剪。每步将干预方向缩放到该臂当前状态下真实源梯度的范数；该控制不保证不同轨迹的源改善相同，因此另报告源概率／损失。固定2×3×2×4=48编辑轨迹，24576更新；另有2048预训练更新。

每8步及终点保存源／派生／保持损失、3值概率、派生a−b logit差、真实梯度内积与干预内积，并对记录节点的一步真实损失变化作核验；保留全步源损失及更新范数、终点权重。首个连续两测量点的负迁移内积可作描述性转折；不按转折早停或选择轨迹。比较早期共同改善是否转为竞争、margin是否提前恶化，以及四种反传路径是否改变转折或源改善—保持取舍。若同logit参考公式与真实跨输入梯度不一致，保留该差异，不将softmax参考强行解释为实测路径机制。最小模型生产开始前另存本小节、配置、源码、测试及已完成A/B审计哈希。
