## 核心比较与分析单位

两臂事实图、640原子、256唯一组合链数、逐事实首/次跳组合使用次数、token边际、同世界初值、行索引流和物理计算形状严格匹配。restricted全局8种关系对、两个支持块；broad16种关系对、一个连通块。处理为联合搭配分布改变；不声称只改变一个抽象类型多样性变量。

主要终点：8k时共同strict_test全池完整“答案＋句号＋EOS”正确率，配对broad−restricted。先平均每世界两初始化，再对三个世界等权；同时报告六配对和三个世界的有符号差。不做查询级显著性或挑最好checkpoint。id_test、first_only、second_only和background_neither均为预定次要比较。

strict_test中的目标人物和桥实体不进入任何主臂组合，地点输出值共享；此为跨事实链迁移，不是全部token都未见的泛化。共同首尾实体对留出由两主臂和64条预定positive参考链的并集确定；确认不训练positive，其参考链只定义共同保留对，与开发生成器一致。报告每世界strict_test对512条完整目标路径的覆盖，另对两主臂的全部512条目标链保存自由生成与自主两次单跳，作为预定次要全池复核。未按模型表现筛样本。

全池答案、格式、正确答案概率、相关两原子都正确的子集与覆盖、自主调用完整/路径正确率均保存。首跳错误或输出异常不删题。两个方向的混合角色独立报告；固定restricted支持内/外的关系对在两臂使用相同分组。后两项在开发时增加，确认前冻结，不能称开发预注册。
