# AlphaEdit在现有DiscoLoop上新增原子事实

本批由用户明确授权实际执行。问题是：只编辑MLP down projection，用新原子事实写入，在不监督更新后两跳答案的条件下，新知识能否参与新→旧、旧→新组合，旧知识保持多少。这里检验方法在现有合成知识图模型上的行为，不先改变架构，不进行新的基础或写入器外层训练。

## 起点及历史去重

加载`discoloop-success-restore-v1`原配方300k独立复建终点，宽768、四个物理块、循环两轮；检查点SHA256为`56d17cedf29db93c713e7ec118b55955118dfd54085aa5240806aee14401f671`，基础门槛与模型摘要必须通过。历史原权重不可用，不能称恢复了历史权重。不加载common/single/stream适配。冻结全部基础θ，保存独立增量A，实际计算为每轮共享的`W_down+A`；up、bias、attention、embedding、LN等不改变。

复用`ttcd-novel-fact-transfer-v1-panel.json`的8开发、32正式事实及正式新→旧256、旧→新253题。每个新(h,r)在原世界不存在，t使用原词表实体，旧图真值不覆盖。原TTCD批次和CE原型均未执行本方法；已有分步及逐轮读出是参考，不重复提交旧训练。与此前裸300k TTCD比较同时改变了写入目标和方法，不能归因于零空间一个因素。

## 原论文依据及必要适配

依据[AlphaEdit原文](https://arxiv.org/html/2410.02355v3)§3、§4、附录A.3/B.1/C.7及[作者实现](https://github.com/jianghoucheng/AlphaEdit)。作者的`AlphaEdit_main.py`、`compute_z.py`、`evaluate.py`、GPT2-XL配置和MIT许可原字节保留于`author/`并计入冻结哈希。

保留原算法两步：①冻结模型，以新尾实体CE＋旧分布KL＋latent范数惩罚，用Adam拟合目标块输出z*；②重算当前键和目标残差，分配残差并求AlphaEdit零空间约束的down增量。不是将普通CE梯度投影后称作原AlphaEdit。

- 原配置的target预算为20次目标前向、最多19次Adam更新，lr=.5、KL=.0625、latent正则=.5、范数上限=.75×原状态范数、总损失<.05提前停止。只监督新尾实体，EOS参与生成评分，不新增EOS目标损失。
- 本合成原子输入没有自然语言上下文扩写。采用原生单跳[h,r]这一种上下文；定位在能因果看到h和r的关系位置1，而非只能看到h的subject位置0。KL用同一h的最多两个原有原子查询，不用新两跳问题或答案。
- 明确选最后一轮、最后物理块的输出作为z*位置；获取每个物理块在最后一轮的原子关系位置键。每次更新一个物理down后，重新前向取下一块的键及最终目标残差。真实参数共享，因此增量同时在较早轮执行；不假装八次执行有八份独立权重，不承诺所选晚轮键代表首轮读取。
- 每事实从A0独立写入，历史编辑cache_c=0；不做连续编辑或merge。该条件下作者求解`solve(P K Kᵀ+λI, P K Rᵀ)`与实现的小矩阵求解严格代数等价，CPU测试直接对比作者公式。模块保留完整残差、归一化、causal attention、GELU和DiscoLoop软通道。

这些是循环共享结构及合成数据所需的适配，不称原自然语言基准复现。目标向量能诱导新答案，也不保证将其拟合成共享参数后能达到同样效果。

## 旧知识保护及开发校准

种子固定、只按世界行索引抽样。先确定正式与开发旧题，再抽取4096旧原子、4096原训练II组合作为保护输入。保护统计覆盖所有有效非padding位置、两个循环轮次、四个物理down，使用**平均未中心化二阶矩**。取特征值<.02的方向为数值零空间，沿用作者GPT2-XL配置，不用95%能量截断替代。报告各层空间维数、谱范围、增量范数和投影外残差。若无可写方向或写不成功，保留结果，不以此直接证明组合能力上限。

开发旧题为七池各32道，正式扩展旧题为七池各128道；池名atomic_id/atomic_ood/train_ii/test_ii/test_io/test_oi/test_oo。两者及继承的U64+64与保护统计分离；正式旧题不进入KL或配方选择。保护统计可包含已知组合状态，但写入损失没有任何更新后组合标签，也没有旧组合回放梯度。

8开发事实各拟合一次目标，复用同一z*比较λ=10/1/.1（原配置为10）。只有新原子答案+EOS和七池旧保持用于选择，**不读取开发新两跳成绩**。若候选七池最差的原正确题保持≥99%，在合格候选中先取原子成功最高、再保持最高、再λ较大者；若都不合格，取保持最高者并明确门槛未满足。正式32事实不得重新调参、换事实或加步数。这是一张已观察世界上的开发，非盲新世界确认。

## 正式读出及分析

每事实在同一A下分别评测新原子、新→旧、旧→新；所有推理输入重新开始，没有事实记录、历史KV或隐藏状态。原始答案、EOS、阶段argmax/真值概率/排名、必要旧后继与前驱、原配对旧事实及旧组合、继承U池与七池扩展保持全部保存。答案+EOS为主评分。

全量结果优先，再报告“新原子已写成、旧前提仍成立、内部桥正确”等条件交集及覆盖；零覆盖为NA。模型自行分成两次单跳调用只作额外计算参考，桥由模型自行预测，不补真桥。逐轮解码是观察，不是唯一因果机制证明。

保持同时报告写前/写后准确率及写前正确题保留率。每池128旧题在32独立编辑状态下重复检查，不称4096个独立事实。以新事实为统计单位，配对fact bootstrap 10000次，种子2026101603；一张图、一个初始化，不宣称普遍优势或最优效率。
