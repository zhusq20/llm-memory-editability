# 每轮层数 × 循环次数：普通 Loop / DiscoLoop 开发实验

2026-10-16 用户明确授权开展前一轮提出的四结构、两架构比较。批次 `loop-hop-development-v1`；尚无结果时不写机制结论。本协议先于本批训练冻结。

## 问题与矩阵

主要问题：事实组合的可学深度更随循环次数R变化，还是随完整Transformer层执行次数LR变化？本轮只能建立受控行为证据，不证明架构深度下界，也不由读出单独证明逐跳因果计算。

|---:|---:|---:|---|---|
|1|2|2|一条|一条|
|1|3|3|一条|一条|
|1|4|4|一条|一条|
|2|2|4|一条|一条|

八条从头训练，共2,400,000次科学更新。每条另有32步工程短训练与一次丢弃的CUDA预检查更新；短训练均从独立构造的第0步权重开始，不传给科学训练。先完成固定镜像CPU契约、全部八臂CUDA预检查/短训练/新容器重载，才能启动正式300k。

单层固定参数比较1×2/1×3/1×4；相同执行层数比较1×4/2×2。后一对有独立参数量及轮间接口次数差异，不唯一归因接口。每结构内普通Loop与DiscoLoop逐张量相同初始化，只有对齐通道开关不同。两层块各层独立随机初始化，不复制成相同初值。

## 来源、复用与历史去重

- [DiscoLoop](https://arxiv.org/html/2607.00341v1) §2–4及附录A.2：事实存于参数、实体不重叠双图、图B仅原子训练、混合跳数、软解码后重新嵌入。原三跳设置K=3，未分开L与R。
- [Loop, Think, & Generalize](https://arxiv.org/html/2604.07822) §6及附录B/K：借鉴每关系为随机置换的数据构造，避免长链只依赖末尾关系。该论文同时发现过多迭代会退化，故不预设增加R必有益。
- 复用已验证 `SupervisedAlignmentGPT`、`AlignmentStep/GraphStep`、原生GPT模块、AdamW、合并样本流、bf16/TF32及答案+EOS监督。旧源码不改，另写可变跳数数据与执行入口。
- `strict-loop-hop-audit-20261012`已有普通单层两次的部分三/四跳回答，但为旧小图/子路径可能出现的设计，不能代替当前严格图B结果。`loop-block-depth-v1`固定四层增加R已完成且非单调；不重启。当前改变L与R、增加DiscoLoop配对及双图置换任务，新增问题明确。

这是受控扩展，**不是**原作者数据的逐字节复现：不同于原A.2的500实体/50关系/出度10，本批每图500实体、10关系，每关系为随机双射；每图仍5,000原子事实。也不是当前Wang2000实体旧图的续训，不复用旧训练权重。采用专用符号词表1,013项，不携带50k自然语言词表。

## 数据与隔离

一个新开发世界 `2026101601`，其中两图A/B各500实体、共享10关系，实体不重叠。每个关系分别独立生成随机置换。两图全部10,000原子事实训练；图A两/三/四跳各10,000唯一查询，共40,000训练样本。没有中间实体标签、CoT、额外KV或控制分支。

每长度的图A留出和图B严格测试，各随机冻结10个关系序列，并在全部500起点上评分，共每池5,000题；图A相同完整查询从所有本长度训练支持中排除。图B所有子路径均不参与组合训练。固定任一测试关系序列，500答案是500实体的一个排列，任何忽略起点的关系序列/后缀答案分类器最优只有1/500。跨长度图A子路径可出现，图B严格池为主要证据。所有必要原子都在训练集，但是否真正学会需要实际测量。

评估池：全部图A/图B原子各5,000；各长度训练诊断各1,000、图A留出各5,000、图B各5,000，总43,000题。原始行、原始答案/生成EOS与NLL全量保存，原子正确覆盖及无重复实体子集均另报，不删失败。

## 模型、监督和预算

完整GPT-2 preLN因果attention、GELU MLP、两条残差、原生最终LN及绑定词嵌入。宽768、12头、位置上限1024、学习位置嵌入，三种dropout均0.1。原子/2/3/4跳分别右补齐到6个输入槽；只监督最终答案及EOS两位置。主要评分全词表答案argmax；生成答案后再预测EOS的联合分数为次指标。答案标签不会通过因果attention泄漏到前一预测位置。

DiscoLoop固定alpha=1、temperature=1、RMS eps=1e-6，只在非最后一轮之后、所有token位置加入绑定词表软重编码通道；原连续状态完整保留。普通Loop关闭该通道，其余计算相同。

初始化 `2026101602`、样本流 `2026101603`、dropout seed `2026101604`。每条300,000步，batch512，AdamW lr1e-4、warmup2000后恒定、wd0.1、梯度裁剪1，fp32参数和Adam状态、bf16前向、TF32开启。相同R/架构不假定逐位置dropout掩码一致。一个图/初始化为开发结果，未授权自动新增种子、世界或调参网格。固定预算结果失败也保留，原子前提未学会时不能归因组合或表达能力不足。

评估/保存节点：0、1k、8k、16k、32k、64k、128k、256k、300k。逐样本曝光、有效/执行token、总/激活参数、基础矩阵及通道矩阵FLOPs、耗时分别记录。同曝光主比较不称同计算预算；1×4/2×2还存在参数差异。CUDA capture的参数、优化器及RNG恢复通过预检查；运行时再次核验第0步参数。

## 读出与解释

审计通过后，固定取每个图B池前256题，用实际前向的原生模块hook记录各完整层后、轮间接口后的状态，以原LM head读出各前缀终点；不训练探针。记录与未观察前向完全相同的最终logits，并核对最后层完整残差状态及参数哈希。读出可见性不等于因果使用，也不能由读不出来证明信息不存在。

接口位置对照、因果前缀替换、编辑传播及更长k为后续解释条件，不在本八臂科学矩阵中自动追加。
