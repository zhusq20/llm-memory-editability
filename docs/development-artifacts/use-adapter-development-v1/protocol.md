# 用途适配：实体形式逐条写入＋共享用途更新（开发）

## 状态

- 2026-10-20用户授权（[roadmap §4](../../roadmap.md#next-experiments)“用途练习与实体形式写入结合”一行）。本协议在启动训练前写定，包括预定比较与判读规则。
- 基于[知识调用接口v2](../knowledge-read-interface-v2/protocol.md)已保存的E3 Structural写入与E4设置；v2的结果与归类不改。

## 1. 问题与假说

**问题：** 事实的学习与用途的学习能否分开做？事实逐条写成实体形式的新增参数（E3 Structural），用途只学一次：在少数事实的用途练习上训练一个跨事实共享的更新。

**已有证据：**
- E4：在M2（答案形式写入）之上，少数事实的用途练习能迁移到没练过的事实，修复的主要是“操作被覆盖”（答v），直接回答仍低（0–.19）。
- E3 Structural在Qwen3.5-2B上写在前段，第一跳直接U2为.35–.58，答v≈0；Qwen3-1.7B写在后段，是答案形式。

**假说（待检验）：** 两者结合后，留出事实的使用（包括直接回答）好于任一单独做法。

## 2. 设计

**模型与事实：** Qwen3-1.7B、Qwen3.5-2B；开发集与第二事实集。每个“模型×事实集”取v2已保存的E3 Structural写入（50条事实，`e3/structural-adapters.pt`），按`facts.json`中已有的F_adapt/F_test标签划分。各组F_adapt（即被练习的事实）为22/26（1.7B 开发/第二）、23/29（3.5-2B）。E3学习率沿用v2所选（1.7B 1.5e-3，3.5-2B 1.5e-4），不重做、不重新校准E3。

**底座：** 原模型＋该组50条E3写入。本实验中E3写入冻结（不是参数，不进优化器）。

**三臂（除F_adapt附加数据外完全相同）：**

| 臂 | 训练 | F_adapt附加数据 |
|---|---|---|
| P-0 | 不训练，只评测 | — |
| P-U | 对原模型全部权重做一次共享更新 | E4-U的用途练习：大洲、官方语言两个操作，每操作2个直接＋2个分步，金标答案，模板与格式同E4（每条事实8个） |
| P-P | 同上 | E4-P的单跳改写，数量相同（每条事实8个） |

**两臂共有：**
- U0单跳回放：50条事实各1个U0问句（“What is the R of h? Answer with only the name.”→v，即M2模板0），金标v。
- E4的KL回放：直接复用v2 `inject/e4u.json`中的`replay_pool`（原模型对自然问题的回复），对冻结原模型（不含E3写入）做KL。
- E4训练循环：每步8条新事实样本＋8条回放，答案token交叉熵与回放KL之和除以答案token数；AdamW，学习率3e-6，前10步线性预热，梯度裁剪1.0，weight decay 0；随机种子同E4（`S.SEED+2`）。两臂样本数相同，因此每步抽到的位置与回放完全相同。
- **固定步数：** 等于该组E4-U的实际步数（v2 `inject/e4u.json`）：1.7B 400/400，3.5-2B 360/320（开发/第二）。不使用U0停止规则（E3写入已使U0≥.96）。每20步记录U0教师强制，只作记录。

**这一设计带来的曝光差异：** 新事实数据流只有50＋8×|F_adapt|条（226–282条），固定步数下每条样本约见9–14次；E4的数据流含全部事实的24个单跳问句，每条约见1次。P-U与P-P相同，不影响主比较；与E4-U的比较须记住这一差异。

**评测（与E3、E4同一代码与模板）：**
- E4矩阵：F_adapt/F_test×{大洲、语言（练过）、国家＝U2、货币（留出）}，直接与分步；答案类型分为正确/答v/答h自己的属性/其它。沿用E4的筛选：只计该臂U0答对的事实；非国家操作只计取值通过操作筛选的事实。F_test按主语是否另有被练习的F_adapt事实分两组。
- U0、U1、U3直接与分步，捷径题，U2答案类型（`S.evaluate`）。
- 保持：E3所用的300条无关自然问答（`E3.retention_rows`），以及h与v的自然事实与自然两跳（相对原模型答对者）。
- 成本：步数、监督token、处理token、可训练参数、FLOPs估算、耗时。
- 一致性：P-0重新生成的回答与v2保存的E3 Structural评测逐行对照。

## 3. 预定比较（运行前写定）

1. **主比较：** P-U − P-P，在F_test×国家与F_test×货币上，直接与分步分别判读。“改善”＝按事实配对bootstrap 95%区间下界>0（E4的规则）。另按E4的预定表给出判读行。
2. **描述性：** P-U对P-0、对已有E4-U（`e4/ops-e4u.json`，取同一批50条事实，另报E4全部事实）。问：直接F_test×国家是否同时高于E3单独与E4-U？
3. **答案类型：** P-U相对P-0是否降低“答v”（F_test×国家/货币，直接与分步；按事实配对bootstrap）。

**判读：**

| 结果 | 含义 |
|---|---|
| 主比较改善，且直接F_test×国家高于P-0与E4-U | 事实与用途可以分开学，结合优于任一单独做法 |
| 只有分步改善，直接不高于P-0 | 共享更新只修复操作覆盖，实体形式写入的直接使用没有因此提高 |
| 主比较无改善 | 在实体形式写入之上，用途练习没有超出数据量对照的收益 |
