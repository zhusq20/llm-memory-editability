# 固定调用过程后的新知识组合：开发契约

2026-10-01。用户已授权按本轮讨论执行实验。本轮只比较普通事实交叉熵和交叉熵加统一输出表示约束；不扩大层数、供体或任务矩阵。

## 问题与主张

在A事实上学到的两跳调用过程冻结后，换入只靠B原子事实独立训练的MLP，能否正确回答B的两跳？主要比较B单跳与B两跳的端到端正确率。希望建立的是受控模块模型中的功能复用及表示约束效应，不是自然预训练机制或精确向量对齐的必要性。

## 方法来源

本轮讨论已阅读《MLPs are Hebbians》§5、A.1.2、A.4.3、A.4.5（https://arxiv.org/html/2607.10034v1），直接复用锁定作者实现的SwiGLU和Transformer块。A.4.3固定读取器并替换独立事实MLP，A.4.5以完整向量目标改善模块调用。本轮沿用固定词嵌入、单位范数MLP入口、无残差、固定V/O为单位阵的受控架构，扩展到两层和共享事实MLP。

《Lessons from Studying Two-Hop Latent Reasoning》§3.2、§6（https://arxiv.org/html/2411.16353v4）提出输出/输入失配假说，但桥实体辅助对齐并未迁移。因此不将向量相似或辅助损失下降作为主要机制证据。已有单跳CE/MSE替换均成功，已有手工连续两跳也成功，本轮新增的是有学习的注意力调用和冻结后的新事实替换。

## 最小任务与架构

为缩小问题，先固定一种关系，测f(f(h))，不测试关系选择或任意多跳。每世界128个实体、随机单位向量词嵌入，A/B各为实体集合上的独立随机排列。B与A逐事实不同；两跳答案偶然相同的情况保留并另报真正改变答案的覆盖。实体词表固定，属于新事实映射而非新词迁移。

输入为18个随机中性token、一个随机插入的实体h、末端固定查询token。不输入中间实体或答案，全部因果注意力。两层各一个头、宽64，注意力Q/K通过训练学习选择；V/O固定为单位阵，无位置编码、无残差。两层调用同一个冻结的带偏置SwiGLU事实MLP，宽256。层间保持连续状态，无argmax回送。中性及查询token的MLP目标为自身，固定两臂相同的结构支撑。

MLP先以所有原子映射拟合A。CE臂损失为CE(M(e)E^T,y)；aligned臂额外加10乘以逐样本向量平方误差之和的平均值。目标向量来自同一冻结词嵌入，无组合标签。普通CE允许输出尺度变化，两层的MLP入口及读出均归一化，注意力入口RMS归一化，因此不能仅凭原始输出范数解释结果。

冻结A记忆，只训练两个注意力层的Q/K。第一层查询位置使用全部实体的A单跳答案监督；第二层只在预先抽定的75%头实体上监督A两跳。两种损失等权，归一化读出乘固定20。另25%头实体的A两跳从不进入优化；它们的原子事实仍训练。训练采用所有128头实体的平衡batch，每步重新采样中性上下文。最终调用过程冻结后，再独立拟合B记忆，并同时替换两层的共享MLP；B两跳不参与优化、停止或节点选择。每个端点在每实体8个独立中性上下文上评价。

## 配对、预算与评价

开发世界149001，初始化14901，两臂。每臂A/B记忆各10000步全批Adam、余弦学习率1e-3至1e-6；读取器4000步AdamW、lr2e-4、weight decay0.1。同世界几何、A/B映射、头实体划分、模型初值和上下文流相同。指定全部节点保存，固定最终端点，不按B效果挑节点。

主指标为实际完整词表的单token答案准确率：A训练/留出两跳、B全部单跳和两跳。固定输出长度为一个实体token，不涉及自由文本EOS。另报精确键的记忆读出、保留错误A记忆时对B标签的成绩、两跳答案实际改变子集及覆盖，以及两条相关B单跳均正确子集及覆盖。所有全量分数保留。

开发先检查原子记忆、原A组合训练及留出、B知识写入、冻结参数保持。若必要前提不足，可在本开发世界调整两臂共有的训练设置或任务负载，须另存版本和原因，不隐去失败，不能为了制造CE/aligned差距调参。开发不进入确认分母。确认使用三个新世界及两个初始化，配置在生成和查看确认结果前单独冻结。

相同世界的上下文、初始化和多个节点不当独立世界。报告世界等权均值及逐世界/初始化结果，不将大量查询当作显著性样本。若两臂均成功，不能宣称精确向量对齐必要；若原A两跳前提不足，B低分不能独立解释为替换瓶颈。

## 工程核验

核验输入无答案、排列真值、全池与训练留出不重叠、两层真正共享MLP、只有Q/K更新、B标签不进入读取器优化、初值与数据流配对、替换及保存重载保持。保存源码及作者commit、全部预测、节点、参数、环境与成本；新输出独立存放，不覆写历史批次。测试只覆盖会影响结论的这些契约。
