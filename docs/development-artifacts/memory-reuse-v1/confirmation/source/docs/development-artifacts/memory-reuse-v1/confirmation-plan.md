# 固定调用过程、替换新知识：正式比较

2026-10-01，在正式世界生成和结果查看前冻结。本轮执行用户授权的两臂实验，沿用[开发方法](development-plan.md)及[来源任务校准](calibration-plan.md)，不增加局部消融。

## 冻结决定

初版开发两臂采用75%来源头实体组合训练；开发后为消除不必要的嵌套泛化，把A的全部128个头实体纳入两跳训练。复用四个已拟合事实MLP，仅新增两个4000步读取器。校准CE/aligned的A单跳均100%，A两跳98.44%/100%；B单跳100%/99.61%，B两跳55.66%/92.68%。A与B评价使用独立于训练的中性上下文。保留原开发及校准全部结果；开发不进入正式分母。来源尚存小量错误，不要求每个正式模型达到满分后才保留。

正式保持校准模型、损失、全部超参数和预算；不依据正式世界结果修改。A评价是已训练组合的新上下文；B评价是没有任何组合监督的新事实映射。

## 唯一主要比较

CE与CE＋10倍完整向量平方误差，除此以外逐世界/初始化配对。事实MLP先独立拟合A单跳，冻结后仅训练两层注意力Q/K；随后冻结调用参数，独立拟合B单跳，替换两层共享事实MLP。新记忆同时改变两跳所用的映射。B两跳从不用于训练、早停、超参或节点选择。

B使用同一实体词表和单位向量，随机重新排列关系值，并以每条原子事实都改变为采样条件。因此B并非统计上无条件独立于A；三个随机世界相互独立，B记忆拟合不访问A的组合标签。不能称为新实体词表迁移。仅一个关系f连续使用两次；不推广到任意关系组合。

## 矩阵与预算

三个新世界149011/149012/149013，每世界两个初始化14901/14902，各CE和aligned两臂，共12个正式运行。每运行A/B事实MLP各10000步Adam，完整原子及结构支撑监督；A读取器4000步AdamW，每步128个头实体，单跳/两跳损失等权。固定最终4000步读出，保留0/100/500/1000/2000/3000/4000节点。固定18个中性上下文token、宽64、MLP宽256、两层单头；完整配置见`configs/memory-reuse-confirmation-v1.json`。

正式新增24个事实MLP及12个读取器，240000次记忆更新和48000次读取器更新。每模型单跳/两跳均在128实体×8独立上下文上评价，读取器不接收任何真值中间实体；层间状态保持连续。GPU2、FP32且TF32关闭；最多三运行并发，不把并发进程计时相加解释为独占GPU墙钟。

## 主指标与解释

主指标：固定A读取器换入B后的全池两跳答案正确率。主图同时展示A两跳和B单跳，避免忽略来源能力与新知识写入。全部评分为完整词表上的单实体token分类，不称自然文本生成。A/B原子精确键、保留错误A模块对B标签的表现、真正改变两跳答案的子集及覆盖均另报。

先平均每世界两个初始化，再对三个世界等权；保留全部六个配对差及三个世界差，不把上下文、查询或初始化当作新增世界。另报两臂共同“两条B单跳都正确”的固定查询交集及覆盖；该交集是处理后条件分析，不替代全池。原A误差与替换后变化分别展示，不能把所有目标差异归于一个局部接口或唯一内部机制。

如果aligned在B两跳有稳定改善，支持本受控框架中这一训练约束改善事实可复用性；它同时改变事实MLP的函数形状和A读取器的学习过程，不能唯一归因为余弦方向或宣称必要性。若两组都成功，保留CE亦可复用的证据；若差异不稳定或前提不足，原样报告，不补世界或调参数追求显著。
