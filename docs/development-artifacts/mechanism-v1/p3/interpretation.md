# P3 高例外率：固定人员配对结果与解释

正式状态：12/12 低比例—高比例训练配对完成；72 个学习节点配对与 24 个两步链配对通过完整来源、训练配置、初始化、数据日程与预测审计。`audit.json`、`interpretation-audit.json`、`component-audit.json` 均为 `complete=true`。本报告不包含编辑实验，也不读取 P4 结果。

## 设计与比较单位

宽度 256，约 758 万参数；2 个合成世界 × 2 个初始化 × 3 种组织方式（公司、项目、neither），每种比例 12 个模型。高比例将两条链中每组的例外人数从 2/32 增至 16/32。低/高条件使用配对初始化、同一训练预算和样本暴露日程；基础关系、派生问题 ID、提示及目标保持固定。新增例外通过置换实际城市制造，原例外的事实不变，全局实际城市标签直方图精确保持。

主要分析固定同一批 heldout 人员：每链原例外 64 人、新增例外 448 人、仍普通 512 人。新增例外在低比例条件原为普通人员。各表保留 12 个模型 × 2 条查询链的 24 个比较单元及其 world/seed/组织身份；同一批人员在不同模型中重复使用，不能视为独立查询复制。本报告与图均不提供 query 级置信区间。终点为 15,360 步，所有答案按完整值与 EOS 判定。

## 直接查询与自主两步

以下为 24 个模型—查询链单元等权平均，单位为百分比；变化单位为百分点。

| 固定 heldout 人员 | 直接：低比例 | 直接：高比例 | 直接变化 | 自主两步：低比例 | 自主两步：高比例 |
|---|---:|---:|---:|---:|---:|
| 原例外 | 41.1458 | 78.7760 | +37.6302 | 97.4609 | 98.6979 |
| 新增例外 | 98.7630 | 78.4040 | −20.3590 | 99.2001 | 98.5119 |
| 仍普通 | 98.7386 | 94.8730 | −3.8656 | 98.9827 | 99.0885 |
| 全体 heldout | 95.1497 | 86.6618 | −8.4880 | 98.9827 | 98.8118 |

原例外 24 个配对单元中 23 个提升、1 个持平，无下降；新增例外 24 个均下降；仍普通 2 个提升、22 个下降。原例外的自主两步与直接查询差距由 56.3151 缩至 19.9219 个百分点。全体人员的直接准确率下降 8.4880 个百分点，不能把原例外改善称为总体性能改善。

自主两步先由模型生成组织，再将其预测组织送入根事实查询；输入不使用真值桥接。每步均要求值与 EOS 完整正确。两次调用增加推理计算，且错误组织可能共享城市，因此两步最终正确不等价于模型单次前向采用了正确内部组合路径。

## 原例外：答案变化不是遗忘实际事实

| 同一批原例外的直接答案构成 | 低比例 | 高比例 |
|---|---:|---:|
| 正确 default | 41.1458% | 78.7760% |
| 错答该人的 actual | 48.9583% | 5.9896% |
| 其他错误（含未正确终止） | 9.8958% | 15.2344% |

actual/default 冲突在原例外中始终存在，以上三类互斥且覆盖全部查询。actual 错答在错误中的份额由 83.1858% 降至 28.2209%，但原例外的 actual 基础事实准确率同时从 96.0286% 升至 98.1120%。成员关系从 97.3307% 升至 98.6979%，根事实从 100.0000% 至 99.8698%，两项前提同时正确从 97.3307% 升至 98.5677%。这些基础知识测量覆盖相同人员，未按训练后的正确性筛选。

根事实测量按真值组织索引原始独立基础查询，仅用于描述模型是否掌握该事实；它从未作为自主两步推理的输入。该指标按人员加权，同一组织的 root 可重复计入，人员数不能视作独立 root 查询数；全体基础池另行按独立查询计数。world 0 的原例外 actual 准确率为 95.1823%→98.9583%，world 1 为 96.8750%→97.2656%。因此，actual 错答下降不能简单归因于同人 actual 知识丢失。

| 新增例外 | −19.6987 pp | −21.0193 pp |
| 仍普通 | −3.6296 pp | −4.1016 pp |
| 全体 heldout | −7.9346 pp | −9.0413 pp |

两条查询链平均的组织收益定义为该组织方式减去 neither。全体 heldout 中，公司组织收益从 +1.6846 增至 +6.5552 pp，项目组织从 +1.9653 增至 +7.1533 pp。高比例下两世界均为正：公司组织 world 0 / 1 为 +8.3252 / +4.7852 pp，项目组织为 +3.9307 / +10.3760 pp。因此，这一平均收益并非只出现在与训练组织匹配的一条测试链。

匹配交叉效应定义为：0.5 × [(公司组织的公司查询 − 项目组织的公司查询) + (项目组织的项目查询 − 公司组织的项目查询)]。全体 heldout 的效应为 1.6479→2.2339 pp，但 world 0 从 1.7090 降至 1.2207 pp，world 1 从 1.5869 升至 3.2471 pp，不能声称两个世界都加强了匹配收益。原例外固定人员上的匹配效应为 25.3906→3.1250 pp；world 0 为 25.3906→0.3906，world 1 为 25.3906→5.8594，均明显减弱。完整组织 × 查询链 × 世界/初始化的结果保留在归档 CSV。

## 支持范围与下一步

本实验支持以下受限解释：训练数据中 actual 与 default 的相关性会影响原例外派生查询中对 actual 的错误依赖；当这种相关性降低时，同一批原例外的正确组合答案增加，同时 actual 知识仍然可被独立提取。这与“模型有可用基础知识，但单次派生查询偏向相关的实际属性”的假说一致。

本实验尚不能唯一识别模型内部路由：增加冲突也改变条件分布、联合相关性与学习难度，且高比例总体直接准确率下降。自主两步揭示基础能力可用，不证明单次前向已实现同样算法。两个开发世界上的一致方向仍不是新世界确认。下一步适合执行预设的编辑对照，检验相关性变化是否改变冲突更新传播；以及执行组织 × 上下文阻断对照，隔离跨记录注意力与其他训练组织因素。上述后续实验结果不属于本报告。
