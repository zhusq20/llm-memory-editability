# Context 对照：结果解释与确认范围

完整审计已通过：12 个训练配对、72 个直接预测节点配对、24 个终点两步链配对，缺失与组织块不完整均为零。逐文件来源在分析后重哈希；启动前门控引用的 P0/P1/P2/P3 审计及源码身份一致。所有分析保留固定人员与全部组织/世界/初始化，没有按结果选择子集。

删除训练文档内跨事实的注意力以后，基础知识学得更快、更完整，但原例外的单次派生查询更差。15360 步时，原例外直接准确率由 41.1458% 降至 20.9635%；错答该人的 actual 从 48.9583% 升至 72.0052%。与此同时，同一批人员的 actual 基础事实由 96.0286% 升至 99.0885%，成员事实由 97.3307% 升至 98.6979%，人员加权对应根事实均为 100%，自主两步由 97.4609% 升至 98.7630%。两步与直接查询的差距由 56.3151 增至 77.7995 pp。这排除了“阻断后单纯因为缺少基础事实而导致例外更差”的简单解释。

原例外直接准确率变化在两世界分别为 −17.7083 与 −22.6562 pp。24 个模型—查询链配对中，21 个下降、2 个上升、1 个持平；不能将均值说成所有模型都下降。该差异在预定中间节点已出现：5120 步 38.9323%→24.7396%，10240 步 40.1042%→23.9583%。所有中间节点都是 direct 结果，只有终点有自主两步。

全体基础事实在 5120 步为 78.7190%→97.5987%，10240 步为 93.6289%→99.6402%，终点为 97.4180%→99.8208%；终点 value NLL 为 0.148024→0.009732。因此，不能把这个干预当成“只改变组合路径、知识习得和优化完全不动”。基础知识学习轨迹显著变化，是解释上下文作用时必须保留的因素。

组织优势随注意力阻断而大幅缩小。全体 heldout 的组织匹配交互为 1.6479→0.3052 pp；原例外为 25.3906→−0.5859 pp，两个世界分别从 25.3906 降至 −5.0781 和 +3.9062 pp。公司/项目组织相对 neither 的两链平均收益为 1.6846/1.9653→0.3052/0.1465 pp。不匹配测试链收益为公司 0.8789→0.2441 pp、项目 1.1230→−0.0977 pp。完整 world/seed/组织/查询链分解保留于 CSV。

这些结果说明，在当前预算、模型和合成世界中，训练时跨事实注意力对于观察到的较大组织收益发挥了作用。它们不构成对某个唯一内部电路的定位，也不是排除了优化因素的中介效应识别。阻断同时改善了独立事实学习、加强了 actual 错答并削弱了例外组合；残余组织差异还可能来自批次梯度相关性、绝对槽位等因素。该实验支持“可用事实知识和实际选用的派生答案规律可以分离”，不能把基础记忆准确率当作组合能力的充分代理指标。

全体 heldout 直接准确率为 95.1497%→94.2546%，下降仅 0.8952 pp；普通人员则从 98.7500% 升至 99.1406%。原例外只占 heldout 的 6.25%，因此总体平均掩盖了其 20.1823 pp 的下降。这也是继续使用固定人员分层和答案构成指标的理由。

独立确认建议：值得确认窄化的 H2 行为命题——改变 actual/default 的训练相关性，会改变同一批原例外的单次组合表现与 actual 错答依赖，即使基础事实仍可独立提取。应以新世界为独立推断单位，保留种子、组织及编辑支持集的配对结构；共同报告原例外收益、全体准确率代价、基础知识/NLL、自主两步及 coherent 编辑代价。当前证据不支持把下一阶段命名为“原组织内部中介已获确认”，也不自动触发自然语言扩展。此建议不启动任何确认训练，不生成新确认世界。
