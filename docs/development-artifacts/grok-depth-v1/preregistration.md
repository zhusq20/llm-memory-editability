# 小Transformer组合能力的形成：开发与确认契约

2026-09-30，用户授权执行。结论层级：受控训练中的知识组合泛化，以及深度与学习所需预算的关系。不是自然大模型机制、参数编辑或普遍深度下界。

## 原论文方法与微型化

复用Wang等《Grokked Transformers are Implicit Reasoners》§2–3与作者仓库提交734ca654ec7a71dd6737d640407fac14491d538c。方法及代码逐项对应见literature-alignment.json；MIT原文和上游关键源码保存在data/grok-depth-v1/source。数据生成沿作者composition.ipynb的随机关系图、按原子边95/5划分、全部原子训练、仅ID+ID链抽取组合训练；混合链不纳入，OOD+OOD只作次要描述诊断。

微型化适配：128实体、16关系、每实体8条不同关系，宽128；紧凑词表替代GPT2基础词表；ID链先随机留出10%（原文0.5%，小世界需足够分母），phi=6即训练组合数/ID原子数。此高组合占比用于先校准成功，可能没有明显延迟grokking，不将任何泛化提升都称作grokking。世界仅按预定种子产生一次，不按结果或图属性筛选。

保留GPT2的pre-LN、GELU、4倍宽MLP、绝对位置、绑定输入输出、偏置及标准随深度缩放的初始化；dropout0.1覆盖embedding、注意力与残差。输入[h,r]或[h,r1,r2]，没有BOS或答案分隔符；只监督尾实体和EOS，PAD与EOS不同。普通因果Transformer从头训练，无预训练知识或显式中间答案。完整精度FP32参数/AdamW，TF32矩阵计算，与作者FP16不同。GPU图重放只优化执行，需对普通执行与恢复进行数值核验。

## 开发阶段

开发世界143001、初始化14301。先运行2层与4层参照，lr=1e-4、wd=0.1、batch256、warmup2000后恒定学习率、梯度裁剪1、AdamW(.9,.999,eps1e-8)，每条128000步。均匀打乱整个原子+组合训练集，不另外设50:50采样。每个评价节点不改变后续采样、训练预算或停止规则；预算内所有结果保留。4层用于校准任务是否可学，不宣称独立的正式深度结论。

开发阶段最多新增4条校准轨迹、每条至多128000步；可根据开发曲线在下一轨迹开始前登记学习率、衰减或数据比例的调整及原因。发生非有限数值则保留失败，不把失败当能力上限。最终选择依据包括单跳/训练组合掌握、留出泛化及训练稳定性，不以预设一层失败或两层成功选择方向。若低预算内没有稳定成功，报告边界，不能靠扩大确认矩阵替代有效校准。

## 确认阶段（选择开发设置后另行锁定）

预留独立世界143011、143012、143013，初始化14301/14302；每个块配对1层与2层。学习设置、数据、采样流及预算在读取确认结果前冻结。各层使用架构标准初始化；共同种子不等同所有参数逐位相同，残差投影初始化尺度随层数变化。正式配置、源码哈希和开发选择写入confirmation-lock.json及development-decision.json后启动。

若确认2层稳定成功而1层失败，按原授权补充一个实际参数量最接近2层的宽1层对照；宽度取4的整数倍，按参数量选择，不按准确率选择。该对照须在启动前单独登记，保留相同样本预算及总计算比较。仅1/2层不能拟合深度定律，也不承诺出现线性关系。

## 评价、学习时间和计算

全量原子、训练组合、ID留出组合以及全部OOD组合，分别报告尾实体准确率、完整答案加EOS准确率、两目标平均NLL。完整生成使用模型自己的尾实体续写EOS。外部两次调用提供已知关系分解，分别使用模型自己的中间答案，单列为额外计算诊断。确认主比较采用固定终点完整答案正确率，尾实体分数同时报告；不以最优中途点替换终点。

T90为首次连续三个已登记节点完整ID准确率均至少90%的首节点，并同时报告其前一节点以显示时间分辨率。未达标为预算内未达到，不作无穷大、不删轨迹。保留全学习曲线及每节点逐例生成/NLL。训练量并列样本数、每类事实曝光、有效输入token、监督token与矩阵乘法估算FLOPs；FLOPs包含固定长度4的实际padding计算，以前向的3倍估计训练，排除逐元素/优化器开销，不当成硬件计数。墙钟分训练、评价与图捕获，另保留总体UTC起止。

统计以3个独立事实世界为单位，初始化是世界内重复，案例不是独立世界。报告各运行、世界均值、配对差与范围；小样本不作显著性宣传。正式评价不用于调参。内部分析随行为结果决定，只在需要支持具体计算机制时添加，不另建预测器。

确认前补充等计算对照：对每个世界/初始化配对，共同FLOP上限取两臂完整预算计算量的较小者；每臂取不超过上限的最后一个已登记评价节点，报告实际计算量、分数及剩余预算差，不按效果选择节点或插值。这与固定样本预算结果同时保留。原子事实另按既定ID/OOD边集汇总，防止总准确率掩盖小型OOD子集。

采样实施差异：为了固定GPU图形状，epoch末尾不足batch的样本与下一个随机epoch开头拼接；原作者DataLoader保留较小尾batch。各事实长期曝光仍均匀，各深度使用完全相同的采样序列。开发启动后的代码修订仅补预算末端恢复完成标记、无梯度读取loss和空评价分支；开发启动源码已独立保存，模型/优化/数据/采样没有改变，确认前重做执行预飞。
