# DiscoLoop新增事实的三组CE参数范围对照

用户于2026-10-16明确授权实际补充：同一个DiscoLoop、同一批新事实，分别只改Down、改整个MLP、改全模型；三组预算相同，不监督更新后的两跳答案，尽量保护旧知识，并与已有AlphaEdit比较。本批不重训骨干、不重启已完成AlphaEdit或TTCD，不运行架构网格。

## 问题及历史去重

主要问题是固定原子写入目标和保持约束后，开放更多参数是否改善新事实写入及自然组合，是否增加旧能力干扰。已有AlphaEdit只改down建立了部分成功，但没有这个参数范围对照。历史普通原子CE/早期实体监督、TTCD裸基础/适配终点均有不同的模型、任务或目标，不能代替本批。新问题是参数范围的配对比较，不重复把旧CE失败当成新发现。

复用`alphaedit-discoloop-novel-v1`的原配方300k独立复建DiscoLoop检查点，SHA256 `56d17cedf29db93c713e7ec118b55955118dfd54085aa5240806aee14401f671`，四个物理块、两轮共享、宽768。原300k训练配方的独立复建不冒称恢复历史权重；不加载common/single/stream适配。复用同一8开发/32正式缺失键、256条新→旧和253条旧→新查询；每次编辑独立从相同基础开始，不做32条连续累计编辑。

## 方法依据与共同目标

参考[ROME作者FT实现](https://github.com/kmeng01/rome/blob/main/baselines/ft/ft_main.py)的目标CE、选定参数Adam更新及相对原参数的逐元素改动约束；旧输出KL沿用本项目原子编辑的保持思路，并扩展到旧训练组合。作为参照的[AlphaEdit](https://arxiv.org/html/2410.02355v3)是latent目标拟合＋零空间矩阵求解，本批CE不称其原实现复现，也不把CE梯度投影称作AlphaEdit。

三组只改变可更新参数范围：

| 组 | 可更新参数 |
|---|---|
| down | 四个共享MLP down的weight；不改bias，与AlphaEdit范围一致 |
| mlp | 四个共享MLP up/down的weight与bias；不改相邻LayerNorm |
| all | 所有唯一模型参数，含attention、MLP、LayerNorm、token/position embedding及其偏置；绑定embedding/decoder只计一次 |

全部保留实际残差、因果attention、LayerNorm、GELU、DiscoLoop全词表软通道与两轮共享。参数实体不按轮拆开，编辑同时用于两轮；dropout关闭、eval前向、FP32、TF32关闭。

每步损失为新原子尾实体CE，加上10倍的旧输出KL。新原子输入仅`[h,r]`，监督仅`t`；不加新EOS损失、早期实体监督、latent目标或任何更新后组合监督。旧保护每步16条原子＋16条原训练II组合，各自使用基础模型在原尾实体/EOS位置上的完整输出分布，KL按目标位置平均、两种旧输入等权。旧组合的真值没有因本批新增缺失键而改变；它们与依赖新事实的评测组合分开。

Adam β=(.9,.999)、eps=1e-8、weight_decay=0；全局梯度范数裁剪1。每步之后约束每个允许更新的参数元素在其原值±0.0005内。这保护的是参数改动幅度，不能保证完整非线性网络行为不变。记录实际改动范数和最大元素改动，不把三组不同的总改动量说成已匹配。

## 旧知识集合和选择隔离

直接读取已审计AlphaEdit的`protection.pt`，并用其冻结采样函数重算逐字段核对：保护池4096旧原子＋4096旧训练II组合、开发七池各32题、正式七池各128题、继承U64＋64及原配对事实/组合均原样复用。原始保护文件、32份AlphaEdit原始预测及其正式汇总逐文件SHA256绑定。

从保护池用固定种子2026101604无放回抽取320旧原子＋320旧训练组合，分为20个16＋16批次。一次保存基础模型分布，全部CE范围、候选学习率、开发/正式事实复用相同教师、顺序及曝光。原模型多次前向不计作新增知识监督。保护、开发和正式旧题互斥；正式旧池不参与KL或参数选择。

每组在同一8开发事实、同一四候选学习率5e-6/2e-5/8e-5/3.2e-4下，各固定20次更新，不早停。只读取新原子答案＋EOS及开发旧池原正确题保持，不运行开发新两跳查询。以七池最差保持≥99.5%为合格；合格候选中先最大化原子成功，再保持，再选较小学习率。若无候选合格，先选保持最高者，再原子成功、较小学习率，并明确门槛未通过。三组拥有相同校准机会；分别校准学习率属于配方比较，不声称仅在完全相同数值优化轨迹下改变范围。

## 预算和预定分析

每条正式事实每组固定20个Adam更新、20次新尾实体曝光、320次旧原子＋320次旧组合曝光、1280个旧分布目标位置。开发每组8×4×20=640更新，正式每组32×20=640更新；三组科学编辑合计3840更新。CUDA流程短测三组各2步，共6次工程更新，完成后精确恢复原参数。基础预训练及writer外层训练均0。独立审计只读保存的参数，不重复优化。

这里“预算一致”指三组CE的更新次数、新事实目标token、旧保护样本顺序/曝光及开发网格相同。可更新参数数目、反向计算和优化器成本不同，分别记录总/可更新参数、输入token、矩阵前向FLOPs估计、单独标注的2×前向反向代理、耗时、GPU显存。该代理不是精确的硬件反向FLOPs匹配。已有AlphaEdit实际latent步数、四层求解和8192保护输入统计与CE不同，因此四方法比较不宣称等计算预算下的算法优越性。

主分析保留全部32事实：新原子、两种两跳角色、必要旧前提和七池旧能力原正确保持。另报原子已写成等条件子集及覆盖率、显式两次模型单跳参考、各轮读出、旧正确题丢失与新答对，均使用AlphaEdit原评分。原子只看实体的准确率另作格式核查；EOS同时正确仍为主指标。

新→旧/旧→新答案仅由评测读出接触，不传入编辑函数。记录新增参数实际值、每步原子CE和旧KL及计数、全部原始预测，逐事实与AlphaEdit基础读出完全一致才接受比较。按事实配对bootstrap10000次；同一图/初始化、不同问法及32状态下重复旧题不冒充独立世界。三组CE参数范围配对比较与AlphaEdit方法参考分别解释，不凭结果唯一归因于零空间或Loop机制。
