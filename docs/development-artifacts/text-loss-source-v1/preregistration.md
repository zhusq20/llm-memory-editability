# 预训练损失来源的因果干预：开发契约

2026-10-01 UTC。用户明确要求核对 Allen-Zhu 的 Physics of Language Models，并在决定后自动实验。主问题：已能提取的事实在继续预训练中，其组合使用能力受到哪些训练损失来源的促进或干扰？不再仅报告单跳/两跳差距。本批主要主张层级为受控训练更新的行为因果效应；若没有模块干预，不声称定位了MLP内部机制。

## 原文核验与本次扩展

阅读 Zeyuan Allen-Zhu / Yuanzhi Li, Physics of Language Models Part 3.2（https://arxiv.org/html/2309.14402），§2、§4、附录B/C。原文比较BIO预训练或再QA适配的模型，知识抽取充分后，在部分人物上训练月份/专业的分类与比较、在其他人物上评价。With-hint训练50%有提示、50%无提示，测试分别生成中间属性或直接回答；不是只在测试时给真实属性。原文主要模型12层768维，BIO约100k人物；附录另有更大模型和数据，不能从有限实验推出所有Transformer不可能组合的定理。它的识别重点是参数知识的提取/操纵与人物留出，不是我们的二跳随机关系图的完全复现。

沿用它的“先检查知识与操作前提、严格留出操纵对象、区分中间提示与直接输出”方法论。已有bioS同权重诊断提供提示路径证据；本轮复用已校准的完整文本预训练P1模型，所有相关事实初始均可正确提取、背景组合操作已学会。扩展为直接操纵后续训练损失来源，保持输入及优化历史。目标人物不接受组合结论监督，测试首尾对原有全局留出不变。

## 开发与预算

固定来源 results/text-pretrain-v1/development/development-P1/latest.pt（32000步）；已有开发世界147001、初始化14701。四臂均从同一模型、AdamW一阶/二阶矩、步数、抽样流、CPU/CUDA随机状态继续4096步，不重置优化器、无新warmup，原lr=3e-4、weight_decay=.1、dropout=.1。节点0/1/32/128/512/1024/2048/4096。全部臂完整执行，不按结果延长或删除。4096步用于局部续训效应，不宣称达到新目标最优解或重建先前8k→32k的退化过程。

三个来源：A是基础单跳文本及角色槽中两条原子句的全部有效下一词元；B是背景组合文本的全部有效下一词元；N是角色槽第三条独立中性记录。每批有效目标数A=1120、B=288、N=576，总1984。A/B均包括提示实体、关系、答案、标点和EOS，不能将A效应只归为“答案记忆梯度”。

四臂AB、A、B、N的目标分别为 (L_A+L_B+L_N)/1984、(L_A+L_N)/1984、(L_B+L_N)/1984、L_N/1984。这里各L是对应token损失之和。不按剩余token重归一化。所有臂相同输入token、标签、位置、可见上下文、batch行序及物理前后向形状，仅损失系数改变。实际非零监督量不同，明确记录；不把该设计说成同监督信息量。N仍包含中性文本更新、继承的动量与weight decay，不是冻结模型或纯衰减臂。梯度裁剪、Adam非线性和优化历史均属于这项训练处理，不能称为独立梯度线性贡献。

## 评价与结论边界

固定4096步主指标为完整目标测试池的答案+句号+EOS准确率。全量原子、背景训练/留出、目标非测试/测试均测；正确答案概率、A/B/N完整训练表NLL、相关两条原子均正确子集及覆盖另报。后续配对比较用四臂共同原子正确子集补充，不能删掉前提受损案例。保留逐节点原始预测、初末权重、完整末端优化器、采样摘要。

主要因素效应为 .5[(AB−B)+(A−N)]（打开A），及 .5[(AB−A)+(B−N)]（打开B）；同时报条件效应AB−B与AB−A、交互AB−A−B+N，以及每臂相对共同来源的变化。初期干预只支持短程局部因果效应；终点不变或下降不证明机制不存在。单跳保持而目标变化支持训练损失改变了组合行为，但尚不能区分存储、检索、路由和读出。若显著破坏背景操作或原子，明确报告对应失败前提。

开发用于校验操作和确定后续固定比较。后续在原有三个世界×两个初始化的全部P1端点分支，不按过去是否退化筛选；这些是已见世界的冻结后续比较，不冒充新世界确认。开发结果不并入后续均值；按初始化世界内平均、再世界等权，不把查询当独立世界。
