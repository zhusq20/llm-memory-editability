# 来源更新的参数互换分析

在四臂开发结束后设计，正式后续比较结果尚未查看。动机来自开发：A与N都有较高单跳，但目标差距很大；检查两臂训练造成的哪些参数差异对行为差距具有条件性因果作用。它不同于已有跨查询激活替换：直接互换共同祖先分支训练后的参数组。

以A与N两个分支互为供体；两种方向均测。预先固定四组，不按结果选层：token embedding（与读出绑定）、全部attention投影、全部MLP、全部LayerNorm与位置embedding。四组互斥且覆盖所有参数，两块重复调用仍共享权重。self不换、all全换是身份及正操作对照。每个条件测原子、背景训练/留出、目标留出全池的完整答案与概率，保留原始预测。部分换组不产生梯度、不训练新适配器。

先开发校验self/all与原保存预测一致；随后将完全同样的12模型状态条件（2方向×6选择）用于六个既有世界/初始化配对，不挑选差距更大的来源。正式执行前保存源码与本说明哈希；不按正式结果调整分组。四组只提供相对其余参数固定条件下的因果归因，不是唯一/独立模块：原子损失也会改变attention，MLP效果依赖其输入，embedding同时改变读出；互换可产生分布失配和参数共同适应问题。只报告全部组件结果与知识/背景保持，不用最高恢复率作为单一主结果。

参数移植效应不是“知识储存在该组”的证明；某组能双向转移行为差异也不自动证明单跳/组合共享同一知识编码。此分析可以把训练处理与一类参数改变联系起来，仍不等于完整神经算法解释。
