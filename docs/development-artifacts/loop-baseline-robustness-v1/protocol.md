# 普通 Loop、基础 DiscoLoop 与 invariant 的配对比较

2026-10-21 用户要求：“能不能和 discoloop（不加 gate 的最基础版本）、普通 loop 进行比较？”本批据此补齐正在执行的稳定性、换数据和同题深度测试；不改动或重启前批训练。遵循项目研究原则。

## 比较什么

上一批的 ema 是带归一化跨轮聚合的结构，不能代替普通 Loop。依据 [DiscoLoop §3–5、附录 A](https://arxiv.org/html/2607.00341v2)的共享块与固定 α=1 对照，保持本文实际 GPT-2 残差、归一化、attention/MLP 计算：

- **普通 Loop：**输入嵌入一次，重复执行同一个完整 Transformer 块，轮间直接传递输出隐藏状态；不解码再编码、不重新注入输入、不加 gate。
- **基础 DiscoLoop：**同一骨干，在非最终轮的隐藏状态上加归一化软解码再编码向量，α=1、温度=1；无学习式注入门或更新门，最终答案读自反馈注入前的隐藏状态。
- **invariant、ema：**复用原训练及新批正在运行/排队的对应条件，不再新增其训练。

主比较统一当前配方：150 万步、batch 512、两个答案/EOS 监督段、第一段均匀抽取 4–6 轮、后段 1–4 轮、段间截断梯度、相同学习率/优化器/EMA。这检验架构在相同配方下的差别。旧固定四轮、单段监督、无参数 EMA 的普通 Loop/DiscoLoop 终点另报，不能把那组与 invariant 的差全部归因于架构。

## 评分与解释

沿用前批冻结协议：主指标是固定 150 万步参数 EMA、R8 的 B 两/三/四跳；报告完整学习曲线、末五节点、峰值到终点及最大相邻回落，三个初始化分别展示并汇总。原子知识掌握和 A 留出组合与 B 组合一起报告；多对一世界报告原有答案偏置基准、必要原子均正确子集覆盖及准确率。

各新增终点先在新进程做 R1–32 全池重载，再在相同 11 池/43,000 问题逐轮测至 R256，固定嵌套子集到 R1024 和 R16,384。固定每轮所有问题，不按真值挑停止点；报告答对后变错和新增答对。普通 Loop 的 FLOPs 不计不存在的解码再编码通道。等步数、数据曝光与实际计算量分别记账，不称等 FLOPs。
