# 跨 Loop 残差门与解码注入：两臂消融

## 授权与主要问题

2026-10-18，用户明确选择“两条都做：仅残差门＋固定q配残差门”，沿用当前数据、普通训练和每臂150万步终点。新增两条从头训练，共300万科学更新；既有普通Loop、固定注入DiscoLoop、学习注入P及P+学习残差门只读复用。本批不添加新的数据任务或训练方法。

主要问题：此前跨轮更新门的收益/退化，是否依赖学习注入门g，或者依赖整个解码注入通道？两条新臂之间隔离固定注入通道的有无；固定注入臂与旧P+u之间比较固定/学习注入，但旧g初值.99与新系数1、历史执行环境不同，不能称完全只改变可学习性。

## 完整模型中的改变

X是本轮输入，H=Fθ(X)是完整共享Transformer块的输出，保留原attention、MLP、残差和归一化。q(H)是原DiscoLoop的软解码、嵌入再编码和RMS归一化结果。u(H)=sigmoid(wᵀLN₀(H)+b)，LN₀不带仿射参数；w=0，b=logit(.95)。u是每token一个标量，参数跨轮/位置共享。

| 新臂 | 非末轮交接 | 解码反馈 |
|---|---|---|
| `only-u` | X+u(H)(H−X) | 完全不计算q，也没有g参数 |
| `fixed-q-plus-u` | X+u(H)(H−X)+q(H) | 注入系数固定1，没有g参数 |

“固定q”指注入系数固定；q仍随隐藏状态及正在学习的嵌入/读出变化，不冻结q向量、不detach。q在u门之外。计算顺序沿用现有残差修正实现；最后一轮仍直接读取H。因而u→0只在无q的非末轮给出精确保留通路，不代表整个四轮网络恒等或保证最终答案保持。

## 固定配方和数据

复用现有40,000条训练、43,000条评测的双图世界；两图原子事实均训练，图A另有2/3/4跳组合，图B组合留出。世界SHA256为`e132eaf6bba5786bbf05f6f36c1b7383f698e93ee0dee313f568f6d50a77026f`，评测池SHA256为`c991cebeeeec05639be87d981cd20031016f47965c43fed8bf5cc55579c3b468`。不混用25,000条变体，不重新生成世界。

共享1层×4轮，宽768、12头、dropout .1；初始化2026101602、样本流2026101603、dropout2026101604。两臂共享初始骨干和u，但因是否注入q不同，初始函数不相同。batch512、AdamW、lr1e−4、wd .1、2000步warmup后恒定学习率、梯度裁剪1，FP32参数/优化器、BF16前向与TF32沿用旧配方。只在原答案和EOS位置使用末轮交叉熵，无中间监督、门正则、随机深度、额外KV或训练日程修改。

每臂1,500,000步，共768,000,000样本曝光；两臂共1,536,000,000。曝光由实际保存的计数核对；非PAD token和估算矩阵FLOPs由runner记录。步数与样本配对不代表计算量配对；only-u省去非末轮词表反馈，须另报耗时、参数和计算估算。

## 评价和解释规则

主要端点为固定150万步、R4的图B三跳全词表答案准确率。保留B两跳、A留出三/四跳、全部11池、答案+EOS联合评分、全部预定训练节点以及终点R1–4；不以最佳节点或最佳轮数替代终点。节点为0/1k/8k/16k/32k/64k/128k/256k/300k及400k至1500k每100k。

固定q+u若优于旧gq+u，支持学习注入相关因素值得关注，但不能单独归因于sigmoid、门值或梯度。only-u若更好，支持本任务不需要该注入通道；不能推出所有LLM都应删除它。若两臂都不稳定，则继续检查整轮状态更新、数据支持与末轮读取，不能把失败强归于g。低分不波动不算稳定成功。保留原子、训练组合与留出组合的差别；单图/初始化不作为跨世界结论。
