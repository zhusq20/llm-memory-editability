# 独立一步写入后合并增量，与连续写入：第一跳和第二跳

2026-10-15。用户明确授权加入独立增量merge，三架构、相同模型/事实、每事实一步，分别检验第一跳与第二跳编辑，重点为第二跳新答案和旧知识保持。[配置](../../../configs/ttcd-merge-hops-v1.json)。

## 固定比较与复用

矩阵为普通Transformer D8、Loop4×2、DiscoLoop4×2 × 连续写入/独立增量相加 × 被编辑事实在第一/第二跳，共12种条件。另保留共同单事实参照。基础及外层训练新增更新0；复用`ttcd-one-step-second-hop-v1`各自已固定的stream10000模型、单事实增量与连续快状态，不修改原训练、旧控制器或冻结源码。

每架构等待自身原一步评测的本地重放、云端canonical结果核验及相应正常退出后再使用，不因分数低筛除模型。原一步第二跳连续结果直接复用，避免重复产生相同轨迹和相同问题的结果；第一跳新读出与merge结果单独保存、独立审计。复用模型的外层写入训练为每事实4步，当前两方法部署均1步；不能称一步外层训练或完整作者实现复现。

## 两种写入方式

连续写入沿原式(6)递归，A_i=U(A_(i-1),f_i)。独立方式对每条事实在相同A0=0与固定骨干上只调用一次writer，得到ΔA_i=U(0,f_i)，再按同一顺序累加A_i=Σ_(j≤i)ΔA_j。本批ΔA_i直接复用原已审计单事实状态，另在新审计中逐事实从零重写核验。相加的是增量，不包含重复基础W、不平均、不缩放、不追加学习率搜索。

原子更正材料、窗口32/16、gap17、η=.001、首轮每物理层写入位置、FP32快矩阵和原FP32独立读取均保持。材料与写入操作不因事实在测试链中的跳位改变，因此同一快状态供两种跳位读出，不能为每个跳位另写不同材料。数学上最终增量和不依顺序；实际FP32累加的舍入可能依顺序，本批保留全部32个顺序，不宣称逐值顺序不变。

该独立累加近似[TTCD§3.3](https://arxiv.org/html/2608.01672v1#S3.SS3)使用基础权重求各段更新的off-policy原则，但原文处理连续token块并有卷积、投影等额外结构；不称完整复现。相似MLP激活仍可产生交叉读出，是否更好由端到端E/D/U检验。

## 相同事实，两种跳位

原32个事实键、替换尾实体、ID/OOD分组、32个旋转顺序及64 U原子/64 U组合全部保留。原面板文件SHA-256为`ac6082dcb857fab85fc106d4d3d39a7a3adb67de33976edeb13c4a1bd201c081`。

第二跳原D完全不改：查询未训练，被编辑键是第二条事实，第一键不属于整批编辑集合，新答案为该事实的新尾。

第一跳只用纯图新增查询：原查询第一键为同一被编辑事实；原第二键和新桥实体对应的第二键都必须存在、都不属于整批32编辑集合；原查询未训练，新的终点与原答案不同。固定seed20261015、每事实最多8题，不使用任何模型成绩。不改变原32事实或replacement来补题；没有合法查询的事实保持0覆盖。第一跳覆盖和题目不同，跳位之间的分数差不能直接解释为仅跳位的因果效应；同一跳位内两方法严格使用同样查询。

第一跳新答案按实际图查出新桥实体的后继尾实体；其必要未编辑事实是该新后继事实。不能把新桥实体本身当作两跳最终答案，也不能用旧后继事实的准确率代替新后继前提。

## 状态、评分与保持

每架构逻辑状态为A0一次、32个单事实参照、32旋转×32前缀×2方法，共2081条记录。其中1057个原状态直接引用原一步产物，仅新增1024份merge快矩阵，两跳位共享。预计新增快矩阵D8约72GiB、Loop/Disco各36GiB，总144GiB，预留200GiB。不扩展原再次更正分支；旧批对应结果和双新面板仍由原协议保留。

主比较是t32第二跳两跳新答案的全量正确率及A0原正确题上的更新成功率，明确分母、覆盖、query-equal与fact-equal；单事实参照和t1…32曲线保留。第一跳按同样标准作为辅助。另报必要未编辑事实在写入前的可回答性、写后两条必要原子均正确的条件结果、旧答案残留，以及三架构共同A0正确交集；空交集和零查询事实保持为空，不补题。

E按全部已写事实计数，零第一跳D覆盖的事实也进入E和按年龄保持，不能按D查询数重复放大E分母。U同时报全量正确率及A0原正确集合的保持，包含旧原子和旧组合。连续与merge的U完全同题同真值。年龄曲线记录早先写入E在立即成功后是否保留。旋转、前缀、同事实的多个查询均为重复测量，不当作独立世界。
