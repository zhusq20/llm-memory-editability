# grokking-reproduction-v1：原两跳任务的训练时间与架构条件

2026-10-02，用户授权按文献复核计划开展并行复现。问题：在原论文的事实图、答案监督与组合占比下，能否观察拟合后延迟泛化；共享参数怎样改变其速度与OOD角色边界？本批为一个世界、一个初始化的开发复现，不是独立世界确认。

## 原论文与执行移植

复用Wang等NeurIPS 2024的§2–3、附录E及作者仓库提交`734ca654ec7a71dd6737d640407fac14491d538c`。原代码、GPT-2配置与分词器的固定revision和文件哈希见reference-manifest.json。无需下载或使用预训练权重。

原始GPT-2基础词表50257，加入2000实体、200关系及6特殊词元，共52463。实体角色共享；每实体20条随机不同关系出边，尾实体在全图均匀抽取。40,000原子按边随机分为38,000 ID和2,000 OOD。ID–ID链用原实现的0.005概率划出独立查询测试；训练候选只含ID–ID，混合角色及双OOD均不训练。主要留出遵循原查询留出，不能称完整首尾实体对留出。

保留GPT-2的宽768、12头、位置表1024、pre-LN、完整注意力投影、4倍gelu_new MLP、残差、绑定读出以及三处dropout=.1。普通8个独立块；共享模型4个块循环2次，Embedding/位置只加一次、final LN只用一次。按作者配置以独立块数做残差输出初始化；相同seed不保证两个架构全部权重一致，不称纯共享参数干预。

每条原子或组合只监督尾实体及`</a>`，两项等权，不监督前缀或中间桥。pad为GPT-2原EOS，与`</a>`不同。所有参数训练；AdamW lr=.0001、betas=.9/.999、epsilon=1e-8、clip=1，bias与ln不衰减。遵循原scheduler的optimizer→scheduler顺序：首次更新lr=0，warmup2000后恒定。合并全部原子与训练组合后随机遍历，最大batch512；epoch末尾保留原DataLoader的不足一批，不跨epoch补入训练样本，CUDA Graph空槽目标置−100不计损失。曝光和监督token按实际非空槽计算，不沿用历史三等份采样。

明确移植差异：PyTorch 2.6/Transformers 4.40、bf16 AMP替代原fp16 AMP，float32权重/Adam状态；SDPA与CUDA Graph执行；仅计算两处监督logits、截去无损失的右侧pad。CPU测试核查与原GPT-2的前向、损失与梯度一致；GPU预飞核查随机dropout下保存恢复。不同φ用同一随机排列的嵌套子集，各支持的均匀边际不变；合并采样使用独立NumPy逐epoch打乱流，不复现作者未公布的数据seed或逐次dropout随机数。该批是核心实验协议复现，不是原软硬件的逐bit重跑。

## 固定开发矩阵与预算

世界790101，初始化791101，采样792101，评价793101。φ=3.6/7.2/12.6分别取136800/273600/478800条独立组合；相应每步组合占比约77.38%/87.24%/92.29%。标准8层/共享4×2 × 三档φ，wd=.1，共6条；另在φ=7.2给两个架构各加wd=.3，共8条。同φ共享事实、支持、评价与采样；同架构的wd比较精确共享初始化。

每条固定1,500,000更新，共12,000,000；700k/1M/1.5M为同一恒定lr轨迹的节点。8 GPU每卡一条并行；先做源码/任务/原模型等价性、随机恢复及全尺寸速度预飞，成功后冻结源码、配置、环境与数据。预飞更新另记、不作为科学轨迹。出现失败保留日志、状态及检查点，不择优删除或按泛化出现提前停止。仅技术中断可从完整优化器、采样、CPU/CUDA随机状态恢复。

## 评价与产物

节点0/256/512，随后1k间隔至64k，之后4k间隔至1.5M。固定7个面板：ID原子、OOD原子、共同训练组合、ID–ID、ID–OOD、OOD–ID、OOD–OOD；各最多3000，与原论文的抽样评价相衔接。面板拟合不称全训练集拟合；终点另完整评估40,000原子及各臂全部训练组合。首跳与次跳的ID/OOD定义来自边划分，并核查实际支持中的组合角色。

答案先闭卷贪心生成，再把自产答案送回产生结束符；答案、答案+结束符、答案NLL分别记录。每个节点保留全部预测、真值及逐题NLL，不平滑掉回落。保存0/1k/2k/4k/8k/16k/32k/64k/128k/256k/512k/700k/1M/1.5M权重，完整恢复状态更新于同节点。记录逐例累计曝光、数据/初始/终点权重哈希、监督token、估算矩阵乘法FLOPs、训练秒与墙钟。

主要分析为固定终点与完整拟合后轨迹；描述首次及持续共同拟合≥99%、测试≥50%/90%的保存节点及间隔。未达标记为预算内未观测，不称不可能。t_gen/t_fit、平台与转换宽度描述训练效率；准确率阈值不单独定义grokking，NLL和曲线形状共同解释。报告所有支持、正则和架构条件，包括即时泛化、延迟泛化和未泛化。一个世界的初始化/查询不作为多个独立世界。

本批不追加编辑、供体、所有宽度或新世界矩阵。端点完成后另进程重载，核查文件哈希、面板逐题预测和完整终点计分；只有全部注册运行与重载完成才标记批次完成。
