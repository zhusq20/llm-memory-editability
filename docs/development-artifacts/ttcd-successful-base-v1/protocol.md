# 合格DiscoLoop上的单事实与跨样本连续写入

2026-10-15，用户授权先恢复成功配方，再比较两种外层训练。此前小模型批次保留，此批要求[恢复基础](../discoloop-success-restore-v1/protocol.md)独立通过后才开始。当前为实现及工程核验，尚无新科学结果。[配置](../../../configs/ttcd-successful-base-v1.json)。

## 核心比较

同一个具有可靠旧组合能力的DiscoLoop，是否通过训练“在同一个A连续写入多个事实，再回答之前事实”，学会保持和组合使用较早写入的信息？比较只改变外层训练时快状态的共享范围：single每事实独立A；stream同一个A连续写8事实。部署时两组都只保留一份A连续写入32事实，公平检查较早事实、未写入旧知识和组合使用。

两组复用完全相同的共同读取终点、AdamW状态、普通样本流、纠正事实/顺序、随机数起点及更新预算。原基础完整Transformer/DiscoLoop通道保留。会话实际保存四个物理层MLP down矩阵的增量ΔA，初始为0；有效矩阵为原W＋ΔA，在两轮执行中共享读取。局部写入特征只取首轮，整包读取结束后再统一提交所有层的增量；这不意味着增量只在首轮生效。局部内循环为TTCD在本项目GPT GELU实现中的适配，不是原v9完整架构复现。原有共享QKV/残差局部写入计算和停止梯度的教师均沿用。

## 在两臂之前先学共同读取

基础模型没有学过更正记录格式。先固定10000更新，训练同一共同接口：原混合流512样本平均CE，加128条更正记录的单跳读取平均CE，权重均1。lr1e-5恒定，wd.1、bias/LN不衰减、梯度裁剪1。所有更正目标键排除16条校准及32条正式目标；普通旧事实仍按原基础流回放。

适配采用确定性eval前向，dropout置0（原基础JSON及权重保留），BF16前向、A为FP32，TF32关闭。dropout在原模型eval时本来失效；须实际检查原权重和A0包装的基础前向/答案一致。此后优化与基础300k阶段不同，明确记作新增适配，不能冒称全程原配方。

共同接口终点先独立重载，重复完整旧七池和原始更正读取检查。旧七池前四项各≥98%、IO/OI/OO各≥90%，且各项较本次刚验证的基础终点下降≤2个百分点；校准ID/OOD各至少8条、长窗口单跳准确率各≥60%。两类条件全通过才分叉；否则保存失败，不启动两臂，不用正式D筛选终点或增加预算。

## 配对外层训练

每臂固定10000更新、lr1e-5，native512、correction128，四个平均损失等权相加：原混合流CE、更正记录读取CE、写入后原子答案CE、未写旧原子的输出保持CE。原混合流原子/II比例仍由40000/273600的原partial-epoch流决定，不能改成各一半。每事实4次局部写入，single每128事实128份状态，stream分16组每组8事实连续写入，并在终状态读取该组全部事实；两组保持查询都排除对应八事实更正键。

一次更新先预采样整批事实，再按原512样本micro64、事实micro32累计梯度；每个微批按整批占比缩放，所有微批结束后只裁剪及更新一次。stream微批包含4组完整8事实，保留跨写入的梯度，不在事实边界detach A。这是减少峰值内存的实现方式，须通过整批/微批全部梯度与优化一致性检查，不改变有效batch。更新后的两跳答案从不用于训练、校准或终点选择。正式执行前，micro8工程检查测得单事实峰值约4.04GiB、连续组约7.14秒/更新（10k约19.8小时纯训练），因此将内部微批改为32以减少小批调用开销，并追加完整尺寸16步及状态重放检查。有效128事实与四项损失不变；只按内存、速度和数值完整性确定实现，不使用D成绩。

固定终点各做独立重载、校准、正式连续评价、逐状态写入/读取重放及云端核验。普通回放为旧世界能力保持提供监督；因此本实验不能宣称无回放持续学习。

## 正式评价与成本

16 ID＋16 OOD固定事实、32个预定旋转顺序。每组从同一A0开始，依次写入32事实，再按预定流程再次更正旧事实。报告E写入事实回答、D依赖事实的两跳新答案、U未写旧原子/组合，以及随写入年龄变化的保持、再次更正及串扰。保留全量答案+EOS预测、必要事实前提、写入前正确子集与覆盖率，不把原组合错误计作更新传播失败的唯一证据。旧事实保持须同时包括较早写入事实和原有未写知识。

两臂都保存1313个快状态及所有写入转移，供独立新进程逐值重放。每个A含9437184个FP32元素、约36MiB，约46GiB/臂，预留至少200GiB持久空间。微批仅减峰值内存，不减少事实曝光/内层写入次数或等同两臂计算成本。记录外层更新、普通/更正曝光、有效token、内层写入与墙钟/资源；不将不同计算图称为等FLOPs。
