# 两层Transformer首跳接口置换：执行前契约

2026-09-30。用户授权回顾一层/两层比较并执行最值得做的后续实验。本批复用已训练权重，仅前向评价；不覆盖或继续训练grok-depth-v1。结论层级为现有受控模型中的激活干预证据，不是自然模型机制、参数编辑或普遍深度下界。

## 问题与方法依据

原比较已控制单跳掌握、总参数量及估算计算量，但尚未解释第二层的有效计算。本轮检验：第一块结束后、第一关系r1位置的状态，能否作为后续计算可替换的首跳接口？若换入另一首跳的状态、保留原第二关系r2后，输出准确地转向新路径的答案，且同中间实体的替换保留原答案，便支持该位置承载可组合信息。只造成任意输出改变不够。

运行前重读Wang等[Grokked Transformers are Implicit Reasoners](https://arxiv.org/html/2405.15071v3)§2、§3.1–3.3、附录A、B、D.1及E.2。论文使用8层宽768模型、随机事实图和原子/组合联合训练；§3.3在300条训练组合上，以同类token替换产生扰动，移植隐藏状态并测最终输出变化，附录D.1据此简化回路。本轮复用其因果状态置换思想和本项目已验证的小型实现；改为预定第一块位置、全量留出组合、明确反事实答案命中，并把供体限制为两token首跳前缀。无需训练探针或预测器，也不重新执行原论文全矩阵。

## 供体与比较

原问题为[h,r1,r2]，真值路径h→b→t。供体模型仅输入[h′,r1′]，绝不输入r2、尾实体或答案；从第一块结束后的残差状态取值。因此供体计算在因果上看不到第二关系，不能由完整问题直接计算待测尾实体。

- 不同中间实体供体：r1′=r1，h′≠h、b′≠b，存在ID第二边(b′,r2)→t′且t′≠t；完整反事实组合[h′,r1,r2]不得在训练组合中，可来自预留测试或未抽中的ID组合。h′不得等于t或t′。按固定种子与世界选择一条，不按任何模型的预测筛选。
- 相同中间实体供体：另一条ID首跳(h′,r1′)→b，优先同r1、不同h；若无此供体才允许r1′不同。h′不得等于t。同关系与不同关系控制分别计分，不用混合数替代；不把缺少供体的案例悄悄删除，公布覆盖率与缺失原因。
- 原始全部ID测试组合为评价母集。相同世界的所有模型、初始化和训练节点使用完全相同的供体。

固定条件：原始基线；第一块后r1位置identity；不同中间实体供体替换r1（主条件）；相同中间实体供体替换r1；不同中间实体供体只替换h；同供体联合替换h和r1；完整反事实输入正常回答（操作前提）。主干预保留原问题的h、r2位置状态及全部权重。联合替换检验仅替换r1不足是否与其它位置有关，不视为同等范围的对照；h位置看不到r1，因此也不是信息量严格匹配的扰动。

## 矩阵与指标

开发世界沿用143001的两层模型，节点4k/32k/64k/128k，用于确认实现、供体与评分。随后锁定源码，在原3个确认世界×2初始化上评价全部18个终点；两层另评价4k/32k/64k，共36个确认状态。**这些世界的训练结果已经看过，本轮是新问题的预定后续分析，并非新的未见世界确认实验。** 路径中的confirmation仅沿用旧批次分组名。不按开发效果挑位置、节点、供体或扩大矩阵。

主指标为供体合格母集上不同中间实体r1置换后的t′加EOS正确率；并列原答案t正确率、任意改变率、仅答案准确率与全部基线。生成EOS时使用模型自己刚生成的答案，重施同一前缀状态干预。相同中间实体条件报告原答案保留。另报原问题及完整反事实都正确的条件子集及覆盖率，不能替代全量；同时报告供体第一跳及反事实第二跳的单独提取，避免早期未掌握事实时错误归因。另报非退化子集b′≠t′且b′≠t，检查首跳答案恰好等于尾实体的影响。保留每例供体、真值、预测与评分；先在世界内平均两个初始化，再对3世界等权，并给范围。节点/初始化/查询不是独立世界，不作查询级显著性宣传。

单层模型第一块后h/r1状态没有通往r2预测位置的后续计算路径，干预应不影响输出。这是结构和实现负对照，不能把两层和一层的干预差本身当作后天学成机制的证据。早期节点仅描述形成过程，不拟合内部特征对表现的预测。

## 执行、核验与解释边界

使用空闲GPU2，配置configs/grok-depth-bridge-v1.json；最多40个模型状态，不增加训练步。启动前验证供体真值、留出隔离、纯前缀、因果性、identity、干预前向与历史前向一致、EOS自回归计分及单层负对照。保存实际源码、配置/权重/世界哈希、环境、全部失败与墙钟；历史源码按各运行冻结快照加载。开发执行通过工程校验后锁定确认源码；成功信号不是进入确认的门槛。确认完成后独立重算评分并抽样重载干预。

阳性结果支持该位置对下游有因果可用的首跳信息，但隐藏状态仍可编码h/r1等信息，不能证明它只表示b、事实唯一存于某个MLP，或每层严格做一跳。阴性结果可能源于分布不匹配、旁路或分布式编码，不能证明模型没有组合机制。同中间实体供体的完整组合可能在训练集里，需保留该身份，不能与不同中间实体条件声称完全匹配。额外的参数编辑、MLP单独归因或参数共享训练需另立实验。
