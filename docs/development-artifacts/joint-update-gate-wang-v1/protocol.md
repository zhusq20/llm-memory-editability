## 原数据与配对

直接复用历史世界790101的原字节：2000实体、200关系、40000原子事实，
φ7.2对应273600条训练II；原七个评测池以及全部原子前提评测保持。
world/panels分别固定为配置中的e31ec995…与8655858c…，与`wang-original`逐文件相同。
这是按Wang作者构造方法生成后保存的既有合成数据，不是新生成的置换图，也不是自然语料。
来源方法已核对：[Wang §2–3与附录E.2](https://arxiv.org/html/2405.15071v2)，
[DiscoLoop §2–4](https://arxiv.org/html/2607.00341v2)。本项目适配不称作者全部实验的逐位复现。

参考配方为冻结`configs/gate-extension/wang.json`：四个完整GPT层构成共享块，循环两轮；
宽768、12头、词表52463、batch512、AdamW lr1e-4、warmup2000后常数、wd.1、clip1、BF16/TF32。
初始化791101、样本流792101、dropout20261017501，与现有Wang token-update配对。
主干和两门的初始参数相同，边界前向有意改变。各参数梯度及后续优化轨迹不承诺相同。

原队列的Wang P/固定.95/学习.95各150万步继续复用，不重复提交。
主对照是该队列的学习连续门；P与固定门为辅助比较。旧95.66%的DiscoLoop结果仅作历史参照，
它的注入方式不同，不能替代本轮配对P。新批与原队列镜像ID/执行硬件可能不同，
虽然主要依赖版本一致，也不宣称跨环境逐位一致或直接比较独占墙钟。

## 预算、终点与解释

新增科学更新1500000，新增臂1；不重新生成图、不新增基线预算。
保留原全部节点、300k次终点、400k起每100k到1500k。主指标固定1500k/R2的OO答案与生成EOS
联合准确率，另报答案、II/IO/OI、原子，以及固定门和P的配对差。
保留终点R1–2，按已有评测间隔报告首次达到50/75/90/95%的区间及对应曝光/估算FLOPs，
未达到如实保留；不选最佳检查点。旧任务接近满分时，学习成本是重要比较，不能只看终点。
仍只有一张已观察图与一个初始化，不能由此证明真实预训练大模型上的普遍优劣。
