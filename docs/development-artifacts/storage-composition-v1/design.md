# 标准Transformer中的事实负载与多跳计算

2026-10-01，用户授权实际训练，并要求完整标准Transformer与Loop Transformer；浅层允许，删除残差、固定Embedding、指定功能的简化记忆网络不用于本批主实验。旧批次保持原契约。本批建立受控行为证据，不预先归因于唯一MLP机制。

## 问题与来源

同一套参数承载更多原子事实时，已掌握事实的未见两跳组合是否先下降？重复完整Transformer块能否改变这种影响？[MLPs are Hebbians](https://arxiv.org/html/2607.10034v1)的单跳存储条件、[Scaling Latent Reasoning v5](https://arxiv.org/html/2510.25741v5)的bioS/关系QA与[Grokked Transformers](https://arxiv.org/html/2405.15071v3)的首尾留出方法已按项目计划阅读。复用已验证GPT和Loop实现；新增的是固定词表、同一目标子图、逐条共同曝光控制下的负载比较。它不是已有Loop一般能力结论的重命名，也不是信息论容量定理。

## 模型与比较

- 普通GPT-2形式：可学习词嵌入与绝对位置，完整Q/K/V与输出投影，因果多头注意力，pre-LayerNorm，两条残差，4倍宽度GELU MLP，最终LayerNorm及绑定输出。所有参数训练，没有辅助向量对齐或中间实体监督。
- 宽度256，4头，MLP1024；标准1/2/3块与共享1块循环2/3次，共5架构。Dropout=0是固定优化设置，不改变块结构。Loop与标准1具有完全相同的初始参数，采用legacy_unique初始化；不加入循环门控、额外记忆或输入重注入。
- 标准1对Loop1×2/3控制独立参数量；标准2/3对相应Loop控制执行块数，独立参数量不同。FLOPs分别报告，不称同时等参数和等计算。

## 数据与曝光

固定1024个人、512个桥实体、128个终点、4类首跳和4类后继关系，词表1685；整个世界有6144条单值随机原子事实。共同子图含96个人与96个桥实体、768条事实，其中64+64参与背景组合，32+32的事实完全不参与任何组合训练。模板句子如“Person000 's mentor is Expert001 .”，组合查询不给桥实体。

背景组合按完整(首实体，终点实体)留出25%，同首尾的其他关系路径也不得训练；熟悉事实的新路径是主评分池。另报严格无组合角色事实的新路径，不混称为同一泛化。所有真值逐边核查，不静默重抽世界。

每批192例：64条共同原子、64条训练组合、64条额外槽位。各流独立洗牌遍历；同世界不同架构/负载的共同原子、组合逐条曝光完全相同。低负载额外槽位重复已知背景原子，因此独立事实仍768；高负载额外槽位为5376条新原子，总6144。模板、padded形状和监督token数一致。低负载额外背景练习多，高负载每条新增事实曝光较低，这两项差异明确保留；主张是固定预算的额外事实干扰，不自动等同全事实掌握后的纯容量边界。

完整下一词元交叉熵，原子7、组合9个监督token；BOS及padding不作预测目标，EOS参与。AdamW，lr=0.001，前200步线性预热，weight_decay=0.01，clip=1。CUDA Graph仅优化执行；捕获后恢复初始权重，三步与eager训练权重差0，校验另存。

## 开发、冻结与评分

开发世界710001、初始化711001，首先固定4000步和0/1000/2000/4000节点，10条训练。训练量不足时另存开发修订配置与原因，不覆盖已完成轨迹。开发检查相关原子、背景操作及高负载新增原子曲线；不能把短训失败称架构上限。确认预算根据开发固定，不用确认端点重选步数或架构。

拟确认世界720001/720002/720003、各同一个配对初始化721001，五架构×两负载×三世界=30条；确认仅在开发审阅并冻结新配置后启动。世界是重复单位，种子与查询不是新增世界。主端点是最终固定步的熟悉事实留出两跳完整生成准确率；各世界完整报告。

生成答案后，将自产答案再输入以生成句号和EOS，完整正确为三者均正确。答案准确率和答案NLL另报。链上两条必要原子单独调用，全池主结果之外报告两原子完整正确的覆盖及条件准确率。自主两次调用使用自产桥实体，不给真实桥实体。单跳不足时不归因组合接口。

循环端点固定权重测R=1/2/3/4/6/8；训练轮数之外属于计算分布外诊断，保留单跳与格式退化，不挑最佳R代替主分数。单轮主模型无法完成两跳不作为必须淘汰前提，至少多执行块模型的相关事实/训练操作须有效才能解释比较。
