# 已见规则补测（事后诊断）

主诊断world-142701-MP-task的开发24人结果已见后增加本项：月份oracle24/24，而日期比较oracle0/24，且均输出不属于两个输入的第三个日期。为检验日期规则训练前提，本补测对全部12个任务端点重放原rule_rows中的36条训练规则：12个月份奇偶、24个固定日期比较。样本来自原实现，不筛选、不新增训练，不将其与未见日期对混称泛化。预定分别报告原规则正确性、EOS、原始prompt/target/generated。若已见日期对成功、未见日期对失败，只支持规则训练尚未建立跨日期对泛化；不能把所有比较失败归于事实知识调用。
