# answer-gradient-address-v1：答案监督的一步梯度写到哪里、写了什么（零训练）

## 状态

- 2026-10-20用户授权（[roadmap §4](../../roadmap.md#next-experiments)待补第一项）。零训练：只用原模型权重算一次梯度，不更新参数。
- 本协议在运行前写定，预测与判读规则不随结果修改。

## 1. 问题

[原则二](../../roadmap.md#principles)：只监督答案时，MLP输出投影的一步梯度为

`∂L/∂W_ℓ = Σ_p δ_{ℓ,p} k_{ℓ,p}ᵀ`

- `k_{ℓ,p}`：第ℓ层`down_proj`在位置p的输入，即**地址**；
- `δ_{ℓ,p} = ∂L/∂(down_proj输出)_{ℓ,p}`，即**内容**。MLP输出直接加到残差上，所以它等于对第ℓ层输出残差的梯度，与unembedding、实体表示处在同一空间。

本批直接测量新事实“h的R城市是v”的这次写入：
1. **地址：** 梯度主要来自预测答案的位置，而不是主语。
2. **内容：** 后层的答案位置上，`−δ`指向“说出v”（v的unembedding）；前中层的主语末token上，`−δ`更接近v的实体表示。
3. **可辨识性：** 同一事实的不同用途（说出v；v在哪国；v在哪洲；v所在国的官方语言），在主语位置给出相近的`−δ`，在答案位置给出不同的`−δ`。

## 2. 设定

- **模型：** Qwen3-1.7B与Qwen3.5-2B，revision与[知识调用接口v2](../knowledge-read-interface-v2/protocol.md)相同；原权重，float32，不用autocast，关闭thinking，同一chat模板。每一层都有MLP，包括Qwen3.5-2B的Gated DeltaNet层。
- **事实：** v2两个事实集（dev、second）`facts.json`中的全部主事实（不含校准事实），每个模型82/102条×2组。不加载任何注入后的权重，所以与v2中是否写入成功无关。
- **用途与目标**（提示×金标，按M2训练格式教师强制）：
  - **U0：** M2的24个单跳模板，回复为模板规定的完整回复（含v），共24条。
  - **U2：** 两个U2直接问句（“h的R城市在哪国”，加“Answer with only the name.”），回复为country(v)。
  - **continent / language：** E4评测模板的直接问法各2条，回复为v所在的大洲／v所在国的官方语言。只用E4筛选（`e4/screen.json`）中该操作答对的v；回复取原模型筛选时给出的名称（属于金标），这样目标是模型已知的那个名称。
- **损失：** 文本为`chat(prompt) + 回复 + <|im_end|>`，对回复全部token求交叉熵之和（与M2一致：M2按批内token总数归一，故每条样本的梯度正比于其交叉熵之和）。
- **梯度：** 在每层`mlp.down_proj`上挂钩子，取输入`k`与输出梯度`δ`，每个位置都取；同一事实的全部提示左补齐成一批，一次反向。批内各行互不影响，CPU契约测试检验这一点。

## 3. 位置分组（互斥，按以下优先级）

| 组 | 位置 |
|---|---|
| A 预测答案 | 最后一个提示token，及每个预测后续回复token的回复token（位置a−1…n−2） |
| S 主语 | 用户提示中h的全部token；另单列主语末token `S_last` |
| R 关系 | 用户提示中关系短语的token（两个U0模板不含关系短语，此组为空） |
| O 其它 | 其余位置（chat模板、虚词、回复末token等） |

回复中出现的h、R属于A组，因为它们在预测后面的回复。

**内容读出的位置：**
- `a*`：预测该用途金标首token的位置（U0为预测v首token的位置）。设计稿写的是“第一个预测答案的位置”；U0有17个模板的回复不以v开头（如“The R of h is v.”），这些模板的最后一个提示token预测的是“The”。为使“说出v”的读数对准v，主读数取`a*`。对回复以v开头的7个U0模板及其它全部用途，`a*`就是最后一个提示token。
- `a0`：最后一个提示token，按设计稿字面一并报告。
- `S_last`：用户提示中主语的末token。

## 4. 读出

每个模型×事实集×用途×层，先在事实内对模板平均，再对事实平均（事实是分析单位）。

1. **地址份额：**
   - 近似份额`Σ_{p∈G}‖δ_p‖‖k_p‖ / Σ_all`；
   - 精确份额`‖Σ_{p∈G} δ_p k_pᵀ‖_F / ‖Σ_all δ_p k_pᵀ‖_F`。用Gram积`Σ_{p,q∈G}(δ_p·δ_q)(k_p·k_q)`计算（float64），不显式构造矩阵；
   - 另报投影份额`⟨ΔW_G, ΔW⟩/‖ΔW‖²`，各组之和为1。
2. **内容**（在`a*`、`a0`、`S_last`三处）：
   - `cos(−δ, u)`：u为目标token的unembedding行（`a*`处的实际目标token；U0即v的首token），另报乘上最终归一化权重后的`cos(−δ, g⊙u)`；
   - `cos(−δ, u_v)`：v首token的两种写法（有无前导空格）取较大者；
   - `cos(−δ, e_v(ℓ))`：e_v取自E3读出代码（`read_interface_e3.entity_directions`），即v在4个中性语境中末token第ℓ层残差的均值减去全部城市的均值。特异性对照：同一`−δ`与其它城市e_c的平均余弦、v在全部城市中的余弦名次；另报与主语自身实体方向e_h的余弦；
   - logit lens：`−δ`经最终归一化与W_U后，目标token与v首token的名次（0为第一）。
3. **用途共享：** 每条事实、每种用途，先对模板平均`−δ`，在`S_last`与`a*`（另报`a0`）计算U0与其它各用途的余弦。对照：
   - 不同主语事实之间的同一余弦（跨事实基线）；
   - U0模板奇偶两半之间的余弦。

**按构造成立的部分**（数学事实，不当作经验发现）：最后一层MLP的输出只影响本位置的logits，所以最后一层只有A组位置的δ非零。最后一层`S_last`的`−δ`为零，余弦与名次记为缺失，判读时不计入该层。

## 5. 预定预测与判读

层号ℓ=0…L−1。“前中层”为前2/3（1.7B为0–17，2B为0–15），“后层”为后1/3（1.7B为18–27，2B为16–23）。各条在每个模型×事实集上分别判读，再按模型报告。

| 预测 | 判读规则（U0，事实平均） |
|---|---|
| **P1 地址** | (i) A组精确份额大于S组的层数过半；(ii) A组精确份额与层号的Spearman ρ≥0.5 |
| **P2a 答案位置的内容** | (i) `a*`处`cos(−δ, u)`与层号的Spearman ρ≥0.5；(ii) 后层中过半的层，目标token的logit lens名次（事实中位数）进前10 |
| **P2b 主语位置的内容** | 前中层中过半的层，`S_last`处`cos(−δ, e_v)`大于`cos(−δ, u_v)` |
| **P3 可辨识性** | 对U2、continent、language每一种，`S_last`处与U0的余弦大于`a*`处的层数过半（只计两处都有定义的层） |

一条预测在某模型的两个事实集上都成立，记为该模型“成立”；只一组成立记为“部分”。结果出来后如实报告命中与否，不改规则。
