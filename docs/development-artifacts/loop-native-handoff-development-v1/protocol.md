## 1. 问题

只用答案与EOS交叉熵训练时，回答两个问题：
- InfiLoop式的归一化跨轮交接配合身份无关的接收分数，能否保住无门DiscoLoop的图B组合与多轮稳定，同时消除加性交接的1/r冻结？
- 能读取实体身份的分数，是否会重现学习u门那种依赖图的时刻表？

- **配对：** 样本流种子、dropout种子与轮数序列种子在四臂间相同。

## 4. 评价

- **训练节点：** 与A0相同的21个节点（0到150万）。每个节点评测：EMA权重在R4与R8下的11个池，原始权重在R4下的11个池。指标为答案与答案+EOS，保存全部预测；不选最佳节点。
- **终点网格：** EMA与原始权重各做一次R1–32逐轮读出，记录每轮答案准确率、答题位置的相对状态变化、答题位置与中间关系位置的γ中位数；另测R4/8/16/32的答案+EOS。
- **主指标：** 150万步EMA权重下图B两/三/四跳在R8的全词表答案准确率。同时报告R4、R16、R32、图A留出四跳、全部池、原始权重与完整学习曲线。
- **稳定性：**
  - 相邻节点最大下降（逐池）；
  - 答案形成后第+1轮的变化（沿用[诊断§7.2](../../reports/loop-depth-extrapolation-gate-stability-survey-20261019.md)的定义）；
  - R4→R32是否变坏。
- **成本：** 每次更新按实际轮数序列累计矩阵FLOPs与执行轮数，另报墙钟。A1在固定4轮单段时的计数与A0记录的6.133e11/步逐值一致（测试覆盖）。

## 5. 预测与判读（看结果前固定）

- **冻结：**
  - 若加性累积导致冻结，A2–A4答题位置的相对变化在训练轮数之外不按1/r衰减，且图B四跳或图A留出四跳可能随R上升；A1仍呈1/r。
  - 若四臂随R都平坦，额外轮次的失败不能归因于交接方式。
- **身份：**
  - 若能读身份的接收规则造成图间错位，A3在同题型、同轮次上图A与图B的γ时刻表不同，图B组合低于A4；A4在解码统计相同时时刻表相同。
  - 若A3与A4无差别，身份读取不是本配方下的问题。
- **只靠配方：** 若A1已消除第+1轮瞬态与节点间大幅下降、并保住图B组合，这些性质不需要改架构。

以上不设统一的掌握率门槛；单图单初始化，只作开发证据。

## 8. 限制

- 一个已观察开发图、一个初始化；查询、轮次与检查点都不是独立世界。
- 学到的绝对位置编码只覆盖序列长度6，不测五跳及以上。
- 新配方整体改变，A1只隔离整体。
- 解码—再编码通道依赖本模板"下一词就是中间实体"。
- 每臂每次更新的计算量不同，也与A0不同，需要分别记录。
