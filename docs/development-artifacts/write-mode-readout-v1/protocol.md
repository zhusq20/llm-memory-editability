## 1. 问题

roadmap把四类常用方法放在同一个外积写入下比较：
- **上下文（注意力）：** `Σ_i v_i k_iᵀ`，键由上下文中实体词元自己算出，每层一份。
- **梯度写入（微调、LoRA、上下文蒸馏、TTT）：** `−η Σ_p δ_p a_pᵀ`，键是损失位置的状态，内容是“说出答案”的方向。

G1–G3在同一组事实上直接比较这两类写入：在哪里被读到、读出什么形式、上下文在哪一深度被读取。

## 2. 共同设定

- **模型：** Qwen3-1.7B、Qwen3.5-2B，与[知识调用接口开发批](../knowledge-read-interface-development-v1/protocol.md)同一revision，float32，chat模板，关闭thinking。
- **事实：** 开发批的开发集与第二事实集，各82条主事实（不含校准事实）。
- **写入方式**（开发批已保存的权重与生成）：

| 记号 | 方法 | 对应的常用方法 |
|---|---|---|
| context | 事实放在系统提示中 | 上下文学习 |
| M1 | 陈述SFT，两种固定格式 | 在陈述文本上做TTT／继续预训练 |
| M2 | 24种问法的多样数据SFT | 带改写增广的微调 |
| M3 | 离线上下文蒸馏，前向KL | 上下文蒸馏 |
| M5 | 只训练down投影 | 参数受限的写入（LoRA类） |
| M4 | MEMIT | 以主语为键的秩一写入 |

E3（逐事实秩一增量，近似逐事实LoRA）协议不同，只在G1中描述性并列。

## 4. G2：写入在哪里被读到、读出什么形式

**做法。** 对每种写入W和用途u∈{U0、U1.0、U2.0直接、U3.0直接、捷径}，在同一提示上比较写入模型与参照每层残差流（层输出）的差`Δ(l,p)`：
- 参数写入：参照为原模型；
- 上下文：系统提示为目标事实加3条同关系干扰（与R2相同，种子20261021）；参照把目标事实一行换成另一条同关系、主语与取值均不同的主事实，格式与行数相同。两者问句部分逐token相同。

**位置组：** 主语h、国家C（U3与捷径题）、关系名、最后提示位置、问句其它位置。

**读数：**
1. **地址：** 相对变化`‖Δ‖/‖h_ref‖`，按位置组平均。
2. **内容：** 对每个城市c定义两个方向：
   - 实体形式`e_c(l)`：原模型读“Tell me about c.”时c末token的第l层状态，减去城市平均；
   - 答案形式`a_c`：最终归一化有效增益乘以c首token的unembedding行，减去城市平均。

   v特异分数 = `cos(Δ, 方向_v)`减去其它城市的平均值。实体形式分数与答案形式分数分别报告。
3. 参数写入只统计该方法在开发批中已写入的事实（U0生成正确）；上下文统计全部主事实。

**预测与判读**（“后段”“中段”分别为后1/3、中1/3层；每条在两个模型×两个事实集上分别判读）：

| 预测 | 判读规则 |
|---|---|
| **G2-1 键：** 参数写入由显式主语触发，上下文由实体关联触发 | 最后位置后段相对变化的比值U3/U0：M1、M2、M3、M5都<0.5，且上下文的比值高于每一种参数写入 |
| **G2-2 内容：** 参数写入交出答案形式，上下文交出实体形式 | U2最后位置：M1、M2、M3、M5后段答案形式分数>实体形式分数；上下文中段实体形式分数>答案形式分数 |
| **G2-3 MEMIT写在主语上** | 主语位置在MEMIT编辑层段内的相对变化均值高于M3 |

## 5. G3：上下文在哪一深度被读取

**做法。** 原模型，系统提示为目标事实加3条同关系干扰（与R2相同），防止靠唯一城市直接复制。逐窗口阻断注意力：从查询位置到目标事实整行的全部token。
- **窗口：** 1.7B宽5层，2B宽4层，起点逐层滑动；2B的DeltaNet层把该行token的混合器输入换成所有提示中该行token输入的均值，只取查询位置的输出（同开发批标定）。
- **查询集：** (a) 用户问句首token起的全部后续位置，含答案token；(b) 只最后提示位置及答案token。
- **用途：** U0、U1.0、U2.0直接（金标country(v)）、U3.0与U3.1直接、捷径题；教师强制贪心匹配金标。只统计不阻断时正确的题，报告覆盖率。
- **读数：** 每个窗口的正确保持率；读取重心 = `Σ start·drop / Σ drop`（drop为1减保持率，取正值）；按事实bootstrap 1000次。

**预测与判读（查询集a）：**

| 预测 | 判读规则 |
|---|---|
| **G3-1 深度：** 第二跳先算出桥实体，再读上下文 | U3（两个模板合并）的读取重心晚于U0，差值95%区间下界>0 |
| **G3-2 关联读取：** 第二跳由C与h的关联直接匹配记录 | G3-1不成立，且U3与捷径题重心之差的区间含0 |

G3-2成立时，roadmap论点4的“深度”部分收窄为“地址宽”。U2与U0的重心差只作描述。
