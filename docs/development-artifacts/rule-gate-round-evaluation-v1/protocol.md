# 规则门相对无门DiscoLoop的逐轮评测

2026-10-19用户采纳比较规则门是否相对无门DiscoLoop带来有用性质，并授权安排实验。本批复用正在训练的两条规则门和已完成无门DiscoLoop的150万步终点，新增训练更新为0。相较旧R1–16诊断，本次新增两种规则门，并把三个模型的答案、生成答案后的EOS、逐题增失和同型GPU耗时放在同一评测中。旧诊断的无门答案结果保留；重放无门基线是为补齐同口径EOS与耗时。

## 固定比较

- 三模型：`stability-u`、`readiness-u`、`disco`；原40k训练数据对应的全部11池43,000条评测，每池逐题顺序不变。
- 只取各150万步终点，推理轮数固定为R1–16。主指标仍为R8图B三跳全词表答案准确率，相对无门DiscoLoop报告配对增失；R4、R16及其它池完整报告，不选择最好轮数或节点。
- 本批是同一已观察世界/初始化上的比较，用户是在看到中间曲线后选择此分析，不称新世界确认。原规则门协议中相对学习门保持四跳的判据保留，本批回答相对无门基线的另一项问题。

## 回答什么

1. 是否更早学会：复用完整训练曲线，在共同保存节点对比准确率、曝光和含规则额外计算的矩阵FLOPs。历史训练跨时间/运行环境，原墙钟单列，不当作严格同环境效率证明。
2. 是否更少轮数答对：逐题记录第一次答对轮数和从某轮起一直正确到R16的最早轮数；未达到单列。这是用真值事后描述轨迹，不是部署时停止规则。
3. 多跑是否有净收益：每轮相对本模型R4的新增正确、丢失正确、净增和原正确保持率；同时记录相邻轮正误转换。原正确集合为空时保持率为null，不填100%。
4. 是否解出无门模型不会的组合：每轮同题比较两者独有正确、共同正确、共同错误；另报无门R1–16从未答对而规则门答对的题数，重点保留图A/B四跳。
5. 收益是否值得计算代价：同样256条图B三跳输入，三次预热、七次同步计时，逐轮报告标准原生答案+EOS两次前向的耗时、每题矩阵FLOPs。规则解码和依赖门QKV/QK计算计入；不包含softmax、归一化、逐元素运算和访存。基准计时是固定形状吞吐，不能当作逐题动态早停延迟。

## 评分与执行

答案从每轮原始Transformer块输出H读出，非末轮按各自原交接继续。单轨迹读取R1–16答案；每一轮的EOS重新用该轮实际生成的答案做原生前向，禁止用真值答案替代。每个模型首池首batch的16轮logits与原生同轮前向逐值比较；全部11池R1–4的rows、答案和EOS与已有grid逐题一致才接受结果。这些检查验证评测实现，不另称独立训练审计。

两条规则门分别等待原GPU0/1的train与grid退出0，再在原卡执行。GPU0完成稳定性门后接无门基线；GPU1运行依赖闭合门。检查实际Docker及GPU进程、显存和利用率，资源不空闲则等待；不新增第五张卡。三项各独立容器，固定原LM镜像、CPU两核、16GiB内存；最后主机CPU18/19进程以已有NumPy/Matplotlib汇总JSON和PNG/PDF图。固定训练镜像没有Matplotlib，因此只把绘图放到既有主机环境，不修改镜像。失败保留、不自动重试，不修改原训练或原控制器。
