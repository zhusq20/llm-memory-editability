# 完整Qwen中的事实学习与组合：首轮开发

本轮承接简化架构验证，使用真实预训练的小LM观察现象。MLP作为重要事实记忆载体的依据保留，见[Geva等](https://aclanthology.org/2021.emnlp-main.446/)和[ROME](https://rome.baulab.info/)。已有模块替换结果继续支持其架构条件下的表示约束收益；本轮不把该收益直接等同于Qwen内部机制。

方法借鉴[Lessons from Studying Two-Hop Latent Reasoning](https://arxiv.org/html/2411.16353v4)§2、§4和附录B的事实分开/同文档学习比较。保留普通模型和单一主要处理。与原文不同，本轮为Qwen3-0.6B-Base、少量导师/居住城市事实、全序列交叉熵、无需选项限制的贪心生成；不称原论文数值复现。

## 模型与数据

- 原始Qwen3-0.6B-Base，revision `da87bfb608c14b7cf20ba1ce41287e8de496c0cd`。保留28层、各层独立参数、正常残差/注意力/归一化、原分词器及已学习Embedding，全部模型参数共同优化。无新词表、无随机固定实体向量、无共享或替换MLP、无隐藏状态对齐损失。
- 一个开发世界150001、一个训练种子15001。64目标三元组与16背景三元组，160个互不相同的虚构人名、16个城市名称，城市在各组均衡。文本明确为虚构登记，不声称描述真实人物。
- 事实形式为“a的导师是b”“b居住于c”。同一世界两臂完全一致。目标人名与背景人名隔离；目标两跳问答不训练。背景的直接两跳问答在两臂中共同用于任务格式及组合练习，不含目标人物。
- 单跳各4种问法；背景两跳4种问法。评价目标的两单跳使用其中一种训练问法；目标两跳是未训练的问题。没有额外测问法泛化，输入不提供桥实体或事实段落。

## 唯一比较与预算

separate：两原子问答作为独立文档训练；linked：按第一跳、第二跳的顺序连接同样的两原子文档。每个原子文档均以原模型EOS结束，连接后仍保留EOS，允许后文注意到前文。直接复用原模型普通二维padding mask及因果注意力，无自定义模块或隐藏态干预。

两个条件每步使用同样8组原子对和2条背景组合，固定512步。每个原子文档首token均不计损失，拼接后保持相同，故原子曝光、输入token及有监督token逐批精确匹配。训练序列长度、位置和attention计算量随分组改变，记录真实padded token和attention cells，不宣称等FLOPs。

全参数AdamW，lr 2e-5、20步warmup、cosine至2e-6、weight decay 0、梯度裁剪1。FP32权重与优化状态、BF16 autocast、TF32关闭，GPU2顺序运行两臂。0/128/256/512节点均评价，固定512步作为本次开发端点，不按目标组合收益选点。学习率参考原文Qwen训练量级；更少事实、不同模型和训练目标均是适配条件。

评价为同一贪心解码、最多16个新token、不限制候选词表、不输出CoT、不提供真实中间答案。主评分是去大小写、空白和末尾句点后的首行完整答案匹配；保存完整生成，不能仅凭EM把格式不符当知识缺失。报告两条单跳、目标两跳、背景两跳；两臂共同单跳正确的子集只作补充，报告覆盖。

## 范围与执行

这是开发校准，不是新世界正式确认。两臂单跳尚未掌握或背景组合未学会时，不把低两跳归因于MLP接口；仍保留全部分数。若需要修改设置，另立开发版本并保留本轮。联合文档已让头实体和城市共同出现，收益可能来自训练中建立直接关联，不据此声称严格跨事实调用或唯一隐式推理过程。

运行前完成数据泄漏/曝光/评分测试，冻结配置、源码和模型文件哈希。终点保存完整模型，独立重载并对全部208项生成逐token核对。训练与报告入口为`scripts/run_small_lm_composition.py`。本轮不同时启动0.8B、1.7B或4B矩阵；后续优先同系列Qwen3-1.7B-Base复核，Qwen3.5-0.8B-Base为混合架构扩展。
