## 16. v2.11 上下文统计与真实早期梯度：独立开发实验

### 16.1 问题、来源与比较对象

用户在阅读 [Im et al., How Do Transformers Learn to Associate Tokens, arXiv:2601.19208v2](https://arxiv.org/html/2601.19208v2) 后指定执行“带监督权重和注意力掩码的上下文统计→真实早期梯度”诊断。论文的早期attention-only理论提示从语料关联统计预测权重变化；本项目答案/EOS监督、绑定embedding/head、GELU、LayerNorm及AdamW不满足原定理设定。本实验构造新的、无拟合系数的残差路径近似，并直接检验其预测方向及幅度。它服务于§15的组织效应研究，不修改已有确认结果，也不把完整内部机制识别设置为其他探索的前置条件。

使用已见开发世界0/1、初始化0/1、宽度256/8层/4头模型，三种交叉组织company/project/neither。每个世界/初始化只运行一条共同neither轨迹，在0、32、128步固定同一权重，反事实评价三种组织各自的平均梯度。因此新增4条128步短轨迹、12个共同状态；不会把不同组织训练后的知识水平差异混入梯度对比。短轨迹沿用原文档、QA采样、0.8/0.2损失、AdamW、1e-4目标学习率、16轮预热、weight decay 0.1及裁剪1；为梯度相减精度使用FP32、关闭TF32，不冒充原BF16轨迹的精确续训。此处32/128步均仍在原预热的第一轮，结论仅覆盖初始化附近。

每个状态使用全部2048篇文档的完整10位置轮换，开放或阻断跨事实注意力，共3组织×2掩码=6臂，总计72臂。每臂409600个监督位置，答案和EOS分别均值计分，再各乘0.4，合计原文档损失权重0.8。三组织的QA流及QA梯度在共同参数处完全相同，因此对组织差值精确抵消；不把QA省略误写成更换训练目标。记录全模型真实梯度，主预测对象为第一层attention输出投影权重，其他模块用于定位梯度差值的大小。

### 16.2 统计预测器：定义在读取真实梯度之前

对监督位置t、目标y、可见前文集合A(t)，令x_j=E[token_j]+P[j]，v_j=W_V LN_1(x_j)+b_V，m_t为A(t)内v_j的均值。以所有残差分支均为零的基线得到p_t=softmax(E LN_final(x_t))及epsilon_t=J_LN_final(x_t)^T E^T(p_t−onehot(y))。预测第一层attention输出投影的梯度为监督加权的epsilon_t m_t^T平均。

这是带位置、掩码和目标权重的token共现统计，经共同固定参数收缩得到的矩阵；无需真实模型的上下文化激活或梯度，也不拟合旋转、比例或回归系数。它等于在零残差基线中加入一条无穷小均匀注意力OV分支时的精确导数，而不是完整Transformer的精确导数。真实模型的注意力仍按原QK计算。本预测忽略其他残差分支、学习到的非均匀注意力及跨层反传，实际误差正是待测对象。

三个固定版本：position保留绝对位置；token去掉绝对位置以检查纯token统计的解释力；shuffled在每轮每个监督列内打乱目标与前文的对应，精确保留该关系/位置的答案直方图及监督量，使用同一固定置换种子317041和跨组织共同置换。EOS目标相同，因此shuffled对EOS本身不构成有效负对照，主要用于答案梯度。关系token保留在前文中；本轮不拟合关系专属参数或对每个关系另做多重检验。

补充数据审计：共同事实多重集与监督bigram一致；计算中心化城市×人物上下文统计子块。阻断跨事实注意力后，该子块及共同状态的完整梯度应在三组织间一致，后者只允许数值消减残差，主投影相对两臂平均范数须小于1e-4。对接近零的差值不解释余弦。全部统计按实际掩码归一化，不能用整篇文档无权词袋替代。

### 16.3 终点、预算与结果解释

主终点为0步、开放注意力、答案部分中company−neither及project−neither的真实与position预测梯度差值余弦；完整保留四个世界/初始化块。并列未拟合的相对误差与预测/真实范数比，不能用高方向相似声称幅度准确。次要分析固定为32/128步、EOS及两部分相加、company−project、token/shuffled对照和各层各模块差值范数。所有结果按预先给定矩阵发布；不挑最好层、最好状态或最好组织对比。两世界只作开发描述，无参数维度、查询层面或初始化层面的显著性检验。

正方向且相对shuffled有稳定改善，可支持继续检验此近似；幅度误差大则只保留方向结论。若所有版本都差，优先定位残差/非均匀注意力近似哪里失效，而不判定语料统计无作用。本轮不测编辑收益，不把梯度预测直接写成组织→编辑的完整机制。小幅或条件性信号仍可用于决定下一步探索。

固定配置为`configs/bios-context-gradient-v1.json`，入口为`python scripts/run_bios_context_gradient.py freeze/run/summarize`。采用当前可用PyTorch环境，运行器记录软件、设备、世界/初始化、共同checkpoint、数据/源码指纹及每臂梯度文件。原始产物位于`results/bios-context-gradient-v1/`，小型契约与汇总位于`docs/development-artifacts/context-gradient-v1/`。启动前完成解析预测与独立autograd推导的一致性、掩码、梯度消减、模块计数及计分测试；不重复既有大批次归档。
