# 层数、循环次数与多跳组合：开发实验 v1

授权：2026-10-16用户明确要求编写代码并行运行普通Loop／DiscoLoop的1×2、1×3、1×4、2×2八臂；每个训练终点评估测试1–4轮下1–4跳，重点为仅受原子训练的事实组合。历史状态、轮次条件均不加入。

## 问题与证据层级

分别改变每轮完整Transformer层数L与训练轮数R，比较固定曝光下的组合表现及同一检查点改变测试轮数r后的行为。1×4和2×2同为四次层执行，但参数量和DiscoLoop接口次数不同。端到端成绩不直接证明每层或每轮恰好执行一跳；本批不新增内部预测器或干预网格。

## 来源与历史去重

详见[历史核查](history-review.md)。借鉴DiscoLoop附录A.2的双图、全部原子加图A组合及最终答案监督；借鉴Kohli等的置换图控制后缀捷径；借鉴Zhuang等固定执行深度与训练／测试轮数区分。不是这些论文的原实验复现，且不与Wang原图分数混算。旧规划撤下置换世界的决定，被本次明确采纳方案与执行授权在本批范围内更新；原Wang主设定和旧批产物不改。

## 数据

两个实体不相交的图，各500实体、10关系，关系词汇共享。每图每个关系为独立随机置换，共10000条原子事实；全部进入训练。图A每跳2／3／4各5000条唯一组合训练题。图B任何长度的组合和子路径训练题均为0。单跳与各长度混合训练，不是未见长度外推。

每跳分别抽4组关系序列，遍历该图全部500起点，形成ID／OOD各2000题；相同关系序列的答案恰好遍历500实体，后缀关系独立于起点不能超过1/500。ID完整问题不与同长度训练重叠；图A跨长度子路径可能重叠，单列限制。图B全部组合从未训练，是主评价。另报路径实体不重复子集。一个开发世界、一个初始化，不冒充独立世界确认。

## 模型、监督与预算

完整原生GPT-2 pre-LN、因果attention、GELU MLP、残差、学习位置嵌入、原最终归一化与绑权词表读出。宽768、12头，dropout .1。独立层各自随机初始化；相同L的两架构及不同R使用相同初值。DiscoLoop沿已审计实现，在每个非末轮、所有位置添加温度1、alpha1、无仿射RMS软解码再编码通道。无首轮KV、历史状态、轮次条件和辅助损失。

每臂固定300000步，共2400000科学更新。batch512、AdamW、lr1e-4、前2000步warmup、wd.1，来自已验证GPT/DiscoLoop配方；新图下不声称已找到最优训练参数。仅监督答案和EOS两个位置，不监督桥实体；工程32步每臂另计、全部丢弃并重置科学初值，不据其得分选条件。固定曝光为主比较；唯一参数、每类样本曝光、有效／执行token、包含词表通道的矩阵FLOPs与耗时分别记录。共享主机耗时不当独占GPU效率基准。

## 评价与审计

主指标为全词表答案argmax，答案+自行预测EOS另报。答案在第一遍因果前向中读出，不反馈桥实体；第二遍仅用于EOS，答案分数不依赖它。训练曲线在原训练轮数下保存；每个正式终点重新加载，在r=1,2,3,4分别完整前向，覆盖单跳A/B、训练组合和ID/OOD两／三／四跳共11池。不得把训练四轮测试两轮称为按两轮训练。

保留全量预测、每题标签、EOS及NLL。按同测试轮数的必要原子事实正确子集另报覆盖率和成绩；另报同模型四个测试预算共同前提子集。零覆盖记NA。评价前后模型哈希、原训练轮数、训练模式和RNG保持。新独立容器对原轮数和全部四轮网格逐题重放；答案／EOS ID须一致，NLL和汇总容差1e-6。云端完整终点JSON与独立审计结果核验单列，不用训练完成代替审计。

## 执行与恢复

使用固定LM镜像sha256:9643a7d6aeda1b4c9ac2ac50c2d84474b082d649a87e423bc6e0bdc0994097ee。所有数据、冻结源码、日志、权重、运行命令和锁在`/ossfs/workspace/llm-memory-editability/loop-hop-depth-development-v1`。仅通过`docker --context lm-memory`，每阶段独立容器、每臂2个CPU和16GiB内存。凭据通过Docker API仅复制为容器内0400文件，不扩大原主机私有文件权限。

先CPU契约，随后全部八臂CUDA预检、32步工程短训和新容器原轮数／全网格重放均通过，再启动科学训练。最大八臂并行，每卡一臂。显卡须无CUDA进程、无其他任务明确按设备登记的运行／等待容器，且使用≤512MiB、利用率≤5%；不抢占、不停止旧任务、不利用旧任务等待间隙占卡。无卡时控制器排队，等待上限168小时；单阶段硬超时24小时仅停止本批该容器。阶段失败保留记录，不自动重训或扩预算。

恢复先读controller-process.json、controller-state.json、freeze.json、各阶段exit.json及实际Docker进程。已完成阶段只校验复用，失败阶段不得直接重试。锁防止双提交。当前授权不包括确认世界、历史／轮次分支或接口新增训练。
