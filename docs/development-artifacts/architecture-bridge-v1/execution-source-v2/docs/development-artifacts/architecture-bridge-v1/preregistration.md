# 小模型架构与桥接通道实验 v1

本轮于模型实验前登记，用户于2026-09-29授权执行。研究原则、当前理论与历史结果沿用主计划；本批结果不改写任何旧契约。精确启动时间、配置/数据/源码哈希和模型revision写入机器可读锁。

## 问题与范围

检验已有信息经过MLP输出与后续序列状态时，哪些通道改变完整答案及竞争分数。比较Qwen3-0.6B-Base与Qwen3.5-0.8B-Base文本骨干；不将两个预训练模型的分数差归因于架构。Qwen3.5的视觉分支不参与。MoE及路由边界仅作独立CPU数学检查。

## 自然语言配对干预

- 从历史冻结288例中按新哈希顺序固定MQuAKE/2Wiki各4开发+24评价；这是复用案例的探索，不是全新独立确认。MQuAKE闭卷，2Wiki只给gold-support段落，额外信息单列。
- 每例构建同一上下文、两跳问题与`Intermediate entity:`提示。三个前缀只更换桥实体：正确桥、错误桥、另一错误桥。候选桥来自同数据集同split；排除正确桥别名、正确答案泄漏与相同名字，要求三个完整前缀在两个tokenizer中长度一致。按哈希选取，不读模型输出。没有合格替换的案例记缺失，不追加替代案例。另测不提供桥的原问题和两条单跳。
- 在层6/14的前缀末位置，捕获MLP输出；捕获同层mixer的完整前缀缓存。Qwen3缓存是K/V，Qwen3.5是递归矩阵与卷积状态。MLP修改影响更高层残差/缓存；同层mixer缓存替换影响后续token，二者不是同一个操作。
- 从错误桥前缀出发，分别替换MLP输出、同层缓存或同时替换。正确供体、另一错误供体及按正确供体差分逐张量匹配范数的随机方向均执行；随机通道允许离开自然状态流形，只作为非特异扰动对照。baseline与identity重复用于数值及hook清理审计。所有前缀之后继续完全相同的`\nAnswer:`再生成，避免state干预尚未影响首个答案token。
- 主读数为完整短答案canonical EM及F1；另报collision-filtered aliases、结束符/预算耗尽、正确答案含EOS的平均及总log概率与固定竞争答案分差。原始输出、token ids和分数保留。正负对照差和MLP×state交互按案例配对，不把层或条件当独立样本。
- 检验self/identity、cache deepcopy、完整前向与拆分前向等价、state类型/形状、固定权重、每条件可重建。FP32、禁TF32；缺失、数值异常、所有条件不论效果均报告。前缀上限2048，不静默截断。

## 有限局部学习

每模型4个固定2Wiki目标episode，从同一原始权重独立开始，仅更新第14层down矩阵8步SGD(lr=0.001, clip=1)。训练输入是第一跳问题+相同support段落，监督完整正确桥答案含EOS；另外4条独立R第一跳提示以编辑前next-token分布KL回放，权重1。D为原两跳问题，只评价不训练；8条U独立第一跳问题完全不参与更新。0/1/4/8节点报告E/D/R/U生成及R/U分布漂移。目标、R、U按源实体分离，从未用于干预的同split预留案例中确定R/U，不能用U调参。学习的是补强原事实，不称为事实替换或参数记忆容量实验。保存每episode端点down矩阵、节点结果、损失与参数增量。

## 数学与受控架构

CPU float64验证固定路由MoE、路由切换反例、GatedDeltaNet状态传递和非线性接口余项；这不是自然模型机制实证。小型从头训练比较另由`architecture-bridge-toy-v1`配置冻结：2世界×2初始化×2架构，共8条1024步轨迹，全部运行；训练/留出组合分离，比较完整答案与自主两次调用。自然模型缓存干预与小模型mixer输出干预分别报告。

## 解释限制

显式桥提示建立可控制的信息通道，不能证明自然推理已经使用可分离的两跳接口。一次patch的改善可能来自通用扰动；须与错误供体、随机方向及完整供体输入比较。冻结权重下的缓存替换不会永久改写知识；持久保持只由局部学习E/D/R/U实验讨论。P4不被解释成SGD/Adam长期速度规律。所有小样本区间为探索性，不作普遍架构优劣声明。
