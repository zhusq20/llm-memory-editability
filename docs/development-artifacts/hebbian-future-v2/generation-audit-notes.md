# 生成原文事后检查

本记录在冻结评分完成后形成，未改写`measurements.json`中的解析结果、主预测表或自由生成准确率。

`generation-audit-sample.json`按可识别正确、可识别其他实体、歧义、未识别四层各保留8个固定哈希样本。它是案例检查，不是各类错误率的无偏估计。

另查看自然改写评价集的全部16个歧义输出，均为“实体 and is/was/released…”结构。依原别名库，仅解析` and `之前的部分，16/16均与来源目标实体一致。这里的and连接后续谓语，冻结解析器过于保守。该核对只说明所问实体与标签一致，不认证续写中其他年份等主张。

未识别案例还包含“died in”“was founded in”后生成年份、影片/作品的一般介绍、额外格式文本等。未知不是已证实事实错误；完整句严格整行不匹配也不是知识缺失。可识别但与标签不同的案例存在潜在实体歧义或多值真值，尚未外部逐例复核。

下一批应先在独立开发材料明确地点/年份问法、允许实体后合法谓语续写，再对新的评价材料冻结测量规则。当前原始输出和评分完整保留，供独立重评。
