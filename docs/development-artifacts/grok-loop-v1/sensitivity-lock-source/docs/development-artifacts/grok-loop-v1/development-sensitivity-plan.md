# 开发敏感性补充：初始化与计算深度

这是在读取两跳开发结果后设计的补充，不属于原始确认矩阵，也不按其OOD最高分替换原主设置。原15臂先完成，以下六条随后一次性运行，固定128k步；无论结果如何保留全部六条，不继续搜索初始化、循环数、学习率或训练预算。

触发证据：145001世界两跳C4和L2R2的原子与训练组合均100%，ID分别98.21%/100%，OOD1.30%/6.48%。L2R2同checkpoint的预设测试轮次1–8扫描在R4时OOD36.48%，但单跳降到92.19%，随后更多轮次退化。这提示训练深度与初始化值得独立核查，不能由原预算低OOD判架构上限。

方法依据：[Loop, Think, & Generalize v2](https://arxiv.org/html/2604.07822v2)§4–5、附录F使用共享4层、R至少2及残差输出零初始化，并报告默认初始化对循环外推的敏感性。本批仍是宽128、2层共享块的小型适配，不称原规模复现。
