# Looped Transformer 知识组合比较 v1

用户已授权按前一轮讨论实施。本批从头训练，不使用预训练权重。历史实验与产物不改写。本文件在本批首次研究训练前写入；开发选择、确认锁与修订另记。

## 研究问题与方法来源

主要问题：在相同事实、监督和实际展开深度下，跨计算阶段共享参数是否改变留出知识组合；等参数浅层对照用于区分额外计算的作用。结论目标是受控行为规律。纯前缀状态置换进一步检验哪些执行阶段携带后续可用信息，不能直接证明知识独占于MLP或一轮一跳。

- Saunshi et al., [Reasoning with Latent Thoughts](https://arxiv.org/abs/2502.17416)，已读方法§2–3及附录B：借鉴固定共享块、等参数浅层与等展开计算深层三方比较。原p-hop是上下文检索，本批是闭卷参数事实；不照搬原文最佳种子统计。
- Kohli et al., [Loop, Think, & Generalize](https://arxiv.org/html/2604.07822v2)，已读§3–6及附录C/E–K，并核对[官方实现](https://github.com/OSU-NLP-Group/Loop-Think-Generalize)：借鉴GPT2循环、仅最终答案监督与只学过单跳事实的组合评价。原文还改变初始化、NoPE和课程训练；本批第一阶段不同时引入这些变化。其残差零初始化作为开发阶段明确候选。
- [DiscoLoop v2](https://arxiv.org/pdf/2607.00341v2)，已读§2–5及附录A/B：共享权重并不自动保证桥表示可复用。其实体隔离OOD图、固定循环数与本批不同，不把论文成绩作为本批预期。

## 数据、监督与配对

每世界128实体、16关系、每实体8条边、1024原子事实，复用既有随机图构造。原子边ID比例改为0.75，全部原子均参加单跳训练，只有ID边参与组合训练；纯OOD链只用于评价，混合链不纳入本批主评分。此变化为补足原95/5小图的长链OOD样本，不将新成绩与旧批次直接合并。

分别训练单跳加指定两/三/四跳，无中间实体或CoT监督。完整ID链先随机留出10%，其余抽取组合训练。phi分别6/24/96，先公布纯数据数量与覆盖，不依据模型表现筛世界。每批256例固定32原子、224组合，两流独立均匀遍历并交错；这使phi变化不改变每步单跳比例。只对最终实体和EOS计算等权交叉熵；评价使用自产答案继续生成EOS。

开发世界145001；确认候选世界145011、145012、145013。开发初始化14501，确认每世界两个初始化14501/14502；不将初始化视为独立世界。每个世界/跳数/初始化内所有模型使用相同数据、batch序列与训练步数。开发结束前不评分确认世界。

## 架构、优化与预算

宽128、4头、GELU、pre-LN、学习式位置嵌入、tied embedding/head、dropout0.1，与现有模块相同。独立层数b，循环R，实际执行深度D=bR；全部模块参数跨轮共享，完整反传，embedding仅首部、最终LN/head仅末部。

每跳5臂：C1=(1,1)、C2=(2,1)、CD=(D,1)、L1=(1,D)、L2=(2,D/2)。两/三跳D=4，四跳D=6。CD/L1/L2约等每例矩阵计算，C1/L1及C2/L2分别等参数。计算次数与数据跳数不绑定为机制假设。

默认残差输出初始化按实际展开深度缩放0.02/sqrt(2D)，其他初始化沿用现有实现；独立层保留独立随机抽样，不声称同seed意味着跨架构逐参数同值。AdamW lr1e-4、wd0.1、warmup2000、梯度裁剪1、128000步，每例最终两个目标。使用FP32参数与优化器、TF32矩阵乘法，CUDA Graph只作执行优化。

开发先完整运行15臂。若两/三跳循环臂的单跳<99%或训练组合<95%，在相同数据/预算上对受影响跳数的C2/CD/L2追加zero_residual配方，记录全部原结果；仅用开发原子/训练拟合及ID学习曲线判断优化是否有效，不按确认分数选配方。四跳若CD与L2均未在留出ID达到90%，以开发数据进一步校准覆盖或训练预算；所有同一比较配对接受同一修改。修改原因与预算必须先写修订，再训练。90%只是是否已有高准确率参考的工作标记，不作为删除低分臂或证明架构上限的标准。

正式矩阵与优化配方在开发后另锁，原则上保留5臂、3新世界×2初始化；四跳若仍在开发校准，明确单列而不伪称已建立高准确率确认。每条固定终点，不按最高中途成绩替代。每2000步评价至16000，之后每8000步至128000；0/16000/64000/终点保留权重，其余保存恢复状态与完整预测。

## 终点、机制与解释边界

主报告ID完整留出链与纯OOD链的答案+EOS准确率，并列答案准确率、单跳ID/OOD、训练组合、外部自主逐跳调用。完整测试集终点，固定1024题ID子集学习曲线；全量结果不得被原子均正确子集取代，条件子集另报覆盖。

统计先平均世界内初始化，再世界等权，给各世界配对差与全部运行。并列训练步数、曝光、参数、实际展开FLOPs及墙钟；同GPU并发时间不当作架构速度结论。绘制随训练及实际计算量的ID/OOD曲线，达到90/95%的成本未达者记未达。三世界不足以支持普遍架构定律。

机制分析先在开发实现和冻结，然后对正式端点遍历执行层：same-r1的纯首跳供体[h',r1]，不同bridge，后继边存在、新完整组合未训练、最终target变化，供体不可见后续关系或答案。在r1位置分别替换注意力增量、MLP增量、两者和完整残差，混合后不重算当前MLP。必须检查self恒等；首个执行层因same-r1嵌入相同，两增量同时替换应等价整块替换，后续层输入残差已不同，不要求此等价。记录coverage、原答案保留与新路径target+EOS、完整反事实输入的正常表现。只凭混合状态失败不能断言信息不存在。

同一checkpoint增减测试循环只作为循环稳健性描述，固定循环训练的额外轮次属于分布外执行；不把其失败等同于架构不能长度外推。训练短链到测试长链、知识容量负载与离散桥注入为后续独立实验，不混入本批主比较。

## 执行审计

先检查权重绑定、展开梯度求和、R=1兼容、因果性、数据真值与隔离、采样恢复、FLOPs、CUDA Graph/eager及恢复一致性。每阶段冻结配置与实际源码哈希并保存源码快照。所有端点独立同精度重载复算，保存原始答案/EOS/NLL。失败、重试、未达标臂与开发修订全部保留。
