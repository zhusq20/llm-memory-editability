# Looped Transformer 正式确认计划 v1

本文件在确认数据生成、模型训练和评分之前登记正式矩阵。配置已准备，尚未冻结或执行；原15条开发运行完成后另行保存 `confirmation-lock.json` 及源码快照。方法、数据构造与评分沿用[原预注册](preregistration.md)和[开发配置](../../../configs/grok-loop-development-v1.json)。

## 固定矩阵与预算

[确认配置](../../../configs/grok-loop-confirmation-v1.json)登记3个新世界145011、145012、145013，每世界2个初始化种子14501、14502，每种初始化分别训练两、三、四跳及5种架构，共90条运行。初始化重复嵌套在世界内，不视为独立世界。

两、三跳实际展开深度D=4，四跳D=6。每跳保持C1=(1,1)、C2=(2,1)、CD=(D,1)、L1=(1,D)、L2=(2,D/2)，括号内分别为独立层数与循环次数。宽128、4头、残差输出按实际深度缩放初始化 `scaled_effective`；学习式位置嵌入、dropout0.1、AdamW学习率1e-4、weight decay0.1、warmup2000均沿用开发基准。

每条固定128000步，每批256例由32条原子事实与224条组合构成，总曝光32768000例，其中原子4096000例、组合28672000例，监督65536000个答案/EOS token。90条共11520000次更新、2949120000例曝光；各架构实际计算量按执行层数分别记录，不能把相同步数称为所有架构等计算。评价节点与保留权重节点逐项继承开发配置。

图规模128实体、16关系、每实体8条边，原子ID比例0.75、完整ID查询先留出10%，phi分别6/24/96，固定ID probe最多1024条。构造器的训练池上限、空分母与覆盖不足照实记录，不重选世界。所有原子事实参加训练，只有ID事实进入组合训练。

每个世界/跳数/初始化内5个架构使用相同采样序列。采样种子固定为 `world_seed * 1000 + hops * 10 + (initialization - 14500)`；它不依赖模型或观察到的准确率。输出位于 `results/grok-loop-v1/confirmation/<run_id>`，与开发及敏感性实验分开。

## 开发敏感性与确认的边界

[6条开发敏感性比较](development-sensitivity-plan.md)检验初始化和D8的影响，独立保留。**正式主矩阵不根据敏感性OOD结果替换初始化、深度、架构、预算或世界。** 主比较保持原15臂的设置，在3个新世界与2个初始化上重复。

原子或训练组合拟合不足的臂、低准确率臂及失败重试均保留。四跳是否已有高准确率开发参照由完整开发结果决定；它影响结论措辞，不用于删除失败臂或将确认世界用于再次校准。固定128k内缺少系统组合收益只支持该预算与配方下的有界结果，不能证明架构能力上限。

## 评分与汇总

主评分为终点完整ID留出池与纯OOD组合池的答案+EOS准确率，并列答案准确率、ID/OOD单跳、训练组合与自产桥实体的外部逐跳调用。保留全部学习节点和原始预测，终点不得被中途最高成绩替代。原子均正确的条件子集与多目标关系后缀子集另报准确率及覆盖率，不取代全量评分。

同一世界与初始化内比较CD/L2、CD/L1（等执行深度）及C2/L2、C1/L1（等参数）。共同训练FLOPs比较以两端点预算较小值为上限，分别取上限内最新已有评价节点；明确节点、实际FLOPs及剩余预算，此处ID使用固定probe而终点ID使用全量留出池，不为凑预算插入训练。

等参数浅层与循环模型的残差初始化尺度随实际深度D变化，因此该比较同时改变执行次数和初始化尺度，不能单独归因为增加计算。等D的CD/L1/L2使用相同残差初始化方差，但参数是否共享及独立参数量不同；同编号种子不表示逐参数相同初值。

先平均世界内初始化，再世界等权汇总；报告各世界结果、配对差及世界范围。三世界不足以支持普遍架构定律。逐学习节点独立复核计分、32/224曝光、tokens、FLOPs；比较配对采样状态，终点按执行精度重载核验。内部机制归因另依原预注册的纯前缀置换及其控制。

## 预定循环扫描与机制分析

正式所有L1/L2终点固定权重，逐一扫描测试循环次数 `repeats=1..8`。完整报告原子事实的答案准确率和答案+EOS准确率、固定ID probe与全量OOD准确率曲线，并用竖线标明该模型训练时循环次数。扫描不用于选择主终点、最佳循环次数或停止规则；改变测试循环次数属于执行分布变化，不能与重新训练该循环数的模型混同。旧C2/CD重复执行仅在开发两跳中作为探索对照，不纳入正式循环模型汇总。

正式5种架构的所有终点均按训练时正常循环次数进行机制评价。在 `test_composite` 和 `ood_composite` 上，沿全部实际执行层分别替换注意力增量、MLP增量、两者及完整残差，供体、反事实有效性、self恒等和覆盖报告遵循原预注册。分析保留源checkpoint与其训练时循环次数，不使用扫描中表现较好的额外循环设置替代机制主结果。
