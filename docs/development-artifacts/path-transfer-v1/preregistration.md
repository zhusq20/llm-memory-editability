## 18. v2.13 Transformer计算路径与知识促进／干扰

### 18.1 研究目标、授权与阶段

用户于2026-09-27要求从数据组织推进到架构本身的机制与数学解释，并授权将计划写入本协议、开展实验。主要问题是：在固定事实与模型状态时，后续注意力的跨位置反传及MLP分支怎样改变学习一条事实对另一条事实的影响？§17的早期第一层均匀注意力结果仅提供动机，不作为成熟模型机制已成立的证据。

阶段A：在现有8层模型中做精确逐位置梯度分解，覆盖初始化、中期、训练终点。阶段B：保持前向值不变，干预反传路径，实际做单步更新并评价影响。A/B为本次先行执行的固定开发批次。阶段C：根据A/B定位出的路径，建立两层最小Transformer并开展针对性的结构／学习验证；先完成固定注意力两层公式的数值校准，具体训练变量及预算在读取A/B结果后、最小模型训练前另行封存，不把校准当成从头训练。若A/B没有选择性机制信号，记录负结果并据此决定C的操纵，不事后挑选最有利事实。独立新世界与完整AdamW多步编辑属于后续验证，不将既有世界100–107重新当作未见数据。

本批次配置`configs/bios-path-transfer-v1.json`，生产实现`bios_path_transfer.py`，结果`results/bios-path-transfer-v1/`，小型工件`docs/development-artifacts/path-transfer-v1/`。首次真实模型测量前封存本节、配置、实现、测试及输入文件哈希。历史生产源码和结果保持不变。

### 18.2 数学对象与可证性质

固定层的MLP输出写为残差增量Wz_t+b，z_t为真实GELU激活。令δ_it为损失L_i对该增量的梯度，则G_i=∇_W L_i=Σ_t δ_it z_itᵀ精确成立，求和覆盖全部位置。将监督位置集合记作S，G=G_S+G_非S；各部分的范数可相互抵消，不将范数比称为解释百分比。

只对W做SGD：ΔL_j=−η〈G_j,G_i〉_F+O(η²)，其中〈G_j,G_i〉=Σ_tu〈z_ju,z_it〉〈δ_ju,δ_it〉。特征重叠与反向信号同向程度共同决定局部迁移；等式和Taylor展开是校准工具，不能独立算作机制发现。对于干预产生的更新方向g_i^a，预测必须使用**原模型的真实G_j**：ΔL_j≈−η〈G_j,g_i^a〉，不能把j的梯度也换成干预梯度。记录实际FP32舍入后的ΔW并以〈G_j,ΔW〉复核。

在当前逐位置LayerNorm／MLP和残差结构中，若某中间输出之后不存在跨位置Jacobian块，且损失仅监督S，则δ_t=0（t不在S）。该性质针对中间激活，共享参数仍可造成跨样本干扰。对于固定A的最小后层注意力残差h_s=r_s+BΣ_t A_st r_t，单位置监督下∂L/∂r_t=1_{t=s}e_s+A_st Bᵀe_s。均匀A仍传递梯度。学习QK、后续MLP及LayerNorm后必须加入真实Jacobian项；不把固定A公式直接当成全模型定理。

残差／注意力路径分析参考[Transformer Circuits](https://transformer-circuits.pub/2021/framework/)；早期关联学习参考[Gradient Leading Terms](https://arxiv.org/html/2601.19208v2)。后者理论采用attention-only与早期梯度下降，不能直接代替本模型GELU、LayerNorm及成熟状态的分析。本研究贡献若成立，应是可预测、可干预的具体路径机制，而非重新命名链式法则。

### 18.3 固定数据、模型与事实对

只用既有neither组织（仍保留同人分组），宽度256／8层／4头，世界0/1×初始化0/1，共4条既有学习轨迹。读取同一轨迹的0、5120、15360步，共12状态；不拼接v2.11的FP32短轨迹。目标为0起算第4层MLP的down.weight，其余参数全部冻结。阶段A/B不会新增预训练。

沿用每世界两条关系的edit_pair(support=0)，每链3组。每组从原exception冲突人员中，按人物ID固定选择首个组合QA留出人员；另取首个不同的、非旧例外的组合QA留出同组人员。没有符合条件则在生产前报错，不按模型效果换人。每组建立3个源更新：组织默认事实→新默认；该人的实际城市→新默认（一致）；完全相同实际城市问题→新替代城市（冲突）。共2链×3组×3=18源案例／状态。

每案例评价源目标、所选人物的留出组合QA、另一个同组人物的留出组合QA、关联直接事实（源为默认时评价个人实际，否则评价默认）、同人另一链实际城市及组外人物实际城市。前四者按本案例新真值，后两者按旧真值；所有原始ID与目标保存。组合查询和保持探针不进入更新目标；留出指学习QA划分或本轮未用于更新，不冒称模型从未见过全部直接探针。选择不依赖基线答对与否，同时报告全部及基线旧正确保持子集。

源和探针损失均为答案与EOS两位置交叉熵各1/2，长度、答案输入和因果mask按原查询接口。主要终点为真实目标损失的变化；额外保存完整答案自由生成（预测答案后生成EOS），不以teacher forcing正确率替代自由生成。

### 18.4 干预与数值控制

full：原模型完整反传。no_cross：仅将第5–7层attention输入到输出Jacobian的跨位置块置零，同位置块、LayerNorm和残差保留；不是把attention整体置零。no_mlp：仅截断第5–7层MLP分支反传，残差不变。fixed_qk：第5–7层attention在反传时固定softmax权重，保留V/O内容路径。所有干预前向返回原attention／MLP值；仅目标W可更新。

先用独立小模型核验：前向完全一致；no_cross的Jacobian等于原Jacobian的对角位置块；fixed_qk保留值路径；no_mlp保留残差；外积和重构真实参数梯度；全模型截断后非监督位置梯度归零；固定A公式对上autograd。真实测量每案例检查前向一致与重构误差；另外保存未干预重测sham。FP32模型／梯度、禁TF32，内积与损失归约FP64；工程测试的随机数据不计入科学样本。

### 18.5 单步预算、指标与判读

每个源更新从相同父状态重新开始，禁止累积；不使用KL回放、权重衰减、动量或裁剪。以full梯度定义η_f=f‖W‖_F/‖G_i‖_F，f={1e−4,3e−4,1e−3}。shared_lr所有臂用同一η_f；matched_norm各臂改用η_f^a=f‖W‖_F/‖g_i^a‖_F。零方向保留零更新并标记，不除以零。full的两个尺度条件相同，属于重复数值控制，不当作独立重复。共12×18×4×3×2=5184个单步条件（含648个full重复条件）。主比较固定成熟状态、matched_norm、f=3e−4；其他阶段与步长作为完整预定次要分析。

保存每个源及探针的z、δ、梯度分解、真实内积的监督／非监督四项贡献、前向值、实际更新范数、更新权重哈希、预测损失变化、实测损失变化和自由生成。必须核对非目标参数无变化、每次父状态恢复，以及预测误差随步长的情况。Taylor预测准确属于数值／局部有效性证据；科学问题是路径删除是否有选择地改变一致／冲突事实的联动，并保留源目标改善。范数匹配不能保证源损失改善匹配，二者均报告，不把更弱的目标更新当成选择性修复。

按世界／初始化配对汇总链与组，公开全部4块；仅2个开发世界，不做查询级显著性检验，不按终点换层、换人或增加世界。机制信号允许部分、相反或零效应；目前没有预设“attention有害”或“MLP保护”。仅相关、局部Taylor准确、或截断一切导致学习消失，均不足以声称识别选择性机制。完成后更新本节执行记录及结果报告，按结果为阶段C锁定最小操纵。
