# 开发后冻结的后续比较

开发两臂8k完成且独立评分与端点重载通过。R4单终点/多终点为10.19%/27.78%，R8为40.19%/44.07%；原子R4均100%，ID均≥99.77%。两臂额外循环均转为收益，故不能再把R8−R4直接称为退化，需与绝对分数及全曲线一起解释。

保留共同8k步固定预算，不宣称优化已收敛或这是最优预算。该预算已使训练操作产生清楚且不同的行为变化，先检验其跨世界可重复性；节点波动不作为删臂或追到显著的理由。12条后续运行前冻结此决定，沿用原配方、节点、R4/R8主比较和R1…16曲线，世界145011–145013各两个初始化。开发不并入主均值。

R4保持的描述性参照为相对原端点不下降超过1个百分点，同时报告未经阈值化的连续差和每世界数据；这个参照不作为接受假说或继续研究的门槛。组间差和各自相对起点变化都报告。

附带有限轮数动力学检查：全部六个原端点及其两个续训端点，在纯OOD全池上逐轮运行至R64；仅对问题前缀的完整循环边界测原始残差绝对步长、状态范数、相对步长、LayerNorm后变化及答案margin。前缀不含正确答案。全量保留逐题统计；不拟合预测器，不凭余弦相似或相对步长下降命名不动点。该检查是行为比较之后的探索性测量，不能证明无限轮数收敛或吸引性。若原始步长持续非零而范数增长，则区分尺度增长造成的方向稳定与原始状态收敛；不能据此否定其它架构/训练下的不动点问题。
