# 多终点答案监督与循环退化 v1

## 授权、问题与证据层级

用户已授权执行修订计划，并明确不要因严格gating放弃有价值的方向。本批从既有模型配对续训，先检验训练目标的行为因果效应；隐藏状态诊断用于区分后续解释，不把方法收益直接命名为不动点机制。

方法来源及已读范围见当前计划的 loop-method-revision：NeurIPS 2022 Bansal等的训练/输入因素消融、ICLR 2025 Saunshi等的计算对照，以及Loop Think Generalize的匹配训练跳数比较。这里拆分监督终点因素，采用完整反传，不冒称原progressive方法复现。

## 配对操作

旧两跳L2训练R=2、128k端点，复制完整模型、AdamW、采样流及随机状态；不改写历史文件。每batch 32基础原子+224原ID组合，OOD边继续没有组合曝光。两组都执行R=4：single目标为ℓ4，multi为(ℓ2+ℓ3+ℓ4)/3。每个ℓ沿用最终实体与EOS等权CE，不加入中间实体。两组都计算三支CE及其反向，single用零权重保持中间分支；无编译剪枝。总目标权重为1，但第四轮权重及早期梯度同时改变，效应解释为整体训练目标的效应。

保持原FP32/TF32、dropout0.1、AdamW lr1e-4/wd0.1及裁剪1。学习率已处于原warmup之后，继续1e-4，不重启warmup。CUDA Graph只作执行优化，捕获前后权重和优化器必须一致。所有中间读出均从残差旁路读取，不写回循环状态。计算量采用原矩阵乘FLOPs估计并计入三次head；两组同图，另报墙钟。

## 开发与后续比较

开发世界145001、初始化14501，两组先续训8k步；节点0/100/500/1k/2k/4k/8k。若学习轨迹仍变化，可登记修订后配对延长两组，保留原节点与预算。小收益、负结果、非100%掌握不是停止研究的门槛。配置改变只在开发中校准，记录原因，不丢弃初始设置。

开发检查操作有效性与知识保持后，锁定共同预算和配方，在既有145011/145012/145013三个世界×14501/14502两初始化×两臂进行12条后续续训。它是既有世界的冻结后续比较，不称新世界确认。不得根据某个后续世界的结果删臂、换预算或重选主循环数。

## 评价、统计与解释

主比较：纯OOD全池R4/R8完整答案+EOS正确率；各臂d=Acc8−Acc4及配对d_multi−d_single，同时报绝对分数，避免以降低R4换取表面退化减小。原子、ID和EOS单列。R1…16在起点及终点完整扫描，内部节点R2/3/4/8；训练组合在R2/3/4全量评价。保存各节点原始logits、自产答案、自产EOS、CE和margin，CPU独立复算并在GPU重载端点。

每世界内平均两个初始化，再世界等权，同时列全部配对差；题目、节点和循环数不当独立世界。报告全池逐题正确→错误/错误→正确转移。若另报起点R4正确子集，用同一源模型固定筛选并给覆盖，不替代全池；不按真值挑最佳停止轮次。

R8提升且R4保持、退化减轻：支持多终点目标改善行为稳健性。两者整体提升而退化相近：仅支持一般能力改善。有效优化后仍无明确收益：限定于该配方与预算，保留不确定性，可据证据选择新的机制比较。操作未有效优化：修订优化/目标而非宣布研究问题无价值。

开发后冻结时再登记预算、容差与必要后续动力学比较。代码/数据错误需修复并保留记录；科学效应阈值不作为自动淘汰研究主题的规则。
