# 两跳同桥实体供体比较 v1

用户已授权完成既有轨迹连续评分复盘及本供体实验。本批只评价既有权重，不增加训练、不重建世界。原Loop冻结契约与历史产物按原文保存。新分析先用145001开发端点校准，随后冻结145011–145013的后续比较；这些模型的行为已经被观察过，因此本批不是新的独立世界确认。

## 问题、依据与结论层级

在真实桥实体相同、第二关系与最终真值固定时，第一跳事实是否参加过组合训练，会不会改变其前缀状态对下游的可用性？目标是受控干预证据，不能据此证明知识只在MLP、首跳状态只编码桥实体，或一轮一跳。

方法依据为用户提供的 Wen et al., *Generalization Dynamics of LM Pre-training*, arXiv:2609.33150v1（已读正文及附录）的竞争解释、事实提取与后续使用分开评价；激活操作复用本项目已审核的纯前缀组件置换，其来源是 *Grokked Transformers are Implicit Reasoners* §3.3与附录D.1。新增条件是同桥实体的ID/OOD供体比较；论文的预训练模式波动和容量竞争猜想不作为本批已成立前提。

## 固定输入、矩阵与供体

开发使用原两跳C1/C2/CD/L1/L2五个128k端点；后续使用三个原正式世界、每世界两个初始化、同五架构，共30个端点。主架构比较是CD/L1/L2，C2为浅层参照，C1因只有一执行层而必须对r1置换无后续效应。训练时循环次数保持原设置，不根据既有循环扫描选择R。

接收查询为全量原纯OOD两跳池 `[h,r1,r2,t]`，真实路径 `h→b→t`。ID供体首边必须有实际首位置组合训练曝光，OOD供体两位置的组合曝光均为零。两种供体均满足同r1、同b、不同h，且供体h不等于t；供体前向只输入 `[h′,r1,PAD,PAD]`。全部合格供体枚举，不依据模型表现选择。显式排除head=target会使可用候选受target影响，因此只声称供体前向不访问后缀，不声称整个资格规则与后缀无关。

图审查已知共同供体覆盖较小：开发30/540；三个后续世界为16/515、37/521、42/515。这些数量来自图与训练表，不来自新模型评分，不据此增加世界或换数据。分别报告全量接收基线、单侧可用、双侧共同子集及缺失原因。ID与OOD比较在同一共同查询子集进行；ID单侧可用池相对基线另报，不与共同子集混淆。不同查询共享原子事实，报告独特首边和后继边数，不将查询、供体、组件、初始化视为独立世界。

## 操作与控制

固定第一执行层、r1位置。原状态为e+A+M；正常完成当前块再替换注意力增量、MLP增量、两者或完整残差，混合后不重算当前块MLP。供体MLP已经依赖供体注意力，因此组件效果不等于独立模块知识存储量。

全部self条件及来自接收自身纯前缀的条件须重现基线；第一执行层同r1的both与full须恒等；C1所有供体patch须无效应。核对native/traced和纯前缀因果性、保存端点答案/EOS及答案NLL、模型参数前后哈希。FP32参数与训练TF32设置，不使用autocast；EOS使用自产答案并再次施加同一干预。每个供体池有同批形状基线。

正常反事实完整问题只改head，仍使用相同b、r2、t。ID供体对应ID首跳+OOD后继的未训练混合链；它答对说明同一后继在该完整输入下可以调用，不能把patch失败直接定位为第二跳瓶颈。r2位置的当前层状态仍来自接收问题，混合不兼容或其它位置信息也是竞争解释。

## 评分、前提与汇总

主要终点为共同查询上完整残差置换的答案+EOS正确率的ID−OOD差；分别并列相对各自同批基线的变化。预定次要终点为答案准确率、EOS准确率、全词表下正确答案概率、正确答案log概率以及正确logit减最大其它logit的margin，四组件完整报告，不挑最好组件。

先平均每个接收查询的全部供体（配对时平均全部ID×OOD对），再平均世界内两个初始化，再世界等权；保留每世界/初始化/架构的原始结果和配对差，不做查询级显著性检验。零分母记未定义。条件前提另报接收两条原子皆正确、全部所选供体原子正确、两种正常反事实皆正确及基线失败/正确；不据此筛选或改变主供体集合。

既有轨迹复盘使用独立脚本，恢复答案NLL第一列的连续概率，教师强制EOS第二列与自产EOS正确率分开，开发、敏感性和正式分别报告。本批为事后轨迹分析，不改变原训练终点或T90规则。
