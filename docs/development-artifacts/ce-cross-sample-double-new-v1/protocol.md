# 跨样本连续学习两条新事实的组合实验

复用普通Transformer、普通Loop和DiscoLoop的原生300k检查点，连续接收新原子事实，检查两条分别写入的新事实能否在独立两跳问题中组合使用，以及先前新知识和旧知识的保持。核心比较是相同事实对在独立学习和64条连续学习后的差别。

## 研究问题与已有实验

主要问题是：在相同新事实、写入预算和旧知识保护下，三种现有架构能否把分散在不同样本中的两条新事实用于未监督的组合问题，并在随后写入其它事实后继续使用？这是当前配方上的受控行为比较，尚不以架构排名证明唯一机制。

| 已有批次 | 已回答的问题 | 本次新增条件 |
| --- | --- | --- |
| [整个MLP原子CE三架构比较](../../../results/ce-architecture-novel-v1/report.md) | 每条独立写入后，新事实能否与旧事实组合；三架构新原子均32/32，DiscoLoop两方向均100% | 同一状态连续新增64事实；两跳的两条前提都必须来自本次写入 |
| [TTCD双新评测](../ttcd-double-new-eval-v1/protocol.md) | 已知键更正值的双新组合及连续保持 | 原图缺失键的真正新增；复用已有效的整个MLP CE写入，不加载TTCD适配终点 |
| [一步与merge结果](../../../results/ttcd-evaluation-summary-20261016/report.md) | 指定TTCD配方中连续与独立增量相加的行为 | 连续CE更新共享的MLP参数；不相加独立编辑增量，不追加merge臂 |

[PERK §3及附录B](https://arxiv.org/html/2507.06415v3#S3)提供材料语言模型更新后无原文QA的范式；本次沿用已有符号尾实体CE，不采用其LoRA元学习，不能称PERK复现。[DiscoLoop §4](https://arxiv.org/html/2607.00341v2#S4)的软解码再编码通道保持原样。[uTTT §2–3](https://arxiv.org/html/2610.05484v1#S3)已研究独立骨干层共享快记忆，因此本次仅评价这三个现有模型的整体适应配方；不从排名推出Loop共享是必要条件。

## 检查点与写入规则

只复用已审计的原生300k基础检查点，不加载common/single/stream适配权重，也不重训底座。精确路径与SHA256绑定在配置中；执行前重新核对实际文件、基础审计收据和原生输出。当前设计准备只检查了引用和已有编辑状态文件存在，未重新读取全部检查点/状态字节计算哈希。

| 模型 | 物理层与执行 | 学习率 | 可编辑MLP参数 |
| --- | --- | ---: | ---: |
| 普通Transformer | 8独立层，执行1次 | 5e-6 | 37,779,456 |
| 普通Loop | 4层，循环2次 | 3.2e-4 | 18,889,728 |
| DiscoLoop | 4层，循环2次，保留原通道 | 8e-5 | 18,889,728 |

学习率直接继承已完成CE开发的选择，不使用本次新组合结果重选。原Loop/Transformer开发未通过最差池99.5%保持门槛，按原fallback选定；本次保留这一事实，不能称三架构都经过同等成功的保持校准。

每个事实独立呈现为`h r t`，仅对当前事实的尾实体token作CE，相当于在事实记录上的指定位置做next-token learning。每条固定20次Adam更新，β=(.9,.999)、eps=1e-8、weight_decay=0，梯度裁剪1；沿原CE使用FP32、eval前向、dropout关闭、TF32关闭。只修改全部唯一物理MLP的up/down weight和bias；attention、LayerNorm、embedding、DiscoLoop gate等其余参数冻结。保留原完整残差、因果attention、归一化、GELU与两轮计算，不增加首轮监督或组合答案监督。

每步加10倍旧输出KL。直接复用各模型自己的已审计20批教师，每批16旧原子及16旧训练组合，教师始终来自该模型的基础θ0。各架构的输入、样本顺序及曝光一致；每个事实重复同20批。旧保护池为4096原子＋4096训练组合，实际每事实使用其中320＋320条。正式旧保持题不进入保护或选择。先前新事实不回放。因此本次是有旧知识保护的跨样本适应，不称无回放学习或自然文本TTT。

**持续状态明确为MLP参数改动。** 同一流内每条写完后保留参数，下一条继续更新；每条开始时重置Adam的矩、计数和梯度，不保留跨事实动量。不同流、不同独立事实对均恢复θ0。每个查询单独清空文本、attention/KV和推理状态，只读取当前参数，查询不更新模型，也不能改变写入采样或RNG。

**改动上限始终以原始θ0为锚。** 每次更新后将可编辑参数限制在θ0±0.0005，而不是上一条写完的参数±0.0005。孤立两事实对照也使用同一锚。已有atomic_ce_edit默认以调用时的当前参数为局部锚，后续实现必须新增显式全局锚，不能直接循环调用旧函数而声称本协议已实现。固定改动区间可能限制累计容量，失败只限于该预算和约束，不解释为架构能力上限。

## 新事实与两跳问题

保留旧面板全部32条正式新事实A及其原目标：`A_i=(a_i,r_i,b_i)`。再为每条补一条`B_i=(b_i,s_i,c_i)`，形成32对、64事实。A和B的实体关系键在原40,000原子中都不存在，旧真值一条不改；实体和关系token均已有，不扩词表。

查询是`a_i r_i s_i → c_i`。A与B从不放在同一个写入样本中，未来查询及其答案不会传入写入函数。三架构使用完全相同的64事实和32查询。32个A的历史参考分组为16 ID/16 OOD；两条新增键本身都未受训，这个参考分组不改称新增键的II/OO覆盖。

先按原32正式事实顺序，再按原8开发事实顺序，用固定seed2026101609＋index选择B的关系和尾实体。B关系选种子排列中首个原图与全部已保留新键均不存在的键；c选种子排列中首个不属于所有A的头/尾、且未被此前B使用的实体。每对a、b、c互异，全部新键唯一。选择只依原图，不查看任何模型输出。

原8开发A同样各接一个B，得到8开发对/16事实，仅供未来工程检查，不参与正式比较、学习率选择或本次科学预算。完整40对的80键及40个两跳前缀已经核对：均不在原40,000原子及800,000两跳中。

另为64正式事实各取4条新→旧和4条旧→新组合，固定256＋256题，必要旧原子完全来自未改原图。它们辅助区分单条新事实调用与双新组合困难，不能替代32对双新主指标。

## 连续顺序与独立参照

固定seed2026101610打乱32对得到π。每架构只有两条主流：

1. 正序：`A_π1 … A_π32 B_π1 … B_π32`。
2. 逆序：将上面64条记录整体反转，即`B_π32 … B_π1 A_π32 … A_π1`。

同一对的两次写入之间均隔31条其它事实，两种顺序覆盖A先和B先。每对在两条流终点的闭合年龄之和恒为31，平均年龄相同。两个顺序是同一组事实的重复测量，不是两个独立世界。

每对另有五种参照：θ0、只写A、只写B、独立A→B、独立B→A。只写A直接复用三架构已有32份各自审计过的MLP状态，新增优化0；本次B和组合查询没有出现在这些状态的原训练中。只写B是B→A的中间状态，避免重复写入。独立两事实在原子目标、每事实20步、教师批次、Adam重置和全局锚上均与连续流相同。

独立两事实与连续流含有不同数量的新事实和保护曝光；差异量的是这整段流带来的额外影响，不能把它唯一归为新事实之间的参数竞争。主流与参照均保留，不为获取高分替换顺序、事实或检查点。

## 评价节点和指标

θ0及每条写入20步结束后保存参数状态并做只读评价。每个节点读取64原子、32双新问题、512混合问题，以及沿用原CE的七个旧池各128题（896题）。未提供的新事实只保存最终目标命中率；组合主计分仅包含两条都已提供的链。未闭合链不当作组合遗忘。

主结果是每架构写完64条后32对双新组合的准确率，先在每对内平均两种顺序，再对32对等权平均。按原greedy实体答案及EOS共同正确计分，另列实体正确率，避免混淆格式失败。必须同时报告：

- 全量双新组合、两条原子同时正确率，以及“两原子＋组合均正确”的联合率。
- 两原子当前都正确子集内的组合率和覆盖；无覆盖记NA。另报三架构共同满足原子前提的同对/同顺序子集，不用模型各自不同的分母代替全量比较。
- 刚写齐两条时的组合率及之后保持；先前新原子只在刚写时答对的集合上计算保持，同时给全部已写原子的准确率和写入年龄。
- 七个旧池的写前/写后准确率、A0原正确题保持、丢失与新增正确数；旧原子与旧组合分开。原正确0时保持NA，不当成100%。旧题在不同状态反复读取，不算新增独立知识。
- 连续流相对匹配顺序的独立两事实组合差，以及新→旧/旧→新混合组合与必要旧原子是否仍成立。

终点加一个只读参考：模型自行回答A，再把它预测的桥实体作为B查询的头，报告桥和最终答案均正确的严格两步率。不得输入真实桥实体；其额外两次完整单跳计算单列，不能当作等计算预算的改进臂。

原生七池基础能力另列。三架构基础OO、总/可编辑参数和训练计算已有差别；同展开深度、相同更新数不等于等FLOPs，也不能唯一识别参数共享或软通道的因果作用。

## 统计与结果判读

按32个事实对做10,000次配对bootstrap（seed2026101611），每对内保留两种顺序及全部时间点，报告三架构两两分差及连续相对独立参照的95%区间。区间描述这个固定面板对事实对重采样的敏感性，不代表跨知识图或初始化的不确定性；不同对可共享已有实体，新增键互不重复。两条流、64条事实和重复旧题不当作独立世界。仅一张已观察图、每架构一个已有初始化，本批为开发证据，不用于声称跨世界稳定优势；不追加训练来满足独立世界数量。

不按正式结果选择最优方法或宣布普遍胜者。预定解释为：

| 结果模式 | 支持的解释 |
| --- | --- |
| 独立两事实已失败，但两原子当前都正确 | 当前写入后内部组合仍有缺口；尚不能归于连续干扰 |
| 独立两事实成功，连续流原子保持下降 | 当前持续写入/保持不足，组合下降可伴随前提遗忘 |
| 独立成功，连续原子都正确但组合下降 | 当前流影响了组合使用；不只表现为单跳记忆丢失 |
| 连续双新更好且旧知识保持相近 | 当前整体配方有收益，尚需后续受控证据区分机制 |
| 双新更好但旧知识明显下降 | 报告学习与保持的代价，不称全面优势 |

主结果以组合和旧保持的成对读数呈现，不设事后加权总分或把100%掌握作为实验有效性的前提。若模型新原子没有写成，仍报告全量结果及条件覆盖，不能由高旧保持声称有效学习。
