# 与实体无关的规则门：从头训练两臂

## 授权与主要问题

2026-10-19，用户授权从头训练两条规则门臂，每臂150万步，共300万新增科学更新。无门DiscoLoop与`fixed-q-plus-u`（学习u）的已有150万步运行只读复用为对照。本批不添加新数据、训练方法或其他架构。

主要问题：门如果从训练开始就只能使用与图无关的信号，模型能否学出可迁移到图B的组合，同时保持图A的长链？零训练检验（[§7.8–7.9](../../reports/loop-depth-extrapolation-gate-stability-survey-20261019.md#78-解码稳定性规则能否替代学到的门零训练)）只能判断规则与冻结模型已学时刻表是否兼容，不能回答这个问题。

## 完整模型中的改变

X是本轮输入，H=Fθ(X)是完整共享Transformer块的输出，保留原attention、MLP、残差和归一化。q(H)是原DiscoLoop软解码反馈，系数固定1。非末轮交接沿用`fixed-q-plus-u`的X+u(H−X)+q(H)，运算顺序相同；末轮直接读取H。唯一改变是u不再学习：

| 新臂 | u |
|---|---|
| `stability-u` | 相邻两轮解码一致度 \(s_t(r)=\sum_v p_r(t,v)\,p_{r-1}(t,v)\)；\(p_r\)为第r轮该token的全词表解码，\(p_0\)为输入token的one-hot |
| `readiness-u` | 依赖闭合的稳定性：t不读取任何注意力权重≥0.1的前序位置时为1；否则为 \(s_t(r)\cdot\min_j c_j(r-1)\)，j取这些来源，\(c(0)=1\) |

就绪规则的注意力由共享块的Q/K在本轮输入上以float32重算，12头取平均。门信号在no_grad下计算，没有门参数；它不读取图身份、跳数、答题位置或标签。实现：[规则门](../../../src/llm_memory_editability/rule_gate.py)，与零训练预检使用相同定义。

两臂与`fixed-q-plus-u`共享初始骨干，初始骨干哈希与历史配方一致，也不消耗额外随机数。初始化时解码接近均匀，`stability-u`的门值约为1/词表大小，所以训练早期主要只传解码反馈。这是规则本身的性质，没有为此调整规则。

## 固定配方和数据

复用40,000条训练、43,000条评测的双图世界（世界SHA256 `e132eaf6…`，评测池 `c991cebe…`）。1层×4轮、宽768、12头、dropout .1；初始化2026101602、样本流2026101603、dropout 2026101604。batch 512、AdamW lr 1e−4、wd .1、2000步warmup后恒定、梯度裁剪1。BF16前向、TF32；只在答案和EOS位置使用末轮交叉熵。每臂1,500,000步，评测节点与上一批相同。

## 评价与解读

- **主指标：** 150万步后，用冻结的零训练回放代码做R1–16回放，取R8的图B三跳全词表答案准确率，与复用的`fixed-q-plus-u`和无门DiscoLoop比较。R8为主是因为R4可能包含报告中记录的一轮瞬态。
- **同时报告：** 原生R1–4、图A留出三/四跳、图B两/四跳、原子保持、全部11池、学习曲线及答案+EOS；不挑选最佳节点或推理轮数。
- **可作为与实体无关的替代：** 图A留出2–4跳在R8与`fixed-q-plus-u`相差不超过2个百分点，且图B两/三跳不低于`fixed-q-plus-u`。
- **若`stability-u`丢失图A长链而`readiness-u`保住：** 支持从头训练时进度信号是必需的。
- **若两者都丢失图A长链或图B组合：** 说明这两种信号在本配方下不足，不排除其他进度信号。

## 执行

沿用上一批的执行方式：
- 固定镜像`sha256:27b3ab67…`、LM Docker上下文、每臂独立GPU与容器；
- 冻结源码、配置、输入与哈希；W&B在线追踪；
- CPU契约（81项）与每臂一次丢弃的CUDA graph工程更新，随后正式train→R1–4 grid；
- 不做32步短训与独立重载；训练后的R1–16回放属于零训练诊断。

**实际执行（2026-10-19 02:56 UTC）：** 用户要求立即开始训练、不做哈希等验证。因此未冻结源码快照（中途停止的部分复制保留在批次目录，未使用），未做哈希校验与CUDA预检，源码为仓库工作树的只读挂载；训练入口自带的配置一致性和输入检查照常运行。两臂分别在GPU0/GPU1，由批次目录`execution/launch.py`依次执行train与R1–4 grid。失败记录保留，不自动重试。实际状态以`execution/controller-state.json`和实际Docker容器为准。

## 限制

- 一个已观察开发世界、一个初始化；属于任务内的架构比较。
- 对照运行在其他时间与主机上训练；配方和曝光相同，不等于运行环境逐位等价。
- 门信号不回传梯度：模型只能通过前向效果间接适应规则，不能直接优化门值。
- 规则额外引入前向矩阵计算：每个非末轮多一次词表解码，就绪规则还要重算Q/K/V与QK^T。耗时与FLOPs另报。
- 无学习控制器、中间损失、课程、随机深度、提前退出、种子扫描或新世界训练。
