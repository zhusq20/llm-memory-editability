# 知识学习的理论依据：回答、组合与更新后的使用

本文保存支持知识学习三个层次的数学对象、推导、假设和适用边界。论文立意、实验优先级与待检验设计统一见[研究路线图](roadmap.md#question)，已执行实验见[结果汇总](results.md)。2026-10-07研究方向进一步明确：从实际Transformer计算图解释三层能力的分离，再检验通用架构能否降低学习成本。当前数学入口为[§14：完整Transformer中的条件命题](#transformer-conditional-results)；前面的联想记忆、固定特征和图校准模型保留为各自假设下的辅助分析，不直接充当自然Transformer机制。

| 研究层次 | 对应理论 | 阅读位置 |
| --- | --- | --- |
| [知识能被回答](roadmap.md#recall) | 联想存储、知识量、地址与存储资源；区分数据要求的信息量与实际学会的信息量 | §2–4、§12、§14.2 |
| [知识能被组合](roadmap.md#composition) | 单跳解码与后续可用性、训练支持与可辨识性、有限步误差传播 | §3–9、§11、§13–14 |

**能够回答事实，不保证该事实能被后续计算复用；更新前能复用，也不保证更新后仍然成立。** 下文用联想记忆、可辨识性和计算稳定性的受控模型说明这些条件的区别，不预设一个机制解释全部现象。

证据分为已有论文的定理、给定假设下的推导与反例、训练后模型的实测。标准恒等式与经典证明的整合不自动构成理论创新；受控模型的结论也不自动识别普通GPT的内部机制。原公式编号与既有引用锚点保留，便于复核历史分析。

## 1. 概念与适用范围

| 经典概念 | 在本文中的确切对象 | 对应问题与范围 |
| --- | --- | --- |
| **Associative memory / Hebbian memory，联想记忆／赫布式记忆** | 键到值的映射，核记忆的信号与串扰项 | 参数和宽度如何支持存储。MLP的代数表示不证明SGD遵循Hebbian学习规则。 |
| **Identifiability / system identification，可辨识性／系统辨识** | 哪些调用算子在训练数据上能被区分 | 事实已答对时，训练是否足以确定可复用的调用方式。本文严格命题限于固定特征或校准模型。 |
| **Spectral bias / conditioning，谱偏置／谱条件** | 训练Gram矩阵的正特征值及零空间 | 已被约束的方向学得多快；未被约束的方向是否仍有自由度。 |
| **Robustness margin / finite-horizon error propagation，鲁棒间隔／有限步误差传播** | 正确答案的logit差，以及有限次状态更新的误差界 | 更多循环提供执行步骤，也改变误差的累积。需要定义理想计算与实际状态。 |
| **Gauge freedom / graph Laplacian，规范自由度／图拉普拉斯** | 接口校准图每个连通分量的共同平移，以及关联矩阵的零空间 | 给可辨识性一个可完整证明的数据组织实例；不是普通GPT的既定内部表示。 |

**Persistent excitation（持续激励）**可作为系统辨识的背景概念：经典动态定义要求输入Hankel矩阵达到相应阶数的满行秩；静态回归中的对应条件是训练Gram在待辨识方向上正定。不能把“每条事实至少出现一次”直接称为持续激励，更不能把本文训练图当作已验证的Willems基本引理条件。参见[Willems等，2005](https://doi.org/10.1016/j.sysconle.2004.09.003)与[作者提供的后续严格分析，§2–3](https://imarkovs.github.io/publications/fl-rev.pdf)。

以下概念需要各自的操作定义和证据：

- **Hopfield / attractor / fixed point**需要对应更新规则、能量或收敛条件。我们的残差GPT循环没有这些已证前提；[现代Hopfield论文](https://arxiv.org/abs/2008.02217)的注意力对应关系不能自动推广到整个GPT块。
- **Observability / controllability**在控制论有明确状态、输入和输出定义。多个时刻输出的观测矩阵满秩，不保证只读取最后状态的Loop答对。
- **Grokking / phase transition**需要依据学习轨迹分别确认延迟泛化与相变；名称不能代替存储与调用的机制。
- **Superposition**能解释低维表示与串扰，是容量背景；尚不足以解释组合接口如何被训练出来。

## 2. 《MLPs are Hebbians》确切证明了什么

本节依据[Garcia等《MLPs are Hebbians: Constructing Efficient Fact-Storing MLPs for Transformers》，2026-07-10 v1](https://arxiv.org/abs/2607.10034)，核对范围为§3–5、附录B.2.1及B.8.4。

令MLP为 \(M(x)=B\phi(x)\)，取 \(y_i=M(x_i)\)，定义如下。带输出偏置时可将常数特征1并入 \(\phi\)。

\[
\widehat\Sigma=\frac1F\sum_i\phi(x_i)\phi(x_i)^\top.
\]

当它可逆时，白化核 \(K(x,z)=\phi(x)^\top\widehat\Sigma^{-1}\phi(z)\)满足

\[
\frac1F\sum_i y_i K(x_i,z)=B\widehat\Sigma\widehat\Sigma^{-1}\phi(z)=M(z).
\]

这是MLP输出的精确代数重写；这里的 \(y_i\)是MLP自己的输出，未必是事实真值。论文另外构造双线性随机特征MLP，推导记忆解码间隔的容量缩放。二者是不同命题，白化恒等式本身不给出最优容量。

其各向同性构造的简化界为

\[
\gamma_{\rm mem}\ge 1-C\sqrt{\frac{F\log(F/\zeta)}{md}},
\tag{1}
\]

其中 \(m\)为MLP隐藏特征宽度、\(d\)为键／值维度，\(\zeta\)为失败概率。正式Corollary B.31依赖独立均匀球面键和值、指定双线性随机特征、\(F\ge2\Lambda\)、\(m\ge\Lambda^3\)、\(m\le d^2/\Lambda\)、\(m,d\le F\)，\(\Lambda=\log(C_0F^2/\zeta)\)。常数与额外几何项不能省略后直接套入小模型。它不是任意GELU MLP、任意学习表示或端到端Adam训练的通用定律。

## 3. 两个基础边界：计算不会凭空增加事实bits，答对不保证能接着调用

**有限精度计数。** 固定输入、解码规则、运行过程以及除权重外的信息；\(P\)个参数各有至多 \(2^b\)种取值，则模型最多编码 \(2^{bP}\)种事实世界。若需表示所有 \(\Omega\)中的世界，必要条件是

\[
bP\ge\log_2|\Omega|.
\tag{2}
\]

例如 \(F\)个独立任意事实各有 \(V\)个答案，\(|\Omega|=V^F\)，故 \(bP\ge F\log_2V\)。固定权重多运行几次不会增加权重状态数，但可执行更复杂的读取程序。所有可学习Embedding也计入 \(P\)；若事实由排列约束或生成规则压缩，须改用合法世界数，不能套独立事实的bits计算。外部记忆、含答案的输入或随事实变化的执行计划会改变此前提。该计数与[事实召回的联想记忆理论，§6](https://arxiv.org/html/2412.06538)一致。

**分类与接口兼容性不同。** 设理想状态为 \(z^*=(1,0)\)，实际状态为 \(z=(1,3)\)。单跳读出间隔 \(g_{\rm atom}(z)=2z_1\)，两者都正确且间隔均为2；后续调用的最终间隔若为 \(g_{\rm next}(z)=1-z_2\)，理想状态正确而实际状态错误。因此单跳正确率不约束全部状态误差。该反例不预设GPT存在这两个坐标，只证明由单跳正确推不出下一次调用正确。

## 4. 从Hebbian表示到可辨识性：奇异情形需要保留余项

设 \(S=\operatorname{span}\{\phi(x_i)\}\)，\(P_S=\widehat\Sigma\widehat\Sigma^+\)为其正交投影，\(+\)表示Moore–Penrose伪逆。即使协方差奇异，也有恒等式

\[
M(z)=\underbrace{\frac1F\sum_i y_i\,
\phi(x_i)^\top\widehat\Sigma^+\phi(z)}_{B P_S\phi(z)}
+\underbrace{B(I-P_S)\phi(z)}_{\text{观测特征跨度以外的作用}}.
\tag{3}
\]

证明只需将 \(y_i=B\phi(x_i)\)代入并利用投影恒等式。在观测特征跨度内余项为零；在所有查询上恒等于纯伪逆核记忆，需要另满足余项处处为零。直接把逆换成伪逆却删除余项，会得到错误的普遍等价。

固定 \(\phi\)时，若 \(w\perp S\)，则 \(B\)与 \(B+uw^\top\)在全部观测样本上输出相同，但在 \(w^\top\phi(z)\ne0\)的查询上可以不同。这是经典零空间／可辨识性问题。它不声称当前GPT的事实特征协方差实际奇异；满秩也不保证一个内部查询已经接近正确的事实键。下面的调用Gram与这里的事实协方差是不同对象。

## 5. 训练支持与时长：一个可精确求解的调用学习模型

明确限制为：固定训练状态特征 \(X=[x_1,\ldots,x_n]\in\mathbb R^{p\times n}\)，给予理想线性接口 \(A_*\)的状态监督 \(Y=A_*X\)，以平方损失

\[
\mathcal L(A)=\frac1{2n}\|AX-Y\|_F^2,
\quad G=\frac1nXX^\top
\]

进行梯度流。令 \(E_\tau=A_\tau-A_*\)，则

\[
\dot E_\tau=-E_\tau G,
\qquad E_\tau=E_0 e^{-\tau G}.
\tag{4}
\]

取 \(S=\operatorname{range}(G)\)，当G非零时令 \(\lambda_+\)为最小正特征值，\(B_0=\|E_0\|_{\rm op}\)。G为零时所有方向保持初值；其余情形由谱分解，对任意查询特征 \(x\)，

\[
\|E_\tau x\|\le B_0\left[
\|(I-P_S)x\|+e^{-\lambda_+\tau}\|P_Sx\|
\right].
\tag{5}
\]

**第一项与第二项有不同含义。** 零空间方向的算子误差保持初值；非零特征值方向的误差指数衰减。全空间唯一辨识要求 \(G\succ0\)，但只要测试查询都落在已辨识子空间，就不必要求整个特征空间满秩。较小正特征值提供一种延迟改善机制，不能据此证明本项目出现grokking。

全部样本等比例重复，归一化 \(G\)及其跨度不变；改变采样权重可改变正谱而不扩张跨度。增加新特征方向可以扩张跨度。增加样本后未归一化的 \(XX^\top\)按PSD序增加，归一化 \(G\)的最小正特征值却不必单调；增加宽度也可能改变特征与未约束方向。

这里 \(n\)是受到状态监督的特征列数，不能直接等同于唯一训练链条数。真实GPT使用所有文本位置的交叉熵、Adam与变化的特征；没有上述理想内部状态监督，128k优化步也不等于 \(\tau\)。式(4)是固定特征模型的经典解，与[NTK论文§5](https://arxiv.org/html/1806.07572)的谱学习分析衔接；本文不训练内部表现预测器。

## 6. 用经典图论把“覆盖不等于可辨识”写成一个完整例子

考虑一个**独立的加性接口校准模型**。首／次跳使用角色分别为左右节点 \(u,v\)；每个节点有未知校准值 \(\theta_u\)。每条训练链给予一个相对校准观测

\[
y_{uv}=\theta_u-\theta_v,
\qquad y=D\theta,
\]

其中 \(D\)为训练图的有向关联矩阵。若有 \(q\)个节点、\(c\)个连通分量，则

\[
\operatorname{rank}(D)=q-c,\quad
\ker D=\operatorname{span}\{\mathbf1_{C_1},\ldots,\mathbf1_{C_c}\}.
\tag{6}
\]

证明：\(D\theta=0\)等价于每条边两端的值相同，故 \(\theta\)在每个连通分量上为常数。于是各分量的共同平移不改变任何观测，留下**gauge freedom**。新角色对的差值可从这些观测唯一确定，当且仅当两端在同一分量；不同分量可以独立平移。若另有绝对校准锚点，辨识条件会改变。

**支持图距离与事实推理跳数分别定义。** 上述节点是调用角色，边是训练链的搭配记录；它不是模型查询要遍历的实体事实图。[执行后CPU核查](development-artifacts/latent-support-depth-review-v1/hop-audit.json)确认，本批全部实体边都为头→桥或桥→尾，最长有向路径为2，全部组合训练与测试均用两条事实。支持图分量内直径为6–8，部分测试角色的最短支持路径为7，但这些查询仍是两跳。训练过程整合多条样本的约束与一次前向执行多少事实调用是不同问题；没有证明支持路径长度等于所需Transformer层数、循环数或优化步数。

**与GPT监督的对应仍缺失。** 加性模型每条边观察的是校准差值，普通GPT的组合标签是最终尾实体，另有完整原子监督。尚未构造两者的等价映射，也未验证普通GPT遵循局部图消息传递；原子监督还可能提供校准模型没有的额外信息。因此不能由式(6)推出普通GPT的断连不可学、连通充分或浅层架构的最大推理跳数。该图例用于说明覆盖与可辨识性在一般情况下不同；把它当作当前模型的主要学习瓶颈需要新增依据。

以平方损失训练校准值，误差满足

\[
\dot e=-\frac1{|E|}D^\top De.
\tag{7}
\]

\(D^\top D\)正是**graph Laplacian**。连通性决定额外零空间，正谱决定非零方向的收敛；连通图的第二小特征值是经典的**algebraic connectivity（代数连通度）**，见[Fiedler，1973](https://doi.org/10.21136/CMJ.1973.101168)。

一个八节点例子已经数值核验：两张二部图都有八条边、每个角色度数均为2；第一张是两个分离的四环，第二张是一个八环。它们样本数、角色覆盖与逐角色使用次数全部相同，关联矩阵秩却分别为6和7。第一张可在训练残差为零时改变跨分量的未见相对校准。**这说明仅匹配样本量与使用次数，仍可能没有匹配可辨识性。**

此例的标签是相对校准值，真实事实组合答案不一定有这种分解；因此不能把式(6)直接当作GPT准确率的上界。完整事实图还天然按桥实体分组，不能要求跨所有桥实体全局连通。我们审计的是是否额外拆开完整可用训练池的分量。与[Scaling can lead to compositional generalization，§3.4、附录A.1](https://arxiv.org/html/2507.07207)的connected support论证借鉴关系明确，但该论文的任务支持图与我们的角色图也不相同。

## 7. 循环计算：有限步的间隔保持条件

令 \(z_r^*=T_*(z_{r-1}^*)\)为给定问题的理想状态过程，\(z_r=T_\tau(z_{r-1})\)为实际过程。状态应包含相关全部token位置；不预设一轮对应一跳。假设在两条轨迹及其比较所需区域上，\(T_*\)为 \(L\)-Lipschitz，且实际状态处的实现误差不超过 \(\epsilon\)。三角不等式给出

\[
e_R\le L^Re_0+\epsilon A_R(L),\qquad
A_R(L)=\sum_{j=0}^{R-1}L^j.
\tag{8}
\]

当 \(L<1\)时该误差界的累积因子有界；\(L=1\)时为 \(R\)，\(L>1\)时可能指数增长。更精确的分阶段形式用每步 \(L_j,\epsilon_j\)展开；这里仅为清楚展示各轴采用共同上界。受控Transformer程序的误差累积也在[Looped Transformers as Programmable Computers，附录B](https://arxiv.org/html/2301.13196)中直接讨论。

若正确答案对每个竞争答案的最终logit差 \(g_j\)都是 \(\ell\)-Lipschitz，且理想终点最小间隔为 \(\gamma_R^*\)，实际最小间隔满足

\[
\Gamma_R\ge\gamma_R^*-\ell\,[L^Re_0+\epsilon A_R(L)].
\tag{9}
\]

右侧为正是正确解码的**充分条件**；为负不代表必然失败。若 \(R\)尚不足以完成给定理想程序，就不能假设理想间隔为正。一块GPT可执行多种操作，也可能走捷径，不能从逻辑跳数 \(h\)推出 \(R\ge h\)是普遍必要条件。多词元自由生成需要各词元及EOS都满足相应正确排序，单次分类间隔不替代完整生成。

没有普遍的循环单调性：同一二维旋转算子 \(T(z)=Q_{0.6}z\)、初值 \((1,0)\)、最终间隔 \(2z_1\)，R2间隔为 \(2\cos(1.2)>0\)，R3为 \(2\cos(1.8)<0\)，算子范数仍为1。它是存在性反例，不证明我们的GPT采用旋转机制。

## 8. 连接存储、调用学习与计算的条件定理

在式(4)的固定特征接口学习条件之外，进一步假设：

1. 实际状态更新误差可写成 \(E_\tau\psi(z)+r(z)\)，\(\|r(z)\|\le\eta\)；这里 \(\eta\)覆盖其它实现误差，不能由单跳正确率推得它很小。
2. 所有被访问状态的特征满足 \(\|P_S\psi(z)\|\le M\)、\(\|(I-P_S)\psi(z)\|\le\delta\)。这些常数、前节 \(L,\ell\)均在明确的坐标和范数下定义。
3. 理想程序在预定R到达最终事实记忆的正确标准键；终端读出使用该记忆，故其理想间隔可由 \(\gamma_{\rm mem}\)下界。此前提不能从“模型训练了R轮”自动得到。

将式(5)代入式(9)，得到

\[
\boxed{\quad
\Gamma_R\ge\gamma_{\rm mem}
-\ell\left\{L^Re_0+A_R(L)\left[
\eta+B_0\left(\delta+M e^{-\lambda_+\tau}\right)
\right]\right\}.
\quad}
\tag{10}
\]

证明是两次代入；条件定理是标准谱学习与鲁棒误差界的整合。它给出四种不同作用：参数／宽度影响存储间隔及表示几何；训练支持影响跨度与谱；时长削减非零谱方向的误差；循环改变理想程序完成程度及误差累积。参数增加不会自动补齐训练约束，训练延长不会在固定特征模型里消除零空间自由度，循环增加不会增加权重编码的任意事实bits。

若还满足式(1)的全部构造条件，令式(10)的误差扣减为 \(\kappa_R\)，且 \(\kappa_R<1\)，则一个充分的存储预算为

\[
md>\frac{C^2F\log(F/\zeta)}{(1-\kappa_R)^2}.
\tag{11}
\]

它展示在该受控模型中，调用误差可提高保证正确解码所需的存储预算。\(\kappa_R\)本身也可能随宽度和参数变化，不能把它视为独立常数拟合真实GPT；\(md\)也不是包含Embedding、注意力等参数的总 \(P\)。式(11)不证明存在当前实验的经验幂律或架构容量极限。

## 9. 理论与已有实验的对应边界

## 11. 用功能一致性连接回答、组合和更新

本节区分单跳回答、组合一致性与更新后的保持。§3–8的容量计数、零空间、谱学习及误差界仍是条件数学；不能把它们当作普通GPT已被识别出的学习机制。相关实测见[重编码与编辑传播](results.md#memory-interface-next)，研究设计见[知识变化后的使用](roadmap.md#updating)。

**知识真值已确定，计算方式仍可能欠约束。** 在确定性事实图中，若训练已给出所有必要的单跳事实，那么两跳真值由图唯一决定；无需额外信息才能在数学上计算答案。但拟合单跳与有限组合训练集的函数，不止正确的逐步查询这一种。通用函数也可以在受训查询上记表、在留出查询上任意延拓。因此这里须区分“事实图的可辨识性”和“学习者在给定函数类内怎样实现/延拓计算”。上一轮角色支持图的秩不直接测量后者；连通匹配实验没有稳定全池收益，也不违反图论恒等式。

**一个可直接检验的充分条件。** 用 $A_\theta(s,r)$ 表示单跳生成答案，用 $C_\theta(s,r_1,r_2)$ 表示直接组合答案。实体、格式与解析规则固定；非法生成记为失败符号，不借助真值修复。定义模型自主两次调用

\[
S_\theta(s,r_1,r_2)=A_\theta(A_\theta(s,r_1),r_2).
\]

令图真值为 $b=f_{r_1}(s)$、$y=f_{r_2}(b)$。事件 $E_1$、$E_2$ 分别是单跳 $A_\theta(s,r_1)\ne b$、$A_\theta(b,r_2)\ne y$；$Q$ 是直接答案与自主两次调用不一致。逐例有

\[
\mathbf 1[C_\theta\ne y]\leq\mathbf 1[Q]+\mathbf 1[E_1]+\mathbf 1[E_2],\qquad
\Pr(C_\theta\ne y)\leq\Pr(Q)+\Pr(E_1)+\Pr(E_2).
\tag{12}
\]

证明：若三个事件都不发生，则 $S_\theta=y$ 且 $C_\theta=S_\theta$。不需要错误独立。必要原子都正确的固定子集上，直接组合错误恰等于直接/自主调用不一致；这时“不一致率”只是已有错误率的重述，不能包装成新预测指标或独立机制证据。不同模板、别名与多词元格式要先统一判定。重编码批18个父模型的自主两次调用均正确，本轮逐数组验证了这项恒等关系。

将图和权重替换为编辑后的 $f',\theta'$，同一论证仍成立。因此新原子写入与后继事实正确，再加编辑后 $C_{\theta'}=S_{\theta'}$，足以保证派生更新。编辑前 $C_\theta=S_\theta$ 并不推出编辑后的一致性。即使所有端到端答案一致，也不证明内部真的执行两次同一子程序；需要跨后继关系的反事实干预，且仍只对所测范围成立。

**可复用的表示按后续行为定义，不按向量相等定义。** 固定执行边界、其他上下文和允许的后继操作集合 $\mathcal R$，设 $H_r(z)$ 为继续计算的输出；若所有 $r\in\mathcal R$ 都有 $H_r(z)=H_r(z')$，则两个状态对这些后继操作功能等价。若要讨论更长链，须把允许的后继序列也纳入，不能由两跳等价推出任意跳等价。完整状态应包含有关token位置；单位置交换须另外固定其余上下文。

在抽象函数组合中，任意可逆坐标变换 $Q$，配套将状态改为 $Qz$、后继函数改为 $H_r\circ Q^{-1}$，所有答案不变。因此对输入embedding的接近不是功能复用的普遍必要条件。这里不是声称任意 $Q$ 都能在保留LayerNorm/逐元素激活的原GPT参数化中实现。共同参数也不充分：同一函数 $M(z,t)$ 可依据上下文/执行阶段 $t$ 采用不同查表规则。

**静态组合与继续学习是两个量词范围。** 已有对齐实验和长训OO实验测的是同一训练阶段内的已知原子集合，不能自动推出“规则成熟以后才加入的新事实”仍可组合。顺序新增与改写旧事实分别检验迁移及旧答案竞争；全参数续训同时改变知识与调用参数，不能称冻结调用器。具体比较统一见[顺序迁移设计](roadmap.md#sequential-transfer)。

**待检验的解释。** 单跳正确约束了回答，却未强制模型在不同调用情境及知识版本中复用同一映射。组合训练、共享计算、长期优化与表示监督可能通过不同途径促成功能兼容；它们能否互相替代、是否得到同一种可迁移实现，仍是经验问题。固定事实世界内查表和可迁移计算的复杂度差异可以启发假说，但训练偏好、收敛时间或相变不能由复杂度计数直接推出。

## 12. 架构设计空间：区分参数存储、序列状态、调用和执行

本节区分长期参数知识、前向状态、写入规则与计算资源。这些数学关系约束架构解释，不代替实验；是否开展对应比较由[研究范围](roadmap.md#scope)决定。

**参数知识与深度不是一一对应。** 参数θ承载训练后保留的信息，前向临时状态承载本次查询和中间结果；闭卷任务中，序列mixer与层间连接均能改变这些参数怎样被访问，不能称前者只管上下文而后者直接存知识。区别是GDN按token更新序列状态，mHC沿层传播多流状态。更多独立层增加参数及执行阶段；固定θ增加Loop次数只改变执行，不增加θ所包含的事实信息，不同循环配置的训练则可能改变编码与学习效率。MoE主要改变稀疏参数组织，mHC主要改变活动状态与连接，二者都不是单纯深度增加。[ICLR 2025联想记忆论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/0bf9f909c24c8879d1b7f86fa50a9e49-Paper-Conference.pdf)§4在指定合成分布中给出单层attention加MLP的存储构造，已足以否定“存储很多事实必然需要很深”的一般命题，但不保证任意真实任务或优化能实现该构造。

**参数容量与上下文状态是两本不同的账。** §3的参数计数包含所有embedding、router、expert、attention等权重。稀疏MoE虽然每次只激活部分专家，不同查询可以访问不同专家；所以事实世界的计数上限仍由总参数决定，不能直接换成单次激活参数数。激活量约束每次访问/计算成本，不等于全部长期存储量。

另设模型参数固定、输入上下文包含F条独立任意事实、每条V种答案。若读完以后只能保留D个各b位的状态量，不再访问上下文、外部表或其它随世界改变的信息，并须对所有事实查询都正确，则同样由抽屉原理得到

\[
bD\ge F\log_2V.
\tag{13}
\]

状态D须包括所有层递归矩阵、卷积缓存及其它可用记忆；此式是精确恢复所有世界的必要条件，不是有限误差下的实测容量估计。普通softmax的KV缓存可随长度增长，固定状态的线性递归没有相同的资源增长。GDN仍有参数知识；这条状态界不说明它记不住通过训练存入参数的事实。真实事实有相关性，V与独立性也须重新定义。

**Delta写入的选择性取决于地址几何。** 按[Gated DeltaNet正式论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/4904fad153f6434a7bcf04465d4be2cc-Paper-Conference.pdf)§3.1的记号，

\[
S_t=\alpha_t S_{t-1}+\beta_t(v_t-\alpha_tS_{t-1}k_t)k_t^\top.
\tag{14}
\]

固定这一步的键/值与门控，令 $e_t=v_t-\alpha_tS_{t-1}k_t$，任意后续读取方向u满足

\[
(S_t-\alpha_tS_{t-1})u=\beta_te_t(k_t^\top u).
\tag{15}
\]

因此与k正交的u必不受这项增量影响；非正交地址一般会受影响，但β或误差e为零时增量也为零。α小于1仍衰减其它旧状态。单位范数k且β=1时，新键读出被精确设为v；这不保证所有旧键或最终答案保持。已生成token、其它层和后续非线性还会改变行为。本式直接支持分别改变键冲突、同时存储量和距离的实验，不支持“delta规则天然解决参数知识编辑”。实体名称相似不自动等于实际键内积大；归因地址几何须操作实际键或核实其变化。

**mHC的混合稳定不等于语义信息保持。** 对固定双随机矩阵H，$H\mathbf1=\mathbf1$、$\mathbf1^\top H=\mathbf1^\top$，且 $\|H\|_2\le1$；矩阵乘积仍双随机。但 $H=\mathbf1\mathbf1^\top/n$ 会把所有流替换为均值，完全消去流间差异。因此[mHC正式论文](https://proceedings.mlr.press/v306/xie26aa.html)的约束给固定线性残差混合以稳定性质，不能推出实体可分辨性或知识不遗忘；输入相关H的导数和pre/post分支也使全网络Jacobian超出这个界。普通残差、同多流但H为I、完整mHC的比较才能分开状态扩展与混合作用。

以上分析将架构比较的预算分为总参数、激活计算、每例活动记忆、执行次数和训练曝光。一次实验无法只用“相同参数量”消除它们的差异；应根据待检验命题分别匹配并报告资源，而非先假定统一的长度×深度×宽度幂律。

## 13. 预训练是否隐含中间表示监督：梯度推导与待验证解释

**普通next-token prediction已经提供答案身份的梯度信号；输入输出权重共享时，输出端信号直接涉及输入embedding。但这不保证某个早期状态与正确实体embedding对齐，也不保证事实能用于下一跳。** 以下是给定模型形式下的直接推导，不是新增实验、文献新颖性主张或自然预训练模型的机制确认。相关观测见[对齐覆盖与编辑传播](results.md#memory-interface-next)。

### 13.1 输出端：交叉熵包含正确token方向，但不是向量相等约束

设前缀为x、正确下一token为y，h是最终归一化后送入线性输出头的向量，输出权重行为u_v。先固定当前参数，以无偏置输出头为例：

\[
p_v=\frac{\exp(u_v^\top h)}{\sum_w\exp(u_w^\top h)},\qquad
L=-\log p_y,
\qquad
\frac{\partial L}{\partial h}=\sum_vp_vu_v-u_y.
\]

若输入输出共享权重，则u_v=e_v，e_v为输入embedding。负梯度含有指向正确token向量的分量，以及远离当前预测分布加权平均向量的分量。若把h暂时当作独立优化变量，一步下降为

\[
h^+=h+\eta\left(e_y-\sum_vp_ve_v\right).
\]

这是一种相对候选的判别信号，**不能据此声称每次参数更新都增加h与e_y的余弦相似度**。CE依赖的是logit间隔：

\[
L=\log\left(1+\sum_{v\ne y}\exp\bigl(-(u_y-u_v)^\top h\bigr)\right).
\]

因此低CE只要求这些间隔足够大，不一般要求h的方向等于e_y；输出权重差张成空间的正交分量也不受这一输出约束区分。是否存在非零正交分量取决于实际秩。若输入输出不共享，梯度直接涉及u_y，不能将它换成输入向量e_y。

真正训练优化的是共享参数θ而非自由变量h。固定输出头、只考虑单个样本和普通SGD时，令A=∂h/∂θ，一阶近似为Δh=−ηAAᵀ(∂L/∂h)。多样本、共享输出权重、Adam及其他损失还会改变这一更新。因此上述负梯度是局部监督方向，不是完整训练轨迹的保证。

### 13.2 中间层：监督经过后续计算的Jacobian变换

取一个早期位置的状态z，并把后续输出写为h=F(z;c)，其中c代表固定的其他边界状态与上下文；最终归一化也包含在F内。链式法则给出该输出损失的贡献：

\[
\frac{\partial L}{\partial z}
=J_F(z;c)^\top\left(\sum_vp_vu_v-u_y\right).
\]

完整序列损失还须对所有受该状态影响的预测位置求和。正确答案信号确实可能传到z，但会被后续网络旋转、缩放、混合或消去；不能保证每个位置都收到非零信号。训练要求的是“z经后续计算能得到正确输出”，不是“z本身必须等于正确实体的输入向量”。答对不唯一确定内部编码；共享参数也不自动把不同情境的编码统一。

### 13.3 为什么单条事实训练可能监督组合题的早期状态

在本项目受控模板中，原子题与对应组合题在首关系位置具有相同的token前缀、位置和注意力可见范围。固定同一模型，关闭dropout或耦合同一随机掩码，因果网络在该位置的早期状态相同；后面的第二关系与组合答案不能影响它。

因此，原子文本中预测首跳实体的损失，经由上述梯度塑造的状态，也是对应组合题在这一位置使用的状态。**严格组合留出不等于其早期事实状态从未受监督：相关原子事实仍参加训练。** 这个结论依赖完全相同的因果前缀；自然语言中问法、tokenization、位置或上下文不同，只能提出迁移假说，不能套用状态相等结论。

还应区分teacher forcing与内部组合。标准预训练在后续位置读到的通常是真实前缀token；文本中写出桥实体后，下一句可以直接使用它的输入embedding。这提供组合使用的机会，但不强迫模型在没有显式桥token时先自行产生桥状态、再完成第二跳。多token实体还涉及逐token条件化，上述单token公式不能直接解释为完整实体向量对齐。

### 13.4 与已执行的显式监督比较

实际[状态提取](../src/llm_memory_editability/representation_alignment.py)在首执行Transformer块结束后的首关系位置；这是残差状态，不是MLP单独输出。既有[覆盖实验损失](../src/llm_memory_editability/alignment_coverage.py)为

\[
L_{\rm total}=L_{\rm text}+0.3L_{\rm bridge}+0.3L_{\rm align},
\qquad
L_{\rm align}=\operatorname{Reduce}_{\rm mask}
\left\|\frac{z}{\|z\|}-\frac{\operatorname{sg}(e_b)}{\|\operatorname{sg}(e_b)\|}\right\|^2.
\]

b为训练数据提供的正确首跳实体，sg表示停止该参照分支的梯度；非零向量下单例项等于2−2cos(z,e_b)，实现使用带数值保护的normalize。L_bridge通过共享输出头与最终LayerNorm直接监督该早期状态读出b；全模型参与训练，embedding仍可由其他路径更新。Reduce按冻结方案使用全batch均值或选中样本均值。

**覆盖实验四臂都保留相同的显式首跳CE，只有几何项的mask和归一化改变。** 严格组合正确率10.25%（关闭几何项）、25.55%/23.80%（仅组合，两种归一化）、92.12%（原子及组合）不能描述为“纯预训练与中间监督”的比较，也不能解释为从完全无监督到有监督。原先全文CE、首跳CE、再加对齐的三臂比较另见[结果](results.md#representation-alignment)，不要混用两个实验的分母与处理。

### 13.5 猜想、现有支持与不能推出的结论

1. **表示选择猜想。** 原子CE允许多种可正确读出的内部编码；显式对齐可能偏向后续计算更容易复用的一类编码。覆盖扩展和自产桥重编码的收益与此相容，但也可能涉及优化难度、正则化及多个模块的共同适应；尚未识别唯一中介，更未证明embedding对齐是必要条件。§13.6给出不经训练的对应构造：解码再编码把读出间隔直接换成e_b格式。
2. **使用经历猜想。** 组合文本和共享计算可能间接促成类似的功能兼容，不一定形成与输入embedding相同的几何。若无显式对齐的模型能稳定完成跨关系反事实复用，即使余弦不高，也应保留为功能复用的证据，不能以几何不相似否定它。
3. **编辑不同步猜想。** 修改原子输出可能改变后层读出，而没有同步更新组合使用的早期状态或后续解释方式。现有“原子写入成功但派生答案仍旧”的结果与此相容，却未排除分布漂移、其他上下文路径和知识保持损伤；单凭CE梯度不能定位失败位置。

这些解释需要同一事实在原子/组合情境中的行为与状态干预证据，并分别核对原子掌握、目标写入、保持和训练曝光。具体比较见[写入与复用状态](roadmap.md#write-interface)，内部特征不另作表现预测任务。

**结论层级。** CE梯度、Jacobian传递和相同因果前缀的状态一致性是带条件的数学结论；覆盖实验收益是既有受控观测；“对齐使事实编码更便于后续使用”仍是机制猜想。当前不能据此宣称自然预训练必然形成或完全缺乏这种接口，也不能外推普遍的知识编辑能力。

### 13.6 离散交接：解码再编码把读出间隔变成输入格式

§13.1说明CE只约束正确答案的logit间隔，不约束状态方向。[DiscoLoop](roadmap.md#discoloop2026)在两轮之间先用输出头解码、再用绑定embedding编码，等于把“可读出”直接换成“与原子查询相同的输入”。下面的引理和线性键值示例是给定模型下的数学结论；关于读出函数与编辑传播的推论另需明示假设，训练后的模型是否满足，由[Z2、R2、U1](roadmap.md#zhang2026-next)检验。

**对象。** 对某位置的状态h，令z=E N_f(h)/τ、p=softmax(z)，

\[
\Phi(h)=E^\top p=\sum_v p_v e_v .
\tag{27}
\]

E的各行e_v是绑定的输入／输出embedding；DiscoLoop原式没有N_f，本项目GPT-2读出含最终LayerNorm，两者都可写成此式。记b=argmax_v p_v，ε=1−p_b，Δ_E=max_v‖e_v−e_b‖。

**引理（饱和时的偏差与敏感度）。**

\[
\|\Phi(h)-e_b\|\le\varepsilon\,\Delta_E,\qquad
\Bigl\|\frac{\partial\Phi}{\partial h}\Bigr\|_{\rm op}\le\frac{2\varepsilon}{\tau}\,\|E\|_{\rm op}^2\,\Bigl\|\frac{\partial N_f}{\partial h}\Bigr\|_{\rm op}.
\tag{28}
\]

若对所有v≠b有z_b−z_v≥m，则ε≤(V−1)e^{−m}。

**证明。** Φ−e_b=Σ_{v≠b}p_v(e_v−e_b)，且Σ_{v≠b}p_v=ε。∂p/∂z=C=diag(p)−ppᵀ半正定，‖C‖_op≤tr C=1−Σ_v p_v²≤1−p_b²≤2ε；又∂Φ/∂h=EᵀCE(∂N_f/∂h)/τ。最后ε=Σ_{v≠b}p_v≤Σ_{v≠b}p_v/p_b=Σ_{v≠b}e^{z_v−z_b}。

读出间隔越大，通道输出越接近e_b，并且对h中CE不约束的其余分量越不敏感。硬替换（DiscoLoop式(2)取α=1，即本项目[自产桥重编码](results.md#bridge-reencoding)）在argmax正确时把槽位精确置为e_b的归一化形式。DiscoLoop架构是加法形式h+α·RMSNorm(Φ(h))：原状态仍在，只是叠加了一个近乎固定的e_b分量。

**能读出为什么不等于能用：线性键值示例。** 设次跳读取是以输入embedding为键的线性联想记忆：键e_x，值与读出都用绑定embedding，y(x)为(x,r₂)的存储答案。槽位状态为s时，答案w的logit为

\[
\ell_w(s)=\sum_x (e_x^\top s)\,G_{w,y(x)},\qquad G=EE^\top .
\tag{29}
\]

原子查询的槽位输入是e_b，设其答对t=y(b)，间隔为m_w=ℓ_t(e_b)−ℓ_w(e_b)>0。组合查询的槽位状态写成s=e_b+n，则

\[
\ell_w(e_b+n)-\ell_w(e_b)=\sum_x (e_x^\top n)\,G_{w,y(x)} .
\tag{30}
\]

从s读出b只需对每个v≠b有e_vᵀn−e_bᵀn<G_{bb}−G_{vb}，是逐坐标的条件。次跳答对则要求式(30)的差对全部x的加权和不推翻m_w。若e_v两两正交且y为一一映射，两条件等价；实体数多于维度（叠加；Wang原图2000实体、宽768）或多个x共享答案时，许多各自很小的坐标可以累加成大的串扰，“能读出却不能用”是一般情形。硬替换把n换成零，组合查询的串扰回到原子查询本身，后者已被原子训练压在间隔以内；加法形式不消除n，只把e_b分量的系数加大，系数乘以m_w超过式(30)在t与w之间造成的差时即可答对。对(1−α)h+α·λe_b，答对条件对α是线性的，每个查询都有一个由串扰与间隔之比（及原状态中的e_b分量）决定的阈值α*，α扫描的正确率曲线就是α*的累积分布；OOD曲线右移对应其串扰更大。普通组合训练可以只为ID前缀压低串扰，与OOD前缀滞后相容。这是线性键值模型中的例子，不是GPT定理；它说明读出条件与使用条件的形式不同。

**读出函数的条件推论。** 设Loop共享参数θ，原子用途c′=(b,r₂)。假设：(A1)第二轮在读出位置的计算只经由桥槽位与关系槽位的状态依赖输入，且关系槽位状态与原子查询的关系输入相同；(A2)桥槽位为硬替换的e_b，或满足式(28)的O(ε)偏差。则组合查询的读出作为θ的函数，与c′在第一轮末的读出（DiscoLoop的Stage-1）是同一个函数（位置差另计）；软通道下第二轮若对输入Lipschitz，误差为O(ε)。因此任一写入对二者的作用相同，不限于一阶；写成核即K(u, c)=K(c′₁, c)+O(ε)，c′₁表示c′的第一轮读出。这是路径一致性的构造性实例。另由式(28)，组合损失经Φ回传到第一轮参数的梯度只有O(ε)，第一轮主要经连续分量接受组合训练，格式不需要组合训练来协调；这是否解释DiscoLoop更早的相变，尚待R2检验。(A1)一般不精确成立：槽位位置、第一轮后的关系槽位状态和其余位置都与原子查询不同，影响大小只能实测。

**编辑传播的离散性。** 在(A1)、(A2)硬替换下，首跳编辑(a,r₁)→b′对组合答案的作用只经过槽位上的argmax：未翻转时槽位输入不变，翻转后跳到e_{b′}，次跳按(b′,r₂)的原子查表读取，所以首跳传播的必要条件是编辑翻转第一轮解码。次跳编辑(b,r₂)→t′的传播，等于编辑后c′的第一轮读出是否变为t′。DiscoLoop的加法通道保留原状态，只近似满足这些条件；它们是[U1](roadmap.md#zhang2026-next)的预测，不是训练后模型的定理。

**多跳。** 硬替换下第k跳的槽位输入只取决于前面各跳的argmax序列；只要每跳argmax正确，误差就不跨跳累积，与§7连续状态的有限步误差累积不同。加法通道介于两者之间。

**数值核查。** [核查脚本](../scripts/verify_discrete_handoff.py)（numpy FP64，种子20261009，[输出](development-artifacts/discrete-handoff-20261009/verify.json)）：引理的三个不等式在300个随机情形（含与不含LayerNorm）全部成立，左右比最大0.71。线性键值记忆中，加入与e_b正交的噪声（标准差0.05–0.15）后，e_v正交且y一一映射时，1200个可读出查询无一答错；正交但答案随机时2个答错；实体256、维度64的叠加情形，每档278–299个可读出查询中有33–193个次跳答错。200个查询的α扫描都至多切换一次正误。这些只核对代数与玩具模型，不是GPT训练证据。

**不能推出的结论。** 引理不说明训练会让第一轮在槽位完成首跳：本项目全文CE臂该位置自解码桥0%，注入真桥也只到1.60%（[结果](results.md#bridge-reencoding)）。它只处理输入格式，不说明第二段参数中有没有次跳查表（层段前提），因此不预测普通独立层加通道会成功。通道只携带一个token，不覆盖多token实体。DiscoLoop的收益来自格式，还是来自优化路径的改变，须由R2分离。

## 14. 直接基于完整Transformer的条件命题

本节不将模型替换成自由线性记忆：保留实际attention、LayerNorm、残差、非线性MLP及最终输出头，再明确固定哪些量、改变哪些参数。目标是先给出可严格证明的非蕴含关系和架构约束，再由端到端实验检验这些条件是否解释已有现象。以下结论是标准线性代数与链式法则在实际参数化上的应用，不宣称新颖性，也不将它们当作已证明的样本复杂度定律。

### 14.1 实际计算图与完整状态

以当前[ReproductionGPT](../src/llm_memory_editability/grokking_reproduction.py)为主对象，固定token前缀，关闭dropout。每个pre-LN块作用于全部相关token位置组成的状态 \(H_l\)：

\[
R_l=H_l+A_l(N_{l,1}(H_l)),\qquad
H_{l+1}=R_l+M_l(N_{l,2}(R_l)).
\tag{16}
\]

\(A_l\)包含多头因果softmax attention和输出投影；\(M_l(z)=W_{l,\downarrow}\sigma(W_{l,\uparrow}z+b_{l,\uparrow})+b_{l,\downarrow}\)，当前GPT-2实现采用其配置指定的GELU。输入为token与位置embedding之和，最终logits为 \(f_x(\theta)=E N_f(H_T(x))\)，只在所需位置读出，\(E\)与输入token embedding共享。Loop重复同一块组，不在每轮重新加入embedding。自然模型若用RMSNorm、SwiGLU、RoPE或GQA，应在相应实际计算图上替换，不能把GPT-2数值结果直接归给所有Transformer。

将整个序列向量化，记 \(f_A=A_l\circ N_{l,1}\)、\(f_M=M_l\circ N_{l,2}\)，则

\[
J_l=\frac{\partial H_{l+1}}{\partial H_l}
=(I+D f_M)(I+D f_A).
\tag{17}
\]

导数分别在 \(R_l,H_l\)处取值。固定输入状态、对块参数求偏导得到
\(Q_l=(I+D f_M)\partial_\theta f_A+\partial_\theta f_M\)。
若执行位置 \(l\)使用参数组 \(\theta_{\pi(l)}\)，全微分为

\[
dH_T=(J_{T-1}\cdots J_0)dH_0+
\sum_{l=0}^{T-1}(J_{T-1}\cdots J_{l+1})Q_l\,d\theta_{\pi(l)}.
\tag{18}
\]

空乘积为单位矩阵。最终还须对 \(E N_f(H_T)\)求导；若更新embedding，不能遗漏 \(dH_0\)和输出端的 \(dE\)。这些是完整计算图的恒等式；没有假设每层存一个事实、每轮完成一跳或全部知识在MLP。

### 14.2 最后一个未共享MLP：保持与写入可以精确分离

**限定操作。** 固定所有上游参数、最终LayerNorm和输出头，只改变最后一次执行且未在上游共享的MLP输出矩阵 \(W\in\mathbb R^{d\times m}\)。对任一固定前缀的评价位置 \(x\)，令

\[
\phi_x=\sigma(W_\uparrow N_2(r_x)+b_\uparrow),\qquad
h_x=r_x+W\phi_x+b_\downarrow,\qquad f_x=E N_f(h_x).
\tag{19}
\]

这里 \(r_x\)是最后attention之后的真实残差状态；其余层和attention均未删除。因为该 \(W\)不出现在上游，\(\phi_x,r_x\)在这次编辑中不变，故 \(\Delta h_x=\Delta W\phi_x\)精确成立，没有Taylor近似。

**命题：受保护输出下的最小范数写入。** 设保护集合的特征矩阵为
\(\Phi_P=[\phi_{p_1},\ldots,\phi_{p_n}]\)，\(\Pi_P=\Phi_P\Phi_P^+\)投影到其列空间。目标为 \(t\)，令 \(q=(I-\Pi_P)\phi_t\)。若 \(q\ne0\)，则对任意指定状态变化 \(\delta h\)，

\[
\Delta W_*=\frac{\delta h\,q^\top}{\|q\|^2},\qquad
\Delta W_*\Phi_P=0,\qquad
\Delta W_*\phi_t=\delta h.
\tag{20}
\]

因此所有保护位置的状态及最终logits完全相同，目标位置的状态精确变为 \(h_t+\delta h\)。在这两项线性约束下，

\[
\min\|\Delta W\|_F=\frac{\|\delta h\|}{\|q\|}.
\tag{21}
\]

**证明。** \(q\perp\operatorname{span}(\Phi_P)\)且 \(q^\top\phi_t=\|q\|^2\)，直接代入得式(20)。任一可行矩阵都有
\(\Delta W\phi_t=\Delta Wq\)，故
\(\|\delta h\|\le\|\Delta W\|_F\|q\|\)；式(20)达到等号。
若 \(q=0\)，保护约束必使 \(\Delta W\phi_t=0\)，在这一限定参数操作下非零写入不可行。GPT-2的Conv1D把输出投影存成 \(m\times d\)，实现使用上述矩阵的转置。

三层含义分别是：

- **回答。** 固定这些真实上游特征时，指定MLP写入值 \(W\Phi=Y\)可行，当且仅当 \(\ker\Phi\subseteq\ker Y\)。若要求任意 \(Y\)都可写入，则需 \(\Phi\)列满秩；这是固定特征下的插值条件，不是端到端Transformer容量定律。
- **组合。** 保护全部被考虑的原子评价前缀，目标选择组合前缀。若其 \(q\ne0\)，原子logits可以全部不变而组合状态改变。若最终头存在能产生另一个答案的可实现状态 \(h^*\)，取 \(\delta h=h^*-h_t\)，还能精确构造答案不同的模型。这给出单跳行为不唯一确定组合行为的Transformer内条件反例。
- **更新后使用。** 反过来保护相关组合前缀，目标取待编辑原子。在相同非零残量与可实现读出条件下，可以把原子改成新答案，而组合logits保持旧值。这解释“写入成功”为什么在逻辑上不足以保证“派生答案更新”；并不证明实际SGD采用这种解。

**不能省略的条件。** 实际所有原子特征可能已张满 \(m\)维，不能默认 \(q\ne0\)；矩阵保持是比保持argmax更强的要求。状态变化也不必改变读出，LayerNorm本身有不变方向。多token答案若要保证完整生成保持，保护集合必须包括各条生成路径的相关前缀及EOS。式(21)是参数扰动成本，不是训练token或步数。只改该层的不可行，不代表更新其他层也不可行。

该有限编辑构造不能直接套到Loop共享MLP：同一 \(W\)的早期执行会改变后续特征。若要使用式(20)，必须另行保证所有早期执行的相关状态不变；否则应采用式(18)的完整求导或实际有限更新。

### 14.3 原子学习的局部收益不保证组合学习收益

设 \(L_A(\theta)\)为原子训练损失，\(L_C(\theta)\)为组合评价损失，两者都由式(16)的完整模型计算。对于普通SGD的一步 \(\Delta\theta=-\eta\nabla L_A\)，在局部梯度Lipschitz条件下，

\[
L_C(\theta+\Delta\theta)-L_C(\theta)
=-\eta\langle\nabla L_C,\nabla L_A\rangle+O(\eta^2).
\tag{22}
\]

训练自身取 \(C=A\)时，一阶项为负的梯度范数平方；组合任务的一阶项则可能为正、零或负。CE对正确原子答案的约束因此不提供组合损失下降的符号保证。
对于AdamW、回放、辅助损失和梯度裁剪，必须使用真实更新方向 \(d=\Delta\theta\)：
\(\Delta L_C=\nabla L_C^\top d+O(\|d\|^2)\)，不能直接称为原始梯度夹角效应。若要解释许多训练步，还需沿实际轨迹控制这些量和余项；局部式不是grokking或全程收敛定理。

这不是新增表现预测指标。后续实验直接比较原子、组合及保持行为；梯度/状态操作仅用于检验更新通路，不训练内部特征到成绩的预测器。

### 14.4 Loop严格改变的是参数约束和更新耦合

在某一共同权重处，把Loop的 \(R\)次块组执行展开成独立参数副本 \(\theta_1,\ldots,\theta_R\)，且每个副本都等于 \(\theta\)。此时两种模型前向完全相同。固定其余公共参数，令 \(g_r=\nabla_{\theta_r}L_{\rm untied}\)，则

\[
\nabla_\theta L_{\rm shared}=\sum_{r=1}^R g_r,\qquad
\left\|\sum_r g_r\right\|^2
=\sum_r\|g_r\|^2+2\sum_{r<s}\langle g_r,g_s\rangle.
\tag{23}
\]

**证明。** 共享模型为独立模型与对角映射
\(\theta\mapsto(\theta,\ldots,\theta)\)的复合，链式法则即得。各 \(g_r\)已包括所有下游Jacobian，不能以某次块的局部导数替代。

正交叉项可能加强相同用途的学习，负交叉项也可能抵消；因此共享既可能减少重复学习、促进同一参数被多阶段使用，也可能约束不同角色并拖慢学习。相同权重被重复访问并不要求各次状态、路由或功能相同。

欧氏SGD中，先对独立副本各用步长 \(\eta\)更新，再正交投影回相等副本子空间，得到
\(\theta^+=\theta-(\eta/R)\sum_r g_r\)。
这与共享模型使用步长 \(\eta/R\)相同，说明相同步长不能简单称为相同更新强度。逐副本Adam的二阶矩不满足这一等价；新实验须给各臂同等开发预算校准优化，并记录更新范数，而非用该比例追溯重写旧训练。

**可检验的架构假说。** 全块共享、仅MLP共享、完全独立层分别限制哪些调用角色共同修改同一参数。三者在相同展开深度与相同初始前向下比较，才有机会区分共享存储、共享读取与单纯增加计算。前向相同和式(23)可数值核查；长期训练是否更少数据达到三层能力，必须另用学习曲线验证。

**同一起点的跨调用Jacobian恒等式。** 为明确“一个位置学到的参数更新怎样影响另一位置的调用”，将完整模型写为
\(f_x(\psi,\theta_1,\ldots,\theta_R)\)。\(\psi\)包括未展开的公共参数，\(\theta_r\)为第\(r\)次块组执行的全部参数副本。固定输入token及读出位置，关闭dropout，并在所有\(\theta_r=\theta\)的共同起点取导数：

\[
J_r(x)=\frac{\partial f_x}{\partial\theta_r},\qquad
J_0(x)=\frac{\partial f_x}{\partial\psi},\qquad
K_0(x,z)=J_0(x)J_0(z)^\top.
\tag{24}
\]

这里\(f_x\)是logits向量，\(J_r\)保留式(16)–(18)全部attention、MLP、归一化、残差和输出头的导数。公共embedding同时用于输入和读出时，其两条路径均包含在\(J_0\)中。以各自唯一参数的普通欧氏内积定义输出Jacobian核，则

\[
\begin{aligned}
K_{\rm shared}(x,z)
&=K_0(x,z)+\Bigl(\sum_rJ_r(x)\Bigr)
                    \Bigl(\sum_sJ_s(z)\Bigr)^\top,\\
K_{\rm untied}(x,z)
&=K_0(x,z)+\sum_rJ_r(x)J_r(z)^\top,\\
K_{\rm shared}(x,z)-K_{\rm untied}(x,z)
&=\sum_{r\ne s}J_r(x)J_s(z)^\top.
\end{aligned}
\tag{25}
\]

**证明。** 在对角参数约束下，\(\partial f_x/\partial\theta=\sum_rJ_r(x)\)；解共享参数的Jacobian是各\(J_r\)沿参数轴的拼接，故其与另一输入Jacobian的乘积只包含同副本项。公共参数的计算图与前向相同，贡献均为\(K_0\)。展开乘积即得差异。此处相同内积是明确的参数化选择，并不表示两种模型中相同梯度范数具有相同函数作用。

设训练例\(z\)的损失仅通过其logits依赖参数，令\(v_z=\nabla_{f_z}\ell_z\)。在共同起点、所有参数使用同一步长\(\eta\)的无动量、无裁剪、无正则普通SGD下，若局部二阶导数有界，

\[
\Delta f_x=-\eta K(x,z)v_z+O(\eta^2).
\tag{26}
\]

训练批次对各例按损失权重求和即可。共享增加的是跨执行位置的更新通路，而非一个必然有利的标量增益；式(25)的差异没有保证改善组合损失的符号。即便\(x=z\)，两种核都半正定，它们的差也未必半正定。对未见组合的影响还取决于该查询与训练查询的完整Jacobian及损失方向。因此可提出“原子学习是否通过共享参数影响后续推理调用”的机制问题，不能由等式推出泛化、知识保持或grokking。

**仅MLP共享与实际优化器。** 若只绑定对应MLP参数，使用\(J_r^M\)替代式(25)中的\(J_r\)，新增项仅为MLP参数的跨调用项；attention与块归一化副本仍独立，均按解共享参数计入共同部分。这是参数约束的定位，不能据此认定全部知识位于MLP。式(26)不适用于把原始梯度直接代入AdamW：共享参数与各独立副本拥有不同的一、二阶矩，裁剪、权重衰减和参数组步长也改变更新。在AdamW实验中应测实际\(d=\Delta\theta\)，使用\(\Delta f_x=Df_x\,d+O(\|d\|^2)\)解释局部作用。不同训练轨迹离开共同起点以后，不能把两个自然训练模型的差继续全部归于式(25)的跨项；可将各检查点临时复制解共享，重新建立其自己的同前向局部对照。

**与本轮开发的对应。** [Loop开发矩阵](roadmap.md#architecture-efficiency)使用相同起点的全共享、MLP共享、解共享，另以浅层模型区分额外计算。微观诊断固定只来自训练池的原子和组合小批次，记录各调用位置梯度、交叉内积及实际更新；诊断副本不训练，未见AA/BB答案不参与优化。训练梯度相容只能说明所测批次的更新关系，不能替代未见组合与旧行为保持的端到端证据。新增[真实Transformer核验脚本](development-artifacts/loop-learning-development-v1/verify_loop_kernel.py)及[结果](development-artifacts/loop-learning-development-v1/verify_loop_kernel.json)使用CPU/FP64、宽8、1基块重复2次：三臂初始前向误差0，按真实参数别名计入绑定embedding的全部路径，式(24)–(25)最大误差2.22×10⁻¹⁵。普通SGD步长减半时，式(26)的一阶余项缩小约4倍；这是小模型代数与有限差分核验，不证明AdamW学习效率。

### 14.5 架构特性怎样连接条件命题

| 架构 | 能严格讨论的操作 | 仍需经验验证的桥梁 |
| --- | --- | --- |
| Loop | 式(18)、(23)–(26)中的重复访问、参数耦合与跨调用更新项 | 不同知识使用角色是否获得相容更新，是否降低训练成本；当前优先检验 |
| MoE | 固定路由且仅更新某专家时，不访问该专家的样本不受该参数改动直接影响 | 共享层和router通常也变化；原子与组合可能不走同一专家。更多总参数与稀疏访问作用须分开 |
| DeltaNet / Gated DeltaNet | §12的快状态覆盖与键相关干扰；Gated版本另含全局衰减 | 每样本重置的快状态怎样帮助提取、组合参数知识；序列内覆盖不等于跨样本参数编辑 |
| mHC | 固定双随机残差混合的非扩张性质 | 动态控制器与子层导数仍在完整Jacobian中；稳定传播是否提高学习效率或保持事实需直接检验 |

这些结构并不处于同一知识存储层次。MoE直接改变可访问的参数容量与访问分配，适合保留为次级比较；[知识容量论文§9、附录D](https://arxiv.org/html/2404.05405v1)的稀疏专家结果支持研究其事实存储，但组合使用仍需单测。[Gated DeltaNet§3及检索实验](https://arxiv.org/html/2412.06464v1)中的覆盖与门控首先作用于序列内状态；逐样本重置的短闭卷任务未充分检验该设计，因此当前暂缓。[mHC§4–5](https://arxiv.org/html/2512.24880v2)主要验证多流传播及大规模深层训练稳定，当前浅层知识任务未建立对应限制，也暂缓。暂缓是任务与机制匹配判断，不是无效性结论。

知识与推理的收益也不必一致。[Reasoning with Latent Thoughts§3、附录A.2](https://arxiv.org/html/2502.17416v1)分别比较闭卷知识和推理；[2026年iso-depth研究§3–4](https://arxiv.org/html/2604.21106v3)进一步分离循环数、参数和计算。该研究v3§5.2还发现循环边界的双流Hyperconnections改善其循环等效性拟合，支持保留Loop与跨轮状态连接的结合；这不是mHC的直接验证，而且未对非循环基线施加相同连接改造。两者为比较轴提供依据，但其自然预训练结果和拟合关系不构成本节实际GPT-2任务的收敛或scaling定理。

相关原始方法：[Universal Transformers](https://arxiv.org/abs/1807.03819)、[DeltaNet训练方法](https://arxiv.org/abs/2406.06484)、[Gated DeltaNet](https://arxiv.org/abs/2412.06464)、[mHC](https://arxiv.org/abs/2512.24880)、[Switch Transformers的稀疏专家方法](https://jmlr.org/papers/v23/21-0998.html)。本地MoE为top-2而非Switch的top-1，本地mHC为GPT-2适配；具体差异见[架构实现](../src/llm_memory_editability/parametric_architecture.py)。
