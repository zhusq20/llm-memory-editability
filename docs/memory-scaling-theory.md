# 知识学习的理论依据：回答、组合与更新后的使用

**读者导引。** 本文为论文提供理论推导。论文研究的是参数知识（存储在模型权重中的事实）的三个问题：它能否被回答；能否被组合进多步推理；在更新之后能否继续被使用。“回答”指单跳事实查询答对。“组合”指两跳查询（two-hop query）(h, r₁, r₂)能否答对：模型须先由(h, r₁)得到桥实体（bridge entity）b，再把b作为第二跳的头实体，由(b, r₂)得到尾实体t。“更新后使用”指编辑或续训写入一个事实之后，依赖这个事实的多跳答案能否随之改变。

全文的核心对象是经验神经正切核（empirical NTK）K(u, c)=J(u)J(c)ᵀ。c是训练情境（写入情境），即事实以什么样本被训练，例如原子陈述、某种提问模板、两跳查询中的某个角色或一次编辑。u是使用方式，即之后在什么查询中用到这个事实。J(·)是该查询的logits对模型参数的Jacobian。在训练情境c上做一步梯度更新，一阶近似下查询u的logits变化为Δf_u≈−ηK(u, c)v_c，其中η是学习率，v_c是c的损失对c的logits的梯度。K(u, c)近零，意味着在c上学到的内容一阶下传不到u。

文中反复使用的几个名词如下，完整定义以[研究路线图的“术语与记号”一节](roadmap.md#glossary)为准。

- **原子事实（atomic fact）**：一条三元组(h, r, t)，训练时以“头实体 关系 → 尾实体”的单跳查询出现。
- **r₁位置**：两跳查询中第一个关系token所在的位置；桥实体b应在这里形成。
- **分布内／分布外组合（ID／OOD测试）**：分布内组合用到的事实在训练中都出现在其他两跳样本里，只是这一组合本身没训练过；分布外组合用到的事实只以原子事实训练过。II/IO/OI/OO四类测试中，第一个字母表示第一跳事实、第二个字母表示第二跳事实是ID（出现在训练两跳样本中）还是OOD（只有原子训练），定义同Wang等2024与Zhang等2026。
- **标准Transformer**：各层参数独立的Transformer。**循环Transformer（looped Transformer）**记作Loop L×T：一个L层的参数共享块重复执行T次；Loop 4×2即4层块执行2次，总深度与标准8层模型相同。
- **Wang设定**：Wang等的Grokked Transformers论文所用的合成知识图与训练配方。
- **组合的三个前提**：层范围（第二跳查表所用的层是否就是存储该事实的层）；逐跳完成（每一跳是否在下一跳读取的token位置上完成）；表示格式（该位置的隐藏状态是否处在下一跳查表所读取的形式，例如与实体的输入embedding对齐）。
- **第一跳辅助损失**：在r₁位置、第一次执行之后，用输出embedding解码并以桥实体为标签的辅助交叉熵。**表示对齐损失**：把r₁位置第一次执行后的隐藏状态方向拉向桥实体的输入embedding。
- **解码—再编码（re-encoding）**：在两次迭代之间，把r₁位置的隐藏状态替换为模型自己解码出的实体的输入embedding（保持范数），参照DiscoLoop v2式(3)的替换操作。DiscoLoop的**解码—再编码通道**则是在每次迭代末加上按softmax概率加权的输入embedding之和。

本文分两部分。[第一部分：论文理论](#paper-theory)按论证顺序收录要写进论文的推导，包括完整Transformer中的非蕴含命题（即“A成立不能推出B成立”一类命题）、经验NTK与离散交接（§14、§13、§11）。离散交接指在两次迭代之间，把隐藏状态换成模型自己解码出的实体的输入embedding（即上面的解码—再编码）。[第二部分：历史推导](#historical-derivations)保留容量、可辨识性、误差界与架构资源方面的早期推导；原有假设与边界不变，不进入论文。论文立意与优先级见[研究路线图](roadmap.md#question)，已执行的实验见[结果汇总](results.md)。

## 第一部分：论文理论

论文的理论是一条三步的链。第一步，在实际Transformer中证明：单跳行为不决定组合行为，也不决定更新后的使用。第二步，用经验NTK（输出Jacobian核）说明一次写入能传到哪些使用方式。第三步，在离散交接下给出路径一致性假说的一个构造性实例。路径一致性假说是本项目的工作假说：一种用途须能有效访问相关训练或编辑所写入的内容，并以兼容的表示接入后续计算。层范围、token位置与表示格式是比较这些条件的维度；两种用途的完整计算不必逐项相同，共享层或参数也不保证一致访问。所用的数学是链式法则与softmax梯度等标准工具；论文要写的是由它们推出、可以被实验否定的预测。下表按本部分的排列顺序列出各项内容。

**从循环Transformer推广到任意训练情境与使用方式。** 式(26)对任意两个输入都成立，不限于循环Transformer。把式中的训练样本z换成训练情境c（原子陈述、某种提问模板、两跳查询中的某个角色、一次编辑），把查询x换成使用方式u，就得到[roadmap第1节](roadmap.md#question)中的Δf_u≈−ηK(u, c)v_c，其中K(u, c)=J(u)J(c)ᵀ是经验NTK，η是学习率，v_c是c的损失对其logits的梯度。式(25)只是K在参数共享下的一种分解。同一个K作用于新的使用方式时是迁移，作用于旧的使用方式时是干扰；一阶下两者是同一个式子的两面。迁移与干扰是否来自同一组参数，是经验问题。适用边界与§14.4相同：只在一阶、局部成立；使用AdamW时须代入实测的参数更新；预训练中读取路径本身的形成，超出固定核所能描述的范围。

**路径一致性假说在理论中的地位。** 用经验NTK的语言，路径一致性假说是关于K何时近零的假说，不是已证明的命题。理论给出它的两半。第一半在§13.6：在假设(A1)(A2)下，两跳查询的输出与原子查询在第一次迭代末的输出是同一个参数θ的同一个函数，因此K(u, c)=K(c′₁, c)+O(ε)。这里c′₁表示原子查询c′=(b, r₂)在第一次迭代末的输出，ε是桥实体解码时没有落在argmax上的概率质量（定义见§13.6）。这是假说成立的一个构造。第二半在§14.6：在标准Transformer中，原子事实上的写入只能经由桥实体、到达答案位置之后的那些层，才能传给第二跳；所以当所有原子事实都在同一层范围内完成查表时，K(第二跳使用, 原子写入)近零。训练后模型的激活是否真的如此，由路径重合干预实验实测：在原子查询中找出某个事实的必需成分，再在两跳查询中消融同一成分，看该事实作第二跳时的使用是否受影响。

**2026-10-10补齐的两条推导。** 原先缺少的两条推导分别是“标准Transformer中K(第二跳使用, 原子写入)近零的条件”与“提问模板迁移”，现分别见§14.6与§14.7。前者没有另建联想记忆玩具模型，而是直接在实际计算图上分解MLP输出权重的经验NTK。后者在固定核下成立；训练中特征本身怎样变化（特征学习）的部分仍是开放问题。

## Memory Mosaics：内容、访问规则与组合操作的共同学习

**结论层级：文献机制解释与受控例证；下述值改写关系是给定操作下的恒等式，下游响应只在局部成立。** [Memory Mosaics（ICLR 2025）§3–6](https://arxiv.org/pdf/2405.06394#page=2)为三个层次提供一个概念依据：可用的知识不仅涉及存了什么，也涉及怎样访问，以及取出的内容怎样进入下一步计算。把内容、访问规则和组合操作的共同形成作为本项目要解释的问题，是从该论文得到的启发，不是它已证明的普遍结论。

**训练与序列内学习分开。** 论文§3的上下文记忆在每个序列开始时为空；训练学习key/value提取函数，序列中再追加由观察生成的KV记录。value可以编码下一步观察，但严格排除注意力主对角线，仅在该观察已经到来后使用记录，保持因果性。§6的持久记忆则把KV本身作为训练参数，推理时不更新。二者分别涉及序列状态与参数知识；追加一条上下文记录不等于改写参数中已有的事实。

**predictive disentanglement的证据边界。** [§4、Figure 2](https://arxiv.org/pdf/2405.06394#page=4)把逐位置预测损失解释为尽早适应上下文的压力，并据此解释独立记忆为何可能分工。它是机制解释，不是梯度下降必然找到解耦解的定理。[§5、Figure 3–5](https://arxiv.org/pdf/2405.06394#page=6)用相同的54个可训练实数参数比较联合记忆与三个分量记忆，后者分别学会各月亮的运动后可重组预测；[附录A、Figure 10](https://arxiv.org/pdf/2405.06394#page=14)显示分工矩阵，也明确可靠收敛用了复数矩阵约束与误差截断（附录A称MSE clipping；[作者实现](https://github.com/facebookresearch/MemoryMosaics/blob/main/ThreeMoons/train_planets-3heads.py)先把预测残差截断到[-0.5, 0.5]再平方取均值）。这里是独立分量的并行预测，不是把第一条参数事实的答案作为第二条事实的输入；不能据此认定串行两跳组合已解决。§4对标准Transformer也有类似解耦的判断明确是猜想；§6关于组合规则与动态路由的论述没有单独建立知识编辑传播的证据。

**显式softmax记忆中的限定改写。** 固定输入token、查询q、存储key以及后续参数，只改一条存储value，令

\[
y(q)=\sum_i\alpha_i(q)v_i,\qquad
\alpha_i(q)=\frac{\exp(\beta q^\top k_i)}{\sum_s\exp(\beta q^\top k_s)}.
\]

论文式(7)取q为当前key，只对已可用的记录求和。把\(v_j\)换成\(v_j+\Delta v_j\)，则

\[
\Delta y(q)=\alpha_j(q)\Delta v_j.
\]

这是加权求和的精确恒等式，表明不同查询对同一内容改写的直接响应由各自的访问权重决定。若同一记忆层在多个token位置读取这条记录，令H为记忆读取经固定输出投影写回残差后、任何下游非线性之前的完整残差状态，\(B_j\)汇总各位置的\(\alpha_j(q)\)、固定输出投影和状态注入位置；则\(\Delta H=B_j\Delta v_j\)。把其后的完整计算写成\(f=G(H;\xi)\)，其中\(\xi\)是固定的其他边界量，attention、归一化、残差、MLP与输出头均保留在G中，有

\[
\Delta f=G(H+B_j\Delta v_j;\xi)-G(H;\xi)
=J_G(H;\xi)B_j\Delta v_j+o(\|\Delta v_j\|).
\]

最后一个等号仅在可微点、小改变量下成立。非零读取并不保证答案改变：后续计算可消去或改变这一分量，离散答案还取决于logit间隔。若改写同时改变query/key、其他读取位置或生成的后续token，须回到完整计算图；不能继续假设访问权重固定。这里的\(J_G\)是对状态的Jacobian，不是参数经验NTK。

**追加新值不保证覆盖旧值。** 若两条可用记录有完全相同的key，且没有另加时间优先规则，则任一查询给二者相同权重；它们的合计贡献中旧、新value各占一半，其他记录仍参与总输出。这是上述检索式的条件推论，不是论文报告的编辑实验；它说明追加、替换与依赖答案更新是三个不同操作。

**与实际Transformer及固定核的关系。** §6的持久softmax记忆可写成使用softmax非线性的单隐层网络；它与§14.1的GELU MLP不是同一个计算，以上恒等式不能直接代替GELU Transformer的参数编辑分析。后者仍用式(18)、(26)、(31)保留完整参数与状态导数。固定经验NTK描述既有读取规则下，一次局部写入怎样影响不同用途；它不能解释预训练为何形成这些规则。Memory Mosaics提示我们补上规则形成的问题，但没有证明字面相同的层/头路径是复用的必要条件：同一模块可因查询不同而访问不同内容，不同模块也可能提供功能兼容的内容。路径一致性仍是关于有效访问及后续使用的工作假说，须按三个层次分别检验。

## 14. 直接基于完整Transformer的条件命题

本节要回答两个问题：不简化模型时，单跳行为能否决定组合与更新后的行为？一次参数更新怎样影响其他查询？为此，本节不把模型替换成自由的线性记忆，而是保留实际的attention、LayerNorm、残差连接、非线性MLP和最终输出头，再写明固定哪些量、改变哪些参数。目标是先给出可以严格证明的非蕴含关系和架构约束，再由端到端实验检验这些条件能否解释已有现象。以下结论是标准线性代数与链式法则在实际参数化上的应用。它们不宣称新颖性，也不被当作已证明的样本复杂度定律。

### 14.1 实际计算图与完整状态

**结论层级：恒等式。** 这一小节写出后续所有推导共用的对象：模型前向计算的精确形式，以及输出对状态和参数的全微分。

以本项目当前的GPT-2实现[ReproductionGPT](../src/llm_memory_editability/grokking_reproduction.py)为主要对象，固定token前缀，关闭dropout。每个pre-LN块作用于状态 \(H_l\)，即第l次块执行之前、全部相关token位置的残差状态组成的矩阵：

\[
R_l=H_l+A_l(N_{l,1}(H_l)),\qquad
H_{l+1}=R_l+M_l(N_{l,2}(R_l)).
\tag{16}
\]

式中 \(R_l\)是attention之后的中间残差状态，\(N_{l,1}\)与\(N_{l,2}\)是块内两个LayerNorm。\(A_l\)包含多头因果softmax attention和输出投影。\(M_l(z)=W_{l,\downarrow}\sigma(W_{l,\uparrow}z+b_{l,\uparrow})+b_{l,\downarrow}\)是MLP，\(\sigma\)是当前GPT-2实现按配置指定的GELU。输入是token embedding与位置embedding之和。最终logits为 \(f_x(\theta)=E N_f(H_T(x))\)：\(N_f\)是最终LayerNorm，\(E\)是输出头并与输入token embedding共享，\(T\)是块执行的总次数，logits只在需要的位置计算。循环Transformer重复执行同一组块，每次迭代开始时不重新加入embedding。自然语言模型若使用RMSNorm、SwiGLU、RoPE或GQA，应换成相应的实际计算图；不能把GPT-2上的数值结果直接归给所有Transformer。

把整个序列向量化，记 \(f_A=A_l\circ N_{l,1}\)（attention子层）、\(f_M=M_l\circ N_{l,2}\)（MLP子层），则一个块对输入状态的Jacobian为（\(D f\)表示映射f的Jacobian）

\[
J_l=\frac{\partial H_{l+1}}{\partial H_l}
=(I+D f_M)(I+D f_A).
\tag{17}
\]

两个导数分别在 \(R_l,H_l\)处取值。注意这里的 \(J_l\)是对状态的Jacobian，与§14.4中对参数的 \(J_r(x)\)不同。固定输入状态、对块参数求偏导，得到
\(Q_l=(I+D f_M)\partial_\theta f_A+\partial_\theta f_M\)。
若第 \(l\)次执行使用参数组 \(\theta_{\pi(l)}\)（\(\pi(l)\)表示第l次执行用的是哪一组参数），最终状态的全微分为

\[
dH_T=(J_{T-1}\cdots J_0)dH_0+
\sum_{l=0}^{T-1}(J_{T-1}\cdots J_{l+1})Q_l\,d\theta_{\pi(l)}.
\tag{18}
\]

空乘积取单位矩阵。最终还须对 \(E N_f(H_T)\)求导；若embedding也被更新，不能遗漏输入端的 \(dH_0\)和输出端的 \(dE\)。这些都是完整计算图上的恒等式。推导中没有假设每层存一个事实、每次迭代完成一跳，或者全部知识都存放在MLP中。


**执行次数与知识跳数不等同（2026-10-12）。** 对一个完整共享块Fθ，严格两次执行的输出是G(Fθ(Fθ(H₀)))，其中H₀包含头实体与全部关系token，G含最终归一化及读出。三/四跳真值分别是事实映射fᵣ₃∘fᵣ₂∘fᵣ₁与fᵣ₄∘fᵣ₃∘fᵣ₂∘fᵣ₁；这些映射不自动等于逐次执行的Fθ。每个Fθ仍包含各位置的因果attention、MLP、归一化和完整残差，训练可形成组合映射或压缩子路径。只有额外规定每次执行恰好读取一条原子事实、下一次只能从该结果继续时，才可把一次执行数作一跳；普通Transformer没有内置这条限制。[严格两次执行的重放](results.md#strict-loop-hops-20261012)是受控回答证据，不是任意链长可表示的定理，也不证明正确答案来自逐跳查表。
### 14.2 最后一个未共享MLP：保持与写入可以精确分离

**结论层级：已证明。** 本小节要回答：只看原子查询上的行为，能否确定两跳查询上的行为？编辑一个原子事实成功，是否必然让依赖它的多跳答案更新？为此需要一个在真实Transformer中、不靠Taylor近似的构造：在一部分查询的输出完全不变的前提下，精确改变另一个查询的输出。

**限定操作。** 固定所有上游参数、最终LayerNorm和输出头，只改变最后一次执行、且未在上游共享的那个MLP的输出矩阵 \(W\in\mathbb R^{d\times m}\)；\(d\)是残差宽度，\(m\)是MLP隐藏层宽度。对任一前缀固定的评价位置 \(x\)，令

\[
\phi_x=\sigma(W_\uparrow N_2(r_x)+b_\uparrow),\qquad
h_x=r_x+W\phi_x+b_\downarrow,\qquad f_x=E N_f(h_x).
\tag{19}
\]

这里 \(r_x\)是最后一个attention之后的真实残差状态，\(N_2\)是该块的第二个LayerNorm，\(W_\uparrow,b_\uparrow\)是该MLP的输入权重与偏置，\(b_\downarrow\)是输出偏置；\(\phi_x\)是该MLP的隐藏层激活，\(h_x\)是送入最终LayerNorm的状态；其余层和attention都没有删除。因为这个 \(W\)不出现在上游，\(\phi_x,r_x\)在这次编辑中不变，所以 \(\Delta h_x=\Delta W\phi_x\)精确成立，不需要Taylor近似。

**命题：受保护输出下的最小范数写入。** 设需要保持不变的查询（保护集合）的特征矩阵为
\(\Phi_P=[\phi_{p_1},\ldots,\phi_{p_n}]\)，\(\Pi_P=\Phi_P\Phi_P^+\)是到其列空间的正交投影（\(+\)表示伪逆）。要改写的目标查询为 \(t\)，令 \(q=(I-\Pi_P)\phi_t\)，即目标特征减去它在保护特征张成空间上的投影之后、与该空间正交的分量。若 \(q\ne0\)，则对任意指定的状态变化 \(\delta h\)，

\[
\Delta W_*=\frac{\delta h\,q^\top}{\|q\|^2},\qquad
\Delta W_*\Phi_P=0,\qquad
\Delta W_*\phi_t=\delta h.
\tag{20}
\]

因此所有保护位置的状态和最终logits都完全不变，目标位置的状态精确变为 \(h_t+\delta h\)。在这两组线性约束下，

\[
\min\|\Delta W\|_F=\frac{\|\delta h\|}{\|q\|}.
\tag{21}
\]

**证明。** \(q\perp\operatorname{span}(\Phi_P)\)且 \(q^\top\phi_t=\|q\|^2\)，直接代入即得式(20)。任一可行矩阵都满足
\(\Delta W\phi_t=\Delta Wq\)，所以
\(\|\delta h\|\le\|\Delta W\|_F\|q\|\)；式(20)取到等号。
若 \(q=0\)，保护约束必然使 \(\Delta W\phi_t=0\)，在这一限定的参数操作下，非零写入不可行。GPT-2的Conv1D把输出投影存成 \(m\times d\)，实现中使用上述矩阵的转置。

**由此得到什么。** 这个命题对论文的三个层次各有一层含义：

- **回答。** 固定这些真实的上游特征时，要求MLP写入指定值 \(W\Phi=Y\)可行，当且仅当 \(\ker\Phi\subseteq\ker Y\)。若要求任意 \(Y\)都能写入，则需要 \(\Phi\)列满秩。这是固定特征下的插值条件，不是端到端Transformer的容量定律。
- **组合。** 把全部被考虑的原子查询的评价前缀放进保护集合，目标选两跳查询的前缀。若此时 \(q\ne0\)，所有原子查询的logits都可以不变，而两跳查询的状态改变。若最终输出头存在一个能产生另一个答案的可实现状态 \(h^*\)，取 \(\delta h=h^*-h_t\)，还能精确构造出两跳答案不同的模型。这在Transformer内部给出一个条件反例：单跳行为不能唯一确定组合行为。
- **更新后使用。** 反过来，把相关两跳查询的前缀放进保护集合，目标取待编辑的原子事实。在同样的非零残量与可实现输出条件下，可以把原子事实改成新答案，而两跳查询的logits保持旧值。这说明“编辑成功”在逻辑上不足以保证“依赖被编辑事实的多跳答案随之更新”；但它并不证明实际的SGD会采用这种解。

**不能推出什么：不能省略的条件。** 实际中全部原子事实的特征可能已经张满 \(m\)维，所以不能默认 \(q\ne0\)。这里要求的矩阵保持（保护位置的状态与logits完全不变），是比只保持argmax更强的要求。状态变化也不一定改变输出，因为LayerNorm本身有不变方向。对多token答案，若要保证完整生成不变，保护集合必须包含每条生成路径上的相关前缀和EOS。式(21)是参数扰动的大小，不是训练token数或步数。只改这一层不可行，不代表更新其他层也不可行。

这一有限编辑构造不能直接用于循环Transformer的共享MLP：同一个 \(W\)在早期执行中的改变会改变后续执行的特征。若要使用式(20)，必须另外保证所有早期执行中的相关状态不变；否则应使用式(18)的完整求导或实际的有限更新。

### 14.3 原子学习的局部收益不保证组合学习收益

**结论层级：已证明。** 本小节要回答：在原子事实上做一步梯度下降，是否一定降低两跳查询的损失？这是经验NTK的标量版本，在论文中并入下一小节叙述。

设 \(L_A(\theta)\)为原子事实的训练损失，\(L_C(\theta)\)为两跳查询（组合）的评价损失，两者都由式(16)的完整模型计算。对普通SGD的一步 \(\Delta\theta=-\eta\nabla L_A\)（\(\eta\)为学习率），在局部梯度Lipschitz条件下，

\[
L_C(\theta+\Delta\theta)-L_C(\theta)
=-\eta\langle\nabla L_C,\nabla L_A\rangle+O(\eta^2).
\tag{22}
\]

**由此得到什么。** 训练损失本身（取 \(C=A\)）的一阶项是负的梯度范数平方；两跳查询损失的一阶项则可能为正、为零或为负。所以交叉熵对正确原子答案的约束，不保证组合损失下降的符号。

**不能推出什么。** 对AdamW、回放、辅助损失和梯度裁剪，必须使用真实的更新方向 \(d=\Delta\theta\)：
\(\Delta L_C=\nabla L_C^\top d+O(\|d\|^2)\)，不能直接称为原始梯度夹角的效应。若要解释许多个训练步，还须沿实际轨迹控制这些量和余项；这个局部式子不是grokking定理，也不是全程收敛定理。

这不是新增的表现预测指标。后续实验直接比较原子事实、两跳查询和保持集上的行为；梯度与状态操作只用于检验更新通路，不训练从内部特征到成绩的预测器。

### 14.4 循环Transformer严格改变的是参数约束与更新耦合

**结论层级：一阶恒等式；FP64数值核查。** 本小节要回答：与标准Transformer相比，循环Transformer在数学上究竟改变了什么？答案分两步：参数共享使共享参数收到各次执行梯度之和（梯度池化，gradient pooling）；在经验NTK中，这表现为一个只在参数共享时存在的跨迭代项。

**梯度池化。** 在某一共同权重处，把循环Transformer中共享块组的 \(R\)次执行展开成 \(R\)份独立的参数副本 \(\theta_1,\ldots,\theta_R\)，并让每份副本都等于 \(\theta\)。此时共享模型与展开后的模型前向完全相同。固定其余公共参数，令 \(g_r=\nabla_{\theta_r}L_{\rm untied}\)，即解除参数共享后的损失 \(L_{\rm untied}\)对第r份副本的梯度；\(L_{\rm shared}\)是共享模型的损失。则

\[
\nabla_\theta L_{\rm shared}=\sum_{r=1}^R g_r,\qquad
\left\|\sum_r g_r\right\|^2
=\sum_r\|g_r\|^2+2\sum_{r<s}\langle g_r,g_s\rangle.
\tag{23}
\]

**证明。** 共享模型是展开后的独立模型与对角映射
\(\theta\mapsto(\theta,\ldots,\theta)\)的复合，由链式法则即得。每个 \(g_r\)都已包含其后全部下游计算的Jacobian，不能用某一次块执行的局部导数代替。

**由此得到什么、不能推出什么。** 交叉项 \(\langle g_r,g_s\rangle\)为正时，可能加强相同使用方式的学习；为负时，也可能相互抵消。因此参数共享既可能减少重复学习、促使同一参数被多个阶段使用，也可能约束不同角色、拖慢学习。同一组权重被重复访问，并不要求各次执行的状态、路由或功能相同。

在欧氏SGD中，先对各独立副本分别用步长 \(\eta\)更新，再正交投影回“各副本相等”的子空间，得到
\(\theta^+=\theta-(\eta/R)\sum_r g_r\)。
这与共享模型使用步长 \(\eta/R\)相同，说明相同的步长不能简单视为相同的更新强度。逐副本使用Adam时，二阶矩不满足这一等价。新实验须给各实验条件同等的开发预算来校准优化，并记录更新范数；不应按这一比例回头改写旧训练的解释。

**可检验的架构假说。** 全块共享、仅MLP共享、各层完全独立，分别限制了哪些使用角色会共同修改同一组参数。只有在相同展开深度、相同初始前向下比较这三者，才有机会区分“共享存储”“共享读取”与“单纯增加计算”。前向相同与式(23)可以数值核查；长期训练中是否用更少数据达到三个层次的能力，必须另用学习曲线验证。

**共同起点上的跨迭代Jacobian恒等式。** 为写清“在一个查询上学到的参数更新怎样影响另一个查询”，把完整模型写成
\(f_x(\psi,\theta_1,\ldots,\theta_R)\)。\(\psi\)是未展开的公共参数（如embedding），\(\theta_r\)是第\(r\)次块组执行所用的全部参数副本。固定输入token与输出位置，关闭dropout，在所有\(\theta_r=\theta\)的共同起点求导：

\[
J_r(x)=\frac{\partial f_x}{\partial\theta_r},\qquad
J_0(x)=\frac{\partial f_x}{\partial\psi},\qquad
K_0(x,z)=J_0(x)J_0(z)^\top.
\tag{24}
\]

这里\(f_x\)是查询x的logits向量；\(J_r(x)\)是logits对第r次执行所用参数的Jacobian，\(J_0(x)\)是logits对公共参数的Jacobian，\(K_0\)是公共参数贡献的核。\(J_r\)保留式(16)–(18)中全部attention、MLP、归一化、残差和输出头的导数。公共embedding同时用于输入和输出时，两条路径都包含在\(J_0\)中。经验NTK（输出Jacobian核）用各模型自身各个独立参数上的普通欧氏内积定义，则

\[
\begin{aligned}
K_{\rm shared}(x,z)
&=K_0(x,z)+\Bigl(\sum_rJ_r(x)\Bigr)
                    \Bigl(\sum_sJ_s(z)\Bigr)^\top,\\
K_{\rm untied}(x,z)
&=K_0(x,z)+\sum_rJ_r(x)J_r(z)^\top,\\
K_{\rm shared}(x,z)-K_{\rm untied}(x,z)
&=\sum_{r\ne s}J_r(x)J_s(z)^\top.
\end{aligned}
\tag{25}
\]

**证明。** 在对角参数约束下，\(\partial f_x/\partial\theta=\sum_rJ_r(x)\)。解除参数共享后，参数的Jacobian是各个\(J_r\)沿参数轴的拼接，所以它与另一输入的Jacobian相乘时只含同一副本的项。公共参数的计算图与前向相同，两种模型中的贡献都是\(K_0\)。展开乘积即得差。这里使用相同的内积是一个明确的参数化选择，并不表示两种模型中相同的梯度范数有相同的函数作用。

式(25)第三行的 \(\sum_{r\ne s}J_r(x)J_s(z)^\top\)就是跨迭代项，即共享参数在不同迭代之间的耦合；下文称“跨迭代项”时都指它，或它在某一部分参数上的限制。

设训练样本\(z\)的损失只通过其logits依赖参数，令\(v_z=\nabla_{f_z}\ell_z\)为损失 \(\ell_z\)对logits的梯度。在共同起点上，所有参数使用同一步长\(\eta\)，做无动量、无裁剪、无正则的普通SGD；若局部二阶导数有界，则

\[
\Delta f_x=-\eta K(x,z)v_z+O(\eta^2).
\tag{26}
\]

式中K取所用模型的核（K_shared或K_untied）。对一个训练批次，按损失权重对各样本求和即可。

**由此得到什么、不能推出什么。** 参数共享增加的是一条跨迭代的更新通路，而不是一个必然有利的标量增益：式(25)中的差，没有保证改善组合损失的符号。即使\(x=z\)，两种核各自都半正定，它们的差也不一定半正定。对未见过的两跳查询的影响，还取决于该查询与训练查询的完整Jacobian以及损失方向。因此，式(25)–(26)可以提出“原子学习是否通过共享参数影响后续推理中的使用”这一机制问题，但不能由等式推出泛化、知识保持或grokking。

**仅MLP共享与实际优化器。** 若只绑定对应的MLP参数，就用MLP参数的Jacobian \(J_r^M\)代替式(25)中的\(J_r\)：新增的只有MLP参数的跨迭代项；attention与块内归一化的副本仍然独立，按解除共享后的参数计入共同部分。这只是对参数约束的定位，不能据此认定全部知识都在MLP中。式(26)不能把原始梯度直接代入AdamW：共享参数与各独立副本有不同的一阶矩与二阶矩，裁剪、权重衰减和分参数组的步长也会改变更新。在AdamW实验中，应测量实际的更新\(d=\Delta\theta\)，用\(\Delta f_x=Df_x\,d+O(\|d\|^2)\)解释局部作用。两个模型沿不同训练轨迹离开共同起点之后，不能再把它们的差全部归于式(25)的跨迭代项；可以把各检查点临时复制、解除参数共享，重新建立该检查点自己的、前向相同的局部对照。

<a id="partial-pooling-20261010"></a>
**部分梯度池化：把跨迭代项变成可以连续调节的量（2026-10-10）。** 式(23)说明，循环Transformer的共享参数收到各次执行梯度之和，即梯度池化（gradient pooling）。匿名ICLR 2027投稿《How Weight Tying Elicits Iterative Computation in Looped Transformers》（投稿号34319，见[roadmap](roadmap.md#weight-tying-pooling)）把这一求和做成训练干预。做法是把共享块拆成T份参数副本（T为共享块的执行次数，相当于前文的R），记第t次执行的梯度为g_t、各次梯度之和为G，第t份副本的更新取

\[
q_t=\alpha G+T(1-\alpha)\,g_t,\qquad G=\sum_{s=1}^{T}g_s .
\]

α是池化比例。α=1时各副本收到相同的更新，副本始终相等，就是通常的循环Transformer训练。α=0时每份副本只收到自己那次执行的梯度（乘以T），就是解除参数共享的训练。中间的α只改变更新的聚合方式，模型结构族不变。

下面的命题要回答：池化比例α怎样改变经验NTK中的跨迭代项？

**命题（部分池化的经验NTK）。** 在各副本相等的某一时刻，公共参数ψ照常更新；对各副本使用上述q_t、步长η做普通SGD。局部二阶导数有界时，

\[
\Delta f_x=-\eta K_\alpha(x,z)v_z+O(\eta^2),\qquad
K_\alpha(x,z)=K_0(x,z)+\bigl[\alpha+T(1-\alpha)\bigr]\sum_tJ_t(x)J_t(z)^\top+\alpha\sum_{t\ne s}J_t(x)J_s(z)^\top .
\tag{35}
\]

**证明。** g_s=J_s(z)ᵀv_z，Δθ_t=−ηq_t，Δf_x=J_0(x)Δψ+Σ_tJ_t(x)Δθ_t；代入展开即得。α=1时，式(35)等于式(25)的K_shared。α=0时为K_0+T(K_untied−K_0)，即解除共享时的核，其副本部分被放大T倍。

跨迭代项与同迭代项的系数之比为ρ(α)=α/(α+T(1−α))。T=2时，α=.25/.5/.75分别对应ρ=.14/.33/.60。AdamW按坐标归一化更新幅度，整体尺度大致被吸收；因此实验中应把α理解为在调节ρ，并按本节前文记录实测的更新Δθ，而不是直接代入原始梯度。

**由此得到什么、不能推出什么。** 这一命题有三层含义：
- **用训练情境与使用方式的语言说，循环Transformer是“每次写入同时写到所有迭代”，α是写到其他迭代的比例。** 参数共享对训练情境与使用方式之间关系的全部作用，都集中在式(35)的最后一项。
- **α<1时各副本会逐渐分开，前向不再相同。** 式(35)只在副本相等的时刻精确；长期训练中α造成什么差异，要由端到端实验测量。
- **梯度路由（gradient routing）与α不同。** 该投稿的另一种干预保持前向共享，只改变更新的聚合方式（例如只用最后一次执行的梯度）。前向共享时，任何更新都会在所有迭代中出现，所以路由只改变学到的方向，不改变写入在哪些迭代可见。参数知识中需要把这两种作用分开：α同时改变“写入在哪里可见”和“学到什么”，路由只改变后者。

**与式(31)结合：梯度池化只提供写入的通路，激活是否重合决定这条通路是否起作用。** 把式(35)限制到第j个块的MLP输出矩阵W_j。按式(31)（符号定义见§14.6：φ为MLP隐藏层激活，G为logits对残差的后向Jacobian，e、e′为执行序号，p、q为token位置），

\[
K^{W_j}_\alpha(u,c)=\sum_{e,e'\in\pi^{-1}(j)}w_\alpha(e,e')\sum_{p,q}G_{e,p}(u)\,G_{e',q}(c)^\top
\bigl\langle\phi_{e,p}(u),\phi_{e',q}(c)\bigr\rangle,\qquad
w_\alpha(e,e')=\begin{cases}\alpha+T(1-\alpha),&e=e'\\ \alpha,&e\ne e'\end{cases}
\tag{36}
\]

跨迭代项（e≠e′）非零，需要同时满足三点：两次执行使用同一组参数（π(e)=π(e′)，由池化保证）；使用方式u在第e次执行时的MLP激活，与训练情境c在第e′次执行时的激活重合（⟨φ_e(u), φ_e′(c)⟩≠0，这就是表示格式条件）；两者的后向Jacobian G不正交。

**这解释了上述投稿的任务与本项目任务为什么表现不同（事后解释，未经检验）。** 该投稿使用指针追踪任务（directed permutation traversal），全部边都在上下文中，不涉及参数记忆。那里每一跳的输入都由同一个跳转算子在上一次迭代中产生；算子一旦形成，各次迭代的激活自然重合，所以各个跳数几乎同时习得（作者称compositional burst）。本项目的任务是参数化的两跳查询。原子查询(b, r₂)在第一次执行时的激活来自实体的输入embedding；两跳查询在第二次执行时的激活来自桥实体的隐藏状态。只有桥实体的隐藏状态与它的输入embedding对齐之后，两者的激活才重合，原子训练写入的内容才能经跨迭代项被第二跳读到。这与Wang设定下的观察相容：循环Transformer的原子事实在8k–23k步已达到≥99%，IO（只受过原子训练的事实作第二跳）却到332k步才超过50%（[roadmap](roadmap.md#zhang2026)）。

**可检验的预测（[梯度池化比例实验](roadmap.md#zhang2026-next)）。** 由§13.3，两跳查询在r₁位置第一次迭代末的状态，就是原子查询(h, r₁)在同一位置的状态。Wang设定下的循环Transformer在这一位置解码桥实体的准确率为99.22–100%，即原子查表在第一次迭代内已完成。于是：
- 只受过原子训练的事实作第二跳（IO）时，所需的写入只能由副本1经跨迭代项到达副本2，一阶下与α成正比。
- 有两跳训练经历的事实作第二跳（II）时，两跳训练样本经副本2的同迭代项直接写入，不依赖α。
- 预测IO随α单调上升，II对α的依赖远小于IO。若II与IO随α同涨同落，或IO不随α变化，说明循环Transformer在IO上的优势不来自共享写入。IO对α是渐变，还是只在α=1时突变，两种结果都有信息：渐变支持一阶核的解释；突变说明表示格式的闭合需要副本完全相同。

**数值核查。** [核查脚本](../scripts/verify_write_use_kernel.py)第4项在2×2的ReproductionGPT上做如下核对：把第0块的MLP输出矩阵按两次执行拆成两份相同的副本，在原子查询c上用部分池化更新走一步交叉熵SGD，比较两跳查询u的logits实际变化与式(35)–(36)的一阶预测。在α=0/.25/.5/1四种取值下，步长η=10⁻³时一阶预测的变化约为4×10⁻³，残差约为9×10⁻⁶；η减半后残差缩小3.99–4.01倍，符合O(η²)。四种α下预测变化的最大值依次为4.03/3.92/3.82/3.61×10⁻³，所以相邻α的预测至少相差1×10⁻⁴，比残差大一个数量级以上；这说明该核查能区分不同的α。结果见[输出](development-artifacts/write-use-kernel-20261010/verify.json)。这是小模型上的代数与有限差分核查，不说明部分池化在实际训练中的效果。

**与循环Transformer开发实验的对应。** [循环Transformer开发矩阵](roadmap.md#architecture-efficiency)使用复制初始化的全块共享、仅MLP共享和解除参数共享三种模型，另用浅层模型区分额外计算的作用。微观诊断固定只使用来自训练集的原子事实与两跳查询小批次，记录各次执行的梯度、交叉内积和实际更新。诊断副本不参与训练，未见过的旧—旧、新—新组合的答案也不参与优化。训练梯度相容只能说明所测批次之间的更新关系，不能代替“未见组合能否答对、旧行为能否保持”的端到端证据。新增的[真实Transformer核验脚本](development-artifacts/loop-learning-development-v1/verify_loop_kernel.py)及其[结果](development-artifacts/loop-learning-development-v1/verify_loop_kernel.json)使用CPU/FP64、宽8、1个基础块重复执行2次。三种模型的初始前向误差为0；按真实的参数别名计入绑定embedding的全部路径后，式(24)–(25)的最大误差为2.22×10⁻¹⁵。普通SGD的步长减半时，式(26)的一阶余项缩小约4倍。这是小模型上的代数与有限差分核验，不证明AdamW下的学习效率。

### 14.6 MLP输出权重上的经验NTK分解：标准Transformer中原子写入何时传不到第二跳

**结论层级：分解是恒等式，有FP64数值核查；层范围条件在给定激活模式下精确；哪些单元是选择性的、它们在哪些执行中激活，是经验性质。** §14.4只说明参数共享会多出跨迭代项，没有说明在各层参数独立的标准Transformer中，对应的量为什么小。本小节要回答这个问题。做法分两步：先把MLP输出权重上的经验NTK精确分解成“后向Jacobian × 前向激活重合”；再用§13.3的相同因果前缀推出，标准Transformer中原子事实上的写入只能经由桥实体、到达答案位置之后的那些层，才能传给第二跳。

**分解（恒等式）。** 记号如下。\(\phi_{e,p}(x)\in\mathbb R^m\)是查询x在第e次执行、token位置p处MLP的GELU输出（隐藏层激活），\(m\)是MLP隐藏层宽度。第e次执行使用参数块\(\pi(e)\)；块j的MLP输出矩阵记为\(W_j\)，\(\pi^{-1}(j)\)是使用块j的全部执行。\(G_{e,p}(x)=\partial f_x/\partial H_{e+1,p}\)是logits对第e次执行之后、位置p处残差的Jacobian，包含其后全部的attention、LayerNorm、MLP与输出头；其他执行处的\(W_j\)视为固定。\(K_{W_j}(u,c)\)是只对\(W_j\)求梯度时的经验NTK。则

\[
K_{W_j}(u,c)=\sum_{e,e'\in\pi^{-1}(j)}\ \sum_{p,q}G_{e,p}(u)\,G_{e',q}(c)^\top\,
\bigl\langle\phi_{e,p}(u),\phi_{e',q}(c)\bigr\rangle .
\tag{31}
\]

**证明。** \(W_j\)在每次出现处以\(W_j\phi_{e,p}\)的形式加入残差。按出现位置求和（与式(23)同样的链式法则），得\(\partial f_x/\partial W_j=\sum_{e,p}G_{e,p}(x)^\top\otimes\phi_{e,p}(x)\)；又有\(\langle g\phi^\top,g'\phi'^\top\rangle_F=(g\cdot g')(\phi\cdot\phi')\)。若只取一部分隐藏单元的集合S，就把激活内积换成\(\sum_{k\in S}\phi_k\phi'_k\)。标准Transformer中\(\pi^{-1}(j)=\{j\}\)，只剩e=e'的项；循环Transformer还有e≠e'的项，它就是式(25)的跨迭代项在MLP输出权重上的具体形式。

**推论。** 这一推论要回答：哪些MLP隐藏单元能让训练情境c上的写入影响使用方式u？结论是：单元k对K(u, c)的贡献非零，只在以下情况发生——k在u的某次执行e中激活，在c的某次执行e'中也激活，并且π(e)=π(e')。标准Transformer要求e=e'。GELU的“不激活”不是精确的零，由此产生的误差与该单元在u上的最大|φ|成正比。由此得到：经验NTK在输出权重上的大小，取决于同一组参数上两种查询的激活是否重合；它本身不说明训练后哪些单元会激活。

**第二跳何时能读到原子写入。** 取训练情境c为原子查询(b, r₂)，使用方式u为两跳查询(h, r₁, r₂)，事实f=(b, r₂)。若一个隐藏单元只在答案位置的残差同时包含b的主体分量（按该单元的键格式）与r₂时才激活，称它为f选择性的。记\(D_f(c)\)为f选择性单元在c中激活的执行集合；记\(d_1\)为(h, r₁)的答案在其原子查询中形成于哪一次执行。由§13.3，u的桥实体token位置（r₁位置）与原子查询(h, r₁)的因果前缀相同，各次执行后的状态逐一相等；所以这个位置要到执行\(d_1\)之后才含有b，attention最早在下一次执行把b带到答案位置。因此，f选择性单元只可能在u的执行\(e\ge d_1+1\)中激活：

\[
K^f(u,c)=\sum_{e\ge d_1+1}\ \sum_{\substack{e'\in D_f(c)\\ \pi(e')=\pi(e)}}\ \sum_{p,q}
G_{e,p}(u)\,G_{e',q}(c)^\top\sum_{k\in F_{\pi(e)}}\phi_{e,p,k}(u)\,\phi_{e',q,k}(c)+O(\epsilon),
\tag{32}
\]

其中\(F_j\)是块j中的f选择性单元；O(ε)项来自f选择性单元在“不激活”的执行中GELU输出不为精确零（见上面的推论）。上式把组合的三个前提分开写出：

- **层范围。** 标准Transformer要求e'=e，即\(D_f(c)\)有一部分落在\(d_1+1\)之后。若所有原子事实都在同一段执行中完成查表（\(d_1\)与\(\max D_f\)相近），条件不成立，\(K^f_{\rm untied}(u,c)\approx0\)：原子事实上的写入传不到第二跳，ID事实作第二跳时，只能靠第二跳训练在更深的层另写一份。若第一跳的答案在embedding层就已确定（\(d_1\approx0\)，例如头实体只有一条出边），条件自动成立。
- **逐跳完成。** 循环Transformer中，块j在每个周期P（相邻两次执行同一块之间相隔的执行数；Loop L×T中P=L）出现一次。c在第一次迭代中激活的f选择性单元，在u的第二次迭代中仍属于同一组参数。只要第一跳在一个周期内完成并到达答案位置（\(d_1+1\le\min D_f+P\)），式(32)就有非零项。
- **表示格式。** 这些单元在u中是否真的激活，取决于桥实体所在位置的状态在其键方向上的分量是否超过阈值，即§13.6的假设(A2)。

c中较深的单元还可能以已经形成的答案t为键（称为答案单元）。它们只在u已经得出t时才激活，所以写入这些单元只能放大已有的答案，不能完成第二跳。对编辑而言，写入它们会改变所有以t为答案的查询。路径重合干预实验因此要求以答案相同的其他事实作保持对照。

**与已有结果的对应（事后解释，不是检验）。** Wang设定下的II/IO/OI/OO四类测试中，标准8层模型IO≤4.10%，Loop 4×2为83.83–95.63%：标准模型不满足层范围条件，循环Transformer通过逐跳完成满足条件。第一跳出度实验中，第一跳头实体出度为1时，标准模型IO从16.6升到99.9%：此时\(d_1\approx0\)，层范围条件成立。标准Transformer加表示对齐损失后余弦达.9997，分布外组合仍只有5.27%：表示对齐修的是表示格式，不能把\(D_f\)移到\(d_1\)之后；在参数共享块中逐跳完成已经成立，加表示对齐损失后分布外组合即达到92.3%。DiscoLoop的解码—再编码通道使表示格式条件精确成立。这些对应都是事后解释，不是检验。

**边界。** 式(31)是恒等式。式(32)在给定激活模式时精确；但哪些单元是f选择性的、\(D_f\)与\(d_1\)在哪里，是训练后模型的经验性质，须由路径重合干预实验与Zhang等附录E的窗口遮蔽实测。其中路径重合干预实验包括：对S_f（事实f在原子查询中的选择性必需成分）分别在第一次与第二次迭代中做消融，以及把标准模型分成上半部分层与下半部分层分别分析。本分解只覆盖MLP输出权重：输入权重的项含σ′因子，单元不激活时同样消失；attention与embedding参数的项不是f选择性的，作用于所有事实。叠加表示会带来与相干性成比例的串扰。结论只在一阶、局部成立，不说明训练会不会在更深的层形成副本。

**数值核查。** [核查脚本](../scripts/verify_write_use_kernel.py)（FP64，[输出](development-artifacts/write-use-kernel-20261010/verify.json)）在ReproductionGPT（宽16、gelu_new、绑定embedding，4层标准模型与2×2循环模型）上核对：式(31)与autograd计算的核相比，最大误差为3.6×10⁻¹⁵（核元素最大约6.5）；循环模型的同迭代部分与展开成独立副本后的核完全相同，跨迭代项最大为2.85。输出文件于2026-10-10在CPU环境（torch 2.14.1、transformers 4.57.6）重新生成。原因是同日早先的输出被一次缺少torch的运行覆盖；当时报告的最大误差为4.4×10⁻¹⁵，式(33)为4×10⁻¹⁴。

### 14.7 提问模板迁移：共享部分与有效模板数

**结论层级：固定核下已证明；数值核查。** 本小节要回答第一层（回答）的一个问题：同一事实只用某些提问模板训练时，能否用未训练过的模板提取？重复同一模板与使用多种模板，分别起什么作用？

把式(26)用于同一事实的不同提问模板。事实由训练模板集合\(C=\{c_1,\ldots,c_n\}\)写入，用一个未训练的模板u检验。只看正确答案方向上的标量核，设

\[
K(c_i,c_j)=A+S\,R_{ij}\ (R_{ii}=1),\qquad K(u,c_i)=A .
\]

A是各模板共同使用的参数或特征给出的核。例如：attention搬到答案位置的实体与关系表示、以它们为键的查表单元、实体embedding本身。实体embedding对各模板的作用，与共享块对各次执行的作用相同。S·R是模板特有的部分，S是其大小，R是训练模板之间特有部分的相关矩阵：互不相同的模板R=I，同一模板重复n次R=11ᵀ。

**命题（核回归）。** 这个命题回答：写入落在共用部分的比例与训练模板的组成，怎样决定换模板后的提取？线性化之后，把C拟合到同一个目标改变量y，u的改变为

\[
\Delta f_u=y\,\frac{A}{A+S/n_{\rm eff}},\qquad n_{\rm eff}=\mathbf 1^\top R^{+}\mathbf 1 .
\tag{33}
\]

\(n_{\rm eff}\)是有效模板数（\(R^+\)为R的伪逆）。

**证明。** 记\(K(C,C)\)为训练模板之间的核矩阵，则\(\Delta f_u=A\,\mathbf 1^\top K(C,C)^{+}\mathbf 1\,y\)。由Sherman–Morrison公式（R奇异时取伪逆）得\(\mathbf 1^\top(A\mathbf 1\mathbf 1^\top+SR)^{-1}\mathbf 1=n_{\rm eff}/(S+An_{\rm eff})\)。R=I时\(n_{\rm eff}=n\)，R=11ᵀ时\(n_{\rm eff}=1\)；一般地，\(n_{\rm eff}\ge n^2/\mathbf 1^\top R\mathbf 1\)（Cauchy–Schwarz不等式）。

**命题（交叉熵梯度下降，对称情形）。** 这个命题回答：把平方损失的核回归换成交叉熵梯度下降时，未训练模板上的变化与训练模板上的变化之比是否随训练时间改变？n个模板互不相同（R=I）且初始logits相同时，在线性化的交叉熵梯度流中，各模板的损失梯度每一时刻都相同。于是每一时刻τ都有

\[
\frac{\Delta f_u(\tau)}{\Delta f_{c_i}(\tau)}=\frac{nA}{nA+S};\qquad
\text{同一问法重复n次时恒为}\ \frac{A}{A+S}.
\tag{34}
\]

**证明。** \(\sum_jK(c_i,c_j)=nA+S\)，\(\sum_jK(u,c_j)=nA\)；两者乘以同一个梯度，比值不随时间变化。同一模板重复的情形，两者分别为n(A+S)与nA。

**由此得到什么。** 换模板能否提取，取决于两点：写入有多少落在各模板共用的部分（A相对于S）；训练中有多少个互不相关的模板（\(n_{\rm eff}\)）。重复同一个模板只加快写入，不提高这一比例。A=0时，即未训练模板读取事实的路径与训练模板不共用任何参数或特征，模板多样化也无用；这是路径一致性假说在第一层（回答）的形式。ROME/MEMIT是在MLP输出权重上、带键协方差度量的最小范数写入；单模板编辑就是n=1的情形，A、S按该度量计算。MQuAKE用cloze模板写入、用问句检验，对应换模板提取的问题；[S1正式读出](results.md#recovery-readouts-20261011)已完成，ROME/MEMIT条件覆盖22.44/16.23%，CoT缩小跳位差距的区间均跨0，尚未建立统一机制解释。bioS三种训练数据组织方式下，留出模板的提取率为0.57/14.06/32.90%，与“\(n_{\rm eff}\)增大则比例上升”的方向一致；本式不用于拟合或预测这些数字。

**不能推出什么（边界）。** 这是固定核近似：训练中A与S本身会变。“多样的表达使表示本身更与模板无关（A增大）”是特征学习问题，不在本式的范围内；Physics 3.1的探针结论，本项目没有复现。不同模板的答案位置上输出Jacobian不同时，A应理解为式(31)的加权重合。

**数值核查。** 同一脚本：在500个随机的(A, S, R)上，式(33)的最大误差为2.7×10⁻¹⁴。线性特征、A=0.4、S=1的交叉熵梯度下降400步中，n=1/2/4/8个不同模板的比值恒为0.286/0.444/0.615/0.762（=nA/(nA+S)）；同一模板重复1→8次时，比值恒为0.286，而训练模板上目标答案的概率由0.962升到0.996。

## 13. 预训练是否隐含中间表示监督：梯度推导与待验证解释

本节要回答：只用标准的下一token交叉熵训练，是否已经在监督中间位置的表示（例如两跳查询中r₁位置的桥实体表示）？这个问题决定了“能解码出桥实体”与“能把桥实体用于下一跳”之间的距离。

**结论先行：标准的下一token预测已经提供关于答案身份的梯度信号；输入与输出权重共享时，输出端的信号直接涉及输入embedding。但这既不保证某个早期状态与正确实体的embedding对齐，也不保证事实能被用于下一跳。** 以下是给定模型形式下的直接推导，不是新增实验，不是文献新颖性主张，也不是对自然预训练模型机制的确认。相关观测见[表示对齐覆盖与编辑传播](results.md#memory-interface-next)。

### 13.1 输出端：交叉熵包含正确token方向，但不是向量相等约束

**结论层级：已证明。** 本小节要回答：交叉熵对送入输出头的向量施加的到底是什么约束？

设前缀为x，正确的下一token为y；h是最终归一化之后送入线性输出头的向量；输出权重矩阵中token v对应的行是u_v（与使用方式u无关），p_v是模型给token v的概率。先固定当前参数，以无偏置的输出头为例：

\[
p_v=\frac{\exp(u_v^\top h)}{\sum_w\exp(u_w^\top h)},\qquad
L=-\log p_y,
\qquad
\frac{\partial L}{\partial h}=\sum_vp_vu_v-u_y.
\]

若输入与输出共享权重，则u_v=e_v，e_v是token v的输入embedding。负梯度包含两个分量：一个指向正确token的向量，一个远离按当前预测分布加权的平均向量。若暂时把h当作独立的优化变量，一步下降（步长η）为

\[
h^+=h+\eta\left(e_y-\sum_vp_ve_v\right).
\]

这是一种相对于其他候选的判别信号，**不能据此声称每次参数更新都会增大h与e_y的余弦相似度**。交叉熵依赖的是logit间隔：

\[
L=\log\left(1+\sum_{v\ne y}\exp\bigl(-(u_y-u_v)^\top h\bigr)\right).
\]

**由此得到什么、不能推出什么。** 低交叉熵只要求这些间隔足够大，一般并不要求h的方向等于e_y；h中与各输出权重之差所张成空间正交的分量，也不受这一输出约束的区分。是否存在非零的正交分量，取决于实际的秩。若输入与输出不共享权重，梯度直接涉及的是u_y，不能把它换成输入向量e_y。

训练真正优化的是共享参数θ，而不是自由变量h。固定输出头、只考虑单个样本和普通SGD时，令A=∂h/∂θ（h对参数的Jacobian），一阶近似为Δh=−ηAAᵀ(∂L/∂h)。多个样本、共享输出权重、Adam以及其他损失都会改变这一更新。因此上面的负梯度只是局部的监督方向，不是对完整训练轨迹的保证。

### 13.2 中间层：监督经过后续计算的Jacobian变换

**结论层级：已证明。** 本小节要回答：输出端的监督信号传到中间位置时变成什么样？

取一个早期位置的状态z，把其后的计算写成h=F(z;c)：这里的c只表示固定不变的其他边界状态与上下文（与经验NTK中的训练情境c无关），最终归一化也包含在F内；J_F是F对z的Jacobian。链式法则给出该输出损失对z的梯度：

\[
\frac{\partial L}{\partial z}
=J_F(z;c)^\top\left(\sum_vp_vu_v-u_y\right).
\]

**由此得到什么、不能推出什么。** 完整的序列损失还须对所有受该状态影响的预测位置求和。正确答案的信号确实可能传到z，但会被后续网络旋转、缩放、混合或消去；不能保证每个位置都收到非零信号。训练要求的是“z经过后续计算能得到正确输出”，而不是“z本身必须等于正确实体的输入向量”。答对不唯一确定内部编码；共享参数也不会自动把不同情境中的编码统一起来。

### 13.3 为什么原子事实训练可能监督两跳查询的早期状态

**结论层级：受控模板下精确。** 本小节要回答：分布外组合测试中，两跳查询从未被训练过，它的早期状态是否也从未被监督过？

在本项目的受控模板中，原子查询与对应的两跳查询在第一个关系token的位置（r₁位置）上，有相同的token前缀、相同的位置和相同的注意力可见范围。固定同一个模型，关闭dropout（或让两者使用同一个随机掩码），因果网络在这一位置的早期状态就完全相同；两跳查询后面的第二个关系和答案不能影响它。

**由此得到什么。** 原子文本中预测第一跳实体的损失，经由上述梯度塑造的状态，也正是对应两跳查询在这一位置使用的状态。**分布外组合被留出，不等于其早期状态从未受监督：相关的原子事实仍参加训练。**

**不能推出什么。** 这个结论依赖完全相同的因果前缀。自然语言中提问模板、tokenization、位置或上下文不同时，只能提出“可能迁移”的假说，不能套用状态相等的结论。

还应区分teacher forcing与模型内部的组合。标准预训练在后续位置读到的通常是真实的前缀token：文本中写出桥实体之后，下一句可以直接使用它的输入embedding。这提供了组合使用的机会，但不强迫模型在没有显式桥实体token时，先自己产生桥实体状态、再完成第二跳。多token实体还涉及逐token的条件化，上面的单token公式不能直接解释为完整实体向量的对齐。

### 13.4 与已执行的显式监督比较

**结论层级：实验记录。** 本小节把上面的推导与本项目已经做过的显式监督实验对应起来。

实际的[状态提取](../src/llm_memory_editability/representation_alignment.py)位置，是第一次执行Transformer块结束之后的r₁位置；这里取的是残差状态，不是MLP的单独输出。已有的[覆盖实验损失](../src/llm_memory_editability/alignment_coverage.py)为

\[
L_{\rm total}=L_{\rm text}+0.3L_{\rm bridge}+0.3L_{\rm align},
\qquad
L_{\rm align}=\operatorname{Reduce}_{\rm mask}
\left\|\frac{z}{\|z\|}-\frac{\operatorname{sg}(e_b)}{\|\operatorname{sg}(e_b)\|}\right\|^2.
\]

其中L_text是标准的下一token交叉熵，L_bridge是第一跳辅助损失，L_align是表示对齐损失；z是r₁位置的状态，b是训练数据给出的正确第一跳实体（桥实体），e_b是它的输入embedding，sg表示对这一参照分支停止梯度。非零向量下，单个样本的L_align项等于2−2cos(z,e_b)；实现中使用带数值保护的normalize。L_bridge经由共享的输出头与最终LayerNorm，直接监督这个早期状态解码出b；全模型参与训练，embedding仍可经其他路径更新。Reduce按预注册方案取全batch均值，或取选中样本的均值。

**表示对齐覆盖实验的四个条件都保留相同的、显式的第一跳辅助损失，只改变几何项（表示对齐损失）作用于哪些样本（mask）以及归一化方式。** 分布外组合的正确率为：10.25%（关闭几何项）；25.55%/23.80%（只作用于两跳样本，两种归一化）；92.12%（作用于原子事实与两跳样本）。这些数字不能描述为“纯预训练与中间监督”的比较，也不能解释为从完全无监督到有监督。此前另有一组三条件比较——标准交叉熵训练、加第一跳辅助损失、再加表示对齐损失——见[结果](results.md#representation-alignment)；不要混用两个实验的分母与处理。

### 13.5 猜想、现有支持与不能推出的结论

**结论层级：猜想。** 本小节列出由上面几小节引出、尚待检验的三个解释。

1. **表示选择猜想。** 原子事实上的交叉熵允许多种都能正确解码的内部编码；显式的表示对齐可能偏向后续计算更容易复用的那一类编码。表示对齐覆盖扩展与解码—再编码的收益与此相容，但也可能涉及优化难度、正则化以及多个模块的共同适应；目前尚未识别唯一的中介，更没有证明与embedding对齐是必要条件。§13.6给出不经训练的对应构造：解码—再编码把解码间隔直接换成e_b的表示格式。
2. **使用经历猜想。** 两跳训练文本与共享计算，可能间接促成类似的功能兼容，而不一定形成与输入embedding相同的几何。若没有显式对齐的模型能稳定完成跨关系的反事实复用，即使余弦不高，也应作为功能复用的证据保留，不能以几何上不相似来否定它。
3. **编辑不同步猜想。** 修改原子事实的输出，可能改变后层的解码，却没有同步更新两跳查询所用的早期状态或后续的解释方式。现有“原子事实编辑成功，但依赖它的多跳答案仍是旧答案”的结果与此相容，但还没有排除分布漂移、其他上下文路径和知识保持受损；仅凭交叉熵梯度不能定位失败发生在哪里。

这些解释需要的证据是：同一事实在原子查询与两跳查询中的行为和状态干预；并且要分别核对原子事实是否掌握、目标是否写入、旧知识是否保持，以及训练曝光次数。具体比较见[写入与复用状态](roadmap.md#write-interface)；内部特征不另作表现预测任务。

**结论层级小结。** 交叉熵梯度、Jacobian传递、相同因果前缀下的状态一致性，是带条件的数学结论；表示对齐覆盖实验的收益，是已有的受控观测；“表示对齐使事实编码更便于后续使用”仍是机制猜想。当前不能据此宣称自然预训练必然形成或完全缺乏这种接口，也不能外推出普遍的知识编辑能力。

### 13.6 离散交接：解码—再编码把解码间隔变成输入的表示格式

**结论层级：引理已证明；线性键值示例是玩具模型；关于输出函数与编辑传播的推论是条件命题。** §13.1说明，交叉熵只约束正确答案的logit间隔，不约束状态的方向。[DiscoLoop](roadmap.md#discoloop2026)在两次迭代之间，先用输出头解码，再用绑定的embedding编码；这等于把“可解码”直接换成“与原子查询相同的输入”。本小节要回答：这种离散交接为什么能让“能解码”变成“能使用”，它对组合与编辑传播又预测什么？下面的引理和线性键值示例是给定模型下的数学结论。关于输出函数与编辑传播的推论，另外需要写明的假设；训练后的模型是否满足这些假设，由[解码—再编码通道与自解码对齐比较、编辑传播实验](roadmap.md#zhang2026-next)检验。

**对象。** 对某个位置的状态h，令z=E N_f(h)/τ为该位置的logits（τ是温度，N_f是最终LayerNorm），p=softmax(z)，

\[
\Phi(h)=E^\top p=\sum_v p_v e_v .
\tag{27}
\]

E的各行e_v是绑定的输入／输出embedding；Φ(h)就是按解码概率加权的输入embedding之和。DiscoLoop原式没有N_f，本项目GPT-2的输出含最终LayerNorm，两者都可以写成此式。记b=argmax_v p_v（解码出的实体），ε=1−p_b（不在argmax上的概率质量），Δ_E=max_v‖e_v−e_b‖。

**引理（饱和时的偏差与敏感度）。** 这个引理回答：解码越确定（ε越小）时，Φ(h)离e_b有多近，对h的变化有多敏感？

\[
\|\Phi(h)-e_b\|\le\varepsilon\,\Delta_E,\qquad
\Bigl\|\frac{\partial\Phi}{\partial h}\Bigr\|_{\rm op}\le\frac{2\varepsilon}{\tau}\,\|E\|_{\rm op}^2\,\Bigl\|\frac{\partial N_f}{\partial h}\Bigr\|_{\rm op}.
\tag{28}
\]

若对所有v≠b都有z_b−z_v≥m（m为解码间隔，V为候选token数），则ε≤(V−1)e^{−m}。

**证明。** Φ−e_b=Σ_{v≠b}p_v(e_v−e_b)，且Σ_{v≠b}p_v=ε。∂p/∂z=C=diag(p)−ppᵀ半正定，‖C‖_op≤tr C=1−Σ_v p_v²≤1−p_b²≤2ε；又∂Φ/∂h=EᵀCE(∂N_f/∂h)/τ。最后，ε=Σ_{v≠b}p_v≤Σ_{v≠b}p_v/p_b=Σ_{v≠b}e^{z_v−z_b}。

**由此得到什么。** 解码间隔越大，通道输出Φ(h)越接近e_b，并且对h中交叉熵不约束的其余分量越不敏感。硬替换（DiscoLoop v2式(3)取α=1，即本项目的[解码—再编码](results.md#bridge-reencoding)）在argmax正确时，把该token位置精确设为e_b的归一化形式。DiscoLoop架构则是加法形式h+α·RMSNorm(Φ(h))：原状态仍然保留，只是叠加了一个近乎固定的e_b分量。

**能解码为什么不等于能使用：线性键值示例。** 这个示例回答：既然状态已经能解码出b，为什么下一跳仍可能答错？设第二跳的读取是以输入embedding为键的线性联想记忆：键是e_x，值与输出都用绑定embedding，y(x)是(x, r₂)存储的答案。桥实体所在token位置的状态为s时，答案w的logit为

\[
\ell_w(s)=\sum_x (e_x^\top s)\,G_{w,y(x)},\qquad G=EE^\top .
\tag{29}
\]

原子查询中这一位置的输入是e_b；设原子查询答对t=y(b)，间隔为m_w=ℓ_t(e_b)−ℓ_w(e_b)>0。把两跳查询中这一位置的状态写成s=e_b+n（n是偏离e_b的部分），则

\[
\ell_w(e_b+n)-\ell_w(e_b)=\sum_x (e_x^\top n)\,G_{w,y(x)} .
\tag{30}
\]

从s解码出b，只需要对每个v≠b有e_vᵀn−e_bᵀn<G_{bb}−G_{vb}；这是逐个候选的条件。第二跳答对则要求式(30)的差对全部x的加权和不推翻m_w。若各e_v两两正交且y是一一映射，两个条件等价。若实体数多于维度（叠加表示；Wang原图有2000实体、宽768），或多个x共享同一答案，许多各自很小的坐标可以累加成大的串扰；此时“能解码却不能使用”是一般情形。

硬替换把n换成零，两跳查询的串扰就回到原子查询本身的水平，而后者已经被原子训练压在间隔以内。加法形式不消除n，只是加大e_b分量的系数；系数乘以m_w超过式(30)在t与w之间造成的差时，即可答对。对(1−α)h+α·λe_b（λ为e_b的缩放系数），答对条件对α是线性的：每个查询都有一个阈值α*，由串扰与间隔之比（以及原状态中的e_b分量）决定；α扫描得到的正确率曲线，就是α*的累积分布。OOD曲线右移，对应OOD查询的串扰更大。标准的组合训练可以只为ID前缀压低串扰，这与OOD前缀上的表现滞后相容。

**由此得到什么、不能推出什么。** 这是线性键值模型中的例子，不是GPT上的定理；它说明解码条件与使用条件在形式上不同。

**输出函数的条件推论。** 这个推论回答：在什么假设下，两跳查询的输出与原子查询的输出是同一个函数，从而一次写入对二者的作用相同？设循环Transformer的共享参数为θ，原子使用方式c′=(b, r₂)。假设：
- (A1) 第二次迭代在答案位置的计算，只经由桥实体token位置与关系token位置的状态依赖输入，且关系token位置的状态与原子查询中关系的输入相同；
- (A2) 桥实体token位置为硬替换得到的e_b，或满足式(28)的O(ε)偏差。

则两跳查询的输出，作为θ的函数，与c′在第一次迭代末的输出（DiscoLoop称Stage-1）是同一个函数（位置编号的差另计）。软通道下，若第二次迭代对输入是Lipschitz的，误差为O(ε)。因此任何一次写入对二者的作用都相同，不限于一阶。写成核，即K(u, c)=K(c′₁, c)+O(ε)，c′₁表示c′在第一次迭代末的输出。这是路径一致性假说的一个构造性实例。另由式(28)，组合损失经Φ回传到第一次迭代参数的梯度只有O(ε)；第一次迭代主要经连续分量接受两跳训练，表示格式不需要靠两跳训练来协调。这是否解释了DiscoLoop中更早出现的相变，尚待解码—再编码通道与自解码对齐比较检验。

**不能推出什么。** (A1)一般不精确成立：桥实体所在token位置的位置编号、第一次迭代之后关系token位置的状态，以及其余位置，都与原子查询不同；影响有多大只能实测。

**编辑传播的离散性。** 这一段回答：在同样的假设下，第一跳编辑与第二跳编辑分别什么时候能传到两跳查询的答案？在(A1)和(A2)硬替换下，第一跳编辑(a, r₁)→b′对两跳答案的作用只经过该token位置上的argmax：argmax没有翻转时，这一位置的输入不变；翻转后跳到e_{b′}，第二跳按(b′, r₂)的原子查表读取。所以，第一跳编辑传播的必要条件是编辑翻转了第一次迭代的解码结果。第二跳编辑(b, r₂)→t′能否传播，等于编辑后c′在第一次迭代末的输出是否变为t′。DiscoLoop的加法通道保留原状态，只近似满足这些条件。它们是[编辑传播实验](roadmap.md#zhang2026-next)的预测，不是训练后模型的定理。

**多跳。** 硬替换下，第k跳所用token位置的输入只取决于前面各跳的argmax序列；只要每一跳的argmax都正确，误差就不会跨跳累积。这与§7中连续状态的有限步误差累积不同。加法通道介于两者之间。

**数值核查。** [核查脚本](../scripts/verify_discrete_handoff.py)（numpy FP64，种子20261009，[输出](development-artifacts/discrete-handoff-20261009/verify.json)）的结果如下。引理的三个不等式在300个随机情形（含与不含LayerNorm）中全部成立，左右两侧之比最大为0.71。在线性键值记忆中，加入与e_b正交的噪声（标准差0.05–0.15）后：e_v正交且y一一映射时，1200个可解码查询无一答错；e_v正交但答案随机时，有2个答错；实体256、维度64的叠加情形，每档278–299个可解码查询中有33–193个第二跳答错。200个查询的α扫描都至多切换一次正误。这些只核对代数与玩具模型，不是GPT训练的证据。

**不能推出的结论。** 引理不说明训练会让第一次迭代在这一token位置完成第一跳：本项目标准交叉熵训练的模型在该位置自解码桥实体为0%，注入真实桥实体也只到1.60%（[结果](results.md#bridge-reencoding)）。引理只处理输入的表示格式，不说明后一段参数中有没有第二跳的查表（层范围前提），因此不预测标准Transformer加解码—再编码通道会成功。通道只携带一个token，不覆盖多token实体。DiscoLoop的收益来自表示格式，还是来自优化路径的改变，须由解码—再编码通道与自解码对齐比较分开。

<a id="self-decode-alignment-20261012"></a>
**训练期的对应：DiscoLoop通道与自解码对齐损失怎样计算（2026-10-12）。**

**结论层级：式(37)(38)是两种方法的定义；式(39)(40)是对给定损失的直接求导，已证明；三条推论是条件命题，训练后的模型是否满足须实测。** 本段回答：[整合提案](roadmap.md#loop-solution-integration-20261012)中的自解码表示对齐损失，与DiscoLoop在计算上究竟有什么不同？以Loop 4×2为例，F_θ是4层共享块，

\[
H^{(0)}=E[x]+P,\qquad H^{(1)}=F_\theta(H^{(0)}),\qquad H^{(2)}=F_\theta(H^{(1)}),\qquad \ell_t=E\,N_f(H^{(2)}_t),
\]

E的各行e_v是绑定的输入／输出embedding，P是位置embedding，H^{(k)}_t是第k次执行后位置t的状态；原训练损失L_CE只计算有监督的位置（Wang设定中为“最后一个关系→答案”与“答案→`</a>`”）。下文的p_v(h)即式(27)中的softmax(E N_f(h)/τ)，Φ(h)即式(27)。

**DiscoLoop：不加损失，改变前向。** [v2式(4)–(6)](https://arxiv.org/html/2607.00341v2)在两次执行之间、对每个位置t计算

\[
\tilde H^{(1)}_t=H^{(1)}_t+\alpha_t\,\mathrm{RMSNorm}\bigl(\Phi(H^{(1)}_t)\bigr),\qquad H^{(2)}=F_\theta(\tilde H^{(1)}).
\tag{37}
\]

符号任务固定α_t=1、τ=1；合成语言任务用可学习门α_t=σ(⟨w_α, Φ_t⟩+b_α)；最后一次执行之后不加。原文式中没有N_f，移植到本项目GPT-2时加入。训练损失只有L_CE，原文没有描述辅助损失；原文称整个架构可微，因此L_CE的梯度既经过H^{(1)}_t，也经过Φ中的softmax，后者由式(28)以O(ε)为界。通道在推理时保留，每个非末次执行、每个位置多一次全词表softmax（语言模型版本用top-128近似）。原文式(3)是另一回事：只在桥实体位置、两次执行之间做硬argmax替换的诊断干预，即本项目的[解码—再编码](results.md#bridge-reencoding)。

**自解码对齐：不改前向，增加损失。** 前向与原模型相同，推理时没有任何改动。训练时在H^{(1)}上额外解码一次，令τ=1，

\[
L=L_{\rm CE}+\frac{\lambda}{N}\sum_t m_t\,w_t\Bigl\|\hat h_t-\operatorname{sg}(\hat e_{\hat v_t})\Bigr\|^2
=L_{\rm CE}+\frac{\lambda}{N}\sum_t m_t\,w_t\bigl(2-2\cos(H^{(1)}_t,e_{\hat v_t})\bigr),
\tag{38}
\]

其中\(\hat v_t=\arg\max_vp_v(H^{(1)}_t)\)，\(w_t=\max_vp_v(H^{(1)}_t)\)，二者与目标都停止梯度；\(\hat h_t=H^{(1)}_t/\|H^{(1)}_t\|\)，\(\hat e_v=e_v/\|e_v\|\)；m_t标记非padding位置，\(N=\sum_tm_t\)；λ=.3只是开发起点。第二个等号来自单位向量满足‖a−b‖²=2−2aᵀb。这一项对所有有效位置求和，包括没有L_CE监督的位置。

**对齐项的梯度（已证明）。** 由\(\partial\cos/\partial h=(I-\hat h\hat h^\top)\hat e/\|h\|\)，

\[
\frac{\partial L_{\rm align}}{\partial H^{(1)}_t}
=-\frac{2\lambda\,m_tw_t}{N\,\|H^{(1)}_t\|}\bigl(I-\hat h_t\hat h_t^\top\bigr)\hat e_{\hat v_t}.
\tag{39}
\]

梯度与H^{(1)}_t正交，一阶下只转方向、不改长度；除\(\hat h_t=-\hat e_{\hat v_t}\)这一不稳定点外，只有\(\hat h_t=\hat e_{\hat v_t}\)时为零。因此状态中只要还有e_{v̂}以外的成分，就持续受罚。梯度经第一次执行传给共享参数θ，并经H^{(0)}传给E；目标、权重与解码分布不接受梯度。

**对照：自预测交叉熵。** 整合提案中的对照项为\(\frac{\lambda}{N}\sum_tm_tw_t(-\log p_{\hat v_t}(H^{(1)}_t))\)，v̂与w停止梯度、p保留梯度。由§13.1，

\[
\frac{\partial\bigl(-\log p_{\hat v_t}\bigr)}{\partial N_f(H^{(1)}_t)}=\sum_vp_ve_v-e_{\hat v_t},
\tag{40}
\]

p_{v̂}→1时趋于零，只要求logit间隔足够大，不要求余弦趋于1。两臂的差别正是是否惩罚e_{v̂}以外的成分。

**由此得到什么（条件推论）。**
1. **保留与消去。** 若式(38)在位置t达到余弦1且解码确定，则H^{(1)}_t已与Φ(H^{(1)}_t)≈e_{v̂}同向，在RMSNorm各维增益相同时，式(37)的通道在该位置近似只改长度、不改方向；这一损失的作用是让网络自己产生通道原本现场提供的e_{v̂}方向。差别在于：式(37)保留原状态中的其余成分n，以加大e_b分量压过式(30)的串扰；式(38)的不动点要求n=0，即§13.6硬替换的条件，代价是消去该位置的全部其他信息。
2. **对后来写入的事实是否仍成立。** 式(37)在推理时作用于任何新解码出的token：后来的编辑若翻转第一次执行的解码，下一次执行即读到新实体的embedding（加法形式下近似满足上文编辑传播的离散性）。式(38)只约束训练中出现过的状态；后来写入而未同时使用这一项的事实，可能重新处于“可解码、未对齐”的状态。v̂是模型当前的答案，更新过程中第一次执行的解码尚未翻转时，这一项把状态拉回旧答案。
3. **解码出的token是什么。** 两者都用下一token输出头解码。只有当到达该位置的因果前缀恰好是一条原子查询（§13.3）时，解码结果才是桥实体；自然语言的两跳问句中，桥实体一般不是任何位置的下一个token，多token实体也不能由单个e_v表示。这一限制对两者相同。

**不能推出什么。** 以上不说明式(38)在训练中能达到余弦1，也不说明对齐后组合一定改善；前提仍是第一次执行已在该位置完成第一跳，且第二跳查表位于共享参数中。训练成本上，式(38)每个非末次执行多一次不求梯度的全词表读出，只在训练期发生；式(37)的读出带梯度，训练与推理都要计算。

## 11. 用功能一致性连接回答、组合和更新

**结论层级：式(12)已证明；其余为定义与待检验的解释。** 本节要回答：如何在不依赖内部向量几何的前提下，定义“一个事实被正确复用”，并把两跳查询的错误分解成可以分别测量的部分？本节区分单跳回答、组合一致性与更新后的保持。§3–8的容量计数、零空间、谱学习和误差界仍是条件数学，不能把它们当作一般GPT中已被识别出的学习机制。相关实测见[解码—再编码与编辑传播](results.md#memory-interface-next)，研究设计见[知识变化后的使用](roadmap.md#updating)。

**知识真值已经确定，计算方式仍可能欠约束。** 在确定性的知识图中，若训练已经给出所有必要的单跳事实，那么两跳查询的真值由图唯一决定；数学上不需要额外信息就能算出答案。但能拟合单跳事实和有限两跳训练集的函数，不止“正确地逐步查询”这一种。通用函数也可以在受训查询上记表、在留出查询上任意延拓。因此这里须区分两件事：“知识图的可辨识性”，与“学习者在给定函数类中怎样实现或延拓计算”。上一轮的角色支持图的秩，并不直接测量后者；连通匹配实验在全部测试题上没有稳定收益，这也不违反图论恒等式。

**一个可直接检验的充分条件。** 这里要回答：直接回答两跳查询出错，可以拆成哪几类可以分别测量的原因？用 $A_\theta(s,r)$ 表示模型对单跳查询生成的答案，用 $C_\theta(s,r_1,r_2)$ 表示模型直接回答两跳查询的答案。实体、答案格式与解析规则固定；非法生成记为失败符号，不借助真值修复。定义模型的分步回答（先问第一跳，再把模型自己的答案代入问第二跳）：

\[
S_\theta(s,r_1,r_2)=A_\theta(A_\theta(s,r_1),r_2).
\]

令知识图中的真值为 $b=f_{r_1}(s)$、$y=f_{r_2}(b)$（$f_r(s)$表示知识图中s经关系r得到的尾实体）。事件 $E_1$、$E_2$ 分别是单跳答错 $A_\theta(s,r_1)\ne b$ 与 $A_\theta(b,r_2)\ne y$；$Q$ 是直接回答与分步回答不一致。逐个样本有

\[
\mathbf 1[C_\theta\ne y]\leq\mathbf 1[Q]+\mathbf 1[E_1]+\mathbf 1[E_2],\qquad
\Pr(C_\theta\ne y)\leq\Pr(Q)+\Pr(E_1)+\Pr(E_2).
\tag{12}
\]

证明：若三个事件都不发生，则 $S_\theta=y$ 且 $C_\theta=S_\theta$。证明不需要错误相互独立。

**由此得到什么、不能推出什么。** 在所需原子事实都答对的固定子集上，直接回答的错误恰好等于直接回答与分步回答的不一致；这时“不一致率”只是已有错误率的重述，不能包装成新的预测指标或独立的机制证据。不同模板、别名与多token答案的格式，要先统一判定规则。解码—再编码批次中18个起点模型的分步回答都正确；本轮逐数组验证了这一恒等关系。

把知识图和权重换成编辑后的 $f',\theta'$，同一论证仍然成立。因此，新写入的原子事实与后续事实都正确，再加上编辑后 $C_{\theta'}=S_{\theta'}$，就足以保证依赖被编辑事实的多跳答案随之更新。编辑前 $C_\theta=S_\theta$ 并不能推出编辑后仍然一致。即使所有端到端答案都一致，也不证明模型内部真的执行了两次同一个子程序；这需要跨后继关系的反事实干预，而且结论仍只对所测范围成立。

**可复用的表示按后续行为定义，不按向量相等定义。** 固定执行边界、其他上下文和允许的后继操作集合 $\mathcal R$，设 $H_r(z)$ 为从状态z继续计算后继操作r的输出。若对所有 $r\in\mathcal R$ 都有 $H_r(z)=H_r(z')$，则称两个状态对这些后继操作功能等价。若要讨论更长的链，须把允许的后继序列也纳入定义，不能由两跳等价推出任意跳数下等价。完整的状态应包含相关的token位置；只交换单个位置时，须另外固定其余上下文。

在抽象的函数组合中，对任意可逆坐标变换 $Q$（此处的Q与上文的事件Q无关），把状态相应改为 $Qz$、后继函数改为 $H_r\circ Q^{-1}$，所有答案都不变。因此，与输入embedding接近并不是功能复用的普遍必要条件。这里并不声称任意 $Q$ 都能在保留LayerNorm与逐元素激活的原GPT参数化中实现。共同参数也不充分：同一个函数 $M(z,t)$ 可以依据上下文或执行阶段 $t$ 采用不同的查表规则。

**静态组合与继续学习是两个量词范围。** 已有的表示对齐实验和长时间训练的OO实验，测的都是同一训练阶段内已知的原子事实集合；不能自动推出“规则成熟以后才加入的新事实”仍然可以组合。顺序知识注入检验迁移，改写旧事实检验旧答案的竞争。全参数续训同时改变知识与使用这些知识的参数，不能称为冻结了调用方式。具体比较统一见[顺序迁移设计](roadmap.md#sequential-transfer)。

**待检验的解释。** 单跳正确约束了回答，却没有强制模型在不同的使用情境和不同的知识版本中复用同一个映射。两跳训练、共享计算、长期优化与表示监督，可能通过不同途径促成功能兼容；它们能否互相替代、是否得到同一种可迁移的实现，仍是经验问题。固定知识图内的查表与可迁移计算在复杂度上的差异可以启发假说，但训练偏好、收敛时间或相变不能由复杂度计数直接推出。

| 经典概念 | 在本文中的确切对象 | 对应问题与范围 |
| --- | --- | --- |
| **Associative memory / Hebbian memory，联想记忆／赫布式记忆** | 键到值的映射，核记忆中的信号项与串扰项 | 参数和宽度如何支持存储。MLP的代数表示不证明SGD遵循Hebbian学习规则。 |
| **Identifiability / system identification，可辨识性／系统辨识** | 哪些调用算子在训练数据上能被区分 | 事实已答对时，训练是否足以确定可复用的调用方式。本文的严格命题只限于固定特征或校准模型。 |
| **Spectral bias / conditioning，谱偏置／谱条件** | 训练Gram矩阵的正特征值及零空间 | 已被约束的方向学得多快；未被约束的方向是否仍有自由度。 |
| **Robustness margin / finite-horizon error propagation，鲁棒间隔／有限步误差传播** | 正确答案的logit差，以及有限次状态更新的误差界 | 更多次循环提供更多执行步骤，也改变误差的累积。需要定义理想计算与实际状态。 |
| **Gauge freedom / graph Laplacian，规范自由度／图拉普拉斯** | 接口校准图中每个连通分量的共同平移，以及关联矩阵的零空间 | 给可辨识性一个可以完整证明的数据组织实例；不是一般GPT中已确定的内部表示。 |

**Persistent excitation（持续激励）**可以作为系统辨识的背景概念。经典的动态定义要求输入Hankel矩阵达到相应阶数的满行秩；静态回归中的对应条件，是训练Gram矩阵在待辨识方向上正定。不能把“每条事实至少出现一次”直接称为持续激励，更不能把本文的训练图当作已验证的Willems基本引理条件。参见[Willems等，2005](https://doi.org/10.1016/j.sysconle.2004.09.003)与[作者提供的后续严格分析，§2–3](https://imarkovs.github.io/publications/fl-rev.pdf)。

以下概念各自需要操作定义和证据：

- **Hopfield / attractor / fixed point**需要相应的更新规则、能量或收敛条件。我们的残差GPT循环（循环Transformer）没有这些已证明的前提；[现代Hopfield论文](https://arxiv.org/abs/2008.02217)中attention与Hopfield更新的对应关系，不能自动推广到整个GPT块。
- **Observability / controllability**在控制论中有明确的状态、输入和输出定义。多个时刻的输出组成的观测矩阵满秩，不保证只读取最后状态的循环Transformer答对。
- **Grokking / phase transition**需要依据学习轨迹，分别确认延迟泛化与相变；这些名称不能代替对存储与调用机制的说明。
- **Superposition**能解释低维表示与串扰，是容量方面的背景；还不足以解释组合接口怎样被训练出来。

## 2. 《MLPs are Hebbians》确切证明了什么

本节当时回答：一篇关于MLP事实存储的论文究竟证明了什么、条件是什么。它是容量路线的文献核对，不涉及组合与更新，因此不进入论文。

本节依据[Garcia等《MLPs are Hebbians: Constructing Efficient Fact-Storing MLPs for Transformers》，2026-07-10 v1](https://arxiv.org/abs/2607.10034)，核对范围为§3–5、附录B.2.1及B.8.4。

令MLP为 \(M(x)=B\phi(x)\)（\(\phi\)为隐藏层特征，\(B\)为输出矩阵），取 \(y_i=M(x_i)\)，其中 \(x_i\)是第i个存储的键，共F个；定义如下的特征协方差。带输出偏置时，可把常数特征1并入 \(\phi\)。

\[
\widehat\Sigma=\frac1F\sum_i\phi(x_i)\phi(x_i)^\top.
\]

当它可逆时，白化核 \(K(x,z)=\phi(x)^\top\widehat\Sigma^{-1}\phi(z)\)满足

\[
\frac1F\sum_i y_i K(x_i,z)=B\widehat\Sigma\widehat\Sigma^{-1}\phi(z)=M(z).
\]

这是MLP输出的精确代数重写；这里的 \(y_i\)是MLP自己的输出，不一定是事实的真值。该论文另外构造了双线性随机特征MLP，推导记忆解码间隔随容量的缩放。这是两个不同的命题；白化恒等式本身不给出最优容量。

该论文各向同性构造的简化界为

\[
\gamma_{\rm mem}\ge 1-C\sqrt{\frac{F\log(F/\zeta)}{md}},
\tag{1}
\]

其中 \(\gamma_{\rm mem}\)是记忆解码间隔，\(m\)是MLP隐藏特征宽度，\(d\)是键／值维度，\(\zeta\)是失败概率，C是常数。正式的Corollary B.31依赖以下条件：独立均匀的球面键和值、指定的双线性随机特征、\(F\ge2\Lambda\)、\(m\ge\Lambda^3\)、\(m\le d^2/\Lambda\)、\(m,d\le F\)，其中\(\Lambda=\log(C_0F^2/\zeta)\)。常数与额外的几何项不能省略后直接套用到小模型上。它不是适用于任意GELU MLP、任意学习到的表示或端到端Adam训练的通用定律。

## 3. 两个基础边界：计算不会凭空增加事实bits，答对不保证能接着调用

本节当时回答：增加执行次数能否增加可存储的事实量？单跳答对能否保证下一次调用答对？其中第一条结论是论文保留的唯一一句（见第二部分开头）；推导本身不进入论文。

**有限精度计数。** 固定输入、解码规则、运行过程以及权重以外的全部信息；设 \(P\)个参数各有至多 \(2^b\)种取值（b为每个参数的比特数），则模型最多能编码 \(2^{bP}\)种知识图（事实取值的不同组合）。若需要表示集合 \(\Omega\)中的所有知识图，必要条件是

\[
bP\ge\log_2|\Omega|.
\tag{2}
\]

例如 \(F\)个独立任意的事实各有 \(V\)个可能答案，则 \(|\Omega|=V^F\)，故 \(bP\ge F\log_2V\)。权重固定时多运行几次，不会增加权重的状态数，但可以执行更复杂的读取程序。所有可学习的Embedding也计入 \(P\)。若事实受排列约束或由生成规则压缩，须改用合法知识图的数目，不能套用独立事实的bits计算。外部记忆、含答案的输入，或随事实变化的执行计划，都会改变这一前提。该计数与[事实召回的联想记忆理论，§6](https://arxiv.org/html/2412.06538)一致。

**分类正确与接口兼容不同。** 设理想状态为 \(z^*=(1,0)\)，实际状态为 \(z=(1,3)\)。单跳的解码间隔为 \(g_{\rm atom}(z)=2z_1\)，两个状态都正确，间隔都是2。若后续调用的最终间隔为 \(g_{\rm next}(z)=1-z_2\)，则理想状态正确，实际状态错误。因此单跳正确率不能约束全部状态误差。这个反例不预设GPT中存在这两个坐标，只证明：由单跳正确推不出下一次调用正确。

## 4. 从Hebbian表示到可辨识性：奇异情形需要保留余项

本节当时回答：特征协方差奇异时，§2的白化恒等式应怎样修正，它与可辨识性有什么关系。它属于可辨识性路线，不进入论文。

设 \(S=\operatorname{span}\{\phi(x_i)\}\)为观测特征张成的空间，\(P_S=\widehat\Sigma\widehat\Sigma^+\)为到它的正交投影，\(+\)表示Moore–Penrose伪逆。即使协方差奇异，也有恒等式

\[
M(z)=\underbrace{\frac1F\sum_i y_i\,
\phi(x_i)^\top\widehat\Sigma^+\phi(z)}_{B P_S\phi(z)}
+\underbrace{B(I-P_S)\phi(z)}_{\text{观测特征跨度以外的作用}}.
\tag{3}
\]

证明只需把 \(y_i=B\phi(x_i)\)代入，并利用投影恒等式。在观测特征张成的空间内，余项为零；要在所有查询上都恒等于纯伪逆核记忆，还需另外满足余项处处为零。直接把逆换成伪逆却删去余项，会得到错误的普遍等价。

固定 \(\phi\)时，若 \(w\perp S\)，则 \(B\)与 \(B+uw^\top\)在全部观测样本上的输出相同，但在 \(w^\top\phi(z)\ne0\)的查询上可以不同（这里u、w只是任意向量）。这是经典的零空间／可辨识性问题。它不声称当前GPT的事实特征协方差实际上是奇异的；协方差满秩也不保证某个内部查询已经接近正确的事实键。下文的调用Gram矩阵与这里的事实协方差是不同的对象。

## 5. 训练支持与时长：一个可精确求解的调用学习模型

本节当时回答：在固定特征的线性模型里，训练数据覆盖的方向与训练时长分别怎样决定调用误差。它是谱学习路线的结果，不能区分路径一致性假说与竞争解释，因此不进入论文。

限制条件写明如下：固定训练状态特征 \(X=[x_1,\ldots,x_n]\in\mathbb R^{p\times n}\)，给出理想线性接口 \(A_*\)下的状态监督 \(Y=A_*X\)，用平方损失

\[
\mathcal L(A)=\frac1{2n}\|AX-Y\|_F^2,
\quad G=\frac1nXX^\top
\]

做梯度流（\(G\)为特征的Gram矩阵）。令 \(E_\tau=A_\tau-A_*\)为时刻\(\tau\)的算子误差，则

\[
\dot E_\tau=-E_\tau G,
\qquad E_\tau=E_0 e^{-\tau G}.
\tag{4}
\]

取 \(S=\operatorname{range}(G)\)，\(P_S\)为到S的正交投影。当G非零时，令 \(\lambda_+\)为其最小正特征值，\(B_0=\|E_0\|_{\rm op}\)为初始误差的算子范数。G为零时，所有方向都保持初值；其余情形由谱分解，对任意查询特征 \(x\)，

\[
\|E_\tau x\|\le B_0\left[
\|(I-P_S)x\|+e^{-\lambda_+\tau}\|P_Sx\|
\right].
\tag{5}
\]

**两项含义不同。** 零空间方向上的算子误差保持初值；非零特征值方向上的误差指数衰减。要在全空间唯一辨识，需要 \(G\succ0\)；但只要测试查询都落在已辨识的子空间内，就不必要求整个特征空间满秩。较小的正特征值提供一种“延迟改善”的机制，但不能据此证明本项目出现了grokking。

全部样本按相同比例重复时，归一化的 \(G\)及其张成空间不变；改变采样权重可以改变正谱，但不扩张张成空间。加入新的特征方向可以扩张张成空间。增加样本后，未归一化的 \(XX^\top\)按PSD序增加，归一化 \(G\)的最小正特征值却不一定单调；增加宽度也可能改变特征与未被约束的方向。

这里的 \(n\)是受到状态监督的特征列数，不能直接等同于不重复的训练链条数。真实GPT对所有文本位置使用交叉熵、使用Adam，特征也在变化；它没有上述理想的内部状态监督，128k个优化步也不等于 \(\tau\)。式(4)是固定特征模型的经典解，与[NTK论文§5](https://arxiv.org/html/1806.07572)的谱学习分析衔接；本文不训练内部表现的预测器。

## 6. 用经典图论把“覆盖不等于可辨识”写成一个完整例子

本节当时回答：训练数据“覆盖”了所有使用角色，是否就足以确定未见组合的行为？它给出的是加性校准模型中的图论例子，没有与GPT监督建立对应，因此不进入论文。

考虑一个**独立的加性接口校准模型**。第一跳／第二跳的使用角色分别是左、右两侧的节点 \(u,v\)；每个节点有一个未知的校准值 \(\theta_u\)。每条训练链给出一个相对校准观测

\[
y_{uv}=\theta_u-\theta_v,
\qquad y=D\theta,
\]

其中 \(D\)是训练图的有向关联矩阵。若图有 \(q\)个节点、\(c\)个连通分量（\(C_1,\ldots,C_c\)），则

\[
\operatorname{rank}(D)=q-c,\quad
\ker D=\operatorname{span}\{\mathbf1_{C_1},\ldots,\mathbf1_{C_c}\}.
\tag{6}
\]

证明：\(D\theta=0\)等价于每条边两端的值相同，所以 \(\theta\)在每个连通分量上为常数。于是各分量的共同平移不改变任何观测，留下**gauge freedom（规范自由度）**。一对新角色的差值能从这些观测唯一确定，当且仅当两端在同一个分量中；不同分量可以各自独立平移。若另有绝对校准的锚点，辨识条件会改变。

**支持图上的距离与事实推理的跳数，要分别定义。** 上述节点是使用角色，边是训练链中的搭配记录；它不是模型查询时要遍历的实体知识图。[执行后的CPU核查](development-artifacts/latent-support-depth-review-v1/hop-audit.json)确认：本批全部实体边都是头实体→桥实体或桥实体→尾实体，最长有向路径为2，全部两跳训练与测试都用两条事实。支持图的分量内直径为6–8，部分测试角色的最短支持路径为7，但这些查询仍然是两跳。训练过程怎样整合多条样本的约束，与一次前向计算中调用多少次事实，是不同的问题；没有证明支持路径长度等于所需的Transformer层数、循环次数或优化步数。

**与GPT监督的对应仍然缺失。** 加性模型的每条边观察的是校准差值；一般GPT的两跳标签是最终的尾实体，另外还有完整的原子事实监督。两者之间的等价映射还没有构造出来，也没有验证一般GPT遵循局部的图消息传递；原子事实监督还可能提供校准模型中没有的额外信息。因此，不能由式(6)推出一般GPT中“断开不可学、连通就充分”或浅层架构的最大推理跳数。这个图例用于说明覆盖与可辨识性在一般情况下不同；若要把它当作当前模型的主要学习瓶颈，需要新的依据。

用平方损失训练校准值时，误差 \(e\)满足

\[
\dot e=-\frac1{|E|}D^\top De.
\tag{7}
\]

其中 \(|E|\)是训练边数。\(D^\top D\)正是**graph Laplacian（图拉普拉斯）**。连通性决定额外的零空间，正谱决定非零方向上的收敛；连通图的第二小特征值就是经典的**algebraic connectivity（代数连通度）**，见[Fiedler，1973](https://doi.org/10.21136/CMJ.1973.101168)。

一个八节点的例子已经数值核验：两张二部图都有八条边，每个角色的度数都是2；第一张是两个分离的四环，第二张是一个八环。两者的样本数、角色覆盖与逐角色使用次数全部相同，关联矩阵的秩却分别为6和7。第一张图可以在训练残差为零的同时，改变跨分量的未见相对校准值。**这说明只匹配样本量与使用次数，仍可能没有匹配可辨识性。**

此例的标签是相对校准值，而真实的两跳答案不一定有这种分解；所以不能把式(6)直接当作GPT准确率的上界。完整的知识图还天然按桥实体分组，不能要求所有桥实体之间全局连通。我们审计的是：是否额外拆开了完整可用训练集的连通分量。这里的论证借鉴了[Scaling can lead to compositional generalization，§3.4、附录A.1](https://arxiv.org/html/2507.07207)中的connected support论证，借鉴关系明确；但该论文的任务支持图与我们的角色图也不相同。

## 7. 循环计算：有限步的间隔保持条件

本节当时回答：多次执行同一个块时，误差怎样累积，什么条件下最终答案的间隔仍为正。它属于架构效率路线的误差界，不能区分路径一致性假说与竞争解释，因此不进入论文。

令 \(z_r^*=T_*(z_{r-1}^*)\)为给定问题的理想状态过程，\(z_r=T_\tau(z_{r-1})\)为实际过程（\(T_*\)、\(T_\tau\)分别是理想与实际的单次执行映射，r为执行次序）。状态应包含全部相关的token位置；不预设一次迭代对应一跳。假设在两条轨迹及比较所需的区域上，\(T_*\)是 \(L\)-Lipschitz的，且实际状态处的实现误差不超过 \(\epsilon\)。记 \(e_r\)为第r步的状态误差，由三角不等式得

\[
e_R\le L^Re_0+\epsilon A_R(L),\qquad
A_R(L)=\sum_{j=0}^{R-1}L^j.
\tag{8}
\]

当 \(L<1\)时，这个误差界的累积因子有界；\(L=1\)时为 \(R\)；\(L>1\)时可能指数增长。更精确的分阶段形式可以用每一步的 \(L_j,\epsilon_j\)展开；这里只是为了清楚展示各个因素，采用了共同的上界。受控Transformer程序的误差累积也在[Looped Transformers as Programmable Computers，附录B](https://arxiv.org/html/2301.13196)中直接讨论过。

若正确答案相对于每个竞争答案的最终logit差 \(g_j\)都是 \(\ell\)-Lipschitz的，且理想终点的最小间隔为 \(\gamma_R^*\)，则实际的最小间隔 \(\Gamma_R\)满足

\[
\Gamma_R\ge\gamma_R^*-\ell\,[L^Re_0+\epsilon A_R(L)].
\tag{9}
\]

右侧为正是正确解码的**充分条件**；右侧为负并不代表必然失败。若执行次数 \(R\)尚不足以完成给定的理想程序，就不能假设理想间隔为正。一个GPT块可以执行多种操作，也可能走捷径，所以不能从逻辑跳数 \(h\)推出 \(R\ge h\)是普遍的必要条件。多token的自由生成需要每个token及EOS都满足相应的正确排序，单次分类的间隔不能代替完整生成。

循环次数增加，间隔并不普遍单调变化：同一个二维旋转算子 \(T(z)=Q_{0.6}z\)（Q的下标是旋转角），初值 \((1,0)\)，最终间隔 \(2z_1\)；执行两次时间隔为 \(2\cos(1.2)>0\)，执行三次时为 \(2\cos(1.8)<0\)，而算子范数始终为1。这是一个存在性反例，不证明我们的GPT采用了旋转机制。

## 8. 连接存储、调用学习与计算的条件定理

本节当时回答：能否把前几节的存储间隔、调用学习与循环误差合成一个下界。它是标准结果的整合，主要说明各因素“不自动替代”，不能区分路径一致性假说与竞争解释，因此不进入论文。

在式(4)的固定特征接口学习条件之外，进一步假设：

1. 实际状态更新的误差可以写成 \(E_\tau\psi(z)+r(z)\)，且 \(\|r(z)\|\le\eta\)。这里 \(\psi\)是接口所用的特征，\(\eta\)涵盖其他实现误差（与学习率无关），不能由单跳正确率推出它很小。
2. 所有被访问状态的特征满足 \(\|P_S\psi(z)\|\le M\)、\(\|(I-P_S)\psi(z)\|\le\delta\)。这些常数以及上一节的 \(L,\ell\)，都在明确的坐标和范数下定义。
3. 理想程序在预定的执行次数R时到达最终事实记忆的正确标准键；终端输出使用该记忆，所以其理想间隔可以用 \(\gamma_{\rm mem}\)作下界。这一前提不能从“模型训练了R次执行”自动得到。

把式(5)代入式(9)，得到

\[
\boxed{\quad
\Gamma_R\ge\gamma_{\rm mem}
-\ell\left\{L^Re_0+A_R(L)\left[
\eta+B_0\left(\delta+M e^{-\lambda_+\tau}\right)
\right]\right\}.
\quad}
\tag{10}
\]

证明是两次代入；这个条件定理是标准谱学习与鲁棒误差界的整合。它区分了四种作用：参数量／宽度影响存储间隔与表示几何；训练支持影响张成空间与谱；训练时长削减非零谱方向上的误差；循环改变理想程序的完成程度与误差的累积。增加参数不会自动补齐训练约束；在固定特征模型中，延长训练不会消除零空间的自由度；增加循环次数不会增加权重能编码的任意事实bits。

若还满足式(1)的全部构造条件，把式(10)中的误差扣减记为 \(\kappa_R\)，且 \(\kappa_R<1\)，则一个充分的存储预算为

\[
md>\frac{C^2F\log(F/\zeta)}{(1-\kappa_R)^2}.
\tag{11}
\]

它说明：在这个受控模型中，调用误差会提高“保证正确解码”所需的存储预算。\(\kappa_R\)本身也可能随宽度和参数变化，不能把它当作独立常数去拟合真实GPT；\(md\)也不是包含Embedding、attention等参数的总参数量 \(P\)。式(11)不证明当前实验存在经验幂律或架构容量极限。

## 9. 理论与已有实验的对应边界

本节当时回答：前几节的理论与“连通支持”实验之间能对应到什么程度。实验没有测量理论中的内部量，也没有建立稳定收益，因此不进入论文。

现有[48条运行的新知识图确认运行](results.md#latent-confirmation)中，原子事实及训练过的两跳查询都是100%；执行两次相对执行一次的收益，在完整支持与256支持之间的交互为+18.61个百分点，三个知识图上都为正。这支持“支持集与计算结构共同影响组合使用”，但尚未测得式(10)中的内部算子、误差或谱。执行三次时收益不单调，分布外组合测试题上接近随机；这两点都应继续保留。把执行两次训练出的权重固定、改为执行三次测试时，原子提取也下降，所以不能把退化全部归为组合接口的问题。

## 12. 架构设计空间：区分参数存储、序列状态、调用和执行

本节当时回答：比较不同架构时，哪些资源（长期参数知识、前向临时状态、写入规则、计算）需要分开计量。它服务于已降级的架构效率路线，不能区分路径一致性假说与竞争解释，因此不进入论文。

本节区分长期的参数知识、前向的临时状态、写入规则与计算资源。这些数学关系约束对架构的解释，但不代替实验；是否开展对应的比较，由[研究范围](roadmap.md#scope)决定。

**参数知识与深度不是一一对应。** 参数θ承载训练之后保留的信息；前向的临时状态承载本次查询和中间结果。在闭卷任务中，序列mixer与层间连接都能改变这些参数被访问的方式；不能说前者只管上下文、后者直接存知识。两者的区别在于：GDN（Gated DeltaNet）按token更新序列状态，mHC沿层传播多流状态。更多的独立层同时增加参数和执行阶段；固定θ、增加循环次数只改变执行，不增加θ所含的事实信息，但不同循环配置的训练可能改变编码与学习效率。MoE主要改变稀疏参数的组织，mHC主要改变活动状态与连接；二者都不是单纯增加深度。[ICLR 2025联想记忆论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/0bf9f909c24c8879d1b7f86fa50a9e49-Paper-Conference.pdf)§4在指定的合成分布中，给出了单层attention加MLP的存储构造；这已足以否定“存储很多事实必然需要很深的网络”这一一般命题，但不保证任意真实任务或优化过程能实现该构造。

**参数容量与上下文状态是两本不同的账。** §3的参数计数包含所有embedding、router、expert、attention等权重。稀疏MoE虽然每次只激活部分专家，但不同查询可以访问不同专家；所以可编码知识图数的上限仍由总参数量决定，不能直接换成单次激活的参数量。激活量约束的是每次访问和计算的成本，不等于全部长期存储量。

另设模型参数固定，输入上下文包含F条独立任意的事实，每条有V种可能答案。若读完上下文之后只能保留D个各b位的状态量，不再访问上下文、外部表或其他随知识图改变的信息，并且必须对所有事实查询都答对，则同样由抽屉原理得到

\[
bD\ge F\log_2V.
\tag{13}
\]

状态量D须包括所有层的递归矩阵、卷积缓存以及其他可用的记忆。此式是精确恢复所有知识图的必要条件，不是有限误差下实测容量的估计。普通softmax attention的KV缓存可以随长度增长；固定大小状态的线性递归没有同样的资源增长。GDN仍有参数知识；这条状态界不说明它记不住通过训练存入参数的事实。真实事实之间有相关性，V与独立性也须重新定义。

**Delta写入的选择性取决于地址几何。** 按[Gated DeltaNet正式论文](https://proceedings.iclr.cc/paper_files/paper/2025/file/4904fad153f6434a7bcf04465d4be2cc-Paper-Conference.pdf)§3.1的记号（\(S_t\)为第t步的状态矩阵，\(k_t,v_t\)为键与值，\(\alpha_t\)为衰减门，\(\beta_t\)为写入强度），

\[
S_t=\alpha_t S_{t-1}+\beta_t(v_t-\alpha_tS_{t-1}k_t)k_t^\top.
\tag{14}
\]

固定这一步的键、值与门控，令 $e_t=v_t-\alpha_tS_{t-1}k_t$（写入前的预测误差），则任意后续读取方向u满足

\[
(S_t-\alpha_tS_{t-1})u=\beta_te_t(k_t^\top u).
\tag{15}
\]

因此，与k正交的u一定不受这项增量影响；与k不正交的地址一般会受影响，但β或误差e为零时增量也为零。α小于1时，仍会衰减其他旧状态。单位范数的k且β=1时，用新键读取得到的值被精确设为v；这不保证所有旧键或最终答案都保持不变。已生成的token、其他层和后续的非线性还会改变行为。本式直接支持分别改变键冲突、同时存储量和距离的实验，不支持“delta规则天然解决参数知识编辑”的说法。实体名称相似不自动等于实际键的内积大；把效果归因于地址几何，须操作实际的键，或核实其变化。

**mHC的混合稳定不等于语义信息保持。** 对固定的双随机矩阵H，有 $H\mathbf1=\mathbf1$、$\mathbf1^\top H=\mathbf1^\top$，且 $\|H\|_2\le1$；双随机矩阵的乘积仍是双随机矩阵。但 $H=\mathbf1\mathbf1^\top/n$（n为流数）会把所有流都替换为均值，完全消去流之间的差异。因此，[mHC正式论文](https://proceedings.mlr.press/v306/xie26aa.html)的约束给固定的线性残差混合带来稳定性质，但不能推出实体可分辨或知识不遗忘；依赖输入的H的导数以及pre/post分支，也使全网络的Jacobian超出这个界。只有比较普通残差、同样多流但H为I、完整mHC三种设置，才能分开状态扩展与混合的作用。

以上分析把架构比较的预算分为：总参数量、激活计算量、每个样本的活动记忆、执行次数和训练曝光次数。一次实验无法只靠“相同参数量”消除这些差异；应根据待检验的命题分别匹配并报告这些资源，而不是先假定统一的长度×深度×宽度幂律。

## 14.5 架构特性怎样连接条件命题

本节当时回答：各种架构分别能在数学上严格讨论什么、还需要哪些经验验证。它属于已降级的架构效率路线，因此不进入论文。

| 架构 | 能严格讨论的操作 | 仍需经验验证的部分 |
| --- | --- | --- |
| 循环Transformer（Loop） | 式(18)、(23)–(26)中的重复访问、参数耦合与跨迭代更新项 | 不同的知识使用角色是否得到相容的更新，是否降低训练成本；当前优先检验 |
| MoE | 路由固定、只更新某个专家时，不访问该专家的样本不直接受这一参数改动影响 | 共享层和router通常也会变化；原子查询与两跳查询可能不走同一个专家。更多总参数与稀疏访问的作用须分开 |
| DeltaNet / Gated DeltaNet | §12中快状态的覆盖与键相关的干扰；Gated版本另有全局衰减 | 每个样本重置的快状态怎样帮助提取、组合参数知识；序列内的覆盖不等于跨样本的参数编辑 |
| mHC | 固定双随机残差混合的非扩张性质 | 动态控制器与子层导数仍在完整Jacobian中；稳定传播是否提高学习效率或保持事实，须直接检验 |

这些结构并不处在同一个知识存储层次上。MoE直接改变可访问的参数容量与访问分配，适合保留为次级比较；[知识容量论文§9、附录D](https://arxiv.org/html/2404.05405v1)的稀疏专家结果支持研究其事实存储，但组合使用仍需单独测量。[Gated DeltaNet§3及检索实验](https://arxiv.org/html/2412.06464v1)中的覆盖与门控首先作用于序列内的状态；逐样本重置的短闭卷任务没有充分检验这一设计，因此当前暂缓。[mHC§4–5](https://arxiv.org/html/2512.24880v2)主要验证多流传播以及大规模深层训练的稳定性；当前的浅层知识任务没有建立对应的限制，也暂缓。暂缓是对任务与机制是否匹配的判断，不是“无效”的结论。

知识与推理上的收益也不必一致。[Reasoning with Latent Thoughts§3、附录A.2](https://arxiv.org/html/2502.17416v1)分别比较了闭卷知识与推理；[2026年iso-depth研究§3–4](https://arxiv.org/html/2604.21106v3)进一步把循环次数、参数和计算分开。该研究v3§5.2还发现，在循环边界加入双流Hyperconnections能改善其循环等效性拟合，这支持保留循环Transformer与跨迭代状态连接的结合；但这不是对mHC的直接验证，而且它没有对非循环基线施加相同的连接改造。这两项研究为比较轴提供依据，但其自然预训练结果和拟合关系，不构成本节实际GPT-2任务上的收敛定理或scaling定理。

相关的原始方法：[Universal Transformers](https://arxiv.org/abs/1807.03819)、[DeltaNet训练方法](https://arxiv.org/abs/2406.06484)、[Gated DeltaNet](https://arxiv.org/abs/2412.06464)、[mHC](https://arxiv.org/abs/2512.24880)、[Switch Transformers的稀疏专家方法](https://jmlr.org/papers/v23/21-0998.html)。本地MoE为top-2，而不是Switch的top-1；本地mHC是对GPT-2的适配；具体差异见[架构实现](../src/llm_memory_editability/parametric_architecture.py)。

本节配套的[CPU/FP64核查脚本](development-artifacts/architecture-theory-efficiency-20261007/verify_transformer_algebra.py)只验证真实模块的代数、前向与梯度等式，不做科学训练。架构是否更节省训练的评价与执行优先级，统一见[roadmap](roadmap.md#architecture-efficiency)；经验上的优势不能从数学构造自动推出。
