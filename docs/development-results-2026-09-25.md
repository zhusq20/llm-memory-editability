## 已完成的学习结果

使用完整 8 层、宽度 768、12 个注意力头、MLP 宽度 3072 的自回归 Transformer，参数约 6044 万。每个世界包含 12,352 条基础事实与 2048 条派生查询；每家公司 32 人，其中 2 人为旧例外。全部答案通过无正确答案前缀的自由生成评分，符号语法统一允许一个值 token 与 EOS。

完成世界 0、1、初始化 0、S→A 与 A→S 的四条完整轨迹。每条运行 13,280 步，包含两个各 2640 步的课程阶段与 8000 步共同巩固，batch 128，AdamW 学习率 1e-4，warmup 2000 步。课程之间的逐事实累计曝光、训练预算和巩固清单完全一致；初始模型文件校验一致。

结构先行的两世界平均基础／派生准确率为 99.6600%／99.8779%；事实先行为 99.9676%／100%。两对终点均通过协议中的符号旧知识水平相近条件，但这不证明内部组织相同或不同。两课程在预定检查点网格上具有相同的首次观测学习达标步数；不能据此认定真实首次达标时间完全相同。

第二阶段出现明显遗忘，共同巩固后恢复高准确率。前 5280 步接触的信息类别不同，该部分只描述课程轨迹；从 5280 步开始才进行等曝光比较。完整曲线保留后续准确率下降，不事后选择最好检查点。

全部学习曲线与逐查询预测位于 `results/bios-dev-v1/`，汇总图为 `results/bios-dev-v1/report/learning-curves.png`，CSV 与 JSON 在同一报告目录。阴影为已完成世界的观测范围，不是置信区间。

## 中断与覆盖缺口

预定学习矩阵为 2 世界 × 2 初始化 × 2 课程，共 8 条轨迹；目前完成 4/8。初始化 1 的四条轨迹连续两次被外部 SIGKILL 终止，分别记录为进程返回 137 和子进程返回 -9。日志未记录数值发散，检查时当前会话的 cgroup OOM 计数为 0，具体终止来源未确定。同期服务器有其他大型 GPU 作业，不能据此断言哪个任务造成终止。

第一次中断后从相同初始化重跑，前 0、660、1320、1980、2640 步的全部生成预测与原尝试逐项一致。由于学习检查点没有保存优化器状态，没有将旧权重冒充精确续训起点。两次中断尝试、完整曲线和已执行计算保存在 `interrupted-attempt-1/`、`interrupted-attempt-2/` 及 `interruption-ledger.json` 中，不作为预算内正常未达标，也不并入完成者平均值来代表全部种子。

中断尝试最后日志累计记录至少 62,100 个已执行优化步，这是下界，不补造最后一次日志之后的步数。四条完整轨迹共 53,120 步；额外重跑开销不能从实际实验账本中删除。当前须确认稳定可用的 GPU 或作业调度方式后，再补齐初始化 1 和固定预算编辑。

## 编辑实现检查与未完成部分

配对更新、E/D/U 集合、回放与未见保持测试划分已经实现并通过检查。每个 k=1 案例的 E 为 93 条、D 为 96 条；k=4、16 的计数与答案直方图也通过验证。

在世界 0、初始化 0、结构先行终点完成了 12 个一优化步的端到端工程检查：一致／例外更新 × FT-MLP、FT-All、FT-Down 及三种附加分支。其结果位于 `results/bios-edit-smoke/`，不视为 512 步编辑结果，不据此比较更新难度。

三种分支各有 25,600 个新增可训练参数，初始化前后 logits 最大差为 0。FT-Down 检查中，固定前缀的内部特征最大变化为 0，`Δh = ΔW_out z` 最大绝对误差约为 5.9e-7。这只校验层内关系，不构成编辑成功或知识传播的证据。

完整 512 步编辑、另一初始化的重复、阶段与终点的完整 GPU 组织测量尚未完成。自然语言 QA／人工语义审计、Qwen、SmolLM2、AlphaEdit、NLL 匹配和未见世界预测均未运行。固定中间层窗口与超参数是开发起点，尚未进行协议网格搜索。

## 已完成的 CPU 终点表征诊断

为避免继续占用 GPU，在四个已完成终点上完成 CPU FP32 诊断。它读取原始训练权重，不重新训练；与训练和主要行为评分使用的 GPU BF16 区分记录。每个世界预定 8 个 recipient 公司，在全部 8 层执行 donor 替换、同答案 donor、错误公司 donor、等范数随机方向及消融，每模型 320 项、合计 1280 项干预；保存全体 2048 个实际工作城市查询的层内激活及固定人员子集多位置的 x/z/h。

事实先行的早期层响应在两个世界中更大，不能预设“结构先行一定形成更多共享”。但独立属性也出现较大响应，因而尚不能把该方向解释为纯公司知识。第 1 层等范数随机方向和同答案 donor 对目标成员的平均响应接近零；所有对照与全部层结果都保留，未按最大效果重新选择编辑窗口。

预定窗口中间的第 5 层，四个模型对同公司非例外的 donor 响应都小于 0.01 个百分点。后续开发需要同时检验层位置、候选成分选择和非目标属性损伤；本结果不证明窗口内编辑一定困难。完整诊断见各运行目录的 `organization-cpu-13280/`，全层曲线见 `report/organization-diagnostics.png`。另一初始化与 GPU 精度复查尚缺，不能把此线索作为确认结论。

## 复现与评价边界

- 官方原始字段、源码和许可保留于 `data/bios-source/`，固定来源与文件校验值见 `configs/bios-source-manifest.json`。本批次仅完成符号适配，不宣称已完成自然语言模板审计。
- 可通过 `scripts/prepare_bios.py` 重建两个开发世界、配对目标与数据契约；运行入口是 `scripts/run_bios_development.py`、`scripts/run_bios_pipeline.py`。旧输出不会被静默当成新的完整运行。
- 训练环境记录在 `configs/gpu-environment-dev-v1.txt`，绘图环境见 `configs/report-environment-dev-v1.json`；每条运行记录实际源码哈希，不能仅用未提交更改之前的 Git 提交号复现。
- FLOPs 为按执行形状计算的矩阵运算估计，未包括全部逐元素操作或 SVD；不同编辑参数范围的反向计算估算也不精确。共享服务器墙钟时间单列，不解释为纯算法效率。
- 本记录只支持对已完成两个世界、一个初始化的开发性描述；没有足够证据声称课程影响后续可编辑性或验证了完整共享机制。
