# LLM Memory 研究备忘录：共享压缩如何影响知识的可修改性

- 整理日期：2026-09-24
- 状态：待探索的研究假设；尚未开展实验，尚未完成系统性查新。
- 研究目标：寻找具有核心解释力、建模简洁直观的 LLM memory 视角，连接知识存储、检索与编辑。
- 本文用途：记录当前候选方向、最小模型、关键实验与停止条件，供后续选题和实验设计使用。

## 1. 核心问题与候选 insight

**当模型把大量知识压缩成共享规律之后，这种组织方式会怎样改变知识的可修改性？**

候选假设：

> 记忆更新的难度，取决于更新相对于原有共享结构需要引入多少新的独立自由度。修改大量符合共享结构的事实，可能比修改少量打破结构的例外更容易。

这里不主张“压缩越强，编辑越难”。需要检验的是一种有条件的关系：

- 符合原有共享结构的更新，可能受益于压缩。
- 打破共享结构的更新，可能需要额外的独立表示。
- 同一个模型可能容易接受大范围规律变化，却难以接受少数局部例外。

研究的核心对象是**记忆组织方式与更新代价的关系**。margin、串扰和局部性可以作为测量工具，但不应替代中心命题。

## 2. 与起点论文的关系

起点论文是 *MLPs are Hebbians: Constructing Efficient Fact-Storing MLPs for Transformers*，讨论中的依据为用户提供的 v1。

论文提供了三个有用的出发点：

1. 在适当条件下，可以将 MLP 重写为核空间中的 Hebbian 联想记忆。
2. 事实是否能被稳定召回，与 decoding margin 和事实间串扰有关。
3. 通过构造事实模块，可以受控地研究存储容量、查询扰动和模块替换。

当前方向向前追问：

> 同样正确回答大量事实的模型，如果采用了不同的共享结构，是否会具有不同的编辑能力？

它关注的是事实间的结构及其变化。原论文的容量结果和编辑 proof-of-concept 不能直接推出这里的假设成立。

同时保留原论文的适用边界：真实 Qwen 激活上的几何实验，不等于在原预训练 Qwen 中完成事实编辑；模块替换实验也依赖专门设计的模型与完整的编辑后事实表。

## 3. 最简模型：四条更新为什么可能比一条更容易

### 3.1 事实矩阵与共享表示

把事实表示为“实体 × 属性”的数值矩阵：

$$
Y = UV^\top,\qquad \operatorname{rank}(Y)\le r.
$$

其中，\(r\) 表示模型允许的共享因子数量。这个模型用于研究表示限制，不把所有 Transformer 的知识直接等同于低秩矩阵。

最小例子：

$$
Y=
\begin{bmatrix}
1&1\\
1&1
\end{bmatrix}.
$$

这四条事实可以由一条共同规律表示，矩阵的秩为 1。

### 3.2 两种更新

修改全部四条事实：

$$
Y_{\mathrm{rule}}=
\begin{bmatrix}
2&2\\
2&2
\end{bmatrix},
\qquad
\operatorname{rank}(Y_{\mathrm{rule}})=1.
$$

只修改一条事实：

$$
Y_{\mathrm{exception}}=
\begin{bmatrix}
2&1\\
1&1
\end{bmatrix},
\qquad
\operatorname{rank}(Y_{\mathrm{exception}})=2.
$$

在固定 \(r=1\)、要求精确重建所有数值的条件下：

- 规律更新可以实现。
- 单条例外不能实现。
- 要精确实现例外，必须增加表示自由度。

这个例子揭示：**被修改的条目数，不足以描述一次更新的表示需求。**

### 3.3 数学边界

上述结论是简单的线性代数事实，不作为新定理主张。必须区分：

- 固定秩数值模型与非线性 Transformer；
- 精确保持输出向量与保持答案分类正确；
- 目标是否可表示与现有编辑算法是否能找到表示。

尤其不能直接用更新矩阵的秩替代“新增自由度”。在上述例子中：

$$
\operatorname{rank}(Y_{\mathrm{rule}}-Y)
=
\operatorname{rank}(Y_{\mathrm{exception}}-Y)
=
1,
$$

但两种更新后的目标矩阵分别需要秩 1 和秩 2。

因此，度量必须考虑**更新与原有结构的关系**，而不能只看 \(\operatorname{rank}(\Delta Y)\)。

在完全已知的合成矩阵任务中，可以先用“更新后目标所需最小秩是否超过现有秩预算”刻画表示缺口。如何为真实 LLM 定义可计算、可预测且非事后解释的对应量，仍是开放问题。

## 4. 希望建立的研究命题

一个足够具体、可以被推翻的候选命题是：

> 在控制编辑数量、目标惊讶度、变化强度和训练预算之后，更新相对于已有共享结构所需的新增自由度，能够预测知识编辑的成本与副作用；对这些自由度进行干预，可以改变结果。

应拆成三个可检验假设：

| 假设 | 预测 | 不支持该假设的结果 |
| --- | --- | --- |
| H1：编辑数量不是充分的难度变量 | 编辑条数相同时，不同更新结构产生稳定的成本差异 | 控制原有置信度、语义冲突与预算后，差异消失 |
| H2：原有记忆组织方式影响编辑 | 旧知识准确率接近时，共享程度不同的表示对规律与例外更新响应不同 | 组织方式的改变不能稳定改变编辑结果 |
| H3：部分困难来自独立表示不足 | 增加可独立控制的表示，选择性改善例外更新 | 任何增加参数的方式都同等有效，或独立表示没有帮助 |

“新增自由度”目前是需要操作化的研究概念，不能预先当作已经验证的解释。

## 5. 决定性实验

### 实验 A：固定编辑数量，只改变更新结构

**目的：** 检验编辑条数之外是否存在有解释力的结构变量。

构造由少量潜在因素生成大量事实的合成世界，对同一模型施加：

- 少数共享因素变化所引起的规律更新；
- 缺少共同生成规律、需要更多独立变化的例外更新。

主实验应匹配：

- 编辑条数和涉及实体、属性的覆盖范围；
- 变化幅度及目标答案分布；
- 编辑前准确率、置信度或目标惊讶度；
- 训练样本、优化步数和参数预算；
- 语义冲突程度；在合成世界中尽可能直接控制。

记录编辑成功率、保留事实准确率、改写泛化，以及达到相同目标质量所需的计算或额外容量。

期望观察：不同编辑规模的性能变化，能被预先定义的结构变量更好地预测。曲线对齐是值得争取的结果，不作为既定事实。

### 实验 B：固定知识内容和答题效果，改变组织方式

**目的：** 把知识内容与内部表示组织分开。

先在合成模型中直接控制：

- 共享因子数量；
- 因子的复用范围；
- 独立表示的数量；
- 剩余容量。

在旧知识准确率接近的条件下，比较规律更新与例外更新。

再探索小型 Transformer 中是否存在对应现象。不能只凭一个激活矩阵的有效秩，就认定模型已采用某种知识压缩方式；组织方式的测量需要独立验证。

### 实验 C：补充自由度，进行因果干预

**目的：** 检验表示不足是否是困难的来源。

在相同额外参数预算下，比较不同扩容方式，例如：

- 扩大原有共享表示；
- 提供可以独立控制的表示；
- 保持原共享部分固定，仅允许新增部分学习例外。

关键预测是：独立表示应对例外更新产生更有针对性的帮助，而不是只出现普遍的“大模型更好”。

任何侧记忆或新增模块，在这一阶段主要是验证假设的工具。不能仅凭“增加一个 memory 模块有效”主张机制成立。

### 实验 D：从头训练，区分容量限制与编辑困难

用相同容量的模型，从头学习修改后的完整世界，并使用充分的优化预算和多次初始化作为诊断。

| 观察 | 可以支持的解释 |
| --- | --- |
| 有严格表示下界，且同容量模型无法拟合修改后的世界 | 支持该受控模型中的表示容量限制 |
| 同容量从头训练成功，局部编辑失败 | 排除“该目标在此模型类中不可表示”的解释，需研究更新路径或可用信息 |
| 有限次从头训练失败 | 只能提供经验线索，不能单独证明不可表示 |
| 补充独立表示选择性改善例外更新 | 为“独立自由度不足”提供因果证据，仍需预算匹配对照 |

这一实验是必要的诊断对照，防止把优化失败误写成容量定理。

## 6. 测量与评价原则

首先分开三个量：

1. **表示成本：** 达到目标误差所需的最小模型容量。
2. **编辑成本：** 从原模型出发达到该目标所需的更新预算。
3. **副作用：** 未要求修改的知识、查询泛化和一般能力的变化。

结构指标应在编辑前可获得，不能根据失败结果事后定义。

合成任务可以利用完整目标表与已知生成过程。真实模型中只能观测部分知识，因此不能把抽样评价包装成对全部旧知识的保持保证。

从数值模型迁移到语言模型时，应额外报告离散答案正确率与 margin，检验精确数值模型中的现象是否仍有行为层面的对应。

## 7. 新颖性定位与近邻工作

目前不能宣称该方向无人研究。应争取的贡献是：**可提前预测的结构关系，以及支持该关系的干预证据。**

| 近邻工作 | 已有内容 | 本方向需补上的证据 |
| --- | --- | --- |
| *MLPs are Hebbians* | 构造性容量、margin、几何干扰和模块替换 | 共享规律与局部例外如何改变更新所需的表示资源 |
| *How Well Can Knowledge Edit Methods Edit Perplexing Knowledge?* | 违背模型概念层级的新知识更难编辑 | 控制语义冲突和惊讶度后，记忆组织与新增自由度仍有独立解释力 |
| *An information-theoretic framework for robust large language model editing*（IBKE） | 压缩编辑信息以改善泛化和局部性 | 原有记忆的共享结构，如何决定后续更新的代价 |

不能仅以以下内容作为主要创新：

- “事实之间存在相关性”；
- “反常识知识更难修改”；
- “低秩加独立记忆模块效果更好”；
- “压缩与编辑存在关系”；
- 重新命名经典低秩表示事实。

后续查新还应覆盖：知识依赖与编辑传播、结构化批量编辑、表示共享与例外学习、编辑容量下界，以及存储结构对持续更新的影响。现阶段的参考列表不是完整综述。

## 8. 最小推进路线与停止条件

按依赖关系推进：

1. 完成最小低秩模型，明确精确表示与近似表示下的预测。
2. 做编辑数量与更新结构的配对实验，检验结构变量是否提供额外解释。
3. 加入从头训练和预算匹配扩容，区分容量、优化与信息可用性。
4. 在小型 Transformer 上验证对应现象。
5. 只有在效应稳定后，再扩展到预训练 LLM 和自然语言知识编辑。
6. 方法设计放在机制验证之后。

优先考虑停止或改写中心假设的情况：

- 效应完全由原有置信度、语义冲突或训练预算解释。
- 指标只有事后解释能力，无法预测未见更新。
- 改变组织方式不能改变结果。
- 所谓容量瓶颈只来自人为过窄的 toy model，在非线性模型中没有对应迹象。
- 不同扩容方式表现相同，缺乏支持特定机制的证据。

负结果也有诊断价值，但不应为了保留原故事而不断追加假设。

## 9. 对更广义 LLM Memory 的潜在意义

如果核心假设得到支持，可以进一步研究：

- 哪些规律适合整合进共享参数；
- 哪些独立、易变的例外适合单独保留；
- 什么时候多个例外已经形成可共享的新规律；
- memory 系统应依据什么条件进行整合、拆分或扩容。

这些是后续问题，不应在第一阶段同时铺开。第一阶段聚焦：

> 保持编辑数量不变，仅改变更新与原有共享结构的关系，能否稳定改变所需容量，并通过补充独立表示消除这种差异？
