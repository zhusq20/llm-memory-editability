# 非线性知识编辑实验协议

本协议定义当前 MLP / Transformer 实验。目标是比较相同事实集合上的两类更新，并用从头训练诊断编辑失败。“共享规律”首先指数据生成方式；内部表示是否共享是后续待验证的问题。

## 事实与配对目标

默认世界包含 24 个实体、8 个属性、3 个等大实体组、4 类答案，共 192 条事实。输入为实体、属性，输出为分类答案。旧世界使用：

```text
old_answer(entity, attribute) = (group(entity) + attribute) mod n_answers
```

组身份仅用于生成答案，模型接收实体和属性标识。编辑集合是第 0 组的全部事实：默认 64 条编辑事实、128 条保留事实。

- **规律更新：** 编辑集合上的旧答案统一加 1，再对答案类别数取模。组内实体仍共享相同的属性到答案映射。
- **例外更新：** 为编辑集合内各实体分配平衡的目标映射，每条答案均发生变化，打破组内共同映射。

两种条件使用完全相同的编辑集合，因而编辑数量与实体、属性覆盖相同；每个编辑实体的目标答案直方图相同，因此编辑集整体的目标答案边际分布也相同。分类答案没有有意义的数值距离，标签编号差不能解释成变化强度。例外目标也不等于“无任何规律”或已证明需要更多神经参数。

报告还给出预先可计算的数据指标：在每个“组 × 属性”单元中，以多数答案作为共同映射，统计需要单独覆盖的标签数量，再对各单元求和。该指标衡量目标表偏离这类生成规则的程度，不是神经网络自由度，也没有证明模型使用了这些组。

相同旧模型与相同编辑集合保证了编辑前旧答案准确率相同。新目标答案不同，编辑前目标惊讶度和 margin 可能不同：当前记录但未匹配这两项。

## 模型与默认配置

| 模型 | 计算过程 |
| --- | --- |
| MLP | 实体、属性各自嵌入后组合，经含 GELU 的前馈网络得到答案 logits |
| 因果 Transformer | `[entity, attribute, QUERY]` token 序列经位置表示、因果自注意力及非线性前馈层，从查询位置得到答案 logits |

两者均使用 PyTorch 反向传播学习离散答案，不需要下载预训练权重。答案表不以低秩分解形式存储。

| 配置 | 默认值 |
| --- | --- |
| 模型初始化种子 / 数据种子 | `0 1 2` / `0` |
| 宽度 / 前馈隐藏维度 | `32` / `64` |
| MLP 隐藏层数、Transformer 层数 / 注意力头数 | `2` / `4` |
| 旧世界训练 / 编辑 / 从头训练步数 | `400` / `100` / `400` |
| 学习率 / 保留回放权重 | `0.01` / `1.0` |
| 编辑范围 | `ffn`；可用 `--edit-scope all` 更新全部参数 |
| 评价间隔 / 质量阈值 | 每 `10` 步 / `0.95` |
| 设备 / CPU 线程数 | CPU / `1` |

模型种子变化时保持数据种子相同，区分初始化变异与数据变异。改变网络尺寸属于改变容量，应作为单独配置报告；MLP 与 Transformer 之间不声称参数或计算预算相同。

自定义世界需保持实体组等大且每组至少 2 个实体，至少 2 个组、3 类答案，属性数能被答案类别数整除。例外目标通过有界拒绝采样生成，较长属性表可能超出采样次数限制并报错。

## 训练、编辑与诊断

每个种子执行：

1. 初始化模型，在全部旧事实上以全批量交叉熵训练，记录旧世界学习效果与质量门槛。
2. 复制同一旧世界检查点，分别进行规律与例外编辑。两种条件使用相同编辑步数、学习率、参数范围和回放权重。
3. 在编辑集合拟合新答案，在完整保留集合回放旧答案。默认仅更新前馈层。
4. 对两种完整目标世界，从同一初始权重分别训练相同容量的模型，开放全部参数，作为从头训练诊断。

编辑目标为两个集合各自平均交叉熵的加权和：

```text
edit_loss = mean_CE(edited_facts, new_answers)
          + retention_weight * mean_CE(retained_facts, old_answers)
```

旧世界训练和从头训练均使用完整世界的平均交叉熵。当前完整保留集合可用于训练，是合成世界提供的理想信息条件；真实 LLM 通常无法枚举全部旧知识。

默认仅编辑前馈层是对可编辑参数的约束。全参数从头训练成功不能保证冻结嵌入、注意力或输出层后仍可实现同样结果；解释差异时需要结合全参数编辑对照。

`ffn` 对 MLP 只开放隐藏前馈层，对 Transformer 只开放各块的两层前馈线性映射；输出分类头均被冻结，Transformer 的归一化参数也被冻结。各训练阶段使用重新初始化的 Adam 优化器。

## 结果记录与解释

| 指标 | 定义与用途 |
| --- | --- |
| 编辑准确率 | 编辑集合上预测新目标答案的比例，比较编辑前后 |
| 保留准确率 | 保留集合上预测旧答案的比例，比较编辑前后 |
| 交叉熵 / 目标惊讶度 | 新目标的 `−log p(target)`；编辑前值用于识别初始难度差异，单位为 nat |
| 答案 margin | 目标答案 logit 减去最大非目标 logit；负值表示目标未胜出 |
| 参数预算 | 总参数量与本阶段实际可训练参数量 |
| 优化预算 | 实际训练步数与用时；用时依赖硬件和环境 |
| 达标步数 | 在评价检查点首次同时达到编辑与保留准确率阈值的步数；未达标须明确记录 |

先检查旧世界是否学会，再分析编辑。旧世界未通过质量门槛的运行仍应保存，不能静默删除。达标步数按评价间隔采样，不是逐步精确的首次达标时间，也不保证后续一直达标。

固定预算终点表现是主要可复现实验结果；终点分数或单次用时差不等于达到相同质量所需的最小成本。保留逐种子配对结果，区分初始化失败与编辑失败。少量种子和小型合成任务的结果不能代表预训练 LLM。

从头训练成功说明相同架构可达到对应目标质量；有限训练失败不构成容量下界。当前没有测量自然语言改写与一般能力，也没有验证内部共享程度或实现扩容干预。

## 运行

完成 README 中的安装后：

```bash
memory-editability-neural --model mlp --seeds 0 1 2 --output results/mlp.json
memory-editability-neural --model transformer --seeds 0 1 2 --output results/transformer.json
memory-editability-neural --model transformer --edit-scope all --output results/transformer-all.json
python -m llm_memory_editability.neural --help
```

配置、软件版本、随机种子、实际预算和各次运行结果应随报告保留。用于论证的正式实验还应记录代码提交版本、硬件信息，并在 [实验计划](experiment-plan.md) 中明确未完成的控制。
