## 0. 术语与记号

本项目的主要合成基准沿用Wang等2024（Grokked Transformers）的知识图两跳推理：随机生成实体、关系与事实，训练混合全部原子事实与部分两跳查询，再测试未训练过的组合。“先掌握事实、后会组合”是可能出现的学习阶段，并非原论文规定的两阶段训练。下表是全部文档统一使用的术语。

### 任务与数据

| 术语 | 含义 |
| --- | --- |
| 原子事实（atomic fact） | 一条三元组 (h, r, t)，训练时以“头实体 关系 → 尾实体”的单跳查询出现 |
| 两跳查询（two-hop query） | (h, r₁, r₂)，答案是先由 (h, r₁) 得到 b、再由 (b, r₂) 得到的 t |
| H跳查询（multi-hop query） | 从h依次沿r₁…r_H走H条事实，预测最终实体；H是事实链长度，不是Transformer层数或Loop迭代数 |
| 目标事实的使用位置j | 同一条事实在H跳链中被调用的第j步，1≤j≤H |
| 长度外推（depth extrapolation） | 测试链长度H超过训练中最大的链长度；与已训练长度内的新组合、新使用位置分开评价 |
| 桥实体（bridge entity）b | 两跳查询中第一跳的答案，也是第二跳的头实体 |
| 第一跳 / 第二跳 | 两跳查询中的第一条 / 第二条事实 |
| ID事实 / OOD事实 | ID事实出现在训练两跳样本中；OOD事实只以原子事实训练过 |
| 分布内组合（ID测试） | 用到的事实都在训练两跳样本中出现过，但这一组合本身没有训练过 |
| 分布外组合（OOD测试） | 用到的事实只以原子事实训练过，从未出现在任何训练两跳样本中 |
| II/IO/OI/OO四类测试 | 第一个字母表示第一跳事实、第二个字母表示第二跳事实是ID（I）还是OOD（O）；定义同Wang等2024与Zhang等2026 |
| 推理—原子比 φ | 训练两跳样本数与原子事实数之比（Wang等2024）；φ越大，每个实体参与的训练两跳样本越多 |
| 知识图 | 一次独立随机生成的实体、关系与事实集合；不同随机种子在同一知识图上训练，不算独立知识图 |
| 曝光次数（exposures） | 同一事实在训练中出现的次数 |
| 知识量 | 需要记住的事实总数 |
| 提问模板 | 同一事实的不同表述形式 |
| 旧—旧 / 旧—新 / 新—旧 / 新—新组合 | 顺序知识注入实验的四类测试：前一个字指第一跳事实、后一个字指第二跳事实是先学的旧知识还是后学的新知识 |
| 分步回答 | 先问第一跳，再把模型自己的答案代入问第二跳；与直接回答两跳查询对比，用来区分“事实不会”和“不会组合” |
| 预注册分析计划 | 在看到结果之前冻结的分组、指标和判读规则 |
| 事后再分析 | 只读已有检查点或已保存的预测，不训练新模型；结论层级低于预注册分析 |

### 模型与训练方法

| 术语 | 含义 |
| --- | --- |
| 标准Transformer | 各层参数独立；Wang设定下为“标准8层模型”（8层、宽768） |
| 循环Transformer（looped Transformer），记作Loop L×T | 一个L层的参数共享块重复执行T次；Loop 4×2即4层块执行2次，总深度与标准8层模型相同 |
| 第t次迭代 | 共享块的第t次执行 |
| 小型参数共享模型 / 小型标准两层模型 | 早期小规模实验的两种模型：单个Transformer块执行两次（宽128、260,608参数）；两层独立参数（宽128、458,880参数） |
| 复制初始化 | 各层或各参数副本从同一组随机初始权重复制而来，初始前向完全相同；与“各层独立随机初始化”不同 |
| 跨迭代KV读取 | 第二次迭代额外读取第一次迭代同层的key/value |
| 起点模型 | 编辑或续训开始时的模型 |
| 标准交叉熵训练 | 只用下一token交叉熵，不加辅助损失 |
| 第一跳辅助损失 | 在r₁位置、第一次执行之后，用输出embedding解码并以桥实体为标签的辅助交叉熵 |
| 表示对齐损失 | 把r₁位置第一次执行后的隐藏状态方向拉向桥实体的输入embedding |
| 解码 | 用输出embedding（logit lens）或线性探针从某位置读出对应实体 |
| 解码—再编码（re-encoding） | 在两次执行之间，把r₁位置的隐藏状态替换为模型自己解码出的实体的输入embedding（保持范数）；即DiscoLoop式(2) |
| 解码—再编码通道 | DiscoLoop的架构：每次迭代末加上按softmax概率加权的输入embedding之和 |
| 梯度池化（gradient pooling） | 共享参数收到各次执行梯度之和；部分池化用比例α在“只用本次执行的梯度”与“用全部执行梯度之和”之间插值 |
| 梯度路由（gradient routing） | 前向保持参数共享，只改变更新时如何聚合各次执行的梯度 |

### 编辑与持续学习

| 术语 | 含义 |
| --- | --- |
| 训练情境（写入情境）c | 事实以什么样本被训练：原子陈述、某种提问模板、组合中的某个角色、一次编辑 |
| 使用方式 u | 之后在什么查询中被用到 |
| 经验神经正切核（empirical NTK）K(u, c) | K(u, c)=J(u)J(c)ᵀ，J是logits对参数的Jacobian；一步梯度更新在训练情境c上的学习，一阶下怎样改变查询u的输出 |
| 跨迭代项 | 共享参数在不同迭代之间的耦合项（理论式(25)） |
| 编辑传播（edit propagation） | 编辑一条事实后，依赖它的多跳答案是否随之更新（ripple effect） |
| 被编辑事实所在的跳 | 被编辑事实在多跳问题中是第一跳还是后续跳 |
| 第一跳编辑优势 | 被编辑事实位于第一跳时，编辑后多跳准确率高于位于后续跳时 |
| 目标事实 / 回放 / 保持集 | 编辑实验中被改写的事实 / 编辑时一起训练的旧事实 / 不应改变的旧事实与旧组合 |
| 只复习不编辑的对照（sham） | 与编辑流程相同、只回放旧事实，用来分离“继续训练本身”的影响 |
| 顺序知识注入 | 先学旧知识（含组合），再学新原子事实 |
| 测试时训练（test-time training, TTT） | 测试时利用可获得的输入或自监督信号更新选定参数/快权重；状态可能每序列重置，也可能跨样本保留，须逐方法说明 |
| 本项目拟考察的跨样本TTT写入 | 接收事实样本后保留更新到后续独立查询；明确保留快权重与必要优化器状态，单个查询的隐藏表示与attention/KV另行重置 |

### 路径一致性的三个前提

| 前提 | 含义 |
| --- | --- |
| 层范围 | 第二跳查表所用的层，是不是存储该事实的那些层 |
| 逐跳完成 | 每一跳是否在下一跳读取的token位置上完成 |
| 表示格式 | 该位置的隐藏状态是否处在下一跳查表所读取的形式，例如与实体输入embedding对齐 |

<a id="question"></a>
## 1. 一个总问题，三个研究层次

**总问题：模型通过训练写进参数的知识，怎样才能被回答、被组合进多步推理、并在知识更新后继续被这些推理使用？**

论文把知识学习与基于知识的推理放在同一个问题中，分三个层次：事实能被回答、事实能被组合、更新后能继续被使用。每个层次各有独立实验和机制解释，彼此递进、相互检验。第一层本身是研究对象，不能缩成后两层的“单跳是否掌握”这一门槛。现有实验包含两到四跳的事实组合，Wang原规模复现的主任务仍为两跳；其结论不能等同于一般的数学或推理能力。

**统一表述：训练情境与使用方式。** 一个事实总是通过某个训练情境c的梯度写进参数，例如原子陈述、某种提问模板、组合中的某个角色、一次编辑。之后某种使用方式u（另一种问法、组合中的另一个角色、更新前已会的多跳问题）是否受到影响，一阶上由经验神经正切核（empirical NTK）决定：

> Δf_u ≈ −η · K(u, c) · v_c，K(u, c) = J(u) J(c)ᵀ

其中f_u是查询u的logits，J(·)是logits对参数的Jacobian，v_c是训练情境c的损失对其logits的梯度，η是学习率。这一式子就是[理论§14.4式(24)–(26)](memory-scaling-theory.md#loop-cross-call-kernel)，原本用于比较循环Transformer中不同迭代之间的耦合，这里推广到任意的训练情境与使用方式。同一个K作用在新的使用方式上是前向迁移，作用在旧的使用方式上是干扰，所以持续学习中迁移与干扰的两面都在这一个量里。**路径一致性是关于K何时接近零的具体假说**：如果u读取信息的计算路径不经过c的梯度实际改动的参数与表示格式，c上的学习就传不到u。

这一表述有三条边界：
- 它是一阶、局部的关系。实际训练用AdamW，须用实测的参数更新Δθ代替原始梯度。
- 预训练中特征本身在变化，读取路径怎样形成不能用固定的核描述，只能由训练实验检验。
- K是解释机制的对象，不用来预测成绩。主证据仍是：改变训练情境、参数共享方式或编辑位置之后，端到端行为怎样变化。

| 层次 | 独立研究问题 | 训练情境与使用方式的距离 | 解释目标 | 主要评价 |
| --- | --- | --- | --- | --- |
| 知识能被回答 | 事实怎样进入参数，查询怎样提取它？ | 近迁移：同一事实换一种问法，训练情境与查询格式不同 | 学习内容、表达方式、曝光次数与知识量怎样影响记忆形成和提取 | 原子事实学习曲线、不同提问模板的提取、保持、学习成本与可测知识量 |
| 知识能被组合 | 已掌握的事实什么时候能成为下一步计算的输入？ | 远迁移：事实进入它训练时没有担任过的使用角色 | 组合训练经历、表示与计算结构怎样形成可迁移的调用 | 熟悉事实的新组合、只受原子训练的事实的组合、所需事实是否掌握 |
| 更新后能继续被使用 | 新增或改写事实后，已学会的用法能否接上新事实？ | 已形成的用法接上新写入；同一重合也决定对旧用法的干扰 | 写入是否进入实际被调用的知识，旧答案和旧能力怎样影响更新 | 新事实、依赖新事实的多跳答案、旧答案残留、未受影响的知识与组合保持 |

单跳回答正确不保证组合正确；静态组合正确也不保证更新后的组合正确。这两点都有受控实验支持。“表示兼容、共享访问、使用经历、更新不同步”是需要相互比较的解释，不能提前选定其中一个作为全部现象的答案。

论文按“事实形成与提取 → 组合使用 → 更新后的继续使用”展开，用训练情境与使用方式的表述贯穿预训练与持续学习（见[§1.2](#pretraining-continual)）。工作标题可用 **Learning and Reasoning with Parametric Knowledge: Recall, Composition, and Use after Updates**，或突出统一表述的 **Where Knowledge Is Written Determines How It Can Be Used**；标题随证据调整，不预设已经建立普遍的scaling law或单一的MLP机制。

<a id="path-consistency"></a>
### 1.1 工作假说：路径一致性

2026-10-08用户采纳为论文主线。**假说：一个事实在模型里不是“存在某处、处处可用”，而是挂在特定的计算路径上——在哪几层、哪个token位置、以什么表示格式被读取。** 由此得到三层预测：
- **回答。** 能否回答，看查询的读取路径能否到达事实被写入的位置。
- **组合。** 能否组合，看三个可以分开检验的前提：
  - 层范围：第二跳查表所用的层，是不是存储该事实的那些层；
  - 逐跳完成：前一跳是否在后一跳读取的token位置上完成；
  - 表示格式：该位置的桥实体状态是否处在查表期望的输入形式。
- **更新。** 编辑能否传播，看被更新的参数是否位于组合实际读取的路径上。

这不等于一个事实只存在一处。[Feng等](#feng2025)显示，一次微调写入会在多层各留下一份，不同使用方式读取不同的副本。假说的准确含义是：某种使用方式只能读到写在它自己读取路径上的那一份。

已有两组结果显示，修复表示格式只在前两个前提成立时起作用。第一组是解码—再编码：只用标准交叉熵训练的小型参数共享模型，在r₁位置注入真实桥实体的输入embedding，分布外组合也只到1.60%，因为该模型没有在这一位置完成第一跳（逐跳完成不成立）。第二组是小型标准两层模型的表示对齐：桥实体状态与其输入embedding的余弦已达.9997，分布外组合仍只有5.27%，因为第二跳查表不在存储该事实的层（层范围不成立）。在[DiscoLoop](#discoloop2026)取得成功的设定中，这两个前提恰好都成立。标准Transformer主要靠“在第二跳角色上训练过”另外建立一份查表路径，因此只受原子训练的事实难以作为第二跳被组合，只改单跳路径的编辑也难以传到组合。这一说法限于从头训练的设定：预训练大模型中，只做单跳微调的新事实也能部分作第二跳使用（[Feng等](#feng2025)），可解释为预训练已形成单跳查询与第二跳共用的晚层读取路径。按[§1](#question)的表述，这一假说断言：使用方式u的读取路径不经过训练情境c所改动的层范围、token位置与表示格式时，K(u, c)接近零，c上的学习传不到u。

**参数共享的两种作用（2026-10-11可行性复核）。** 原先“参数共享使单跳路径即第二跳路径”的说法不成立；10-10改称“共享写入”仍须限定含义。按[理论§14.4式(23)与式(35)](memory-scaling-theory.md#partial-pooling-20261010)，共享参数的梯度是各次执行贡献之和；实际参数更新完成后，各次执行使用同一组更新后的参数。这不等于它们读取同一事实：
- **前向可见性。** 更新后的参数确实在各次执行中出现；相同参数面对不同隐藏状态，可以产生不同的attention路由、MLP激活与归一化结果。只有后续步骤实际调用兼容的事实读取过程，相关更新才可能传到组合。单跳最终答案改对或中间实体可解码，均不充分。
- **反向形成。** 梯度汇总是数学恒等式；各次贡献可以加强，也可以抵消。依项目既有阅读记录，权重绑定与梯度池化论文在上下文指针追踪中支持“训练过程促进可重复操作的形成”，不证明这一偏置在任意参数知识任务上成立，也不证明原子更新保留已学操作（见[下文](#weight-tying-pooling)）。AdamW的实际更新另行解释，不能把原始梯度之和直接当作更新或长期泛化证明。

一次写入对其他用途的影响，还取决于相关激活及后续计算的响应；共享参数与梯度汇总本身不保证跨用途影响有利，理论式(36)是局部关系。部分池化与梯度路由可帮助区分结构共享和训练信号汇总，候选方法见[§5.0.1](#zhang2026-next)。当前先按[能力边界复核](#wang-benchmark-boundaries)判断依据，再选择必要干预；完整池化比例与共享模式矩阵不作为默认下一轮。

**可测定义。** 对同一事实，分别用替换或删除干预（activation patching与消融），找出它在三种使用方式下因果必需的层×token位置：被单跳查询时、作第一跳时、作第二跳时。两条路径是否重合，用“在一种使用方式上找到的必需成分，消融后能否同样破坏另一种使用方式”来测。表示格式另用替换来测：把该位置的状态换成解码出的桥实体的输入embedding（[解码—再编码](results.md#bridge-reencoding)，参考DiscoLoop §3.2）。使用随之恢复，支持交接表示的作用；未恢复时还须核查干预操作、后续读取与必要事实，不能仅凭未恢复定位瓶颈。形式上可在已有权重上用实测更新核查K(u, c)，但局部响应不等同于完整路径同一或长期泛化。主证据是改变路径重合程度之后端到端行为的变化，不另建预测器。

**现有弱点与反例。**

- **持续学习阶段是否也有角色不对称，尚无结论。** 顺序知识注入实验的新—旧与旧—新组合在学新事实之前已有基线，且新—旧高于旧—新；唯一的新—旧题只有96道，新事实带来的净增只有一两题。这组数字既不能证明持续学习阶段有不对称，也不能证明没有。

- **自然语言模型。** MEMIT主数据池中CoT没有缩小第一跳与后续跳的差距，符合预注册计划预设的反对模式。但部分记录预览显示，后续跳编辑中被编辑的事实用问句只答对92/300（第一跳编辑为172/213），反对模式可能来自“编辑没有迁移到问句形式”这一前提失败，须由MQuAKE前提子集分析正式读出确认。ROME的CoT只消除约三分之一的差距（8.34/25.34个百分点）。第一跳组与后续跳组是不同的案例，关系与实体构成没有匹配。RippleEdits第二跳的有效测试只有28/1/54条。

这些问题须由复现和功效充足的后续比较决定，不能先当作已成立。

**Zhang等2026：组合层最接近的工作。** [arXiv 2608.07261](https://arxiv.org/abs/2608.07261) v3（2026-08-28；作者[仓库](https://github.com/zzl-strong/two_hop)标注EMNLP 2026），已读正文、附录A–K和仓库脚本。设定就是Wang 2024的原始知识图：2000个实体、200个关系、4万条原子事实，按边以95/5划分ID/OOD，φ7.2；模型为8层GPT-2、宽768，学习率1e-4、权重衰减.1。作者代码在Wang数据上追加IO/OI测试各3000题，用4卡×1024的批量训练，标准模型3.5M步、循环模型1.21M步。
- **现象。** 第二跳事实为ID时（II/OI）模型能泛化，第二跳事实为OOD时（IO/OO）失败；标准模型的OI在训练后期超过80%。

- **范围。** 真实数据为Wikidata5M的稠密子图（φ7.2），只报告循环模型，没有标准模型基线；不涉及编辑与更新。

**DiscoLoop（Fu等2026）：直接干预“表示格式”这一前提。** [arXiv 2607.00341](https://arxiv.org/abs/2607.00341) v2（2026-07-27；未见公开代码），已读正文、附录A–B及全部图。历史的grok-loop-v1预注册计划曾引用其§2–5，本项目的[解码—再编码](results.md#bridge-reencoding)实现的正是其式(2)，但此前没有在本路线图中比较。设定：两张实体互不相交的图共享50个关系，各500个实体、出度10；训练两张图的全部原子事实和图A的1万条两跳样本，图B的两跳全部留作OOD测试，比Wang按边划分的OO更严格。共享块f_θ循环K=2次，只监督最终答案；符号实验的层数、宽度、学习率、权重衰减与位置编码都没有报告，全文没有报告随机种子数或方差。
- **现象。** 普通循环模型在训练集上全对，ID/OOD测试为71.1/8.3%。只执行第一次迭代时，原子事实100%、训练两跳样本8.8%。第一个关系位置在第一次迭代后解码出桥实体的概率为1.000，但与桥实体embedding W[b]的余弦只有.33/.27（ID/OOD）。
- **干预。** 两次迭代之间只在该位置令h←(1−α)h+α·Norm(W[argmax])：图中α=0.6时ID/OOD约99/96%，α=1时约99/97%（正文写“α=0.1即25.9%”，与图中α=0.2的值一致）。
- **架构。** 每次迭代的输出加上α⊙RMSNorm(Σ_v softmax(Wh/τ)_v W[v])，W为绑定的embedding，最后一次迭代不加。符号任务ID/OOD约100/98%（不循环的模型约17/1%）；训练两跳样本在第一次迭代的准确率在相变时降到约1.5%。三跳（K=3）OOD约64%，普通循环模型约0。两种英文模板OOD约95%。440M模型、20B token预训练的平均分为50.5对49.3。没有做“不循环＋通道”的条件。

**解读边界。** 在该文的符号模板中，两跳查询与原子查询共享第一个关系之前的前缀（[理论§13.3](memory-scaling-theory.md#pretraining-implicit-alignment-20261004)），且第一次迭代已完成原子查表，所以桥实体解码概率1.000是这两点的直接结果，不能单独证明存在组合回路。普通循环模型在3000 epoch处的“平台”依赖训练预算：本项目Wang原规模长训练中，普通Loop 4×2的OO最高为81.34%（φ7.2、权重衰减.3、1.5M步）。因此该文更直接支持的是“表示格式使普通循环模型学得慢，通道让这一步不用学”，不能说普通循环模型学不到。该文英文实验没有说明人名是否为单token，而通道只携带一个token；本项目2Wiki中自然名称与单token实体的OO约为17%与85%（标准模型与循环模型相近），提示多token实体的表示格式问题另有来源。reverse模板中第二个关系在前、桥实体在句末，通道仍然成功；这提示路径一致性中的“token位置”应理解为查表读取的位置：注意力的路由可以跨实体学到，与单个事实绑定的是层范围与键的表示格式（解释，待解码—再编码通道比较检验）。

**权重绑定与梯度池化（匿名ICLR 2027投稿34319）：共享参数的作用来自训练过程。** 论文《How Weight Tying Elicits Iterative Computation in Looped Transformers》处于匿名评审，[OpenReview投稿](https://openreview.net/forum?id=vJgG20sjea)编号34319；PDF存于`papers/34319_How_Weight_Tying_Elicits.pdf`（2026-10-11加入仓库），曾记录阅读正文与附录A–C，代码为anonymous.4open.science/r/looped-gradient-pooling-F319。以下细节仍来自既有阅读记录，尚未按该文件逐项重新核对。设定是指针追踪任务（directed permutation traversal）：prompt中给出一个16节点有向环的全部边（顺序打乱），要求报告从起点走H步到达的节点。所有信息都在上下文中，刻意不涉及参数记忆。比较对象是4层块循环8次的循环Transformer（3.22M参数）与32层标准Transformer（25.7M参数），宽256，学习率3×10⁻⁴，100k步，带跳数课程，每个条件3个随机种子。用线性探针准确率减去打乱标签的控制探针（selectivity），定位每一跳在哪一层可解码。
- **现象。** 循环模型每次迭代多解码出一跳（作者称staircase）；标准模型只在最后几层可解码。这一结构不是任务或架构强制的：一个种子的中间跳selectivity只有.28–.56，仍解出H=8；去掉课程训练的循环模型解出H=8，却没有正向staircase。
- **部分池化。** 把共享块拆成T份副本，第t份副本的更新取αG+T(1−α)g_t（G为各次执行梯度之和）。α越大，解出越早、越稳定，第一跳可解码的层也越早（H=4时，α=1在第6–8层，α=0在第23–24层）。α=1时三个种子都解出H≤8，α=0时在预算内都没有解出。
- **梯度路由。** 前向保持共享，只替换更新：只用最后一次迭代的梯度（乘T）、把它缩放到全梯度的范数、每步随机取一次迭代（期望等于G），都不能解出H=8。作者据此认为“求和”本身是关键。随机取一次迭代的方差远大于求和，这一混淆没有排除。
- **习得动态。** 循环模型在一跳算子形成后，H=3–8在同一次评估中同时达到（作者称compositional burst）；标准模型逐个跳数习得。
- **共享模式。** 参数量与每组参数使用次数相同时，交替共享ABABABAB比连续共享AAAABBBB更早解出H=8，三个种子都是如此。
- **其他。** 标准模型只在学习率3×10⁻⁴下可解（10⁻³时0/5），循环模型在10⁻³与3×10⁻⁴下都可解。第一次迭代像在“热身”：第一跳到第二次迭代才可解码。寄存器机任务中答案平均只依赖少数几条指令，没有staircase。

| --- | --- | --- |
| 梯度池化决定循环模型学到可复用的算子 | 理论式(23)早已写出同一求和；微观诊断中360个调用位置梯度对有359个余弦非负（[结果](results.md#loop-learning-v1)） | 在经验NTK中写出部分池化的精确形式（[理论式(35)–(36)](memory-scaling-theory.md#partial-pooling-20261010)，FP64核查）：α只调节跨迭代项。参数知识中共享还决定一次事实写入能到达哪些使用方式，这一作用在只用上下文的任务中不存在 |

| 两组对照：独立初始化与复制初始化 | 本项目也有这两组：loop-learning-v1（复制初始化）与loop-kv-learning-v1（独立初始化） | 复制初始化可以作为机制对照。该文中复制初始化的解除共享模型学得更慢；本项目新—新组合的提升为+3.91对+7.81个百分点，方向相同，但差别在64题的分辨率以内 |
| 只研究上下文中的跳转，不涉及参数知识与更新 | — | 第三层：编辑写入范围实验在同一模型内区分写入在哪次迭代可见 |

借鉴方式：2026-10-10曾提出把部分池化与连续共享搬到Wang设定（[旧候选](#zhang2026-next)）。本轮按[三项主实验](#controlled-multihop)收拢，只在主要结果需要训练过程解释时，从这些方法中选取决定性比较；不整套移植网格。实现正确性用单元测试与FP64核查保证：α=1须逐位等于循环模型训练，α=0须等于解除共享的独立更新。该文引用的Sesodia等2026、Kaissis等2026（按迭代分解共享参数的梯度和，用于数据归因，最接近本项目§14.4的微观诊断）、Takase & Kiyono 2023（交替与连续的参数共享）和Mixture-of-Recursions（Bae等2025）尚未阅读原文，引用前须核对。该文中的“Zhang et al. 2026”指arXiv 2607.20594，不是上文的2608.07261。

<a id="feng2025"></a>
**Feng、Russell与Steinhardt 2025：预训练大模型上的层范围证据。** [ICML 2025](https://proceedings.mlr.press/v267/feng25m.html)（[arXiv 2412.04614](https://arxiv.org/abs/2412.04614) v3，[代码](https://github.com/jiahai-feng/extractive-structures)），2026-10-11已读正文与附录A–I。研究对象是上下文外推理（out-of-context reasoning）：只微调一条事实，模型能否回答由它推出的两跳问题。
- **设定。** 主要模型为OLMo-7B退火前的最后一个检查点，另在Llama 3-8B、Gemma 2-9B、Qwen 2-7B上重复。20个虚构人名与20个城市配对，组成两个数据集：
  - FIRST-HOP（新事实作第一跳）：训练“[人名] lives in → [城市]”，测试“The people in the city [人名] is from speak → [语言]”；
  - SECOND-HOP（新事实作第二跳）：训练“The mayor of [城市] is → [人名]”，测试“The mayor of the city that contains [地标] is → [人名]”。
  - 只在答案token上计交叉熵，冻结embedding与输出层，Adam，学习率3×10⁻⁶，8个epoch，batch 8。指标是正确答案首token在20个候选中的平均排名（随机约9.5，0为全对），不是准确率。
- **框架。** 信息组件以权重变化存储新事实；上游抽取组件处理输入，去查询信息组件；下游抽取组件把查到的结果加工成答案。三类组件各用一种权重或激活替换干预定义分数，再线性化为“梯度×变化量”；信息分数与按组件计算的influence function相关。
- **定位。** FIRST-HOP的信息分数集中在头实体token上的早中层MLP，下游分数在最后一个token的晚层MLP与attention；SECOND-HOP的上游分数在头实体token的早中层MLP，信息分数在最后一个token的晚层。attention头也存储事实信息。
- **冻结与恢复。** 模型共32层，“早”指前24层，“晚”指后8层。下表为平均排名（事实/推论）：

| 微调时冻结 | FIRST-HOP | SECOND-HOP |
| --- | --- | --- |
| 不冻结 | 0.00 / 0.00 | 0.00 / 1.80 |
| 前24层 | 0.00 / 6.50 | 0.00 / 0.50 |
| 后8层 | 0.00 / 0.10 | 0.00 / 6.60 |
| 全部 | 9.20 / 9.25 | 9.10 / 9.50 |

- **恢复实验（附录E）。** 先全层微调，再把某段层恢复为原权重。恢复前24层时，FIRST-HOP为5.10/8.40，SECOND-HOP为0.95/1.85；恢复后8层时，FIRST-HOP为0.00/0.00，SECOND-HOP为0.10/6.30。作者的结论是：事实冗余地存于多层、以早中层为主；早层支持第一跳泛化，晚层支持第二跳泛化；编辑应改每一层。
- **抽取结构的来源。** 作者假设：预训练中遇到已知事实的推论时，模型学会从权重中抽取该事实。用虚构关系做继续预训练检验：事实与推论混合或事实在前时，留出人名上的推论泛化明显好于推论在前。推论在前仍有少量泛化，作者承认另有未知机制。把“学推论带来的权重变化”嫁接到只学了反事实的模型上，反事实推论的排名从9.13降到1.13（对照8.38）；但也带出了原推论（3.30），说明其中部分是记忆。
- **稳健性。** 效应对学习率敏感：OLMo在3×10⁻⁶最好，10⁻⁵明显变差，3×10⁻⁵不稳定；正文主要报告效应可靠出现的学习率。其他三个模型效应更弱、更依赖超参数，嫁接时更多带出原推论。下游分数与信息分数两种定位的相关很弱（r²：MLP .10，attention .07）。

| 该文结论 | 本项目对应证据 | 本项目的贡献 |
| --- | --- | --- |
| 写在早中层只支持第一跳推论，写在晚层只支持第二跳推论（冻结与恢复实验） | Wang设定中标准8层IO≤4.10%，Loop 4×2为83.83–95.63%；[理论§14.6式(32)](memory-scaling-theory.md#untied-second-hop-kernel-20261010) | 给出层范围条件的形式推导：各层独立时，单跳写入只能经由第一跳完成之后的执行传给第二跳。并在真值已知的受控设定与参数共享模型中检验；该文只有预训练大模型上的描述性证据 |
| 冻结早层后SECOND-HOP推论反而改善（1.80→0.50） | 编辑训练目标：监督早期状态使传播从3.12%升到68.75%，再加表示对齐为85.42% | 写入落在哪里可以由训练方式引导；对应写入侧方法与编辑写入范围实验 |
| 单跳改写在任何层都能成功，多跳泛化取决于写在哪层；建议编辑每一层 | 强组合起点模型上原子编辑100%成功，依赖它的多跳答案只更新4.08% | 第三层：回应Hase & Bansal 2023“定位不指导编辑”。他们测的是单跳改写是否成功，本项目测编辑后的多跳使用 |
| 早中层写入只服务第一跳 | MQuAKE中第一跳编辑优势ROME/MEMIT为25.34/24.15个百分点；两种方法沿用MEMIT仓库GPT-J的默认超参数，ROME改第5层、MEMIT改第3–8层MLP（共28层） | 给预注册的跳位差一个层位解释（事后解释）；可用改晚层的编辑检验（[单列候选](#nl-edit-layer)） |
| 抽取结构需要事实先于推论出现（数据顺序效应） | 顺序知识注入：先学组合再学新事实20.57%，联合训练23.18%，原子重复3.12% | 区分读取路径的形成与路径形成之后的写入（[§1.2](#pretraining-continual)） |
| 不涉及参数共享；没有区分新增与改写 | — | 循环模型、梯度池化比例与通道条件下的编辑传播；带旧答案竞争的改写与同答案对照 |

**对本项目主张的潜在反例。**
- **各层参数独立的模型，也能用单跳写入完成部分第二跳。** 只微调单跳事实，SECOND-HOP推论的平均排名为1.80，远好于随机。[§1.1](#path-consistency)“标准Transformer中只受原子训练的事实难以作为第二跳被组合”须限定为从头训练（Wang设定IO≤4.10%）。可能的解释是预训练已形成单跳查询与第二跳共用的晚层读取路径，这正是[§1.2](#pretraining-continual)中预训练状态与持续学习状态的区别；也不排除下文的答案单元解释。论文须正面讨论这一差别，不能把从头训练的结论直接推到预训练大模型。
- **一次写入在多层留下副本。** 假说不能表述为“事实只存在一处”，准确说法见[§1.1](#path-consistency)。这也给路径重合干预实验带来风险：消融一份副本可能被其他副本补偿（见[§5.0.1](#zhang2026-next)）。
- **数据顺序效应与替代机制。** §1.2“新事实能否被用主要看训练情境，与训练阶段无关”只适用于读取路径形成之后。推论在前仍有少量泛化，其他模型中两种顺序有时相近，说明路径一致性不能宣称是唯一机制。
- **标准模型的双重分离已有先例。** 编辑传播实验中“标准8层只改下层或只改上层”一臂的预测，方向上已由该文的冻结实验在预训练大模型上给出。这一臂在本项目中是受控复核；新增在于循环模型、梯度池化比例与通道条件，带旧答案竞争的改写，以及真值已知的设定。

**该文的局限（本项目可以补上的地方）。**
- **跳位与“改写还是新增”混在一起。** FIRST-HOP的人物全新，属于新增；SECOND-HOP把真实城市的市长换成虚构人名，模型多半原本知道真实市长，实为改写。末层的“存储”也可能是[理论§14.6](memory-scaling-theory.md#untied-second-hop-kernel-20261010)所说的答案单元：把旧市长名统一映射为新名字，任何以旧市长为答案的查询都会改变，而不是针对这条事实的第二跳查表。该文没有同答案对照；本项目的受控设定可以用同答案对照区分这两种机制。
- **规模与指标。** 每个数据集20条事实、20个候选，用平均排名；SECOND-HOP只部分泛化，换算成准确率时可能不高。
- **按结果选配方。** 学习率按效应能否出现来选择（附录H）。
- **定位指标一致性弱。** 两种定位分数的相关很弱（r² .07–.10）。
- **细节。** 早、晚层划分不对称（24/8）；图5图注把SECOND-HOP的信息组件写成最后一个token处的早中层MLP，正文写的是晚层MLP；虚构关系在正文称wug，附录模板为zong。

**对本项目实验设计的影响**（逐项写入[§5.0.1](#zhang2026-next)）：路径重合干预实验先只做选择阶段，统计可用事实；编辑传播实验补全层更新的标准模型、同答案对照、事后恢复分析与分级指标，并按编辑成功、保持选择学习率；凡需要先形成读取路径的设计，都让事实先于组合出现或与组合同时出现（[§1.2](#pretraining-continual)）。

### 1.2 预训练与持续学习：同一写入过程的两种状态

2026-10-09用户采纳[§1](#question)的统一表述，本节据此从持续学习（continual learning）的角度看三个层次。核心主张是：**一个事实能被哪些使用方式使用，主要由它被写入时的训练情境决定，而不是由它在哪个训练阶段到来；同一份“训练情境与使用方式的重合”同时决定前向迁移和对旧用法的干扰。** 这是待检验的主张，不是已建立的结论。

| 状态 | 读取路径 | 训练情境 | 本项目对应的实验 |
| --- | --- | --- | --- |
| 预训练（从头训练） | 与写入一起形成：数据覆盖哪些使用角色，就形成哪些读取路径 | 宽：多种问法、多个角色、交错出现 | 合成知识图与真实知识图的从头训练、grokking长训练、bioS |
| 持续学习、微调与编辑 | 大体已经形成 | 窄：原子陈述、单一模板、单个编辑；测试时训练只用单个样本，是最窄的一端 | 顺序知识注入、编辑训练目标比较、强组合起点模型上的编辑、MQuAKE与RippleEdits；跨样本的测试时训练写入待检验（[§4](#updating)） |

**两种状态中成对出现的现象。** 下表每一行是同一机制在两种状态下的表现。

| 现象 | 预训练状态 | 持续学习或编辑状态 |
| --- | --- | --- |
| 写入只落在单跳路径上，第二跳读不到 | Ye §2.4复现：只作第一跳的事实单跳约99.8%，作第二跳只有2/3000；标准8层模型IO≤4.10% | MQuAKE中后续跳编辑比第一跳编辑低约25个百分点（两种编辑方法）；部分记录预览中，后续跳编辑后直接回答仍更多给出旧答案（两跳ROME 87/300对第一跳12/213，MEMIT 119/300对27/213），待MQuAKE旧答案残留分析正式读出 |
| 把训练情境改到使用路径上即可改善 | 组合训练经历：同组留出组合100%，同样次数的原子重复只有25.01% | 编辑训练目标：最终答案交叉熵→早期桥实体监督→再加表示对齐，依赖被编辑事实的多跳答案从3.13升到68.75、85.42% |
| 参数共享使原子训练的写入在第二跳也可见 | Loop 4×2的IO为83.83–95.63% | 小模板两层模型的第二跳编辑：有组合经历的事实标准模型33%、循环模型63%；只受原子训练的事实13.89/58.33%（每格2个事实，仅为先导）。待检验：同一循环模型内只更新第一次或第二次迭代的参数副本，传播是否随之分离（编辑写入范围实验） |
| 桥实体位置的表示格式对上后，原子写入可被下一跳直接读取 | 小型参数共享模型表示对齐后12.6→92.3%；DiscoLoop两次迭代之间解码—再编码使OOD从8.3升到约97%；Wang原规模循环模型中，把输入embedding分量换成另一桥实体并加倍，OOD第一跳题目转向87.6–98.8% | 没有通道的参数共享块中，第一次迭代的桥实体解码被编辑翻转，是第一跳编辑传播的必要条件（编辑训练目标的逐编辑再分析）。待检验：通道条件下第一跳与第二跳编辑的传播是否对称；顺序知识注入中新实体从未作过桥实体，通道能否免去它的表示格式学习（须单token实体） |
| 表达多样使写入落在与问法无关的位置 | bioS三种数据组织的标准问法5.07/35.65/99.96%，留出问法0.57/14.06/32.90% | MQuAKE部分记录预览：填空模板写入成功后，用问句检验ROME 87.8%、MEMIT 54.3%答对（MEMIT后续跳编辑37.7%）；受控的顺序知识注入批次训练与评测用同一个模板，须在实验主机的训练终点上补测留出问法 |

**训练阶段与训练情境。** [顺序知识注入实验](results.md#sequential-transfer-v1)中，新知识只以原子事实训练。新—新组合在三种训练历史下为：先学组合再学新事实20.57%、相同样本打乱后联合训练23.18%、先做原子重复再学新事实3.13%。也就是说，读取路径先由旧知识的组合训练形成之后，新事实无论晚到还是与旧知识交错到来，被使用的程度相近；没有组合路径时接近地板。限制有三点：顺序训练条件在学新事实之前，新—新组合已有14.32%，学新事实只净增+6.25个百分点；联合训练减顺序训练的六组配对为三正、两零、一负；每格只有64题，只能看方向。旧用法受训练时机影响：联合训练的旧—旧组合为46.61%，顺序训练为30.47%，原本答对的旧—旧组合只保留64.78%。目前较准确的表述是：前向迁移主要看训练情境，干扰受训练时机与回放影响。

**迁移与干扰同源。** [编辑训练目标比较](results.md#write-target-editing-v1)的三种目标中，传播越好，起点模型原本答对的分布外组合保持得越差（96.57→92.52→89.96%；各自只复习不编辑的对照为98.94/97.28/99.11%）。写到被复用的路径上，既让已有用法接上新事实，也改动了这些用法；这是持续学习中稳定性—可塑性权衡在路径层面的表述。[逐编辑再分析](results.md#write-target-per-edit-20261010)把它分成两层：
- 同一个案例换用不同训练目标时，传播高的目标损伤也高（62个非并列配对中60对同向）。
- 同一训练目标内，传播多少与损伤无关（中心化后ρ=−.09）；损伤随更新幅度增大（目标内ρ=.26/.67/.57）。

因此“同源”成立在“写到哪里”这一层；单次编辑损伤多少主要看更新的大小，而不看它传播了多少。每次编辑只有4道依赖题，只有三个知识图，须在编辑传播实验中按被编辑事实所在的跳复核。

**可推广的推论（都待检验）。**
- 微调注入的新事实，只在写入时用过的问法与角色上可用。
- 反向查询（由尾实体问头实体）是另一条使用路径。
- 只在一种问法上做遗忘（unlearning），事实仍可能经组合或其他问法被使用。
- CoT与检索把隐含的桥实体变成显式token，等于把读取引回原来的写入路径；MQuAKE中ROME部分支持，MEMIT不支持。
- DiscoLoop两次迭代之间的解码—再编码是同一操作在受控模型中的内部版本，OOD从8.3升到约97%。自然语言模型中显式写出桥实体只部分有效，原因可能是编辑只覆盖了部分问法的读取路径（显式写出桥实体之后的问法没有被覆盖），也可能是第一跳组与后续跳组的案例构成不同，须分开检验。

**边界。**
- 不改写成以遗忘基准为中心的持续学习论文。主证据是新知识接入已有用法的前向迁移，遗忘作为干扰的一面报告。
- 本项目的“预训练”是带答案监督的合成或真实三元组从头训练，不等于自然语料上全token的预训练。
- [Feng等](#feng2025)（已精读）在继续预训练中显示数据顺序效应：事实与推论混合或事实在前时才学到抽取结构；推论在前只有少量泛化，作者承认另有未知机制，其他模型中效应更弱。因此上述“与训练阶段无关”只适用于读取路径形成之后。凡需要先形成读取路径的设计（顺序知识注入、[§1.4](#innovation-rnn-ttt)的写入训练、[§5.0.3](#controlled-multihop)的组合操作学习），都让事实先于组合出现或与组合同时出现。
- 经验NTK的一阶描述不覆盖预训练中的路径形成。“与训练阶段无关”目前只有一个真实知识图的三个划分，功效不足。

**持续学习一侧的文献。** 下表已核对标题与摘要；除Feng等已精读（见[§1.1](#feng2025)）外，方法与附录待读；按[先复现论文](#paper-reproduction-first)的原则，读完再决定复现哪个关键比较。

<a id="wang-benchmark-boundaries"></a>
### 1.3 Loop能力的证据边界与主实验可行性复核（2026-10-11）

用户先指出细项不能承载主线，随后要求判断Loop是否有支持“知识变化后自然泛化”的特殊性质。**本轮判断：Loop为形成可重复的计算提供结构与训练偏置，但未保证更新后的事实能被这些计算正确使用。** 上一轮把静态组合的证据推进到顺序新增、事实改写及再学习成本，跨度过大；撤下这一中心推荐，不把缺少依据的正向收益当作论文前提。

**三种性质须分开。** 同一参数函数被反复执行、各次执行的梯度向共享参数汇总，是架构与求导的性质；学成可重复的事实读取操作，是训练结果；事实新增或改写以后仍正确执行这一操作，还要求更新真正改变组合所读取的事实，并保持交接、关系选择及后继知识。前一种不推出后一种。

**DiscoLoop直接支持什么。** [§2–5及附录A.2](https://arxiv.org/html/2607.00341v2)在固定知识世界上混合训练A/B全部原子事实与A的组合，B的知识从训练开始就在场。普通Loop一轮原子准确率100%、中间实体几乎完全可解码，OOD组合却只有8.3%；交接干预显著修复，作者通道训练提升静态组合及学习效率。这支持“共享参数仍不足，交接可以成为瓶颈”，不建立训练结束后新增B、改写旧事实或保持旧能力的结论；三跳结果也不等于任意链长外推。DiscoLoop的额外通道是显式设计，不能称为普通Loop自然保证的性质。

**权重绑定论文支持到哪里。** 依[项目既有阅读记录](#weight-tying-pooling)，该稿研究上下文中的指针图，改变梯度汇总方式来解释可重复操作怎样形成。换图改变的是输入；本项目新增或改写参数知识改变的是参数，两者不能直接等同。它提供训练机制的研究支点，没有提供参数知识更新的成功保证。[OpenReview原始链接](https://openreview.net/forum?id=vJgG20sjea)已定位，PDF已加入仓库（`papers/34319_How_Weight_Tying_Elicits.pdf`）；相关方法细节尚未按该文件重新核实。

| 候选假说 | 目前依据 | 主实验判断 |
| --- | --- | --- |
| 已学原子事实可复用于未训练的多跳组合 | DiscoLoop有直接支持；[Kohli](https://arxiv.org/html/2604.07822v2)及本项目长训练也有条件性支持 | 可以承载组合层主实验，采用作者已验证的训练前提 |
| 推理训练完成后，后来学入的事实自然进入组合 | 静态OOD不检验这一点；[项目顺序学习](results.md#loop-kv-learning-v1)尚无稳定Loop优势 | 有研究可能，但先作为迁移检验，不押注正向收益 |
| 只改对原子答案，所有多跳后果自然改变 | [Niu](https://arxiv.org/html/2606.20737)有低传播反例；[项目强组合起点](results.md#write-target-editing-v1)同样显示原子写入与组合传播分离 | 不宜作为当前中心的正向承诺；第三层独立检验更新是否进入实际读取过程 |
| 增加Loop次数即可外推任意链长 | Kohli的外推依赖课程和训练迭代条件；项目也观察到过度执行退化 | 有条件边界，不把加迭代视为保证 |

**自然传播何时才有逻辑依据。** 若各步骤确实调用同一个单跳事实函数，并将结果交接成下一步可读的输入，更新又确实改变该函数在目标事实上的返回值、保持后继事实与操作，则可以逐步推得新的多跳答案。这是条件命题；原子查询的最终答案改对不证明这些条件成立。参数共享只为它们提供可能，不替代核查。

**对主实验的修正。** 保留三个知识层次及路径一致性工作假说。机制问题先落在“重复计算何时真正成为可重复的事实读取”；已有静态组合、作者关键比较与已冻结零训练读出提供依据，新增事实和改写事实分别检验其迁移与更新边界。上一轮[组合再学习开销方案](#controlled-multihop)保留为待审候选，不作为当前主线。缺少已有论文的直接结论不等于新假说不可能成立，但此处既缺直接支持又有反例，不能依靠Loop名称押注。没有新训练、编辑或梯度网格进入队列。

<a id="innovation-rnn-ttt"></a>
### 1.4 RNN、TTT与创新候选：写入后能回答的知识，怎样成为可复用的知识？（2026-10-11）

**RNN联系的用途。** RNN沿输入时间更新隐藏状态，Loop主要沿计算深度更新当前输入的隐藏表示；[Huginn §3](https://arxiv.org/html/2502.05171v2)明确采用深度递归与截断反传。TTT还可把可更新参数作为状态：新材料到来时更新它，后续查询读取它。应分清样本之间保留的知识状态、单个问题里的推理状态、固定的读取参数。用完整Transformer块记作H^(k+1)=F_θ(H^k; S_n)，用实际优化器记作S_(n+1)=Update(S_n, d_n; φ)；F保留attention、归一化、残差与MLP，S包括必要优化器缓冲。两个状态转换不是等价计算，也不保证知识自然复用。

**最接近的原方法。** [PERK §3–4、附录B](https://arxiv.org/html/2507.06415v3)冻结底座，内层通过材料的语言模型损失更新LoRA，外层依据没有原文的后续QA学习适应初始化等参数，已测单/两/三跳与多文档QA；[uTTT §2–3](https://arxiv.org/html/2610.05484)保留各层独立骨干、共同读写快权重，未来任务梯度穿过先前写入，序列间重置。因此，“用未来用途训练写入”“共享快记忆”“Loop加TTT”“跨样本保留更新”均不能独自作为创新。uTTT的RULER也含多跳QA；现有工作不能被概括为只测记忆而没有推理。

**拟检验的机制观点。** 同一知识状态能被访问，仍须实际读取操作把它用于新组合。候选问题是：**在所有步骤已经能访问同一份可写记忆时，写入训练与反复执行的读取计算，分别怎样使新事实进入未训练过的多跳用途？** 创新须体现为这一关系的成立条件、反例及干预证据，而非模块组合或新实验名称。Loop只是检验重复读取计算的条件；它有没有额外作用须允许答案为否。该问题是路径一致性的具体化，尚未建立为新贡献。

**最小受控比较草案。** 用一个可学习写入过程及一份共享知识状态，两种reader都能访问该状态；否则比较会混入uTTT已经研究的记忆所有权差别。

| 读取计算 | 写入过程按更新后的原子回答训练 | 写入过程按更新后的组合使用训练 |
| --- | --- | --- |
| 各层独立的Transformer读取，共同访问知识状态 | 原子用途对照 | 检验未来用途训练 |
| Loop重复读取，共同访问相同定义的知识状态 | 检验重复计算 | 检验两者共同作用 |

同一行从同一reader起点出发，固定读取骨干、快权重初态及可写参数范围，以相同的写入控制参数比较两种外层评价目标；不能让一列额外学习推理骨干或初态后，把收益全部归于写入。可继承PERK附录B的token权重与学习率控制，具体范围仍须校准。训练世界的未来查询可提供外层反馈；部署时写入只接收事实材料，不接收未来问题或答案；查询阶段只读。具体fast-state实现需按原方法与共享状态条件校准，不能把改造模型叫作原论文复现。两列的监督信息不同，正是处理变量；匹配事实来源、样本流及读写预算，并分别记录外层标签、token与计算。两行还须披露总/激活参数差别，不把同展开深度当作全预算相等。

**数据与主要结果。** 受控部分保留知识图查询，训练与评价世界/事实绑定留出，在同一知识流上分别测学入事实的回答、新事实与已有事实组成的未训练链、改写后的后果及旧能力保持。第一层仍保留独立的知识形成与提取证据。少量链长是复用负载，reader须已有对应组合操作的训练支持；图上真值与评价隔离是有效性要求，跳位等细项是解释性消融。材料跨样本处理时重置attention/KV与推理状态，仅保留约定知识状态；跨文档分段本身不算创新，因为已有长上下文TTT也使用分段写入。

**结果如何改变观点。** 两种reader都因组合用途训练而同样改善，只支持训练目标的作用；Loop没有额外收益，就撤回重复读取计算促进迁移的猜想。仅训练过的用途提高，不算通用写入；无关组合明显受损，须报告迁移与保持的代价。若有留出用途上的差异，再用实际读写干预解释，架构排名本身不是机制。先复现最接近的原比较，再校准上述最小实验；优先候选为PERK Figure 3的GPT-2/BabiLong QA2条件，作者代码、数据、评分与配方须再核定，本轮没有执行授权。

**历史去重。** 已有顺序学习、knowledge-change及write-target证据继续使用。knowledge-change适应临时改写的MLP，write-target手定早期实体目标，均未按PERK方式穿过事实写入的更新过程学习可迁移写入参数；这是实际不同的训练条件，但元学习本身已有先例。仅把旧原子微调改名TTT或将旧首/次跳矩阵搬过来，不回答本节问题。此处是用户要求讨论的研究候选，不是已采纳路线、冻结矩阵或独立方法论文。

<a id="recall"></a>
## 2. 第一层：知识怎样被学会并回答

**主要问题。** 同样的事实，在什么训练条件下能被稳定记住，又能被不同的查询提取？存储失败、问法不适配、提取失败要分别解释。

已有材料：[bioS学习与同一权重的提取诊断](results.md#bios)、[原子事实学习与知识量控制](results.md#capacity-scaling-development-v1)、[曝光与复习控制](results.md#capacity-recall-controls-v1)、[组合训练支持与知识量曲线](results.md#composition-data-curves-v1)，以及[实体表示与第一跳出度实验](results.md#realworld-loop-diagnosis)。这些材料独立论证第一层，而不只是用来筛选“事实全会”的模型。

**目前可以建立的认识。** 事实能否学会、能否被提取，受训练内容、表达方式和训练预算影响；固定预算下的失败不能自动归为存储上限。新的知识量曲线中，四层模型在每条事实4000次曝光下，知识量N=128/256/512/1024时原子事实平均准确率为100/99.97/92.27/60.86%（组合方面的变化见第二层）。这里测量的是特定任务与训练流程下的行为，还没有解释唯一的存储机制。

**两张主图的数据已经有了，不需要新训练。** 原子事实掌握随知识量变化的图已在[组合训练支持与知识量曲线](results.md#composition-data-curves-v1)中画出（每条事实4000次曝光，N=128→4096时为100→2.41%）；随曝光次数变化的图可由同批38条运行的全部检查点直接画出。问法迁移的同一权重比较已由[bioS同一权重诊断](results.md#bios-same-weight)完成：它比较的是同一组权重在不同问法下的表现，避免把两次不同微调得到的模型差异说成“知识存了却取不出”。

**“固定目标事实及其曝光，增加真正学会的背景事实”已部分完成。** [标准Transformer知识量批次](results.md#standard-storage-composition)固定共同必要原子事实的曝光，把多出的位置换成新事实；知识量从1024增到6144时，必要原子事实仍接近100%。更高知识量只有[早期开发](results.md#capacity-scaling-development-v1)，而那里背景事实本身没有学会（总量4096/16384时全部原子事实为74.46/7.54%），不能称为“记忆拥挤”。

**第一层仍开放的问题。**
- 按训练格式定位单跳事实写入在哪些层。bioS没有探针或层位实验，可以在实验主机的已有检查点上零训练完成。
- 问法迁移已在固定核下推导（[理论§14.7](memory-scaling-theory.md#form-transfer-20261010)）：重复同一问法不提高换问法后的提取，只有互不相关的问法才提高；多样表达是否使表示本身更与问法无关，仍然开放。
- 参数量、词表、目标查询和预算逐项记录，不把“更多数据”直接当作“更多已存知识”。

**机制解释。** 用假设明确的联想记忆模型解释查找键、响应与干扰，再用必要的参数或状态干预检验它与行为的联系。研究MLP的作用，同时允许embedding、attention及它们的协作承担知识，不预先规定模块分工。回答只要求正确答案的logit间隔足够大（[理论§13.1](memory-scaling-theory.md#pretraining-implicit-alignment-20261004)），不要求隐藏状态处于后续计算能读取的表示格式；这是第一层与第二层分离的一个直接来源（[理论§13.6](memory-scaling-theory.md#discrete-handoff-20261009)）。

<a id="composition"></a>
## 3. 第二层：已掌握的知识怎样被组合

**主要问题。** 单跳掌握程度相当时，是什么使事实能在没有训练过的组合中被连续使用？要区分两种情况：“有组合训练经历的事实组成的新组合”（分布内组合），和“两条事实都只受过原子训练”的分布外组合。

| 已有关键比较 | 主要观察 | 对解释的约束 |
| --- | --- | --- |
| [组合训练经历](results.md#grok-usage) | 同组留出组合在三种训练下：做过组合练习100%，同样次数的原子重复25.01%，只有基础单跳3.01% | 使用情境的作用超过单纯的事实重复；监督与上下文的差异须写明 |
| [小型参数共享模型的表示训练](results.md#representation-alignment) | 第一跳标签相同时，加表示对齐使分布外组合从12.60升到92.32% | 训练表示可以改变跨事实的使用，但还不能唯一定位到MLP |
| [小型标准两层模型复核](results.md#independent-alignment-v1) | 分布内组合从16.76升到55.88%，分布外组合只从2.96升到5.27%，而状态方向余弦已达.9997 | 对齐有作用，但输入方向接近不足以保证分布外组合 |
| [长时间自然优化](results.md#grokking-reproduction) | 特定循环模型配方较晚出现分布外组合，已测最强终点81.34% | 显式对齐不是唯一的成功途径；单个知识图的历史结果不能当作普遍规律 |
| [跨迭代KV读取与残差结构比较](results.md#shared-cache-branch-v1) | 跨迭代KV读取提高分布内组合，分布外组合仍低 | 某条通路被使用，不等于跨事实的调用已经形成 |

已有实验组织为三个比较：使用经历、表示、共享访问，统一展示原子事实与组合结果。前两组可以完全由已有批次组成。共享访问一组还缺“同一知识图、同一参数规模下的表示对齐×参数共享”配对：现有的小型参数共享模型有260,608个参数，小型标准两层模型有458,880个参数，知识图也不同，不能只凭分数差把效应归于参数共享。10-10曾建议在Wang设定补齐这一格；当前按[三项主实验](#controlled-multihop)统一底座、选择必要比较，不另启动完整对齐×共享网格。

**机制解释。** “中间实体可以解码”、“该状态能驱动后续计算”、“参数更新能改变这种使用”分别提供不同层级的证据。直接针对后续关系的行为干预，优先于继续增加余弦或探针。标准Transformer也能成功的条件、循环模型失败的条件都要进入解释。能解码而不能使用有了理论上的形式区分（[理论§13.6](memory-scaling-theory.md#discrete-handoff-20261009)）：解码是对每个候选实体逐一比较的间隔条件；使用则要求所有实体方向上的串扰之和不超过原子查询的间隔。在叠加表示（superposition）中两者一般不等价。已有比较按[§1.1](#path-consistency)的三个前提组织：层范围（标准模型与循环模型）、逐跳完成（标准交叉熵训练与第一跳辅助损失）、表示格式（有无表示对齐、解码—再编码）。

<a id="updating"></a>
## 4. 第三层：知识变化后怎样继续使用

**主要问题。** 模型是否形成了能接纳知识变化的调用方式？新增事实与改写旧事实分开检验：前者测已有能力能否迁移到新知识，后者还涉及旧答案的竞争和更新范围。按[§1.2](#pretraining-continual)，这一层是“读取路径已形成之后的写入与使用”问题：依赖新事实的多跳使用测前向迁移，旧用法的保持测干扰，两者由同一训练情境决定。

**关键现象已经建立。** 在[强组合起点模型上做原子编辑](results.md#memory-interface-next)：起点模型做过表示对齐，原子编辑100%成功，无关原子事实保持99.76%，但依赖被编辑事实的多跳答案只有4.08%更新；编辑前能答对的多跳题占93.72%。因此接下来不再把“在更强的起点模型上做普通原子编辑”当作未做过的先导。

[知识变化训练](results.md#knowledge-change-v1)已在三个新知识图上完成。这一实验在训练中临时改写事实，并在用到被改写事实的查询上训练（changed_use条件），与不改写事实的训练（fixed条件）对比。对带跨迭代KV读取的模型，前者使有组合经历的第一跳事实的编辑传播均值从14.58%升到31.25%，但三个知识图分别为0→0、18.75→18.75、25→75%，收益全部来自第三个知识图；第二跳编辑的传播仍是0。保留这一有限的正信号，下一轮不根据平均值自动扩大动态训练矩阵。

本轮两项直接比较补上了正面证据：
- [顺序知识注入](results.md#sequential-transfer-v1)：先学组合再学新原子事实时，新—新组合为20.57%；只做原子训练的对照为3.12%。两者的新事实单跳准确率都是100%。
- [编辑训练目标比较](results.md#write-target-editing-v1)：对同一个新实体标签，监督早期状态使传播从3.12%升到68.75%，再加表示对齐后为85.42%。

两项都伴随旧组合能力的损伤。当前证据支持“使用经历与写入方式能改善新内容的使用”，但还没有同时解决旧能力的保持。

**机制解释。** 先区分三种失败：事实没有写进去、原有的组合能力被破坏、更新没有被已有的调用使用。这三类前提分别测量，不能把所有低传播都统称为接口失败。DiscoLoop通道可改善中间实体的交接，但关系状态与其他上下文仍可改变读取；[理论§13.6](memory-scaling-theory.md#discrete-handoff-20261009)关于查询一致和传播对称的推导只在(A1)(A2)条件下成立，不能直接视为实际模型保证。没有通道的参数共享块已有逐编辑证据：编辑训练目标实验中，翻转了第一次迭代桥实体解码的48次编辑全部有传播（148/192），没有翻转的24次合计3/96，与只复习不编辑的对照同级。但翻转并不充分（48次中只有20次依赖题全对），而且是否翻转与训练目标完全混在一起（[再分析](results.md#write-target-per-edit-20261010)）。参数共享意味着每次编辑改变各次调用的同一参数，不保证每次调用的效果相同；[旧更新可见范围提案](#zhang2026-next)与[本轮创新候选](#innovation-rnn-ttt)须依此解释。

**测试时写入（2026-10-11复核旧跨样本TTT提案）。** 10-09曾提出：只对事实材料做少步自监督更新，保留参数到后续样本，测试事实的组合使用。它仍属于第三层的写入情境，但跨样本持久化并非TTT的统一定义，也非新方法；理论的局部跨调用关系与(A1)(A2)不保证动态组合成功。

本轮核对的正面近邻包括：[PERK](https://arxiv.org/html/2507.06415v3)已用材料CLM写入LoRA、丢弃原文，再做单/两/三跳与多文档QA；[uTTT](https://arxiv.org/html/2610.05484)已跨时间/深度共享快权重，并通过后续任务训练读写；[SEAL](https://arxiv.org/html/2506.10943v2)还评估连续更新与旧能力保持。因此撤下“已有方法都没有检验组合使用”的笼统判断，不把划分样本边界当作新颖性。普通Loop在[Niu](https://arxiv.org/html/2606.20737)的局部编辑与[He、Mian等](https://arxiv.org/html/2601.09049)的新事实迁移中仍有失败证据，不能由这些负结果断定唯一瓶颈。

TTT在本轮的价值是提供有文献依据、可操控的写入与后续读取过程；拟解释共同知识状态下的训练目标与读取计算，见[§1.4](#innovation-rnn-ttt)。先复现最接近的作者比较，再决定受控扩展；新颖性与方法收益仍待检验，旧首/次跳传播对称预测不作为默认主实验。

### 5.0.1 10-10未执行候选与方法依据

本节保留旧提案的具体方法与来源，供解释主结果时选用，不构成默认训练队列。当前优先级由[§5.0.3](#controlled-multihop)的主实验决定；完整起点模型族、两跳跳位矩阵及多种损失比较不自动启动。已冻结的零训练Z1继续按原契约执行。

[Zhang等](#zhang2026)与本项目用同一个Wang原始知识图，已有[grokking-reproduction-v1](results.md#grokking-reproduction)的标准8层与Loop 4×2共8条1.5M步轨迹，每条保存14个权重检查点。因此先在已有权重上做零训练检验，再按该文方法续训，最后做本项目的扩展。[DiscoLoop](#discoloop2026)的两次迭代之间的干预可以直接移植到同一批循环模型权重上：它的模板与Wang相同（原子事实`<h><r><t>`、两跳`<h><r1><r2><t>`），GPT-2使用绑定embedding，Loop 4×2的第一次迭代末就是第4层输出。[权重绑定论文](#weight-tying-pooling)的部分池化与共享模式比较搬到同一主设定上（[§5主设定](#main-setup)）。路径重合干预实验只读权重、不训练，权重在实验主机上；其余各项需要新训练或续训，按[§5的优先级](#next-experiments)须用户授权，并另写预注册计划。

**路径重合干预实验（契约编号Z1；[§1.1可测定义](#path-consistency)的首次直接检验）。**
- 问题：同一事实被单跳查询时因果必需的成分，是否也是它作第二跳时必需的成分？
- 做法：在8条运行的14个检查点上，先按Zhang等的作者脚本移植三种分析：滑动窗口注意力遮蔽（附录E）、层×层余弦（附录G）、桥实体activation patching（§4.2）。再对事实f=(b, r₂)，在单跳查询中找出它的选择性必需成分（层×位置的注意力边、块内的MLP单元），把同样的参数级消融分别只施加在两跳查询的第一次或第二次迭代上（标准模型施加在同一层），测f作第二跳时II/IO答案是否改变。对照为同规模的随机消融，以及无关事实的保持。
- 预测：路径一致性预测，在循环模型中，f的单跳必需成分只在第二次迭代被消融时破坏它的第二跳使用；在标准模型中，ID事实作第二跳的使用不受其单跳路径消融的影响（上层另有一份）。如果循环模型IO成功而消融不转移，路径一致性被否定，循环模型的收益另有来源。
- 成本与前提：零训练；需要实验主机上grokking-reproduction-v1的权重。
- 执行前的可行性检查（2026-10-11按[Feng等](#feng2025)补充；冻结契约未修订）：
  - 风险：事实若在多层冗余存储，消融其中一份会被其他副本补偿，冻结计划中“能翻转单跳答案的最少单元数”可能不存在（记为未定位）。有功效的检查点不足半数时，判读为无法判定。另外，本实验只消融MLP神经元，而该文发现attention也存储事实。
  - 做法：冻结计划规定选择阶段只用单跳查询、从不使用两跳结果。因此先在全部检查点上只执行选择阶段，统计每个检查点有选择性的事实数与未定位比例。若有功效的检查点不足半数，在计算任何两跳结果之前写出修订（例如加入attention输出单元或成组消融），并记录时间。
  - 代码：尚未提交的运行代码（`scripts/run_zero_training_path_format.py`、`src/llm_memory_editability/path_format.py`及其测试）仍指向不存在的`configs/zero-training-path-format-v1.json`，并含已撤下的桥实体格式检验。上机前须对齐到现行契约`configs/zero-training-path-overlap-v1.json`。

**桥实体格式检验（契约编号Z2；2026-10-10撤下）。** 原计划在同样8条×14个检查点的第一次迭代末做解码—再编码与同一桥实体放大。撤下原因见下段。

**Zhang等读取侧修复的复现（该文§5.1与附录H.1，契约编号R1）。**
- 问题：“上层缺第二跳查表”在本项目实现中是否复现？
- 做法：以标准8层模型φ7.2、权重衰减.1的1.5M步权重（II 99.77%）为起点模型，按作者附录F的多轮流程：先常规训练维持能力，再把OOD原子事实以第5层的表示（e、r的均值表示）送入第6层，训练第6–8层；附录H.1的变体改为把原子事实的embedding送入上层。报告II/OI/IO/OO学习曲线。
- 预测：IO/OO应明显提高；H.1变体的OI应下降（该文约6%）。
- 成本与前提：约8k步续训。该文的前提是起点模型的OI已经泛化，而本起点模型OI只有9.17%；另用权重衰减.3的起点模型（OI 43.37%）作次要条件，并说明差异。

**解码—再编码通道与自解码对齐比较（契约编号R2；2026-10-10改到Wang主设定）。**
- 问题：修复表示格式是否只在读取路径共享时有效？即标准模型加通道或加对齐是否仍然没有OOD收益。它同时补上[§3](#composition)缺的“同一知识图上表示对齐×参数共享”配对。
- 做法：在Wang主设定（[§5主设定](#main-setup)）、与主设定起点模型族相同的3个新知识图上，比较{标准8层, Loop 4×2} × {无干预, 通道, 自解码对齐}六种条件。“无干预”两种就是起点模型族中的标准8层与Loop 4×2，不另外训练。
  - 通道：Loop 4×2在第一次迭代末（第4层输出）加DiscoLoop通道（混合系数为1、温度τ=1，最后一次迭代不加）；标准8层在第4层输出处加同样的通道，与循环模型的迭代边界位于同一深度。
  - 自解码对齐：本项目的表示对齐损失，但目标改为stop-gradient的Norm(W[argmax])，即模型自己解码出的实体的输入embedding方向，不使用真实桥实体；施加位置同上。
  - 开发阶段在既有φ7.2知识图上每种新增条件各1条，确定未报告的超参数并记录。
  - DiscoLoop原设定（按其§3.1生成：两张图各500个实体、50个关系、出度10；训练1万条原子事实加图A的1万条两跳样本；ID/OOD测试各2000题）的重建降为复现锚点：只训练普通循环模型与循环模型＋通道两种，各1张图，用来确认实现结果与该文方向一致；普通循环模型的训练终点扫描解码—再编码的混合系数（DiscoLoop记作α，与本文的梯度池化比例不是同一个量）。
- 预测：路径一致性（层范围）预测，标准8层加通道、标准8层加自解码对齐都没有IO/OO收益，循环模型加两者则有收益。如果自解码对齐接近通道，说明本项目表示对齐的收益来自表示格式，而不是来自额外提供的真实桥实体信息。如果混合系数扫描在锚点设定上接近完全修复，而本项目第一跳辅助损失条件只到46%，差别来自“每次迭代完成一跳”的逐跳完成程度。
- 限制：标准8层的唯一参数约为Loop 4×2的两倍，这一配对固定了知识图与配方，没有固定参数量。
- 成本与前提：新增4种条件×3个知识图共12条1.5M步训练（约80 GPU小时），开发4条（约27 GPU小时）；锚点设定是小型符号任务，每种条件约3000 epoch。历史上只有外部的分步回答（相当于从第0层重新进入原子查表路径，2Wiki上两种架构都接近100%），没有网络内部的通道。

**写入侧与读取侧修复对照（契约编号C1；标准模型换对齐目标）。**
- 问题：标准模型的第二跳失败，是因为上层缺少查表（读取侧），还是只因为表示格式不匹配（写入侧）？
- 做法：与Zhang等读取侧修复的复现用同一起点模型、同一续训预算，并维持常规训练。四种条件：(a) 读取侧修复；(b) 把两跳查询中r₁位置第k层的状态对齐到b的输入embedding（[已有方法](results.md#independent-alignment-v1)）；(c) 对齐目标换成单跳查询(b, r₂)中b位置同一层的状态，层j取路径重合干预实验测得的单跳查表层范围之前，并在第j层加第一跳辅助损失，使桥实体在该层可用；(d) (c)加(a)。对齐只用两跳训练集的组合及其真实桥实体，属于额外监督，与已有第一跳辅助损失条件同样标明。
- 预测：“上层缺查表”（该文）预测(b)(c)没有IO收益、(a)有、(d)约等于(a)；“只是表示格式不匹配”预测(c)单独就能提高IO；路径一致性（层范围）预测(c)只在桥实体进入单跳查表层范围之前时有效。
- 成本与前提：4种条件续训；依赖路径重合干预实验定出层j。

**主设定起点模型族（编辑传播实验的起点模型部分，契约编号U1；2026-10-10扩充，含梯度池化比例实验与连续共享对照）。**
- 问题：循环模型在IO上的优势（标准8层≤4.10%、Loop 4×2为83.83–95.63%），来自共享写入（[理论式(35)–(36)](memory-scaling-theory.md#partial-pooling-20261010)），还是来自参数更少、正则更强、每个参数收到更多梯度？同一批起点模型同时服务图3、图4、图5，这就是一致设定。
- 做法：Wang知识图生成器，φ7.2、权重衰减.1，宽768，1.5M步，原配方。五种模型：
  1. 标准8层（各层独立随机初始化）；
  2. Loop 4×2（梯度池化比例α=1）；
  3. 部分池化α=.5：把共享块拆成两份副本（复制初始化），第t份副本的更新为αG+2(1−α)g_t，G是两次执行的梯度和；
  4. α=0：复制初始化之后各副本只用自己那次执行的梯度，即复制初始化的解除共享模型；与标准8层对比，可以分开“初始化方式”与“池化”；
  5. 连续共享：4个独立层，每层连续执行两次（AABBCCDD）；唯一参数量、每组参数的使用次数与Loop 4×2相同，只是同一组参数的两次执行相邻，而不是相隔4层。
  - 开发阶段：在既有φ7.2知识图上做α∈{0, .25, .5, .75}各1条（α=1与标准8层已有轨迹），并核查实现：α=1须逐位等于循环模型训练，α=0须等于各副本独立更新。确认阶段：3个新生成的知识图×上述五种模型（α取0、.5、1）。
- 测量：II/IO/OI/OO四类测试与原子事实的完整学习曲线；r₁位置第一次迭代末（第4层输出）的桥实体解码；桥实体输入embedding分量的删除与换实体加倍（沿用bridge-workspace的流程）；桥实体首次可解码的层（线性探针准确率减去打乱标签的控制探针，与权重绑定论文的定义相同）。
- 预测（在任何结果之前写下）：
  - IO随α单调上升，II对α的依赖远小于IO。原因：只受原子训练的事实作第二跳时，所需写入只能经跨迭代项从第一次迭代的副本到达第二次迭代的副本；有两跳训练经历的事实，则由两跳训练样本直接写入第二次迭代的副本。
  - α越小，桥实体输入embedding分量对OI与II越不必要：第二次迭代的副本可以学会读取自己格式的桥实体，表示格式向输入embedding闭合的压力消失。
  - 连续共享的IO接近标准8层：同一组参数的两次执行都在桥实体形成之前或都在之后，跨迭代项不能把原子查表带到第二跳（理论式(32)的层范围条件）。权重绑定论文的解释（每组参数收到来自整个计算的梯度）在这一对比上给出同方向的预测；要区分两种解释，须等路径重合干预实验定出查表层范围后，再设计只让查表层在后面重现的共享模式（例如ABCDEFAB），作为阶段3的条件项。
  - IO对α的曲线形状本身有信息：渐变支持一阶核的解释；只在α=1时突变，说明表示格式的闭合需要副本完全相同（权重绑定论文中H=8也只有完全池化建成了完整的staircase）。
- 否定条件：II与IO随α同涨同落，或IO不随α变化，说明循环模型在IO上的优势不来自共享写入；连续共享的IO接近Loop 4×2，说明优势与共享参数在计算中的位置无关。
- 成本与前提：原计划标准8层与Loop 4×2各3条（约40 GPU小时，6卡并行约7小时）；新增α=.5、α=0、连续共享各3条约60 GPU小时；开发4条约27 GPU小时。

**编辑写入范围实验（编辑传播实验的先导，契约编号U1；2026-10-10新增）。**
- 问题：一次编辑能传到哪些使用方式，是否由“写入在哪次迭代可见”决定？这在同一个模型内检验第三层的路径一致性预测，不需要跨架构比较，因此参数量、训练历史和初始化完全相同。它也是权重绑定论文中梯度路由在编辑时的版本。
- 做法：起点模型为grokking-reproduction-v1中φ7.2的Loop 4×2在1.5M步的检查点（权重衰减.1与.3各一条，在实验主机上）。把共享块临时拆成两份完全相同的副本，前向不变。对原子事实(b, r₂)→t′做同一编辑、用相同的回放，只改变更新范围：(i) 两份副本一起更新，即普通的循环模型编辑；(ii) 只更新第一次迭代的副本；(iii) 只更新第二次迭代的副本。另对第一跳事实(h, r₁)→b′做同样的三种编辑。
- 测量：原子查询是否给出新答案；该事实作第二跳时，两跳查询给出新答案还是旧答案（ID与OOD事实分开）；第一跳编辑是否传播到两跳答案；以t为答案的其他事实是否被连带改变；无关原子事实与旧组合的保持。
- 预测：由理论§13.3，两跳查询在r₁位置第一次迭代末的状态，就是原子查询(h, r₁)在同一位置的状态；Wang循环模型在此解码桥实体的准确率为99.22–100%，即原子查表在第一次迭代内完成。因此：
  - (ii) 改变原子答案，但该事实作第二跳时仍给出旧答案；第一跳编辑在(ii)下会传播，因为第一次迭代给出新的桥实体，第二次迭代照常读取。
  - (iii) 的训练情境是原子查询，此时第二次迭代看到的是已经形成的答案t。按理论§14.6最后一段，写入只能落在以t为键的答案单元上：原子答案可能被改，但这一改动不是该事实特有的，第二跳不传播，以t为答案的其他事实会被连带改变。
  - (i) 两种使用方式都改变；按“迁移与干扰同源”（[§1.2](#pretraining-continual)），(i)相对(ii)第二跳传播更多，对旧组合的损伤也更大。
- 否定条件：(ii)的第二跳传播与(i)相当。
- 成本与前提：不需要新的预训练，只做编辑；每格≥500个编辑，启动前写出最小可检测差。属于编辑传播实验的授权范围，可以在新知识图训练完成之前先做。同样的三种写入范围可直接用于编辑传播实验中测试时训练写入这一维。

**编辑传播实验（被编辑事实所在的跳 × 被更新的层 × 架构，契约编号U1；第三层，Zhang等未涉及）。**
- 问题：编辑是否只传到读取路径经过被更新参数的使用方式？
- 做法：起点模型为主设定起点模型族的五种模型（3个新知识图）。用原子事实形式的更新改写f=(b, r₂)→t′：标准8层分三种，只更新下层、只更新上层、更新全部层；Loop 4×2更新共享块；梯度池化比例模型与连续共享模型更新全部块；其余事实回放。标准8层的“全部层”一组对应[Feng等](#feng2025)的不冻结基线；缺这一组时，与更新全部参数的循环模型相比会混入“更新了多少参数”。上下层的分界以路径重合干预实验中移植的窗口遮蔽与logit lens实测的查表层为准，不固定为第1–4层与第5–8层。按f是ID（有第二跳训练经历）还是OOD分组，测原子编辑是否成功、f作第二跳时给出新答案还是保留旧答案、编辑(h, r₁)→b′时第一跳是否传播，以及无关事实的保持。
  - 补充测量（2026-10-11按Feng等补充）：同答案对照，即其他以旧答案t为答案的原子事实与两跳查询；编辑后仍给出旧答案的比例；新旧答案的log-prob差与候选排名，分辨率比准确率高。只更新部分层时，按原子编辑是否成功分层报告。标准8层全部层编辑之后，再把下层或上层恢复为编辑前的值，定位改动实际存在哪里（Feng等附录E的做法，不增加编辑次数）。
  - 通道起点模型：直接用解码—再编码通道与自解码对齐比较中的“Loop 4×2＋通道”条件（同样3个知识图），不另外训练。通道使第二跳读入解码后的W[b]，与原子查询的输入相同，作为对表示格式的操纵。
  - 编辑方法这一维（[§4](#updating)的跨样本TTT）：同一批编辑分别做离线原子更新（含回放），以及测试时写入（只在陈述该事实的单个样本上做少步自监督的下一token更新，不回放，参数保留到后续样本）；测后续样本中第一跳与第二跳的使用以及旧组合的损伤。加入这一维之前，先在同一批权重上复现Niu（arXiv 2606.20737）的编辑协议，启动前核对原文方法。
- 预测：路径一致性预测双重分离——标准8层更新下层时单跳答案改变、第二跳多保留旧答案，更新上层时第二跳改变；循环模型两者同时改变。更新上层时，第二跳的改变须超过同答案对照的改变：按[理论§14.6](memory-scaling-theory.md#untied-second-hop-kernel-20261010)，原子形式的写入在上层可能落在以旧答案t为键的答案单元上，此时所有以t为答案的查询都会改变。这与编辑写入范围实验预测(iii)是同一推理，不能计为第二跳读到了新事实。标准8层这一臂的方向，在预训练大模型上已有[Feng等](#feng2025)冻结实验的先例。梯度池化比例模型中，原子形式编辑传到第二跳的程度随α上升。通道条件下，第一跳与第二跳编辑的传播对称，且第一跳编辑只在翻转第一次迭代的桥实体解码时传播。编辑方法这一维：被编辑事实所在的跳与架构的规律不应随编辑方法改变；测试时写入如果只在循环模型＋通道中进入第二跳，就是跨样本TTT在受控模型中的机制依据。
- 否定条件：传播与被更新的层及架构都无关；或通道条件仍有第二跳劣势。这时假说被否定或须修正。上层编辑引起的第二跳改变与同答案对照相当时，按答案单元重映射解释，不支持双重分离。
- 成本与前提：每格≥500个编辑、≥3个知识图，启动前写出最小可检测差。[已有的第0块编辑结果](#path-consistency)来自小模板两层模型，每格只有2个事实，只能作先导；历史上没有任何只改上层的编辑条件。编辑方法这一维不增加起点模型的训练，但编辑评测量加倍。学习率与编辑步数在开发阶段扫描，选择标准只用原子编辑成功与保持，不用传播率（Feng等的效应只在部分学习率出现）；编辑写入范围实验沿用同一规则。

**第一跳出度实验（契约编号B1）。**
- 问题：标准模型的OOD第二跳失败，是普遍的（“上层只学映射”），还是只在桥实体形成太晚时出现？
- 做法：在Wang生成器中只改变第一跳头实体的出度d∈{1, 4, 20}，尽量固定第二跳事实及其ID/OOD划分、实体数、关系数与φ；无法固定的活跃输入token位置与头实体新颖性逐项记录。两种架构×三档出度，测四类测试、桥实体形成的层（logit lens），以及路径重合干预实验中第二跳路径的位置。
- 预测：该文“上层只学映射”预测标准模型的IO/OO在各档出度都失败；路径一致性预测桥实体在单跳查表层范围之前形成时（出度小），标准模型的IO/OO上升，且第二跳走该事实的单跳路径。[已有的第一跳出度实验](results.md#realworld-loop-diagnosis)支持后者：第一跳头实体出度为1时标准模型IO从16.6升到99.9%；但只有两档出度，且头实体新颖性与OOD第一跳完全重合，本项须去掉这一混淆。
- 成本与前提：6条1.5M步新训练；按路径重合干预实验的结果决定是否启动。

### 5.0.3 上一轮待审提案：知识变化后的复用与组合再学习开销（2026-10-11）

**本轮可行性复核覆盖原推荐。** 下列方案保留以说明上一轮具体提案，并非当前已采纳主线或执行计划。[§1.3](#wang-benchmark-boundaries)已撤下其中心推荐：DiscoLoop的静态OOD与权重绑定论文的上下文跳转，不足以支持顺序新增、参数改写后自然泛化及较低再学习成本。这些仍可研究，但须先有稳定的动态行为与机制依据，不以预期Loop优势推进。

**决定性比较。** 从同一个已会静态组合的检查点出发，给相同的事实写入：一组只学新/改写事实；另一组再学习一小部分受影响的组合。评价其余始终留出的多跳后果，同时测未变化的知识与原有组合保持。这个比较直接回答：模型能否只学习知识，还是还依赖重新监督知识的用途。补充组合组的额外标签、token和计算全部计入成本，不能把训练过的链拿来证明推理迁移。

| 主实验 | 数据与训练 | 主要读数及作用 |
| --- | --- | --- |
| 1. 知识形成与提取 | 优先复用已有bioS等证据，比较相同事实在不同表达与学习预算下的形成、提取和保持 | 原子学习与不同查询的提取曲线、学习成本；独立说明第一层，不缩成多跳模型的通过率检查 |
| 2. 新事实能否直接进入多跳推理 | 在事实A上学组合操作，事实B只有原子监督；参考DiscoLoop的分离思路，测试B参与的留出链。必要时以部分B组合监督作对照，评价另一批链 | 给定事实学习预算时的未训练多跳表现，以及补充用途监督的收益；解释推理是否依赖具体知识的组合经历 |
| 3. 知识变化后，需要多少组合再学习 | 对同一更新事件分出“相同原子写入”与“另加少量受影响组合”两组，评价留出的受影响链和无关保持集 | 零组合再训练时的更新后表现；达到相同表现所需的额外组合监督与总学习成本。静态成功与更新成功分别报告 |

**统一的数据设计。** 主数据是一组有明确真值的知识世界，以及其局部变化后的版本；查询只给起点与关系序列，知识靠训练进入参数。训练链与评价链分离，组合恢复组也只接触部分后果。选少数有解释价值的链长作为负载轴，例如2/4/8跳；主比较的这些长度应在A中有操作训练支持，超出训练长度的外推另列，不把所有低分都归为知识不可用。跳位、前缀、后缀不再各立成主实验。

为了让长链确实依赖前面事实，建议先借鉴[Kohli的置换关系构造](https://arxiv.org/html/2604.07822v2)建立可完整遍历的主世界；若采用置换图，用交换两个尾实体生成局部变化，保持更新后的关系仍为置换，并按两条事实变化计预算。这样数据结构服务于“知识变化后的多跳后果”，避免把不存在的后继关系或路径汇合当作更新失败。Wang原图与已有权重保留为复现基准；新结构、事实量与训练配方须明确披露，同一主比较统一使用一套构造，不跨设定比较分数。

**训练与架构保持简单。** 以普通Transformer、Loop、作者DiscoLoop三个条件为建议的主比较，先使用已有方法的答案监督与通道定义，不另堆辅助损失。训练历史只围绕“学会组合→只学习事实→局部事实变化→是否补充组合监督”组织。普通模型各层独立初始化；同图、同监督、同展开深度下比较，并分别记录总/激活参数、曝光、token、FLOPs与耗时。DiscoLoop是已有方法，不能把复用通道称为本项目新方法。原子写入与组合恢复对照量的是再学习开销，三种架构的得分排序本身不能建立机制。

**一项决定性机制比较。** 在同一个普通Loop检查点上完成同一原子更新后，保持权重不变，按DiscoLoop §3的方法打开或关闭中间实体解码—再编码干预，使用模型自己解码的实体。更新前也做相同比较，分别读出静态组合与更新后留出后果。若原子事实已改对、交接干预使后果随之改变，支持“交接格式限制了这次知识复用”；若没有恢复，该解释不获支持。它检验共享计算条件下的交接作用，不能单独证明共享参数的必要性，也不证明长期学习成本已降低；成本仍由主实验测量。先验证作者操作在本任务中的含义，再冻结具体位置与评分，不扩成完整跳位、池化比例和共享模式扫描。

**证据层级与判读。** 仅原子写入的模型若在多跳上仍差、补少量组合后能恢复留出后果，支持“在该配方与预算下仍有用途监督依赖”，不证明其内部有多份事实，也不证明所有优化都必须如此。若共享计算加交接在相同事实预算与保持水平下减少了组合再学习，才支持本轮的条件性观点。若只是静态得分更高、直接事实没有真正学会或保持明显下降，不能声称知识复用更有效。行为规律之外的参数/路径归因须有实际Transformer计算中的证据；局部NTK关系不代替长期学习证明。

**细项的层级。** 图上真值闭合、原子写入是否生效、模型是否已经会相应链长，是数据与评价前提；主结果和条件子集覆盖率同时保留。同一事实第j步、前后缀、问法、出度、旧答案残留、更新可见范围及表示干预，按主结果需要作为诊断或消融；等计算的旧原子/旧组合续训可排除恢复收益只是额外优化量。第一层已有问法实验仍是独立科学证据，不能因这里下放多跳问法诊断而删去。原Z1冻结契约保持不变，不将新分组追溯写入旧分析。

### 5.1 已完成主实验：先练过组合的模型，能否用上后来学的新事实

**问题、设计与结论。** 模型先在旧知识上练过两跳查询（two-hop query），之后只学新的原子事实（atomic fact），从未见过含新事实的两跳样本。这时它能否把新事实直接用进两跳查询？这是持续学习（continual learning）中的顺序知识注入问题。实验在同一张真实知识图上，从随机初始化训练同一个标准Transformer；架构、旧事实、随机种子和训练预算都固定，只改变训练历史。结论：组合练习有帮助，但两跳都用新事实的组合仍只有约两成答对，旧组合也有遗忘。三个数据划分来自同一张真实图，不是三个独立知识图。

**结果。** 同一真实知识图的三个划分、每个划分两个随机种子，共完成24条确认运行。关键主指标是新—新组合（第一跳和第二跳都是新事实）。三种训练历史下，新—新组合依次为20.57/3.12/23.18%：先学旧组合再注入新事实、先只重复旧原子事实再学新事实的对照、把相同训练样本清单混合训练。相关原子事实和分步回答（先问第一跳，再把模型自己的答案代入问第二跳）都是100%。先学组合的模型在学新事实之前，新—新组合已有14.32%，学完升至20.57%。从同一起点模型出发、只继续复习旧原子事实而不学新事实的对照，则降至9.90%。学新事实相对这一对照的收益，在三个划分上都为正。顺序训练的模型在学新事实前后，未训练过的旧—旧组合为34.90→30.47%；原先会答的旧—旧组合题，按划分等权只保留64.78%。因此可以说先前的组合经历帮助使用新知识。不能说旧能力完整保留，也不能把先后顺序学习本身称为这次的主要瓶颈。详见[完整结果](results.md#sequential-transfer-v1)。

**数据与知识划分。** 新事实优先取自现有2Wiki数据中有来源、无歧义的真实三元组。小型人工知识图只用来校准实现，其结果与真实事实分开报告。知识分为旧知识A和新知识B。实体和关系词表尽量沿用已有的，使B占用此前未见过的合法事实地址（头实体与关系的组合）。B的全部提问模板、别名以及它在组合中的使用角色，都不得进入阶段A，也不能借A的组合标签间接教入。先检查合法B事实与新—新链的数量；不足时调整真实数据划分并披露，不用人工补边冒充真实事实。

为此，真实2Wiki图重新划分训练与评价部分，不沿用旧权重。先选出实体在其他A事实中有支持的真实链，再形成B和各评价子集，保证新—新链足够多；每条链保留来源、别名及必要事实。同一真实图上的不同划分与随机种子分层标记，不把划分、种子或查询当作独立知识图。

**两阶段训练。** 阶段A学旧知识，阶段B学新知识。第一轮实验从随机初始化的完整Transformer开始，建立一段可审计的旧/新知识学习史。阶段A固定架构、A事实、配对的随机种子和训练预算，比较“A原子事实＋组合练习”与“A原子事实重复练习”。原子事实的曝光次数、监督token和计算量都有记录。组合监督本身就是要比较的处理因素，因此不声称两种条件的信息相同。用未训练过的旧—旧链确认，练过组合的条件确实形成了可测的组合能力。若以后扩展到现成的预训练LM，“没有进入阶段A”不代表底座模型从未见过该事实，这一限制须单列。

阶段B中，两种起点模型接受相同的B原子事实和固定的A原子事实回放（replay），全参数正常更新。阶段B不提供任何含B的组合答案，也不回放A的组合。练过组合的起点模型另设一个等预算的A原子事实复习分支，用来区分“学新知识”与“继续训练本身”对旧能力的影响。已有起点权重如果已经见过B原子事实，就必须重建划分和起点模型。

**三种训练历史。** 第一种先学A原子事实与组合，再学B原子事实；第二种先重复A原子事实，再学B原子事实；第三种从头混合训练。混合臂把第一种历史的同一份实际训练样本清单重新排列，因此事实与组合的曝光次数、监督token和总更新数都匹配。所有臂都不给含B的组合答案，优化器及学习率日程一致；原子对照缺少的组合监督如上所述作为处理因素。先在一个开发划分上检查学习、保持和代码操作，确定共同的训练配方与预算；随后固定配方，在新划分上做确认运行。

| 固定评测子集 | 研究用途 |
| --- | --- |
| 旧—旧组合 | 旧组合能力是否保持 |
| 新—旧组合（第一跳是新事实） | 新事实能否进入第一跳 |
| 旧—新组合（第二跳是新事实） | 新事实能否进入第二跳 |
| 新—新组合 | 整条新知识链上的使用迁移，关键主指标 |

同时报告A、B原子事实的单跳准确率，必要事实的掌握情况及其子集占比，分步回答，完整直接生成，以及学习轨迹。

**补充实验：按文献配方回放旧组合（已完成）。** 上面的顺序训练在阶段B只回放旧原子事实。用户要求先查论文，再直接采用相近的成功配方。精读Ibrahim et al.的方法与附录后，采用其测试过的设置：50%旧数据回放、优化器重置、1%升温后余弦衰减。每步固定64条B事实和64条旧数据回放。两臂只改变旧回放的内容：只回放旧原子事实，或回放阶段A的完整训练分布（含训练过的旧—旧组合）。两臂都不提供含B的组合答案。开发4任务和原三个划分上的12任务配对扩展都已完成，新增100,000更新；它们仍在同一张真实图上，不称新知识图上的确认。来源与适配差异见[文献核对](development-artifacts/sequential-replay-literature-v1/literature.md)与[执行协议](development-artifacts/sequential-replay-literature-v1/protocol.md)。

结果：只回放旧原子事实与回放完整旧分布两臂，未训练旧—旧组合分别为4.17/37.76%，新—新组合分别为4.95/20.83%，A、B原子事实均为100%。完整回放使训练过的旧—旧组合保持100%，但原先答对的未见旧—旧组合仍只保留73.97%（划分等权）。因此，回放完整旧分布能缓解组合遗忘，并优于本轮匹配的只回放原子事实对照。但完整回放的新—新组合仍与前一轮的20.57%接近，没有突破先前水平。

限制：两轮的优化设置和回放顺序不同，不能把跨轮差值解释为纯回放效应。一个更窄的比较尚未执行：保留原B序列、优化器状态和学习率，只把部分A原子回放换成训练过的旧—旧组合。它现作为必要时的补缺，不优先继续密集调整回放。若要把“注入新事实”与“改写旧事实”之间的差异归因于旧答案的竞争，仍须在相同的更新范围和训练方法下比较。

<a id="write-interface"></a>
### 5.2 辅助比较：编辑能否写进后续计算实际复用的中间状态

**问题、设计与结论。** 编辑一个事实时，如果只在最终答案上训练，事实本身能改对，依赖它的多跳答案却很少随之更新。这里问：如果编辑的训练目标还要求新实体出现在第一跳之后、被后续计算读取的中间状态里，编辑传播（edit propagation）能否改善？比较只改变编辑的训练目标；起点模型、目标事实、可更新参数、回放和预算都保持不变。结果是监督中间状态大幅改善传播，再加表示对齐还能进一步改善，但未受编辑影响的分布外组合损伤也随之增加。结论只覆盖被编辑事实位于第一跳的情形。

**设计。** 本比较已在三个已有知识图、每图两个随机种子上完成，见[写入目标结果](results.md#write-target-editing-v1)。起点模型是已有的、组合能力强的小型参数共享模型。先重新载入已有的编辑权重，直接核对早期状态能否解码出新、旧实体，以及表示怎样变化。只编辑在分布外两跳查询中充当第一跳的事实，比较三种编辑的训练目标：

1. 只在最终原子答案上用交叉熵，即沿用现有方法作基线。
2. 用同一个新实体标签，再加一项损失，监督早期状态解码出该实体（第一次执行之后、r₁位置用输出embedding解码）。
3. 保留第二项的同一标签，再加表示对齐损失，把早期状态的方向拉向新实体的输入embedding。

所有臂都不提供第二跳关系或依赖被编辑事实的多跳答案，并各自保留一个只复习不编辑的对照（sham）。开发运行只用直接编辑效果、必要事实和保持情况来校准操作。主报告包括：全部测试题上的编辑传播、编辑后仍给出旧答案的比例，以及未受编辑影响的组合。起点模型原本会答的子集及其子集占比另外报告。

**限制与后续问题。** 由于传播改善伴随旧组合损伤，后续问题是怎样同时兼顾编辑传播与旧组合保持。第一跳上的结果不能自动推到第二跳或自然预训练模型；暂不展开被更新的层、损失和架构的全交叉扫描。

<a id="architecture-efficiency"></a>
### 5.3 通用架构能否降低三个层次知识能力的学习成本

**2026-10-08降级。** 论文主线采用[路径一致性](#path-consistency)假说后，本节不再作为论文贡献方向。仍保留循环Transformer（looped Transformer，下文记作Loop）与标准Transformer（各层参数独立）的机制对比，因为权重共享对“事实能否沿同一路径被重用”有明确预测。MoE、跨迭代KV读取、mHC、DeltaNet的已有结果至多作为负结果附表，不再扩展。以下是原规划与已完成结果的记录。

**原来的问题与已有结论。** 在知识任务和可用监督都固定时，哪些通用结构能用更少的数据曝光或计算量，得到更好的事实回答、未见组合和更新后使用？比较只改变架构，数据流、监督和训练配方保持相同。已完成的开发比较没有确立Loop的普遍收益，跨迭代KV读取和MoE也没有稳定改善新知识的组合使用。这里不预设所有架构都有收益，也不以单一最终分数判断架构是否合理。有限任务上的收益只说明某个设计适合何种学习条件，不足以说明它在所有大模型中普遍更优。

| 结构与原始方法 | 机制假说与关键比较 | 已有证据如何使用 |
| --- | --- | --- |
| [Loop / Universal Transformer](https://arxiv.org/abs/1807.03819) | **比较已完成。** 标准四层模型、两层Loop执行两次、Loop加跨迭代KV读取；三者都执行四层，数据流相同；标准模型各层独立随机初始化 | 标准模型基线和真实名称顺序学习中的KV读取条件都已补齐；KV读取没有稳定的新知识收益，本配方的扩展结束；早先复制初始化的结果只作有限的辅助证据 |
| [稀疏MoE](https://jmlr.org/papers/v23/21-0998.html) | **开发比较已完成（见§5.5）。** 问专家分工是减少了事实间的干扰，还是只增加了总存储。分别与激活计算相近的稠密模型、总参数相近的宽稠密模型比较；固定路由只作机制消融 | 此前八层MoE、稠密、宽模型（M8/D8/W8）在全部测试题上的结果与曲线可以复用；本地top-2实现不是Switch的逐项复现。[知识容量原论文§9、附录D](https://arxiv.org/html/2404.05405v1)表明稀疏专家能用大量总参数存储事实，但没有证明组合使用也获得相同收益 |
| [DeltaNet](https://arxiv.org/abs/2406.06484) / [Gated DeltaNet](https://arxiv.org/html/2412.06464v1) | **暂缓。** 原论文§3及检索实验主要检验序列内关联状态的写入、保持和清除；当前任务是短闭卷QA，状态逐样本重置，不足以分辨这种设计对参数知识使用的独立作用 | 旧GatedDelta-GQA与GQA差异很小且资源不等，也没有单独的纯Delta臂；结果保留。将来明确研究长上下文或多步工作状态时，再在统一骨架与重置规则下比较GQA、Delta和GatedDelta |
| [mHC](https://arxiv.org/html/2512.24880v2) | **暂缓。** 原论文§4–5聚焦多流混合、深层传播稳定和大规模预训练。当前浅层知识任务尚未出现相应瓶颈；等增加深度或循环后确有稳定性问题，再比较普通残差、Identity多流与完整mHC | 现有HC/IHC及残差扩展没有建立稳定的分布外组合优势，结果保留；固定矩阵的稳定性不能代替全网络或旧知识保持的结论 |

**比较规则。** 架构主比较沿用普通的答案监督，不为某个架构单独提供真桥实体（bridge entity）或额外的多跳答案标签。由数学推导提出的辅助损失、路由限制或状态操作，单列为训练方法或机制臂，并报告它们带来的额外信息与计算；否则不能把收益归于架构本身。优先使用论文已验证的模块实现与优化原则，并写明GPT-2适配、有限次Sinkhorn迭代、纯Delta开关等差异。

**mHC的保留入口。** 暂缓的是单独的大实验矩阵，并非认为多流连接与知识或推理无关。[iso-depth研究v3§5.2](https://arxiv.org/html/2604.21106v3#S5.SS2)在循环边界加入双流Hyperconnections后，改善了其循环等效性拟合。这是普通HC而非mHC的直接结果，而且非循环基线没有作同样改造。若后续Loop曲线提示跨迭代的状态传递值得定位，可把普通连接、固定双流、HC/mHC作为Loop内部的窄比较，使本论文主题保持集中。

#### 已完成：同一起点下的参数共享比较

**问题、设计与结论。** 这组开发运行问：让各次执行共用同一组参数（weight tying / parameter sharing），是否改变旧组合的学习和新知识的组合使用？四个臂从同一组随机初始权重出发，使用同一训练样本顺序，主要改变参数绑定方式（浅层参照另改变执行次数）。结果没有确立Loop的普遍收益。这里的解除参数共享对照来自复制初始化，不是通常的标准Transformer，结论只适用于这一初始化条件。

**设计。** 沿用已审计的2Wiki顺序学习开发划分，从随机初始化训练四臂×两个随机种子；每组共享同一基块初始权重和训练样本顺序。宽度256，基块组2层，循环2次。阶段A为8000步旧原子事实＋旧组合，阶段B为4000步新原子事实＋完整旧训练分布回放。主批共96000次优化更新。另在读取主批训练终点之前，预先冻结了宽128、循环2次与宽256、循环4次两个点上的共享与解除参数共享比较，又增加96000更新。16任务全部完成，见[主批协议](development-artifacts/loop-learning-development-v1/protocol.md)、[扩展协议](development-artifacts/loop-learning-scaling-development-v1/protocol.md)与[汇总](results.md#loop-learning-v1)。

| 开发臂 | 参数约束 | 主要比较 |
| --- | --- | --- |
| shared（整块共享） | 两层基块重复执行两次，全部块参数共享 | 与untied的初始函数和展开深度都相同，检验共享约束本身 |
| untied（复制初始化后解除参数共享） | 把相同基块复制成四个独立块 | 保留同一起点，允许不同执行位置各自学习 |
| mlp_shared（仅MLP共享） | attention及块内归一化各自独立，只有对应的MLP共享 | 缩小共同更新的模块范围；不预设知识只存于MLP |
| shallow（浅层参照） | 同一两层基块只执行一次 | 独立块数相同的计算参照；初始函数与前三臂不同 |

`untied`从同一组随机初始权重复制各层后分别训练，目的是固定初始前向、只改变参数绑定。它不是通常各层独立随机初始化的标准Transformer。已有结果只能按这一初始化条件解释，不能据其分数宣称标准Transformer与Loop之间的普遍效率关系。历史名称和预注册计划保持原文；后续讨论直接写“各层独立随机初始化的标准模型”或“复制初始化的辅助对照”。

**报告内容与限制。** 主报告新、旧原子事实，未见旧—旧组合与新—新组合在全部测试题上的学习曲线，以及阶段A结束时答对的旧—旧组合逐题是否保持。新—旧组合仅14条，旧—新、旧—旧、新—新组合各64条；全部结果保留并注明分母。这个实验测的是新增知识，不等同于改写旧事实。两个随机种子以及之后同一张图上的新划分，都不是独立的新知识图。完整回放旧组合本身也可能改善新—新组合，因此这一轮比较的是整套学习流程。不学新事实的续训分支（无B分支）从未启动，已随跨迭代KV读取配方的后续计划一起撤下。

**原方法与本次扩展。** [Grokked Transformers附录E.2](https://arxiv.org/html/2405.15071v2)把前后两组4层参数共享，在合成知识图上较晚才出现分布外组合；本轮是2层×2次、使用真实名称的小规模开发，并多了一个注入新知识的阶段。[Reasoning with Latent Thoughts §3、附录A.2](https://arxiv.org/html/2502.17416v1)在相同token顺序下比较浅层模型、Loop与等计算量的深层模型，发现知识记忆与推理的收益不同，所以不能预设三个层次会同时改善。[2026年iso-depth研究§3–4](https://arxiv.org/html/2604.21106v1)在特定的自然预训练架构上区分循环、参数与计算，其拟合指数不能直接外推到本项目。本轮结果只支持受控开发中的观察，不足以建立scaling law。

**微观诊断：一步更新怎样在各次执行之间耦合。** 固定一批只取自训练集的原子事实与组合样本作诊断批次。在预先定好的检查点，把当前共享模型临时展开成每次执行各有一份参数副本，测量第t次执行上的梯度、不同执行梯度之间的内积，以及“共享参数梯度等于各次执行梯度之和”这一求和恒等式；同时记录实际的AdamW更新与梯度裁剪。诊断副本不更新，也不用未见的旧—旧、新—新组合答案训练。先检验[理论§14.4](memory-scaling-theory.md#loop-cross-call-kernel)给出的跨迭代更新关系，再用行为差异或针对性干预判断它能否解释学习。多token的自然名称，不直接套用单token实体的桥实体解码方法。不用内部特征另建成绩预测器。

**后续决定。** 这批开发运行没有确立Loop的普遍收益，因此不直接扩成确认运行网格，也不默认补做循环4次条件的不学新事实续训或扫描学习率。新的比较先沿用已能有效学会原子事实和训练过的旧—旧组合的共同配方。如果另外研究优化，须提出与已有曲线不同的可检验问题，并给两臂对称的预算。三个已测的宽度、循环点不支持普遍的scaling指数。在训练中途加上共享约束再继续训练，与从头在共享约束下学习，两者分开解释。

#### 已完成：标准Transformer、Loop与加跨迭代KV读取的Loop

**问题、设计与结论。** 上面的Loop学习代码在每次迭代只读取本次迭代自己算出的key/value。这里问：让第二次迭代额外读取第一次迭代同层的key/value（跨迭代KV读取），能否改善新知识的组合和旧能力的保持？同时用各层独立随机初始化的标准四层模型衡量实际的架构效率。三臂执行同样的四层计算，使用相同的数据、随机种子、样本顺序和优化配方；两个Loop臂只差是否有跨迭代KV读取。结果没有稳定的新知识收益，预注册的后续门槛未通过，这一配方的扩展已结束。

**背景与基线选择。** 历史上的`SharedCacheGPT`在符号知识图的另一套骨架上已验证分布内组合收益，但没有真实名称的顺序知识注入阶段。用户质疑把复制初始化的模型当作主基线；核对论文后，原计划中新增的“复制初始化模型加跨迭代KV读取”一臂被取消，原定的四格设计未启动。

**文献依据与边界。** [Reasoning with Latent Thoughts §3、附录A.2](https://arxiv.org/html/2502.17416v1#S3)的主比较是：k层Loop执行L次、标准k层模型、标准kL层模型；三者数据顺序匹配，参数与计算分别比较。这些方法段中没有找到把本项目的“复制随机初始权重后独立训练”设为主基线的说明。[MIDAS §2–3、§4.4](https://arxiv.org/html/2409.19044v1#S4.SS4)确实通过复制已训练的层来扩展深度，让副本继续学习；但它是分阶段增长，不同于本项目从随机起点一次复制。[共享KV论文附录D](https://arxiv.org/html/2610.02383v1#A4)中数值相同的独立副本用于分解梯度，不是另一个独立训练的标准模型。复制初始化有固定起点的控制用途，但不能据这些相近做法把它称为标准架构基线。

**实现。** 已重读[Monea等共享记忆论文§3、§4、§6与附录A/C/D](https://arxiv.org/html/2610.02383v1)，按其做法实现：第二次迭代把同层第一次迭代的KV与本次迭代的KV拼接，用统一的softmax，两部分分别按原token位置做因果遮蔽。主比较首先保留完整的本次迭代KV，使主变量是新增的跨迭代读取；短窗口和detach（阻断梯度）不同时进入主比较。该论文研究长文本预训练；本项目保留完整的GPT-2 pre-LN、残差、MLP、位置编码和最终答案监督，属于方法适配。这里的缓存是本次输入的激活，每个样本重置，每次前向都用当前参数重算，不是跨问题的知识库。

**控制变量。** 共新增4条×(8000＋4000)=48,000更新。固定的内容包括：原开发数据哈希、tokenizer、随机种子870071/870072、各自的样本顺序、宽256/8头、batch128、原优化器与学习率日程。三臂都执行四层；阶段B每步64条B原子事实和64条完整旧分布回放，不给含B的组合答案。标准四层模型沿用已验证的初始化实现，各层随机权重独立，不复制两层的张量；投影层初始化尺度按共同配方记录，不强制其初始前向等于Loop。已有的`sequential-transfer-development-v1`只回放旧原子事实，`sequential-replay-development-v1`重置了优化器且warmup不同；这两批只能作背景，不能直接替代本配方的基线。新增的KV读取通路从阶段A开始训练；给旧Loop的训练终点临时打开通路，不能代替真正带着通路训练。

已有的真实名称与单token实体结果，用来说明当前结论的适用范围，不作为继续本配方的理由。合成事实用于可控的机制研究，真实事实用于外推；答案监督下的结果不能直接称为自然语料全token预训练的结论。当前没有建立普遍的架构上限，也不以“结论范围有限”为由自动追加新的验证任务。

### 5.4 什么算“更少训练量”

这一节不是实验，而是规定架构比较中“学得更省”怎样衡量；末段记录一次不训练新模型的旧曲线整理。

**学习曲线与达标成本。** 三个层次各自报告完整学习曲线：原子事实的学习及换提问模板后的提取；训练中留出、从未出现的静态组合；新增或改写事实后依赖它的多跳查询，以及旧行为的保持。主报告是固定预算下的比较。达到预先选定能力水平所需的成本作为补充；阈值和“连续几个检查点达标”的规则在开发阶段固定，不在确认运行的曲线上挑最有利的阈值。预算内没有达到就报告未达到，不外推说无限训练也学不会。

**训练量的维度。** 训练量分为：唯一的事实或组合支持数、实际样本的曝光次数、输入与监督token、优化更新数、训练FLOPs和实测时间。重复数据不计作新增的独立事实。Loop的执行次数另报；MoE的总参数、激活参数和路由成本另报；Delta的状态与softmax KV缓存另报；mHC的状态、控制器和逐元素成本另报。数据效率提高可能伴随每个样本的计算增加，两者分别判断。

**怎样配对比较。** 在同一数据流和监督下比较学习效率，各架构给予相同的开发搜索预算。等总参数、等激活计算、等展开深度通常不能同时成立，因此按具体假说做配对比较，而不是声称某个统一的“公平大小”消除了所有差异。共同预算的检查点只在实测支持的范围内比较；检查点稀疏时，不能精确确定首次达标的时间。

**第三层（更新后使用）的成本。** 同时报告阶段A+B的累计训练成本和阶段B的额外成本。共享同一起点权重只用于同一架构内不同更新方法的配对比较，不强行把不同架构拼成同一个起点模型。分别给出：固定阶段A预算下的结果、必要事实的掌握情况、编辑前组合能力的子集占比。按能力匹配的补充分析保留全部未达标的模型和真实成本。主评分用固定的全部测试题；各模型起点答对的子集另报分母，净准确率不能代替逐题保持。

**已完成：不训练新模型的旧曲线整理。** 从8种架构条件×3个随机种子的24条历史记录中，提取1056条“检查点×评测子集”记录，保留源文件哈希和各自不同的学习率。见[曲线PNG](development-artifacts/architecture-theory-efficiency-20261007/existing-panel-curves.png)、[PDF](development-artifacts/architecture-theory-efficiency-20261007/existing-panel-curves.pdf)、[数据与边界](development-artifacts/architecture-theory-efficiency-20261007/existing-panel-curves.json)、[复算脚本](development-artifacts/architecture-theory-efficiency-20261007/analyze_existing_architecture_curves.py)。这些数据来自同一张真实图上的固定小评测子集（原子事实877题、分布外组合OO类64题），不是全部测试题上的训练终点，也不包含第三层。因此它们只用来提出下一项比较，不按固定评测子集上的峰值宣布普遍的架构优势。

### 5.5 已完成：MoE、标准模型与宽模型的顺序学习

**问题、设计与结论。** 稀疏MoE每个token只激活部分专家。它能否用更少的计算学会旧知识、组合后来注入的新事实，并保持旧组合？此前八层MoE、稠密、宽模型的比较（M8/D8/W8）只看静态真实图；本轮补上后来新增事实的组合使用和旧组合保持。三种模型只换前馈层，其余保持一致：标准模型与MoE的激活计算相近，宽模型与MoE的总参数相近。结论：MoE没有表现出稳定的新知识组合或旧组合保持优势；一个开发划分、两个随机种子不足以建立普遍的架构结论。

## 6. 理论怎样连接三个层次

理论文档于2026-10-09按论文用途重新排列：[论文理论](memory-scaling-theory.md#paper-theory)按论证顺序收录§14、§13、§11。原来缺的两条推导于2026-10-10补为§14.6与§14.7，同日在§14.4补入部分梯度池化的式(35)–(36)。[历史推导](memory-scaling-theory.md#historical-derivations)保留容量、可辨识性、误差界与架构资源的推导，原假设与边界不变，不进入论文。三个层次原有的理论对象如下：
- 第一层：联想存储、知识量、查找键之间的干扰，以及参数中的知识与上下文中的状态的区别。区分“数据要求的知识量”与“模型实际学会的知识量”。
- 第二层：单跳解码的条件与后续可用性、训练支持下的可辨识性、有限步计算的稳定性。功能上的复用不要求内部向量处处相等。
- 第三层：直接回答两跳查询与分步回答的一致性，以及参数更新前后这种一致性能否保持。编辑前一致，不推出编辑后仍一致。

已经严格证明的部分：固定真实的上游计算时，最后一个不共享的MLP能否在保护其他输出的同时写入目标，以及所需的最小参数变化；在完整的残差、归一化、attention与MLP中，更新怎样传播；循环模型中共享参数的梯度求和，以及各次执行梯度可能相互抵消。它们解释了为什么不同行为之间没有自动的蕴含关系，以及架构施加了什么约束。“更省训练”和“何时出现grokking”仍是待检验的命题。小型随机模型上的CPU/FP64核查只确认代码与代数正确，不当作自然训练的机制。

数学结论写明模型与假设；训练效应、数值核查与自然模型中的机制分别标注。理论用来提出能区分不同解释的比较，不用恒等式代替实验证据，也不另建预测模型表现的指标体系。

**以经验NTK为中心收束（2026-10-08路径一致性，2026-10-09统一表述，2026-10-10部分池化）。** 已有的计数界、固定特征谱学习、误差累积界主要说明“不会自动蕴含”，不给出区分性的预测，已移入历史推导，不再扩充。理论以[§1](#question)的K(u, c)为中心：§14.4式(26)对任意两个输入都成立，所以从“同一输入的不同迭代”推广到“不同训练情境与使用方式”是直接的。下列五条中，1、2于2026-10-10写入理论§14.7、§14.6；3在一阶下是同一式子的两面；4已写入§13.6；5于2026-10-10写入§14.4：

1. **回答。** [§14.7](memory-scaling-theory.md#form-transfer-20261010)：设各问法共用部分的核为A、问法特有部分为S，则没有训练过的问法被改变的比例为A/(A+S/n_eff)，其中n_eff=1ᵀR⁺1是训练中互不相关的问法数。重复同一问法只加快写入，不提高这一比例；A=0时多样化没有用。固定核下已证；特征学习部分（多样表达是否使A本身增大）仍开放。
2. **组合。** [§14.6](memory-scaling-theory.md#untied-second-hop-kernel-20261010)：MLP输出矩阵的核可以精确分解为“后向Jacobian的重合 × 前向激活的重合”（式31）。由§13.3，桥实体要在执行d₁（第一跳事实在其原子查询中形成答案的那一次执行）之后才进入r₁位置；所以在各层参数独立的模型中，单跳写入只能经由d₁+1之后的层传给第二跳（式32）。如果所有原子事实都在同一层范围内完成查表，K(第二跳, 单跳)接近零；循环模型则在下一次迭代重复使用同一组参数。层范围、逐跳完成、表示格式三个前提由此分开写出；表示对齐只修复表示格式，所以只在读取路径共享时有效。式(31)是恒等式（FP64核查）；式(32)在给定激活模式下精确，激活模式本身由路径重合干预实验实测。
3. **更新。** 编辑的梯度只沿编辑训练情境的路径改动参数。它对依赖被编辑事实的多跳答案的作用（迁移）与对旧用法的作用（干扰）来自同一个核，所以写到被复用的路径上必然同时带来两者，两者的比例由使用方式之间的重合决定。逐编辑再分析支持“写到哪里”这一层的同源：不同训练目标之间迁移与干扰同涨同落；同一训练目标内，损伤随更新幅度增大，不随传播多少变化（[再分析](results.md#write-target-per-edit-20261010)）。
4. **离散交接是一个显式构造。** [DiscoLoop](#discoloop2026)在两次迭代之间加入Φ(h)=Σ_v p_v(h)W[v]。p接近one-hot时Φ≈W[b]且∂Φ/∂h≈0：下一次迭代读到的桥实体只取决于argmax，与第一次迭代怎样算出b无关。于是§13.1中交叉熵能保证的间隔（可解码）被直接转成表示格式（与原子查询相同的输入）。推导已写入[理论§13.6](memory-scaling-theory.md#discrete-handoff-20261009)：式(28)给出饱和时的偏差与敏感度界；线性键值示例（式29–30）说明解码是逐个候选的间隔条件、使用是聚合的串扰条件，在叠加表示中一般不等价；在条件(A1)(A2)下，组合查询的读取与原子查询在第一次迭代的读取是同一个函数，K(u, c)=K(c′₁, c)+O(ε)；第一跳编辑只在翻转第一次迭代的argmax时传播。FP64数值核查已通过。多跳时每次交接都会截断误差，这与该文三跳差距扩大相容；本项目grok-loop-v1中两层参数共享块循环执行的模型，两跳、三跳、四跳的分布外组合6.29/1.02/0.84%也随跳数下降，但都接近地板，只能算不矛盾。仍待检验：实际GPT-2计算图偏离(A1)多少（桥实体所在的token位置、关系位置的状态、其他位置），由解码—再编码通道与自解码对齐比较实测。
5. **参数共享是共享写入。** [§14.4式(35)–(36)](memory-scaling-theory.md#partial-pooling-20261010)：把循环模型的共享块拆成T份副本、第t份副本的更新取αG+T(1−α)g_t时，经验NTK中跨迭代项与同迭代项的系数之比为α/(α+T(1−α))；α=1即循环模型，α=0即解除共享。限制到MLP输出矩阵时，跨迭代项非零同时需要同一组参数（池化）与前向激活重合（表示格式）。由此：池化只提供通道，表示格式决定通道是否起作用；这解释了上下文中的跳转任务为何各跳数同时习得，而参数知识的OOD第二跳要比原子事实晚得多（事后解释）。FP64有限差分核查已通过；长期训练中的效应由梯度池化比例实验检验。

§14.6没有另外建立分层联想记忆的玩具模型，而是直接在实际GPT-2计算图上分解输出矩阵的核。所有推导都标明一阶、局部、固定特征的假设；预训练中路径怎样形成超出这一描述，由训练实验检验。

<a id="scope"></a>
## 7. 范围与暂不展开的方向

论文保留知识容量、MLP记忆、参数共享、grokking、表示和编辑传播这些重要话题。它们是否进入下一轮，取决于解释价值与已有证据，不因已有文献涉及过就回避。

容量是第一层的重要问题，目前只建立了特定任务与预算下的曲线；尚不把“组合容量的幂律”定为已成立的中心结论。循环模型与跨迭代KV读取的比较、MoE顺序学习的开发比较都已完成，当前先解释三个层次的结果与成本。DeltaNet、Gated DeltaNet和mHC暂缓，重新进入的依据是工作状态需求或传播稳定性问题与任务瓶颈直接对应。已有结果全部保留，不做“所有架构×知识量×深度×监督”的完整网格。

2026-10-08采纳路径一致性为主线后，以下方向不进入论文正文的新扩展：以每参数比特数为主线的容量研究（降为第一层的附录）；MoE、跨迭代KV读取、mHC、DeltaNet的比较；以提高分布内组合为目标的实验（属于分布内泛化）；64题规模的小型Qwen组合实验（要么按Balesni等两跳研究的规模重做，要么不进正文）；Hebbian学习与路径学习的早期研究线（存档保留）。已有结果全部保留。

**跨样本TTT在论文中的位置（10-09旧提案，10-11复核）。** 旧安排把它作为第三层的一种写入方法，并以首/次跳传播对称、旧损伤不高于离线编辑作为另写方法论文的闸门。这一闸门未执行，不自动延续；传播差小可能两者都低，不能单独建立方法能力。当前按[§1.4](#innovation-rnn-ttt)讨论机制候选，准确继承PERK与uTTT，尚不宣布新的持续适应方法或独立论文。若以后提出独立方法贡献，旧候选材料包括：
- 已预训练的循环模型，如Huginn、McLeish等的循环与非循环模型对；
- 流式的多跳基准；
- TTT与持续学习的基线：每样本重置的TTT、标准模型的持久化TTT、SEAL、sparse memory finetuning、MEMIT、检索与上下文；
- 长序列中的干扰与计算成本。

上述独立立项安排均为未执行候选，不能视为已有两篇论文路线。更新失败也应作为第三层边界报告，但不足以仅凭结果解释Niu与He、Mian等的内部机制。独立方法立项之前须建立能力与保持证据，并补齐新颖性核查。

多跳服务[可重复事实读取的机制与边界](#wang-benchmark-boundaries)，知识变化后的组合再学习开销保留为[待审提案](#controlled-multihop)，不预设自然传播。追求最大跳数、“最少迭代次数”与少迭代蒸馏暂不单列新项目。模型宽度、迭代次数与知识量不因多跳自动扩成网格。暂缓线性注意力与Gated DeltaNet是针对当前任务的匹配判断，不是证明它们无效。原版bioS的100k正式矩阵、日期更新等旧草案没有自动进入新队列；已完成的bioS开发证据继续服务第一层。历史的“局部响应预测”实验作为历史证据保留，之后不沿着它另设预测任务。

## 8. 共同的评价与执行原则

主指标是端到端的任务表现，同时保留学习过程、全部低分与失败。单跳、组合、更新、表示格式与问法迁移分开评价。以全部测试题为主，满足条件的子集同时报告占比；原子事实掌握率不是所有探索都必须达到100%的统一门槛。

开发运行用来检查任务与操作是否有效，确认运行保持固定的规则。事实曝光次数、训练更新次数、推理时的执行深度和FLOPs分别记录；更多训练步数不自动等于充分优化。人工合成知识图、真实知识图和现成预训练模型的结果分开表述。

正式训练前按[实验协议](experimental-protocol.md)固定关键比较、数据、参数范围、预算与评价；已有的授权与预注册计划继续有效。使用语言模型专用的Docker、每个实验一个独立容器，默认用W&B记录，具体环境见[AGENTS](../AGENTS.md)。已完成的批次不因新的路线图而重新启动。
